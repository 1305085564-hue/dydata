# 懒加载索引规范

## 核心：文件级懒加载

把只在特定场景才用得上的规则，从 AGENTS.md 挪进独立文件，AGENTS.md 只留一行「场景 → 文件」。

命中场景就整读那个文件，没命中就完全不进上下文。省的是那些平时不该在场的内容。

## AGENTS.md 触发行写法

```
- 具体场景 → docs/xxx.md
```

场景必须具体到能判断命中与否（× 「遇到问题时」）。这一行不随文件内容变化，路径不变则永久有效。

## 特例：超长文件才加目录区

文件超过 150 行、且章节之间彼此独立时，才在开头加目录区，让 AI 只读需要的那一章。

150 行以下整读就是最省的，加目录区反而多一次判断和一次读取。

目录区格式：

- 第 1-10 行：只写目录条目，禁止正文；空行补满至第 10 行
- 第 11 行起：标题/简介，然后各章节正文（`##` 标题）
- 条目写 `- 章节名 → 约第X行`，章节名与正文 `##` 标题完全一致
- 行号允许 ±15 行漂移，AI 按行号定位后匹配标题校正
- 漂移超 15 行才回填目录行号，AGENTS.md 不动

## 新建步骤

1. `docs/` 下新建中文 `.md` 文件，正常写内容
2. 在 AGENTS.md「零、懒加载索引机制」加一行 `- 场景 → 路径`
3. 只有写到 150 行以上才补目录区
