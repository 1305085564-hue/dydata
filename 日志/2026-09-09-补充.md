# 2026-09-09 补充日志

### [An] 全站色彩基底与双向深度架构级重构技术细节记录

#### 1. 背景与根因剖析
- 用户阿禅指出系统当前页面色彩与实际 Claude 体验存在明显偏差：全站大底色泛黄沉重（原 `#FBF9F5` 色相达 40°，饱和度达 43%），中间大白卡死白塑料感生硬（`#FFFFFF` 与底色形成剧烈冷暖割裂）。
- 阿禅审阅指出关键本质：这不仅是一次调色，而是一次“图底深度关系的反转”（从单向浮纸到双向深度：展示下沉、交互上浮）。
- 原哲学立论存在“不追随友商”与改动叙事打架的矛盾，且哲学 §2 存在“进入 L2 纯白纸面”、“内部仍保持纯白”的旧教条。
- 原规范中 `#F5F3EE`（12 处）和 `#ECE7DE`（14 处）身兼多职，导致在下沉微气垫上 Hover 提亮反向失效、边线与填充耦合。

#### 2. 六大核心语义 Token 物理标准（全部锁死 H=60° 极低饱和冷暖平衡阶梯）
1. `canvas`: `#FCFCFB` (H:60°, S:14%, L:98.6%) —— 全站统一大背景，现代高档无酸艺术纸底。
2. `surface-sunken`: `#F1F1F0` (H:60°, S:3.4%, L:94.3%) —— 展示型卡片/数据面板/骨架屏下沉微气垫凹槽。
3. `surface-raised`: `#FFFFFF` (H:0°, S:0%, L:100%) —— 交互输入框/浮层，必须搭配 `--shadow-input` 与发丝边。
4. `hairline`: `#E2E2DF` (H:60°, S:4.9%, L:88.0%) —— 发丝边线、防串行线、极细分割线。
5. `state-hover` (双阶):
   - 桌面级/次级按钮 Hover: `#EBEBE9` (H:60°, S:4.8%, L:91.8%) —— 沉入微压感。与发丝线保持 3.8% 健康明度差，绝不溶边。
   - 卡片内行级 Hover: `#F7F7F6` (H:60°, S:5.9%, L:96.7%) —— 微提亮浮现感。
6. `state-selected`: `#E4E4E1` (H:60°, S:5.3%, L:88.8%) —— 下拉选中、Segmented 轨道填充，与边线彻底解耦。

#### 3. 具名 Token 正式注册
- 规范 §6.4 与 CSS 正式立项 `--shadow-input`：`0 0 0 1px rgba(28,25,23,0.08), 0 1px 2px 0 rgba(28,25,23,0.04);`，专属于输入框、选择器等交互表面的物理外压痕，解决纯白在 `#FCFCFB` 上 <2% 亮度差糊成一片的问题。
