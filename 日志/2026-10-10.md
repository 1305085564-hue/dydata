# 2026-10-10 日志

## [CC] 10:45 修复 AI 配置两个严重 bug 并推送上线

### 问题背景
阿禅新接入 DeepSeek 渠道和 flash 模型后遇到两个问题：
1. DeepSeek 模型在渠道视角能看到，但模型视角压根没有，业务调度也无法选择
2. 新接入渠道时，系统会同步已有模型并自动勾选，但这个逻辑有跨渠道污染 bug

### 根因分析
**问题 1**：新模型 `global_is_enabled=null` 导致聚合逻辑认为它"未启用"
- 位置：[src/lib/ai-config/availability.ts:187-194](src/lib/ai-config/availability.ts:187-194)
- 逻辑：`globalStateByModelId.get(model.model_id) ?? null` 当值为 `null` 时，前端判断 `=== true` 为 false，模型不显示

**问题 2**：新接入渠道时批量启用模型缺少 `key_id` 过滤，会污染其他渠道
- 位置：[src/lib/ai-config/batch-actions.ts:233-239](src/lib/ai-config/batch-actions.ts:233-239)
- 代码：`update({ is_enabled: true }).in("model_id", selectedModelIds)` 缺少 `.eq("key_id", keyId)`
- 后果：接入新渠道并勾选模型时，所有渠道的同名模型都被强制启用

### 修复方案
**修复 1**：改为"只要有任何渠道启用了这个模型，就在模型视角显示"
```typescript
// availability.ts:187-202
if (explicitState === null) {
  globalStateByModelId.set(model.model_id, models.some(
    (candidate) => candidate.model_id === model.model_id && candidate.is_enabled
  ));
}
```

**修复 2**：删除冗余且危险的二次 `update`
```typescript
// batch-actions.ts:233-240 整段注释掉
// insert 时已经正确设置了 is_enabled，不需要二次 update
```
