- 切换时重置表单状态

**状态**：
- selectedAccountId：当前选中账号

### 2.3 提交状态概览卡（SubmissionOverviewCard）
**功能**：
- 显示本月提交进度
- Mini 日历点阵
- 豁免状态提示

**数据**：
- monthSubmittedDates：本月已提交日期
- exemptionGrants：豁免授予记录

### 2.4 视频提交表单（VideoSubmitForm）
**核心功能**：

#### 模式流转
```
empty（空表单）
  ↓ 用户开始填写
editing（编辑中）
  ↓ 用户提交
submitting（提交中）
  ↓ API 成功
submitted（已提交）
  ↓ 用户点击编辑
editing（重新编辑）
```

#### 字段分组
1. **基础信息区**
   - 视频链接（必填，URL 验证）
   - 发布时间（日期选择器）
   - 操作人（仅管理员可改）

2. **指标分组区（Metrics）**
   - 播放类：播放量、完播率、平均播放时长
   - 互动类：点赞、评论、转发、收藏
   - 导粉类：涨粉数、涨粉率

3. **截图槽位区（Screenshots）**
   - 3 个槽位：封面/中段/结尾
   - 上传 → OCR 识别 → 自动填充指标
   - 支持手动覆盖 OCR 结果

4. **导粉话术采集区**
   - 话术方向选择
   - 话术文本输入
   - AI 标签（自动生成）

5. **备注区**
   - 多行文本域
   - 可选填写

#### 验证规则
- 视频链接必填
- 播放量 ≥ 0
- 百分比字段 0-100%
- 至少上传 1 张截图（可配置豁免）

#### 提交流程
1. 客户端验证 → 通过
2. 调用 `/api/dashboard/submit`
3. 后端保存 + AI 标签生成
4. 样本质量检查（异步）
5. 成功后刷新列表，表单重置

### 2.5 已提交数据展示区（SubmittedDataView）
**功能**：
- 显示今日已提交的数据
- 编辑按钮（切回 editing 模式）
- AI 标签展示
- 样本质量状态

### 2.6 历史记录抽屉（HistoryDrawer）
**功能**：
- 侧滑抽屉，显示历史记录
- 筛选：账号、月份
- 分页：默认 10 条，展开显示全部
- 编辑历史记录

**交互**：
- 点击"历史记录"按钮 → 抽屉从右侧滑入
- 点击编辑 → 弹出编辑表单 Dialog
- 编辑成功 → 刷新列表

### 2.7 豁免申请弹窗（ExemptionDialog）
**功能**：
- 选择豁免日期（多选）
- 填写豁免理由
- 提交申请 → 后台审核

**状态**：
- 待审核：黄色提示
- 已通过：绿色提示 + 日历上标记
- 已拒绝：红色提示 + 原因

### 3.3 API 调用封装
```typescript
// src/lib/api/dashboard.ts
export async function submitVideoReport(data: SubmitPayload) {
  const response = await fetch('/api/dashboard/submit', {
    method: 'POST',
    body: JSON.stringify(data),
  });
  return response.json();
}

export async function uploadScreenshot(file: File, role: string) {
  const formData = new FormData();
  formData.append('file', file);
  formData.append('role', role);
  const response = await fetch('/api/dashboard/screenshot', {
    method: 'POST',
    body: formData,
  });
  return response.json();
}
```

## 五、设计规范应用

### 5.1 色彩分配
- **行动色 #D97757**：仅用于主提交按钮
- **位置色 #43718E**：账号选中态底边
- **成功色 #6FAA7D**：已提交状态、日历点阵
- **警告色 #B98A54**：待审核、异常提示
- **错误色 #C0685C**：验证失败、API 错误

### 5.2 留白应用
- 头部 ↔ 账号选择器：40px（断层）
- 账号选择器 ↔ 概览卡：24px（呼吸）
- 概览卡 ↔ 表单：24px（呼吸）
- 表单字段组间：16px（紧凑）
- 标签 ↔ 输入框：8px（亲密）

### 5.3 字阶对比
- H1 页面标题：24px + 600
- H2 区域标题：18px + 600
- H3 卡片标题：16px + 500
- 正文输入：14px + 400
- 辅助文案：13px + 400
- 微缩标签：12px + 500

### 5.4 交互细节
- 按钮按压：`active:scale-[0.985]`
- Hover 提亮：`hover:bg-[#F5F3EE]`
- 聚焦光晕：`focus-visible:ring-1 ring-[#D97757]/25`
- 抽屉滑入：300ms cubic-bezier(0.16,1,0.3,1)
