# Claude 设计哲学

> 界面的最高境界：用户只记得事情做完了，不记得界面长什么样。
> 但写定的那一刻——手稿定稿，或判断被认领为结论——克制会让位，因为这一刻配得上被记住；装帧从来是对郑重的回应，不是表演。

---

## 1. 核心理念

### 1.1 人文出版物感 (Editorial Warmth)

界面应当像一本装帧精美、排版考究的现代杂志或思想读本，而不是冷冰冰的“软件控制台”。依靠**衬线标题 + 字阶对比 + 墨度梯次**建立层次。

- **双字协同，看时刻不看位置（大字有骨，小字有肉）**：过程中的内容——正文、表单、常规标题、交互控件、写作途中的草稿——坚守 **Sans 清爽黑体**；被郑重宣告为结论的内容——大标题、核心舱室定名、AI 结论、归档寄语——才启用 **Serif 衬线体**（小字不逞强，大字不因写得大就理所当然庄重）。
- **装帧细节**：引入卷首寄语 (Epigraph)、学者边注 (Marginalia) 与完卷微符 (✦)，赋予精装书般的阅读仪式感——但装帧回应的是内容的郑重程度，不是界面的排场：展示产品能力同样优先用真实代码与数据，不用营销插图，这是编辑感的骨气，不是另立一条。
- **暖墨线描意象**：仅在迎宾入场、深度洞察、安心归档等关键心理节点，采用极简暖墨单线手稿插图（Monoline Ink Sketch），拒绝花哨营销插画与冷冰控制台色块。

### 1.2 温润与单点聚光灯 (Warm Neutrals & Single Spotlight)

**温润是本质，不是策略**。深度思考需要一盏令人愿意久坐的灯，不是一间审讯室——极净暖白与暖陶土橙回应的是这个，基于现代高档无酸出版物与人眼长期阅读的物理光学，不因流行与营销调色板而动摇：

- **极净暖白专属 L1 背景**：`#FCFCFB` 极净温润暖白**只用于全站大背景（L1）**，承托全屏通透视窗，去除老旧发黄感，呈现通透出版物光感。进入 L2 容器层后，实行双向深度：数据展示模块采用浅砂微气垫 `#F1F1F0` 沉于纸下；交互输入框与主弹层浮起纯白 `#FFFFFF`；纸内内容（L3）统一透明 `bg-transparent`，坚守通透纯净。
- **单点聚光灯**：全屏 95% 保持克制的水墨中性，**同一视野内绝不允许出现两个以上饱和色焦点**。暖陶土橙只赋予全屏唯一的主行动 CTA——聚焦环、选中勾、引用线等非行动场景一律不得借用；其余状态色一律降级为低饱和中性阶与微透明底色。

### 1.3 安静搭档与主动退场 (Quiet Partnership & Graceful Exit)

安静，管的是界面机关，不管内容立场。界面不争宠、不聒噪：

- 操作成功若结果直接可见，就地更新，省略打扰性弹窗与 Toast；
- 加载完成立即撤出，不留多余动画；
- 辅助操作默认隐藏，Hover 时浮现。

但克制不等于失语：Claude 的判断、提醒、不同意见值得被听见——不必靠弹窗，走学者边注与卷首寄语这套"发声"语言即可。

## 2. 空间语法：桌子-纸-排版三层决策树

页面空间分三层，每层职责不同，遵循双向深度法则：

| 层级 | 比喻 | 物理心智与色值 | 正向排版与组织手段 |
|---|---|---|---|
| **L1 背景层** | 现代书案 | **`#FCFCFB` 极净暖白大底** | 全站统一视窗底层，通透纯净，去除黄旧感，提供现代高档出版物阅读底色 |
| **L2 容器层** | 气垫与触点 | **`#F1F1F0` 浅砂微气垫**（展示容器下沉） / **`#FFFFFF` 浮起纯白**（交互触点上浮，带 `shadow-input`） | 主工作区直接裸铺于桌面；展示型面板采用浅砂气垫凹槽；输入框与主操作浮现纯白 |
| **L3 内容层** | 纸上排版 | **`bg-transparent`（纸内天然透光）** | 展开批注、子列表、表单项直接在白纸上排版，依靠「留白呼吸」与「发丝线 `border-t border-[#E2E2DF]/50`」建立秩序 |

### 空间法则：双向深度纯排版

**容器物理律：承载 > 装饰**  
自检："删除后内容还有其他白底承载吗？"否 → 这是最后托盘，保留容器，仅去 `border` 改 `shadow-card-ring`。托盘内严禁套实底小盒，改用 `bg-transparent` + `border-t` 发丝线分隔。

进入 L2 容器层后（展示气垫 `#F1F1F0` 或交互纯白 `#FFFFFF`），载体内部严禁嵌套第二层底色块，统一使用以下三种手段建立层次：

1. **留白呼吸**：用 `py-4 px-6` 等间距建立层次
2. **发丝线分隔**：用 `border-t border-[#E2E2DF]/50` 建立秩序，消除泥黄边线
3. **透明触点**：输入框在暖白桌面上呈现自然通透的随手写批注感，配合微外压环与轻微阴影（`shadow-input`）确立物理边界，落笔聚焦时提亮，外部不加任何有色装饰外壳

**容器边界规则**：
- **主角容器**（主表格/主编辑器/主抽屉）：以独立白底主托盘（`bg-white` 配合 `shadow-card-ring`）端庄落座于桌面，依靠留白与微环确立地位，严禁使用显式粗灰边框，也严禁剥除托盘直接散落
- **配角容器**（便签/小面板/数据展示）：托盘内部所有子模块背景强制透明（`bg-transparent`），取消所有四周闭合框，纯靠单条横向发丝线与字阶墨度展开自然排版

**高密度降噪（杜绝电路板）**：多日期、多状态等复杂业务，不在卡片内平铺大量小操作按钮群；一律收敛为极简日历切片与微符印记（如 `✓/✗/✎`）；复杂动作在交互或浮层中发生，常态界面保持如纸张般安静。

### 表面呼吸节奏（严格区分宏观与微观）

**宏观章节呼吸（Page-level，仅用于整页大章节分隔）**：
- 整个页面的纵向大章节之间可以交替使用不同底色，营造装帧节奏
- 示例：极净暖白画布（主内容区） → 浅砂微气垫（统计面板） → 深炭产品面（重器展示） → 极净暖白画布（下一章节）

**微观组件通透（Component-level，单个卡片/弹窗/抽屉）**：
- 坚守双向图底克制，展示型微气垫面板（`#F1F1F0`）作为沉箱凹槽，其内部信息直接依赖留白与墨度排版
- 交互型输入框（`#FFFFFF`）必须配合微发丝（`#E2E2DF`）与轻阴影（`shadow-input`）独立浮现
- **判定规则**：展示型容器严禁内部再套白色实底小方块；杜绝容器层层套娃，内部不再使用任何额外非透明底色块

## 3. 排版与语言

### 3.1 留白四级语义

**留白梯次律：外 > 内**  
公式：`gap(父容器) > gap(子模块)`，违反即错。  
锚点：跨组断层 40px > 组呼吸 20px > 组内紧凑 12px > 标签亲密 8px。

- **断层 (Rift)**：章节与章节之间，表达”不同世界”；
- **呼吸 (Breath)**：标题与该区域内容之间，表达”统领与服从”；
- **紧凑 (Tight)**：同级内容项之间，表达”同伙关系”；
- **亲密 (Intimate)**：强关联元素之间（如头像与姓名），表达”一体关系”。

### 3.2 排版三条铁律

1. **外松内紧**：容器与外部边界的间距，必须大于容器内部元素的间距。
2. **标题头顶 > 脚下**：标题上方的留白必须大于下方（标题贴近其统领的内容以宣告主权）。
3. **跨级 > 同级**：章节间距(断层) > 标题-内容间距(呼吸) > 内容项间距(紧凑)。

## 4. 双文件修撰准则 (The Dual-File Canon)

设计文稿本身亦是出版物。修撰与演进《设计哲学》与《设计规范》时，文字即心智：

- **正向描摹，不立戒律**：美感来自对秩序的确信，而非对错误的围剿。只描摹事物应当如何舒展、空间应当如何透光，指引行者走向开阔，不以密集的禁止清单筑墙。
- **哲学立本，规范定度**：《哲学》述其物理本义与心智因由（何以如此），《规范》定其尺度、墨度与呼吸节拍（如何落地）；两卷相生相映，字句贵在洗练透彻，文约而事丰。
- **留白即敬意**：行文如排版，删去一切多余修饰；当一个通透的法则足以统摄全局，便不再累赘增设琐碎条款。
