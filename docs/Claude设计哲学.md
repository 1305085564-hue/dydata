# Claude 设计哲学

> 界面的最高境界：用户只记得事情做完了，不记得界面长什么样。

---

## 1. 核心理念

### 1.1 人文出版物感 (Editorial Warmth)

界面应当像一本装帧精美、排版考究的现代杂志或思想读本，而不是冷冰冰的“软件控制台”。依靠**衬线标题 + 字阶对比 + 墨度梯次**建立层次。

- **双字协同（大字有骨，小字有肉）**：页面大标题、核心主舱名牌、AI 洞察结论与归档/调养寄语使用 **Serif 衬线体**，赋予思想骨相与出版物庄重感；密集正文、小字说明、表单输入、常规卡片标题与交互控件坚守 **Sans 清爽黑体**，提供饱满耐看的阅读舒适度与扫视效率（小字不逞强，大字不平庸）。
- **装帧细节**：引入卷首寄语 (Epigraph)、学者边注 (Marginalia) 与完卷微符 (✦)，赋予界面精装书般的阅读仪式感。
- **暖墨线描意象**：仅在迎宾入场、深度洞察、安心归档等关键心理节点，采用极简暖墨单线手稿插图（Monoline Ink Sketch），拒绝花哨营销插画与冷冰控制台色块。

### 1.2 温润与单点聚光灯 (Warm Neutrals & Single Spotlight)

**温润是战略武器，不是装饰偏好**。象牙暖底 + 暖陶土橙是对 OpenAI 冷灰、Google 饱和蓝、Microsoft 企业青的**刻意反向定位**：

- **象牙暖底专属 L1 背景**：`#FBF9F5` 象牙暖底**只用于全站背景层（L1）**，作为统一画布承载一切容器。进入白纸（L2 卡片/弹窗/抽屉）后，纸面统一为纯白 `#FFFFFF`，纸内内容（L3）统一为透明 `bg-transparent`，不再使用任何暖色调底色。
- **单点聚光灯**：全屏 95% 保持克制的水墨中性，**同一视野内绝不允许出现两个以上饱和色焦点**。暖陶土橙只赋予全屏唯一的主行动 CTA，其余状态色一律降级为低饱和中性阶与微透明底色。

### 1.3 安静搭档与主动退场 (Quiet Partnership & Graceful Exit)

界面不争宠、不聒噪：

- 操作成功若结果直接可见，就地更新，省略打扰性弹窗与 Toast；
- 加载完成立即撤出，不留多余动画；
- 辅助操作默认隐藏，Hover 时浮现。

### 1.4 真实能力展示优先 (Authentic Product First)

展示产品能力时，优先用真实可运行的代码、数据、工具，而非抽象几何图或营销修饰。真实界面传递“我们对产品有信心”，营销插图传递“我们只会做 PPT”。

## 2. 空间语法：桌子-纸-排版三层决策树

页面空间分三层，每层职责不同，遵循单向透光法则：

| 层级 | 比喻 | 物理心智与色值 | 正向排版与组织手段 |
|---|---|---|---|
| **L1 背景层** | 桌子 | **`#FBF9F5` 象牙暖底** | 全站统一视窗底层，承载一切，提供温润出版物环境光 |
| **L2 容器层** | 纸 / 信笺 | **`#FFFFFF` 纯白纸面** + `shadow-card-ring` | 业务主卡片、弹窗面板、阅读抽屉，作为落座在桌上的纯白信笺 |
| **L3 内容层** | 纸上排版 | **`bg-transparent`（纸内天然透光）** | 展开批注、子列表、表单项直接在白纸上排版，依靠「留白呼吸」与「发丝线 `border-t border-[#ECE7DE]/50`」建立秩序 |

### 空间法则：纸内纯排版（单向透光）

**判定口诀：这个盒子删掉，内容会散吗？不会散就删掉盒子。**

进入 L2 纯白纸面（`#FFFFFF`）后，所有内容统一使用以下三种手段建立层次，不使用底色块或边框：

1. **留白呼吸**：用 `py-4 px-6` 等间距建立层次
2. **发丝线分隔**：用 `border-t border-[#ECE7DE]/50` 建立秩序
3. **透明触点**：输入框用 `bg-white/50 focus:bg-white`（纯白半透明），在白纸上呈现自然通透的随手写批注感

**容器边界规则**：
- **主角容器**（主表格/主编辑器）：直接裸铺在背景上，依靠充裕留白确立地位
- **配角容器**（便签/小面板）：用微气垫阴影（`shadow-card-ring`）或发丝线建立边界，但内部仍然保持纯白底色

**高密度降噪（杜绝电路板）**：多日期、多状态等复杂业务，不在卡片内平铺大量小操作按钮群；一律收敛为极简日历切片与微符印记（如 `✓/✗/✎`）；复杂动作在交互或浮层中发生，常态界面保持如纸张般安静。

### 表面呼吸节奏（严格区分宏观与微观）

**宏观章节呼吸（Page-level，仅用于整页大章节分隔）**：
- 整个页面的纵向大章节之间可以交替使用不同底色，营造装帧节奏
- 示例：象牙画布（主内容区） → 浅砂岩气垫（统计面板） → 深炭产品面（重器展示） → 象牙画布（下一章节）

**微观组件通透（Component-level，单个卡片/弹窗/抽屉）**：
- 卡片、弹窗、抽屉等局部微观阅读载体**内部不进行跨色呼吸**
- 始终坚守纯白纸面（`#FFFFFF`）+ 透明内容（`bg-transparent`）
- 用留白和发丝线建立层次，不用底色块分隔
- **判定规则**：如果这个区域有圆角阴影（是一张"纸"），内部就不再使用任何非白色底色

## 3. 排版与语言

### 3.1 留白四级语义

留白不是均匀分布的像素，而是表达信息关系的语法：

- **断层 (Rift)**：极大留白，章节与章节之间，表达“不同世界”；
- **呼吸 (Breath)**：大留白，标题与该区域内容之间，表达“统领与服从”；
- **紧凑 (Tight)**：中留白，同级内容项之间，表达“同伙关系”；
- **亲密 (Intimate)**：微留白，强关联元素之间（如头像与姓名），表达“一体关系”。

### 3.2 排版三条铁律

1. **外松内紧**：容器与外部边界的间距，必须大于容器内部元素的间距。
2. **标题头顶 > 脚下**：标题上方的留白必须大于下方（标题贴近其统领的内容以宣告主权）。
3. **跨级 > 同级**：章节间距(断层) > 标题-内容间距(呼吸) > 内容项间距(紧凑)。
