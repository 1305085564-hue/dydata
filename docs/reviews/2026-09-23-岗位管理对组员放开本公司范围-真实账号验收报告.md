## 缺陷清单

1. **[P3 · 体验，不阻塞] 组员点同事作品时的提示过弱**
   复现：组员 → 岗位管理 → 文案页签 → 展开任一同事业绩行 → 点作品标题。
   期望：说明"这块是视频复盘模块，你当前没有权限，可找组长/所有者开通"。
   实际：右上角 toast 只有「无权限」两个字，抽屉不出现，容易被理解成"页面坏了"。功能边界本身正确（同操作组长能正常打开）。
2. **[P3 · 待施工方确认] 文案页签里"0 作品同事"对组员不可见**
   复现：分别用 M1 与 A1 打开 2026-9 文案页签，行数 28 vs 40。
   性质：方向安全（组员是子集，不是放大），且差集里包含 M1 自己——组员必然看得见自己，所以这条差异**不是范围判定造成的**，更像"认证候选清单只对管理可见"的显示规则。
   为什么要确认：组员看不到"当月 0 产出"的同事，容易把它读成"这人没产出"，与放开范围的初衷（让组员看清公司分工全貌）有点偏。请确认是有意设计还是顺带漏了。
3. **[环境项，非本次改动] 生产库直连域名解析失败**，`psql` 只读对账不可用，本批次人数结论靠 UI + 接口证据。原先文档里写的直连方式需要更新（改走连接池域名）。
