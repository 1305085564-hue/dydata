## 三、问题清单（附复现）

### F1（低）骨架→内容有 ~6px 垂直位移，导航挂载另有 12px 跳动
- 复现：3000 或 3218 刷新 /dashboard，Slow 4G 更明显；页内采样器读骨架与真实 landmarks 的 y 差。
- 根因：`src/app/(app)/dashboard/loading.tsx` 副行 `h-6`（22.5px，根字号 15px）比真实副行（约 29px）矮 6px；导航挂载把 main  padding 从 83 改到 71.25。
- 建议：骨架副行改 `h-[29px]`、导航占位提前预留，使交换 dy=0。

### F2（中）临时免交/请假日：表单隐藏后下方一片空白，没有说明卡也没有提交入口
- 复现：隔离环境月历点 2026-10-27（有 waive grant）→ 页头"2026-10-27 免交"， notices 之下无任何内容（B-waive-day.png）。
- 根因：`video-submit-panel-v2.tsx:372-378` 计算了 `shouldShowBlockedStateCard` 但**全仓没有第二处引用**，即该卡从未接渲染；`shouldHideFormForExemption` 却已生效隐藏表单。
- 与交接不符：B5a 要求免交日表单仍可交。今日免交且未交的同一路径也会空白。
- 建议：二选一拍板——(a) 接上"这天免交/请假，不用交；仍要交就点这里"的说明卡并保留表单入口；(b) 明确免交日不允许补交并给出文案。推荐 (a)，与"只有一条路、不留下死路"的目标一致。

### F3（中）C1 记住上次署名/题材未生效
- 复现：隔离环境先交一条（署名文案=测试组长、题材=干货），丢弃草稿后今日"再交一条"或补交 11-13 → 更多行仍"文案、剪辑、运营都是我·复盘·出镜"（C1-remembered-clean.png）。服务端 RSC payload 中 `lastSubmissionPreferencesByAccount` 已含 `{scriptAuthorUserId: 8d171330…, topicTag: "干货"}`。
- 代码指针：`video-submit-form-v2.tsx:199,816`（createInitialMeta 传 prefs）、`video-submit-form-model.ts:96-135`、`video-submit-preferences.ts:26-53`、`video-submit-panel-v2.tsx:521`。链路看似接通，实际 meta 仍为默认值，怀疑 draft/restore 或 mode 判定（`mode === "editToday" ? null : prefs`）在"再交一条/补交"路径把 prefs 置空或被草稿覆盖；需 [CX] 定向排查。
- 建议：修复后补一条单测覆盖"今日已交→再交一条"与"补交新建"两条路径的 prefs 注入。

### F4（低）今日已交作品行把发布时间显示成原始 ISO 串
- 复现：今日交 ≥1 条后看已交列表行副行："2026-11-18T02:20:00+00:00 发布 · 播放 100 …"（B-today-raw-iso.png）。历史日列表同位置是格式化后的"2026-11-17 发布"。
- 根因：`src/components/video-submit/today-submitted-card.tsx:72` 直接插值 `report.published_at`；对照 `video-submit-panel-body.tsx:126` 用 `getPublishedDateKey(report)`（上海自然日）。
- 建议：统一走 `getPublishedDateKey`，顺带消除 UTC 串带来的"差一天"误读。

### F5（低）已识别态没有任何陶土橙实底焦点
- 复现：传图识别完成、仍有缺项时全页扫描 `rgb(217,119,87)` 实底 = 0（未传=1、文案已填=1）。
- 说明：灰态"还差"按钮是设计意图；若交接"恰好一处"是硬要求，则识别态缺一个橙色焦点。建议拍板：把规则改为"至多一处"，或识别完成后让"核对/继续"类主动作承接橙色。

### F6（低）请假审批中提示首屏不可见 + 提交成功弹窗不关闭
- 复现：提交两天请假 → 弹窗停留并显示"以下日期已有申请在审批中…"预检文案；关闭后页头 notices 默认只露第一条（驳回通知），"请假审批中 · …"藏在"展开全部 2 条提示"后（C4-two-day-hint.png 为展开后）。
- 建议：提交成功即关弹窗 +  toast；pending 提示在 notices 排序置顶或默认展开最新一条。

### F7（低）关键原因文案只放在 title 悬停里
- 复现：C3 播放量"请核对"格、C2 锁定的平均播放占比格，原因句（"点赞、评论、转发、收藏加起来比播放量还多"/"没绑定作品，这项改不了"）均为 `title` 属性，触屏与不悬停时看不到。
- 建议：格子下方加一行 12px 灰字原因（与"还差"同一来源），title 保留作补充。

### F15（严重，补记）修改模式「平均播放占比」回填放大 100 倍
- 本人实测（22:1x，DOM 读数，早于任何他人报告）：11-17 已交记录进入"修改 · 2026-11-17"后，`#metric-avg_play_ratio` 回填值为 **2302**，而该条识别/提交值为 **23.02**（合成完播截图标注 23.02%）。新建态与修改态相差 100 倍。
- 风险：修改态直接保存会把放大后的值再写库，污染统计口径。
- 代码指针（供 [CX] 排查，本人未改代码）：`src/app/(app)/dashboard/video-submit-form-model.ts` 编辑回填路径疑似对已转百分比的值再乘 100。
- 证据：会话 DOM 读数 `{ratio:{disabled:false,val:'2302'}}`（22:1x）；对照新建态识别值 23.02。截图 B-pastday-1117-edit.png 摄于切换瞬间为骨架，不作证据。
- 建议：修复回填换算并加单测（0.325 → 32.5 只转一次）；修复前禁止在修改态保存该字段。
