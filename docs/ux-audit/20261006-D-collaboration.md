# UX Audit 2026-10-06：D-collaboration（/admin/collaboration 数据管理）

**分片**：D-collaboration ｜ **目标**：http://localhost:3000（本地 dev，禁触生产）
**Persona**：双角色 —— 管理员"阿禅"（company_owner，月度盘产量）；普通组员"小夏"（member，想看自己被怎么统计）
**Browser**：Playwright（@playwright/test 1.62.1，headless chromium，1440×900，deviceScaleFactor 1）
**暗色模式**：按任务要求跳过（仅浅色）→ 未覆盖项
**方法**：ux-audit skill（线程遍历→要素穷举→场景组合→报告）
**说明**：dev 模式慢只记"dev-mode 观察"，不下性能定性；AI 接口限流 429 按环境现象不计 bug

## Summary

数据管理页整体质量高：四岗 Tab 口径脚注自洽、空态带解释、档案卡→作品诊断配对链路全通、组员只读边界用"隐藏写控件"而非"可见-失败"、三个破坏性操作（移入回收站/取消认证/删除小队）确认文案均具体披露副作用。最重的两个问题都在导航层：**浏览器返回键会把用户从组详情直接踢出模块回工作台**（history.replaceState 镜像方案的副作用），以及**文案认证一键即时生效无确认**（自动化探测时被真实误触一次，实证误点风险）。次重问题是组员"Second User 视角"在本页找不到自己。

## Findings

### Critical（阻断任务）

无。

### High（困惑/摩擦/信任受损）

- **H-1 浏览器返回键把用户踢出整个模块**：达人一组详情页按 Back，直接跳到 /dashboard（工作台），不是回到小组列表。月、页签、组上下文全部丢失。根因是页内全部状态切换（tab/view/groupId/person）用 `history.replaceState` 镜像地址栏，历史栈无中间态。页内虽有"全部小队"按钮，但用户最常用的返回手势被劫持成"离开模块"。
  - *Where*：/admin/collaboration?view=teams&groupId=… → Back
  - *Screenshot*：50-back-after-group.png
  - *Thread/scenario*：Wrong Turn Recovery
  - *Fix*：进组/开档案用 pushState 留栈（或在组详情放更显眼的返回并拦截 popstate）

- **H-2 全局"行动中枢"接口 504**：`GET /api/action-center/summary` 返回 504（console error + 网络双记录），一次会话捕获。顶栏待办/审批红点属全局壳层，失败只进 console、无界面降级。
  - *Where*：全局布局（本页任意路由加载时触发）
  - *Screenshot*：logs-t3v2-person.json（网络记录）
  - *备注*：dev 环境观察，可能为 dev 现象；建议复核生产同接口超时率
  - *Fix*：排查超时根因；给顶栏加失败降级态而非静默

### Medium（可工作但次优）

- **M-1 文案 Tab 徽标(5) vs 管理员视图约 30 行全员纵览**：徽标口径=有产出(2)+已认证(3)。组员视角表内恰好 5 行、自洽；管理员视角额外合并了全部未认证候选（"一张表纵览全员，随时可认证"），解释只存在于 Tab hover title 和表格底部脚注，且脚注未解释"为什么还有 25 个未认证的人"。首次进入会产生"徽标错了还是数据多了"的疑惑。
  - *Where*：文案 Tab（writer-tab.tsx 全员合并）
  - *Screenshot*：01-tab-writers.png
  - *Fix*：表上方主动说明或分区（产出/已认证/未认证候选），徽标旁加"全员名单"注记

- **M-2 文案认证一键即时生效、无确认**：点"未认证/待认证"按钮立即 POST 并刷新（影响绩效结算口径），取消才有完整确认弹层。审计自动化误点一次即真实写入（后已撤销还原）——实证误点风险。认证/取消对绩效方向相反，防护却不对称。
  - *Where*：staff-tab 认证状态列（writer-certification-button.tsx `handleClick`）
  - *Screenshot*：40-before-certify.png / 41-after-certify.png / 42-cancel-certify-dialog.png
  - *Fix*：认证也走确认弹层（复制"认证后开始计入绩效结算"），或至少加 2s 撤销 toast

- **M-3 组员在本页找不到自己**：组员（无产出、未认证）在文案 Tab 不出现（候选名单只对管理员加载），达人/运营/剪辑亦无其行。Second User 的核心问题"我被怎么统计"无法在本页得到回答，只能看到别人。
  - *Where*：member 会话，四 Tab 均无本人行
  - *Screenshot*：32-member-writers.png
  - *Fix*：组员视角固定插入本人行（即使全 0），或空态提示"你本月暂无协同记录，统计口径见脚注"

- **M-4 月份下界"上一月"静默无效**：2026-07 点击"上一月"，按钮外观正常可点，点击后 URL 与界面无变化、无提示；另一端"下一月"到当前月则完整禁用+tooltip「已是当前月份」。两端不一致。
  - *Where*：toolbar 翻月控制组，?year=2026&month=7
  - *Screenshot*：12-month-boundary-2026-07.png
  - *Fix*：复用下一月的禁用态模式，tooltip「统计起点 2026-07」

### Low（打磨）

- **L-1 认证与计费口径需悬停拼图**：未认证但有 3 条达标作品的何静，绩效条数列"—"（hover 才知"未认证不计费"），展开明细却逐篇"✓ 达标 (+1条)"，两处并读像矛盾。
- **L-2 宽表无横向滚动提示**：文案表 1960px，1440 视口下认证状态等右端关键列在视口外，无渐隐/箭头提示（可滚但不可见）。
- **L-3 档案卡加载期点击作品行疑似被吞**：dev 观察 2 次，打开瞬间点击无请求无反馈；稳定后重试正常。疑似加载期点击落在重挂节点。
- **L-4 React 挂载期状态更新告警**：console error 1 次（"state update on component that hasn't mounted…side-effect in render"），文案页签展开+排序序列中间歇出现。
- **L-5 认证变更后 60s 月度缓存跨会话滞后**：月度数据集 TTL 60s（collaboration-month-cache.ts）。实测：取消认证后新开会话最长 1 分钟仍显示旧认证态，管理员易误判"没保存成功"。
- **L-6 组员导航显示"管理中心"下拉**：内含"发布管理"项，组员点击后无跳转、无解释（死入口）。建议交 D-admin 分片复核该下拉对 member 的项级过滤。
- **L-7 "保存中"长停留无终态**：认证/取消后按钮停留"保存中"12-14s（dev-mode 观察；生产应更快），期间无进度与成功/失败终态，叠加 L-5 放大不确定感。
- **L-8 CSS preload 警告 ×2**：layout.css 预加载未使用（console warning，低价值登记）。

## Second User 越权反馈质量（专节）

**UI 层（9/9 通过）**：管理小队按钮隐藏 ✓、认证按钮隐藏（只读徽标）✓、诊断抽屉无"移入回收站" ✓、分配成员不可达 ✓——采用"隐藏而非可见-失败"的正确模式，正常路径组员触不到任何被拒弹错。

**API 层**：组员直连 `POST /api/admin/collaboration/writer-certification`（合法 UUID）→ **403 {"error":"无权限"}**，businessSucceeded:false，无写入。反馈是人话但极简（无"为什么/找谁开通"）；因 UI 已隐藏，属纵深防御而非用户会见的文案。

**数据边界**：组员可见全公司数据 = `resolveCollaborationScope` "组员放宽为本公司"的设计口径，非越权泄漏；组员与主人看到的达人/小组数字一致（对账通过）。

**死角（计 2 个 finding）**：
- M-3 组员找不到自己——"我被怎么统计"无法回答
- L-6 管理中心下拉死入口——点击无跳转无解释（建议 D-admin 复核项级过滤）

**降级体验**：假 groupId（组员会话）"该小队不存在或已被删除 · 已返回小队列表" ✓ 是全页最规范的权限/失效反馈样板。
