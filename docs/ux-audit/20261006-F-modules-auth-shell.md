**日期**:2026-10-06
**环境**:本地 dev http://localhost:3000(Next.js 16 dev;按分片纪律未访问生产 dydata.cc)

**双角色**:①对 DYData 一无所知的抖音团队新人(First Contact,未登录起步) ②公司管理员(组长 · 管理)管理成员与权限;另以组员、待审批两身份做 Second User

## 一、结论摘要

- 注册/登录/忘记密码页视觉一致、文案克制,成员管理四件套(列表/Inspector/归档 tab/审批)全部可用,归档-恢复的确认弹窗是全站少见的合格样例(点名成员+后果+必填原因+归档留痕)。
- 问题集中在三类:**提交失败无解释**(注册漏选团队静默清空全部字段)、**错误反馈带内部堆栈**(toast「查看详情」展开 webpack 堆栈)、**权限申请闭环断裂**(组员被告知"已通知公司管理方",管理员行动中心三处均无该申请)。
- 导航外壳三层边界在 1024 与 768 两个断点各塌一次:**768–1023 平板区间顶栏没有任何全局导航**(桌面菜单 `lg:flex`、移动 TabBar `md:hidden` 在该区间同时隐藏,也无汉堡按钮)。
- 键盘可达性:登录可全程键盘完成;**注册不可**——必填的团队下拉不在 Tab 序列,1×1 隐藏 input 反而成为焦点站。

**未测要素(原因)**:

- 归档列表 14 个预存成员的「恢复」逐个点击:数据纪律只允许对自建账号操作(自建账号已验证归档→恢复全闭环)。

- 权限申请的管理员处理动作(同意/拒绝):申请本身在管理员侧不可见(见 H4),无从处理。

## 三、发现(按严重度)

### Critical

无(未发现"任务完全无法完成"级缺陷;最接近的是 H1/H5——注册表单对特定输入路径实际不可完成,但换鼠标操作或补选团队后仍可完成,故定 High)。

### High

**H-1 注册表单:漏选团队时提交,已填字段全部静默清空,无任何错误提示**
- *Where*:/register(组织准入,`src/app/(auth)/register`)
- *复现*:填姓名+邮箱+密码 → 不动「申请归属团队」→ 点「提交加入申请」→ 停留 /register,三个字段全部被清空;无错误文案、无字段标红、无 toast。用户唯一线索是团队下拉的占位文案。
- *截图*:03-register-result.png
- *场景*:First Contact / Interrupted
- *Fix*:客户端提交前校验 teamId,行内标红「请选择您所属的目标团队」;校验失败不得清空已填字段。

**H-2 错误 toast 向用户暴露内部 webpack 堆栈,且同一错误重复两条**
- *Where*:/login(`login-form.tsx:115`)、/forgot-password(`forgot-password-form.tsx:56`)→ `feedback-toast.tsx:118/149 buildToastContent`
- *复现*:登录输错密码 → 右下角 toast 标题+正文重复「邮箱或密码不正确」两遍,「查看详情」展开 `Error at buildToastContent (webpack-internal:///./src/components/ui/feedback-toast.tsx:118:23)`;忘记密码在本地 SMTP 失败时同样暴露 `forgot-password-form.tsx:56` 堆栈,并伴随 `POST supabase/auth/v1/recover 500`。
- *截图*:04-login-wrong-password.png、05-forgot-registered-result.png
- *Fix*:生产移除「查看详情」堆栈(或仅 dev 显示);同因错误合并为一条 toast。

**H-3 768–1023px(平板区间)顶栏没有任何全局导航**
- *Where*:`desktop-nav-menu.tsx`(`hidden lg:flex`)+ `mobile-tab-bar.tsx`(`md:hidden`)+ `navigation-header.tsx`(右侧区 `hidden md:flex`)
- *复现*:1024px 登录态五组导航齐全;**1023px** 桌面菜单消失,顶栏仅剩 logo+行动中枢+用户弹层,无汉堡、无 TabBar;768px 同样。该区间用户无法前往任何页面,只能靠浏览器后退/手输 URL。
- *截图*:10-nav-1024-admin.png vs 10-nav-1023-admin-edge.png、10-nav-768-admin-edge.png
- *场景*:Thread 5(10-03 三层边界拆分的回归点)
- *Fix*:为 md–lg 接入汉堡菜单,或让 DesktopNavMenu 自 md 起以压缩形态渲染。

**H-4 权限申请闭环断裂:组员被告知「已通知公司管理方」,管理员侧三处均无此申请**
- *Where*:成员侧 `permission-guard.tsx` → `POST /api/permission-requests/apply`;管理员侧行动中枢(待审批申请/团队待办/已处理记录)
- *复现*:组员在 /admin/modules 拒绝页点「申请查看权限」→ 约 9 秒后 toast「已通知公司管理方,等待处理中。」;管理员(同团队、组长 · 管理、符合收件人条件)刷新后:铃铛徽标仍为 4,待审批申请=3(请假2/豁免1),团队待办=共 0 项(空态「当前没有需要跟进的权限申请」)。组员再次访问时按钮回到「申请查看权限」,无"已申请/审批中"留痕,会重复申请(API 有 warning 去重路径,但 UI 无状态)。
- *截图*:17-permission-request-applied.png、17-admin-team-todos.png
- *场景*:Thread 4 权限申请 / Second User
- *Fix*:权限申请落点接入行动中心「团队待办」或待审批申请列表;成员侧 Guard 页持久显示"已申请待处理"态。

**H-5 注册流程键盘不可完成:必填团队下拉不在 Tab 序列**
- *Where*:/register 团队选择器(Base UI Select)与隐藏 input `teamId`(1×1)
- *复现*:Tab 序列=姓名→邮箱→**1×1 隐藏 input(不可见焦点站)**→密码→返回登录;团队下拉触发按钮与「提交加入申请」按钮均被跳过。纯键盘用户无法选择团队,提交必然落入 H-1 的静默清空。
- *场景*:Keyboard Only(必做项)
- *Fix*:隐藏 input 设 `tabIndex={-1}`/`aria-hidden`;确保 Select.Trigger 可 Tab 聚焦并支持 Enter/Arrow 操作。

### Medium

**M-1 待审批用户直访 /admin/modules:URL 不变,内容静默换成"静候团队接引"仪表盘**
- *Where*:`admin/modules/page.tsx` 权限守卫(redirect("/admin"))

**M-2 全部 auth 表单用浏览器英文原生气泡校验**

**M-3 375px 下成员列表邮箱列逐字竖排,行高暴涨**
- *复现*:375 宽 /admin/modules → 表格不转卡片布局,邮箱"1305085564@qq.com"一字一行竖排,角色徽标「公司所有者」折行,行高约 3 倍于桌面;信息不可读。
- *截图*:10-nav-375-admin.png

**M-4 桌面「管理中心」下拉 Escape 关不掉**

**M-5 注册表单中途离开,数据无提示丢失**

**M-6 移动端可点击实体热区 <44px(批次清单)**

**M-7 注册成功落地体验断层:骨架屏无文案,审批前导航全空**

## 十、新人 2 分钟指南(First Contact 产出;缺口即 UX 缺口)

> **DYData 是什么**:给抖音内容团队用的数据工作台——每天的视频数据填报、团队选题防撞、作品数据异常复盘,都在这里做,替代微信表格收数。
>
> **新人加入**:打开 DYData 首页 → 点「申请加入团队」→ 填真实姓名、工作邮箱、选你的团队、设密码 → 提交。之后等团队管理员审批,审批通过前登录只能看到"静候团队接引"页面(可撤销申请)。
>
> **审批通过后**:登录进入工作台,顶部导航五组:工作台(每日立卷填报)、选题库(领选题防撞题)、视频复盘(作品复盘)、数据管理(协作数据)、管理中心(发布管理;组长还有成员管理)。
>
> **每天要做的事**:进工作台 → 按提示填当日作品数据(播放/点赞/完播等,可传截图)→ ⌘/Ctrl+Enter 提交立卷。
>
> **忘了密码**:登录页点「忘记密码」→ 输邮箱 → 去邮箱点重置链接。
