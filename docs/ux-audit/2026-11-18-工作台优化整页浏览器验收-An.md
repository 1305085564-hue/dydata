## 二、真实上传与识别耗时实测（B.1）

使用合成抖音样式双图（互动截图 + 完播截图）在 3218 端口 + 本地 Supabase 实测：

- **识别成功轮次**：申请凭证 `grant` 121ms / 118ms → 并行上传 `/api/submission-screenshots` 2414ms / 2410ms → OCR 识别 `/api/ocr-screenshot` **6464ms（互动）/ 7243ms（完播）**，端到端从上传开始到双图完成识别约 **9.7 秒**。
- **并发填写文案**：上传后 `+800ms` 识别进行中，文案框已可见且可编辑（`part-b/01-during-ocr.png`）；「一键粘贴」在授予剪贴板权限后正常填入。
- **全失败兜底轮次（B.5）**：首次上传时本地 AI 通道 500 超时（单接口 20955ms / 20677ms，端到端 **28.4 秒**），触发「这次没认出来，数字请手填」，12 个指标全部变成可编辑输入框并提示「数字请手填」（`part-b/02-after-ocr.png`）。

## 三、问题清单（附复现与截图）

### 1. 【严重】进入修改模式后，「平均播放占比」被放大 100 倍（32.5% → 3250）
- **复现**：新建提交时识别/填写 `平均播放占比` 为 `32.5`（数据库 `video_metrics_snapshots.avg_play_ratio` 正确存为 `0.325`）；提交后点「今天已交」卡片的 **修改**，或从 **历史记录** 点该条进入「修改 · 2026-11-18」，`平均播放占比（%）` 格内回填为 **`3250`**。若不手动改回直接保存，会再次除以 100 写脏数据。
- **根因**：`buildVideoSubmissionEditRefill` 已将小数转为百分比（`0.325 → 32.5`），但 `src/app/(app)/dashboard/video-submit-form-model.ts:332-334` 又额外乘了一次 `100`。
- **截图**：`part-b/10-b3-edit-mode.png`、`part-b/13-c2-opened-from-history.png`。

### 2. 【中等】临时免交日：表单被隐藏且下方一片空白，无法继续补交
- **复现**：在隔离库为测试组员设置 `2026-11-15` 临时免交（`exempt_type='temporary'`、`exemption_category='waive'`），月历切到 `2026-11-15`：页头显示 `2026-11-15 免交`，但下方完全空白，既无说明卡也无补交表单（永久免交账号在 3000 端口测得表单可正常显示）。
- **根因**：`src/app/(app)/dashboard/video-submit-panel-v2.tsx:372-378` 计算了 `shouldShowBlockedStateCard` 但未挂载渲染对应卡片，`shouldHideFormForExemption` 则直接隐藏了表单。
- **截图**：`part-b/14-b5-waive-day.png`（对比永久免交 `part-a/01-loaded-1440.png`）。

### 3. 【中等】375px 手机宽度下，步骤行被右侧手填入口挤压裁剪
- **复现**：将视口宽度设为 `375px` 打开 `/dashboard`，上传框下方的步骤条 `粘贴截图 → 核对识别结果 → 粘贴文案 → 提交`（271px）与右侧 `没有截图，直接手填 · 作品被限流或删了` 处于同一不换行 flex 行，步骤条被挤至 `99px` 并被 `overflow-hidden` 半字截断为 `粘贴截图 → 核对`。
- **截图**：`part-a/03-mobile-375.png`。

### 4. 【轻度】今日已交多条时，卡片副行直接显示原始 UTC ISO 时间
- **复现**：同一天提交 ≥2 条后，「今天已交」列表副行显示 `2026-11-18T11:20:00+00:00 发布 · 播放 2.6万 · 完播 21.8% · 已写入日报`（历史日列表同位置正确格式化为 `2026-11-05 发布`）。
- **截图**：`part-c/05-c4-2day-leave.png`。

### 5. 【轻度】C.2 / C.3 原因提示仅放在鼠标悬停 `title` 中，格子下方无可见文字
- **复现**：
  - C.2 打开未绑定作品的老日报（`2026-11-05`），`平均播放占比（%）` 已禁用，但「没绑定作品，这项改不了」仅存在于容器 `title` 属性。
  - C.3 将 `播放量` 改为 `100`（小于互动之和），`播放量` 立刻出现 `请核对` 且汇总行计数 +1，但「点赞、评论、转发、收藏加起来比播放量还多」也仅在容器 `title` 属性。
- **根因**：`src/components/submission/指标输入卡.tsx:90` 仅将 `hint` 传给外层 `div` 的 `title={hint}`。
- **截图**：`part-c/04-c2-unbound-old-report.png`、`part-b/03-c3-anomaly-before-submit.png`。

### 6. 【细节/文案差异】与交接单描述不一致之处
- **B.5 超过 72 小时**：按钮文字为 **`提交审批`**，点击后弹窗标题为 `申请补交历史数据`，并非按钮本身变成「申请补交」。
- **A.3 已识别但缺文案时**：底部按钮呈灰态「还差：文案」，全屏陶土橙实底为 `0` 个（未传图态 = 1、全部填完态 = 1）。
- **A.6 断网错误卡**：完整加载后断网打开历史记录/切月均显示「交过的记录没加载出来」+「重试」按钮（`part-a/09a-a6-history-offline.png`、`part-a/09b-a6-calendar-offline.png`），但附带了一行英文 `Failed to fetch`；若在页面 JS chunk 未加载完前断网触发加载会进入 `ChunkLoadError`（「工作台内容未能加载」）。
