# 平均播放占比评价标准接入

状态：已完成（2026-11-09）

## 目标与验收

在“管理中心 → 数据口径 → 评价标准”增加“平均播放占比”的可编辑好线、差线。保存后，视频复盘列表和详情使用公司配置与现有最低播放门槛显示相应表现颜色。原始快照值、内容质量评级、评级权重和达人/文案规则保持不变。

## 范围与排除

- 改评价设置类型、校验、旧设置兼容和表单。
- 在已有复盘列表及详情展示平均播放占比，并依同一公司标准着色。
- 快照值按比例存储（0–1），设置/展示均用百分数（0–100）；只在展示和比较时转换。
- 不改数据库表、不改上传/抓取逻辑、不将此项并入内容质量评级或更改任何权重。
- 互动/完播合并与权重方案另行沟通。

## 当前链路

- 设置读取/保存：`/admin/caliber` → `/api/admin/evaluation-standards` → `evaluation-standards-store.ts` → `system_settings.value.standards`。
- 复盘列表：`admin-content-page.ts` 已读取快照字段 `avg_play_ratio` → `buildProcessedContentRows` → `content-list-table.tsx`。
- 复盘详情：`admin-content-page.ts` 同样已读取 `avg_play_ratio` → `ContentDetailMetrics`。
- 原始类型已在 `src/types/index.ts` 定义；指标值是比例小数（如 0.5 = 50%），来源用于视频内容分段参考，不改变其生成逻辑。

## 兼容与错误行为

- 已保存的旧公司标准没有 `avgPlayRatio` 时只补齐该新增项默认值；其余既有字段仍完整校验，损坏配置继续明确报错，不静默恢复整份默认。
- 快照值为 null 时显示“—”并不判好坏；比例值 >1 或 <0 作为异常值标记，不参与评价；低于最低播放量时沿用样本不足降灰规则。
- 无需数据库迁移；新标准持久化到既有 `system_settings` JSON。
