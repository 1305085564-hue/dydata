# 选题库 V2 视觉交接提示词 · Antigravity

你负责本任务的前端审美与体验层交付，Codex 已完成 `/topics-v2` 的接口契约、状态判断和业务动作闭环。请把当前 V2 组件中的样式视为临时实现，重新完成视觉层、布局适配、动效节奏和交互手感；不要重做业务逻辑。当前所有 Tailwind `className`、展示层 wrapper、手写 SVG、Emoji、颜色、圆角、阴影和动效都不构成视觉基线，可以按你的方案全部替换。

## 目标

将 `/topics-v2` 打磨成适合团队每天快速扫描和决策的选题工作台：层级清楚、信息密度可控、主次明确、操作有即时触感，且与 DYData 现有冷灰纸感和暖橙行动色保持一致。

重点处理：

- 页面头部、今日聚焦、团队动态、选题大盘、横向对比之间的视觉层级和阅读节奏。
- 选题卡片的信息优先级：母题/分组、标题、Hook、真实数据、认领状态、主操作。
- 选题池工具栏在窄屏下的换行和操作顺序；网格/表格、搜索、母题筛选、排序、时间范围要容易发现和使用。
- 详情抽屉、创建弹窗、查重结果、替换弹窗的层级、滚动、关闭、焦点和错误反馈。
- loading、error、empty、success 四种状态的视觉区分，以及重试入口的可见性。
- 375px、768px、1280px 下的布局、文本换行、触控尺寸和横向溢出。

## 已观察的视觉问题

以下问题来自已有登录会话的只读浏览器回归，请优先处理并在截图中证明已改善：

- `768px` 顶部主导航与右侧用户区过于拥挤，存在视觉覆盖风险。
- `375px`、`768px` 的团队动态和最新成片辅助文本实际超出父容器边界后被裁切；页面总 `scrollWidth` 虽未扩展，但内容已经不可完整阅读。
- 详情抽屉顶部关闭按钮位于固定导航覆盖层下方，当前鼠标点击会被导航拦截；需要调整抽屉层级或顶部安全间距，同时保持键盘和触摸可关闭。

## 可修改范围

优先只修改：

- `src/components/topics-v2/*.tsx`
- `src/app/(app)/topics-v2/page.tsx` 中页面展示层的 metadata 或包裹结构
- 为 V2 新增的局部样式文件（如确有必要）

允许重排 JSX 的展示结构，但必须保持现有组件的 props、回调、数据字段和状态分支语义不变。可以调整 `className`、展示顺序、局部 presentational wrapper、图标和动画；复杂视觉变化应集中在 V2 局部，不要改全站 UI 组件。

## 必须保留的功能契约

- `myClaim` 是当前用户认领状态的唯一来源；不得从团队认领数组猜测当前用户。
- `candidate` 和 `scripting` 必须视觉上明确区分；候选上限只计算 `candidate`。
- 未认领、candidate、scripting 三态动作必须保持现有允许范围：未认领只能认领，candidate 可开始写脚本或放回，scripting 显示脚本中并可放回或查看完整详情。
- 替换弹窗只显示 candidate，scripting 不得出现在替换列表中；替换失败时弹窗保持打开并显示错误。
- 选题池的服务端搜索、母题多选、排序、时间范围、视图切换和分页请求不能改变参数语义。
- 今日聚焦理由、团队最新认领、最新成片、真实播放量、横向对比和详情深链必须继续展示真实接口数据。
- GET 失败必须保留错误态和重试入口，不能改成“暂无数据”；不能新增 fake/default 业务数据。
- 不新增 AI 推荐前台入口，不替换 `/topics` V1，不改完整详情页的业务职责。

## 视觉执行要求

- 先读取 `docs/美学规范.md`，沿用项目已有颜色、字体、间距、圆角和层级，不引入另一套品牌语言。
- 这是工作台，不是营销落地页：避免大面积装饰、渐变背景、堆叠卡片和过大的标题；让用户能快速比较选题。
- 每屏最多一个主 CTA，次要操作用克制的次级按钮或图标按钮；图标按钮必须有可访问名称，陌生图标提供 tooltip。
- 交互控件保留 hover、focus-visible、active 和 disabled 状态；按压反馈不能改变布局尺寸。
- 动效只服务于加载、状态切换、抽屉/弹窗进出和 hover 触感；提供 `prefers-reduced-motion` 降级，不使用会干扰扫描的循环动效。
- 文本在所有视口内完整落位，不允许标题、Hook、按钮、数据标签互相遮挡或撑破父容器。
- 表格在移动端应有明确的可读方案（合理折叠、横向滚动或切换到卡片），不能让关键操作被裁切。
- 不加载外部字体、图片或第三方视觉依赖；优先使用项目已有的 `lucide-react` 图标和 UI 组件能力。
