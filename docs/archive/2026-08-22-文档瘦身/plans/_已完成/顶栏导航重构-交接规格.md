# 顶栏导航重构 · 交接规格

> 执行者：Antigravity
> 约束：美学规范 docs/美学规范.md

---

## 目标
顶栏一级入口从 8 个精简到 5 个，去掉齿轮按钮，所有页面通过分组下拉直达。

## 新结构

```
Logo | 工作台 | 选题库 | 内容中心▾ | 数据中心▾ | 管理中心▾ | ... 右侧功能区
```

### 分组明细

| 一级 | 二级 | 路径 |
|---|---|---|
| 工作台 | — | /dashboard |
| 选题库 | — | /topics |
| 内容中心 | 文案助手 | /content-tools/rewrite |
|  | 视频复盘 | /admin/content |
|  | 素材库 | /admin/videos |
|  | 发布管理 | /admin/fulfillment |
| 数据中心 | 数据分析 | /growth |
|  | 经营分析 | /admin/analytics |
| 管理中心 | 成员管理 | /admin/modules |
|  | 系统维护 | /admin/settings |
|  | AI 配置 | /admin/ai-config |

### 权限规则
- 二级项按现有权限控制，无权限则不显示
- 如果某个一级下所有二级都无权限，该一级也不显示

## 要删的东西

1. **齿轮按钮**（wrench dropdown）：整个移除，包括 wrenchOpen 状态、相关 useEffect、dropdown 面板
2. **系统维护页面里的三级跳转**：页面内如果还有跳转到成员管理/AI 配置的链接，删掉（已经从顶栏直达，不需要嵌套）
3. `nav-bar-items.ts` 里旧的条件判断逻辑，按新分组重写

## 要改的文件

| 文件 | 改动 |
|---|---|
| `src/components/nav-bar-items.ts` | 按新分组重写 getNavItems()，返回分组结构 |
| `src/components/nav-bar-client.tsx` | 一级渲染改为支持下拉；移除齿轮相关代码 |
| 系统维护页面（如有三级链接） | 删除冗余跳转 |

## 交互设计
由 Antigravity 自行决定：
- 下拉触发方式（hover / click）
- 下拉面板视觉样式（参考美学规范的浮层规则：白底、zinc-200 边框、8px 圆角、shadow-md）
- 选中态指示（文字色+字重，或底线）
- 移动端适配方案

## 注意事项
- 右侧功能区（工作账号切换、通知铃铛、头像）保持不动
- 美学规范是设计宪法，有歧义时用设计目标反推答案
