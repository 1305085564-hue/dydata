# 视频复盘 · 归因舱 A+ 前端规格（Master-Detail 沉浸作战舱）

> 复杂度：**较难**（结构 + 交互改造，非纯换皮：抽 lib、加内嵌导航、响应式防挤爆）
> 执行：Antigravity（审美与实现放开做）｜验收：Kiro（逐条卡）
> 交付：只改本地，不 push；改完贴自检结果 + 改动清单 + 关键截图。

## 一、背景与目标

当前「视频复盘 · 作战舱」减法后变成两块**互斥页面**：
- 屏1「今日待盘队列」：通栏单列大卡片，桌面宽屏 85% 留白，一屏仅 5-7 条，60 条要滚很久 + 「加载更多」。
- 屏2「归因舱」：点「复盘」后队列被整个卸载，返回时滚动位置和选中项全部丢失。

**目标形态 = A+（改良双栏 Master-Detail）**：把「挑视频」并进「归因舱」，消灭页面跳转、留白、无限翻页，实现「挑最差 → 看归因 → 复制发飞书 → 下一条」的连续作战心流。

**A+ 与原版方向 A 的关键差异（防翻车）**：归因舱本身已是两栏（数据 50% ｜ 文案 50%）。若在其左侧再挂一条**常驻宽队列**，1280 笔记本屏会变成「队列 + 数据 + 文案」三栏并排、每栏约 400px，留存漏斗/指标对比/三段台词全被压扁——从「留白」翻车成「挤爆」。所以队列必须做成**又窄又能收起的细轨**：平时收起、归因舱满宽舒展；要挑稿时才滑出，选完自动收回。

## 三、A+ 交互规格（三态 + 快捷键）

### 状态1 · 队列收起（默认盘稿态）
- 归因舱两栏满宽舒展（数据 50% ｜ 文案 50%），左侧仅留一条**细轨**（当前条序号/标题 + 展开把手），或顶部一排可点的进度圆点。
- 右上角常驻「下一条 (J / →)」按钮：点击 → 按当前排序取队列中下一条未盘的，`onVideoSelect(nextId)` 原地刷新，**不跳页、不丢滚动**。

### 状态2 · 队列展开（挑稿那一下）
- 左侧滑出**窄队列抽屉**（宽 300-340px，独立滚动），复用现有卡片信息但**压缩到 ≤72px/条**：序号 + 责任人·账号 + 异常指标 pill（≤2 个）+ 草稿状态 + 权重。
- 顶部保留三种排序（按最差/按人/按时间）+ 态势微仪表（今日待盘总数、删稿/限流/腰斩分布）。
- 点某条 → 右侧归因舱切换该视频，抽屉自动收回（或保持展开由动画决定，审美自定，但选中项必须高亮）。

### 状态3 · 队列清空
- 回落到现有「今日待复盘已清完」空态，不崩、不白屏。

### 快捷键
- `J` / `→`：下一条；`K` / `←`：上一条；`Esc`：收起抽屉 / 返回列表。
- 快捷键不得与输入框冲突（focus 在 textarea 时禁用）。

## 四、响应式硬规（防挤爆，验收重点）

| 断点 | 队列 | 归因舱 |
|---|---|---|
| **≥1536px (2xl)** | 可**常驻停靠**为左侧细栏（≤340px） | 两栏舒展，剩余宽度自适应 |
| **1024-1535px (lg/xl)** | **默认收起**，展开时以**浮层抽屉**盖在归因舱上（不挤占两栏宽度） | 始终满宽两栏 |
| **<1024px (< lg)** | 抽屉全屏或大半屏浮层 | 归因舱两栏塌成单列（沿用现有 `grid-cols-1`） |

**红线：任何断点下都不得出现「队列 + 数据 + 文案」三栏并排硬挤。** 队列要么停靠（仅 ≥1536）、要么浮层抽屉，二选一。

## 五、逻辑红线（只动皮不动骨）

1. **排序算法不许改**：`getPriorityScore` / `queueRows` 的排序权重与过滤逻辑保持一致。若为在归因舱内复用队列而抽取公共函数（建议抽成 `buildReviewQueue`），**抽取后必须有测试证明顺序与抽取前完全一致**。
2. **归因算法零改动**：`content-attribution.ts` / `content-attribution-map.ts` 一行都不许动。
3. **下发止损红线保持**：不得恢复发送/催读/已读的任何 UI 与调用；不新增任何写库动作。
4. **前后端对账**：不新增后端不认识的字段。"下一条"用现成 `anomalyVideos` + `onVideoSelect`，不新增接口。
5. **复制建议**仍是唯一暖橙 CTA `#D97757`；其余语义色（删稿/限流红、腰斩橙黄、正常绿）严格隔离，不得挪用为主行动色。

## 六、美学约束

- 冷灰纸感基底、以留白与色差代替硬边框；沿用现有 `#C9604D`/`#D99E55`/`#6FAA7D` 语义色。
- 队列高密度但不拥挤：≤72px/条，一屏（收起态）能扫 12+ 条。
- 抽屉滑入/滑出用现有 motion 风格，切换视频用轻过渡，不闪白。
