# 视频复盘减法 · Antigravity 前端规格

> **复杂度：较难（视觉重构不难，难在"只准动皮、不准动骨"的边界克制）**
>
> 你只管美学与交互手感——视觉层级、布局、动效节奏、响应式、冷灰纸感。**所有数据逻辑、接口调用、状态机、字段一律不许碰**（那是 Codex 的活）。产品背景见同目录《2026-08-09-视频复盘-减法定稿.md》，视觉遵《docs/美学规范.md》。归因舱主体已由 7-18 那轮建成，本轮是**收缩 + 打磨**，不是从零重写。

---

## 0. 这轮到底在干嘛（一句话）

视频复盘和素材库定位撞车 + 视觉嘈杂。这轮把复盘台**瘦成作战舱**（删掉那张跟素材库重复的大宽表）、把嘈杂的橙色和厚重灰盒收干净、把死掉的下发闭环入口藏起来。**核心链路（归因、复测）已经能跑，别推倒重来，只做减法和打磨。**

---

## 1. 五项改动（按交付顺序，重要性降序）

### 改动一 · 复盘台首屏：删大宽表，换诊断队列

- **现状**：`/admin/content` 首屏是一张 12 列大宽表，跟素材库那张几乎一样，像资产列表不像作战舱。
- **改成**：首屏 = "今日待盘队列"卡片流 + 顶栏一条细异常提醒。
  - 队列卡片：每张露出「成员·账号 + 被标红的异常指标（如 `5s完播22%🔴 均播18%🔴`）+ [复盘] 按钮」，点开进归因舱。
  - 支持"按最差排 / 按人 / 按时间"切换（切换只调已有接口的排序参数，**排序逻辑找 Codex，你只做切换器的样子和手感**）。
  - 顶栏异常提醒：一条窄条"今日异常 N 条：X 删稿·Y 腰斩 [直接去盘]"，低调不抢主视觉。
- **禁区**：不许自己造筛选/排序的数据处理逻辑；列表数据、异常判定都来自现有接口，你只负责"长什么样"。

### 改动二 · 纯化行动色：橙色只留给"确认下发"

- **对照《美学规范》**：暖橙 `#D97757` 是全站**唯一行动色**，只给"去操作"的主 CTA。
- **当前违规（审计已列）**：排行榜第1名序号、部分 Tag 边框、选中 Tab、台词高亮全在用橙色，导致真正的"确认并下发"按钮站不出来。
- **改成**：把上述装饰性橙色全部换掉（序号用中性灰、Tab 选中用底色/下划线而非橙、台词高亮换成低饱和的中性强调）；**橙色只保留在主 CTA**。
- **禁区**：只改 className / 样式变量，不动这些元素背后的任何点击行为和数据。

### 改动三 · 下发闭环入口"止损隐藏"（不是删）

- **背景**：下发反馈全站历史仅 3 次、近 60 天 0 次，工作流没把它当常规步骤。决定**隐藏日常入口、保留历史数据**，等飞书能力起来再正式退。
- **改成**：
  - 归因舱右屏"反馈下发"表单**从默认展开降为收起/次要入口**（如折叠区"如需网站内留档可展开"）。
  - 顶栏"待确认/已确认未发/已下发/员工已读"那排工作流计数**撤下**（数据已死，别占视觉）。
  - 新增主推路径：**"生成改进建议 → 一键复制"**，让管理者把建议复制去飞书发。复制的内容来自现有归因结论 + 建议，**你只做"复制"按钮和 toast，别自己拼文案逻辑**。
- **禁区**：**绝对不许删表单组件、不许删下发接口调用、不许改 `content-review-readiness.ts` 状态机**。只是视觉降级 + 藏入口。删/改逻辑是 Codex 的活，你动了就是越界。

### 改动四 · 分段台词：三段式黄金结构

- **现状**：台词按换行生硬切成几十行文字瀑布，看不出结构。
- **改成**：按短视频黄金结构做视觉分块——**前3s钩子 / 中段承接 / 尾部号召**三段，段与段之间用留白和轻标题分隔。归因带点红项跳转时，高亮落到对应段。
- **禁区**：分几段、每段是哪几句由 `locate.segment_hint`（opening/middle/ending）映射，**这个映射是 Codex 给的字段，你按字段渲染，不许自己写切分算法**。

### 改动五 · 冷灰纸感：去厚重灰盒

- **现状**：外层 `bg-gradient-to-b from-zinc-50/80` 套 Table 套 Tooltip+Badge+自定义底色，层层嵌套显笨重。
- **改成**：按《美学规范》"以留白与色差代替硬边框"，减一层嵌套背景、弱化描边、靠间距分组，做出轻盈的冷灰纸感。
- **禁区**：纯样式，不动结构里的任何数据绑定。

## 2. AI 降级（贯穿全程的一条纪律）

- 归因舱的"AI 辅助分析 / 诊断思路 / 批量生成草稿"**收成一个默认折叠的"AI 参考"入口**，不挡主流程。
- 文案必须体现"仅辅助、你来定"，**绝不写成"AI 已诊断/AI 判定"**。
- AI 挂了只 toast 提示，不影响人工顺数据归因。
- **禁区**：不许让 AI 结果预填进任何结论位；归因结论带永远是 Codex 死规则算的，AI 只在那个折叠入口里。

---

## 3. 素材库：降为二级入口（轻改）

- 素材库 `/admin/videos` **保持独立、功能全留**（补录/评级/标签/回收站都不动），只在导航层从主入口降为二级入口。
- **禁区**：不碰素材库页面内部任何功能和逻辑，只动它在导航里的层级/位置。

---

## 4. 死守的红线（越过任何一条都算不合格）

1. **只碰样式/布局/动效/文案，不碰数据逻辑、接口、状态机、字段。** 遇到"这块逻辑不对"→ 停手，交 Codex，别自己改。
2. **不新增、不改、不删任何接口调用和字段名**。只依赖 Codex 已提供的字段渲染。
3. **不推倒已建成的归因舱重写**。这轮是收缩打磨，复用现有能跑的部分。
4. **下发表单/状态机只做视觉降级，绝不删除**。
5. 红=异常/差、绿=达标/好（数据语义）；红涨绿跌只用于行情，不用在这里。
6. 兜底态必须做全：`snapshot_ready:false` 显示"归因待数据齐"不空白；缺指标显示"缺数据"不显示0；队列清空显示"今日待复盘已清完"。
