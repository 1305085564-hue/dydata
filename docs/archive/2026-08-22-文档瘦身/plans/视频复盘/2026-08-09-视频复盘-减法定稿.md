# 视频复盘 减法定稿（2026-08-09）

> 本文是「视频复盘 × 素材库 减法」的决策地基与续工锚点。逻辑分工见同目录《…-减法-Codex后端规格》，美学分工见《…-减法-Antigravity前端规格》。
> 产品内核仍以 2026-07-18《视频复盘重构-产品设计总纲》为准（归因 80%、AI 只辅助不决策、下发是尾巴）。归因舱（`content-diagnosis-workbench`）已建成，本轮**只做减法与定位澄清，不推翻内核**。

## 一、一句话定位

- **视频复盘（`/admin/content`）= 高频作战舱**：今天该盘哪几条 → 点开归因舱诊断 → 生成建议复制走 → 自动下一条。**首屏不再放大宽表。**
- **素材库（`/admin/videos`）= 低频账本**：全量视频大表 + 检索 / 打标 / 评级 / 24h 补录 / 回收站。**全站唯一的视频大表在这里。保持独立，仅降为二级入口，不合并、不删。**

## 二、决策依据（数据说话，非拍脑袋）

- **复盘台是真入口**：最近约 4 周 148 次访问，每周都有，明显高于素材库 → 保留。
- **素材库低频但有人用**：60 天 32 次（约复盘台 22%），每周仍有人进 → 低频是它「沉淀、低频查完整数据」的设计本分，不是病 → 保留独立、只降二级。
- **下发闭环形同虚设**：查业务表 `content_feedback_cards`（非埋点），上线以来仅 **3 次下发、最近一次 2026-05-27、近 60 天挂零**；且 3 次全部已读，说明功能没坏，是工作流没把它当常规步骤 → **止损，不删**。

## 三、删 / 退 / 留（三清单）

### 删（复盘台内，直接删或下线）

- 复盘台首屏那张**与素材库重复的大宽表** + 8 维重筛选器 → 删，换「今日待盘队列」
- **双复盘入口**里的抽屉 `content-detail-dialog` → 下线，统一走全屏归因舱（Codex 裁决）
- **推流峰值 / 峰值后走势 / 流量承接** 那套人工下拉 → 砍（7-18 已定，本轮执行）
- 归因舱内散落的多个 AI 按钮 → 收进一个默认折叠的「AI 参考」

### 退（止损：隐藏入口，但保留数据与接口）

- 站内下发链路：确认并下发、`sent/viewed` 状态机、员工已读追踪、采纳 / 申诉回传、站内催办 → **隐藏日常入口**
- `content_feedback_cards` 表、`PATCH` 接口、历史数据 → **全部保留不动**（继续用于存草稿 / 建议记录 / 复测对照）
- 沟通降级方案：网站生成建议 + 一键复制，人工粘飞书；等飞书能精准到人 + 已读，再正式把沟通搬过去

### 留（复盘台算力活，本轮重点打磨手感而非新增）

- 死规则归因诊断（比自己 / 团队 / 高手 / 某人 四参照）
- 台词分段 + 点句引用（本轮做三段式结构化）
- 留存曲线漏斗
- 生成改进建议（死规则 + 模板，供复制到飞书）
- 复测对照（读上次建议记录）
- 经验沉淀标记
- 素材库全套能力（补录 / 评级 / 打标 / 回收站 / 完整快照）原样保留

## 四、两条铁律

- **AI 全程可选、核心链路不依赖 AI、现阶段不优化 AI**：归因结论与改进建议都由**死规则 + 模板**产出；AI 收成可折叠的「AI 参考」，不预填、不下结论，文案必须写「仅辅助、你来定」。没有 AI，链路照跑通。
- **埋点 0 ≠ 没人用**：下发闭环敢定生死，是因为查的是业务表 `content_feedback_cards`（真实 `sent_at`），不是埋点。凡只有埋点 0、而代码未必上报的功能（如履约状态），不据此下判。

## 五、分工 · 验收 · 本轮不碰

- **分工**：Codex 管逻辑（裁决双入口 / 删大宽表 / 下发止损 / 走势下线 / 素材库降级 / 建议文本 helper）；Antigravity 管美学（归因舱手感重构 / 队列首屏 / 三段式台词 / 纯化行动色 / 兜底态）；CC 统筹 + 验收，**前端严卡逻辑**（防伪字段、缺数据显示、红绿语义、locate 联动、无站内下发 UI）。
- **本轮不碰**：履约状态（埋点 1 次 / 1 人，不在复盘 / 素材库范围，另开一轮核实）；content 相关死接口清理（属另一条死代码清理线，见《2026-08-08-删除安全扫描》，不混做以免验收边界模糊）。
- **提交纪律**：三份文档只 `add` 自身、**禁 `add .`、不 push**，待阿禅确认后分派 Codex / Antigravity；Antigravity 改动必须阿禅确认后才能 push。
