## 2. 四个守卫与必要修订

| 项目 | 实测结果 | 保持的业务行为 |
|---|---|---|
| 提醒计数 | 本人和受控service调用成功；其他员工冒传本人ID、归档者调用明确42501 | 7天日期边界和计数不变；边界夹具包含区间前一天、起始边界、当日、次日，返回2 |
| 入团审批 | 管理员/负责人可批准或拒绝首次加入的在职普通成员；审批记录及团队归属正确，重复审批失败 | 拒绝普通员工审批、跨团队、自审、归档审批人/申请人、已归属同队/外队、管理员申请人、NULL/无效动作、非pending；负例前后申请与资料逐字段相同 |
| AI生命周期 | 在职负责人、受控service归档/恢复成功；普通员工、管理员、归档负责人被拒；未知/NULL功能和动作、空名称失败且零写入 | 绑定和旧配置各留快照，重复归档不重复快照；恢复原启用状态（false/true分别验证）；并发持锁期间调用等待1490ms（首轮完整通过样本），证明原事务锁仍生效 |

本轮先复现4个修复前失败：他人提醒计数泄露、归档旧owner仍有违规权限、合法管理员因旧JSON缺失被拒、归档owner仍能归档AI。修复后对应正反例通过；未将修复前失败改写成功。

## 3. 依赖、权限和触发器

- 31项owner仍为postgres，均为SECURITY DEFINER；路径固定 `pg_catalog, public, pg_temp`。PUBLIC和anon执行权为零；authenticated仅R11，service为R+S26，O5仅owner/内部调用。函数签名和返回结构不变。
- 匿名真实网关请求：**29个普通函数均401/42501**；2个触发器函数返回404/PGRST202（网关不公开普通调用入口），另以目录确认anon/authenticated/service均无EXECUTE。**这2个404不算权限拒绝证据。** 普通员工调用15个S函数均403/42501。
- R11合法入口均有真实登录调用：提醒本人、案例库4项、发布scope/队列2项、排行榜、违规helper、AI生命周期、入团审核。案例库/发布队列使用自建稀疏数据，仅证明入口可调用，不冒充完整历史业务验收。
- `has_violation_permission`共13条策略，涉及7表：`script_usage_records`、`violation_events`、`weekly_decisions`、`violation_case_reason_tags`、`violation_reason_tags`、`script_purposes`、`violation_cases`。逐表管理员SELECT/UPDATE/DELETE正常，归档管理员写入被拒或影响0行且全库摘要未变；合法usage插入另有真实员工验证。
- 聚合触发链：员工插入100/10与10/5两条usage→110浏览/15关注/2条/15÷110；管理员改值→210/15；迁移case→新旧两个case各自重算；删除末行→0/0/0，比例NULL。直接API撤权后触发器仍正常。
- 消息触发链：员工插入消息，所属会话 `last_message_at` 与消息时间一致，`updated_at`更新；API角色无需直接调用触发器函数。
- 全部public/private函数体扫描只发现 `update_script_usage_aggregate→recalculate_script_usage_aggregate`；相关表触发器2条。`get_today_submission_status/validate_invite_code`无库内函数体/策略/触发调用，也无主线src或迁移分支src/scripts的现役调用；历史migration/测试中名称保留不等于现役入口。

## 4. 事务与回滚实测

| 场景 | 结果 |
|---|---|
| 正向末尾注入除零 | psql非零退出；31项元数据和99表数据摘要均恢复原样 |
| 原定义/配置发生漂移 | 55000硬拒，整笔未应用；不更新审阅基线接受漂移 |
| 正常提交后回滚 | 原定义、owner、ACL原始数组顺序、路径和完整依赖摘要精确相同；业务数据摘要不变 |
| 回滚后再次正向、再次回滚 | 均成功，最终回到原始31项元数据 |
| 独立注入语句超时 | 50ms超时取消，整笔恢复原样 |
| 应用后出现额外配置变更，再用旧回滚包 | 漂移硬拒，未覆盖后来变更；恢复自建变更后原回滚包成功 |

固定生产候选参数：单事务，`lock_timeout=3s`、`statement_timeout=60s`。独立本地测得正向约96ms、回滚约137ms（含docker/psql启动，单样本），**不作为生产耗时承诺**。没有实际制造锁争用超时；3秒锁超时只确认包内设置，AI事务锁另有并发实测。

演练脚本绑定本地快照，不能直接投产。生产须新鲜快照与审阅基线零漂移，再生成绑定包；回滚会恢复原危险授权，只作为故障恢复，须一并获准。
