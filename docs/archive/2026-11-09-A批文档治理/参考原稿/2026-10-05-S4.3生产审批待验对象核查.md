# S4.3 生产审批真实点击待验对象核查

- 日期：2026-10-05（Asia/Shanghai）
- 结论：`BLOCKED`，生产当前没有 `pending` 申诉，未执行任何审批点击，也未发生生产写入。
- 核查范围：仅读取生产 `fulfillment_appeals`，联表读取成员姓名；没有登录浏览器执行动作。

## 只读命令

```sh
set -a; source .env.local; set +a
psql "$SUPABASE_DB_URL" -X -v ON_ERROR_STOP=1 -P pager=off -F $'\t' -Atc "select fa.id, fa.user_id, coalesce(p.name, '(成员名缺失)') as member_name, fa.record_date, fa.status, fa.created_at from public.fulfillment_appeals fa left join public.profiles p on p.id = fa.user_id where fa.status = 'pending' order by fa.created_at asc;"
```
