下列Python只读取原801项，不读取凭据正文到输出；计算文件摘要不展示内容。它从全量清单的数字序号提取原材料，不包含P/S/G处置编号。仓库根目录运行：

```sh
python3 - <<'PY'
from pathlib import Path
import re, hashlib
t = Path('docs/archive/2026-11-09-A批文档治理/参考原稿/2026-11-09-A批文档清点-全量清单.md').read_text()
paths = [p for _, p in re.findall(r'^\| (\d+) \| \[([^\]]+)\]', t, re.M)]
assert len(paths) == len(set(paths)) == 801
assert all(Path(p).is_file() for p in paths)
h = hashlib.sha256(''.join(
    p + '\0' + hashlib.sha256(Path(p).read_bytes()).hexdigest() + '\n'
    for p in sorted(paths)).encode()).hexdigest()
assert h == '1d68d07295bbb675a69d702d66bfd9b825a584ff4bc22990b07de489c0dbf372'
print('PASS: 801 original files unchanged')
PY
```
