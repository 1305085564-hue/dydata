计划今晚分批完成整套确认范围；不因赶时间省略验收。**规划完成不计入施工进度，当前已验收 2/6 批（第 3、4 批）。**

## 总范围与收益

| 范围 | 完成后的变化 |
|---|---|
| 故障定位 | 三个核心写接口可按诊断编号查阶段、结果、版本；验证已有 Sentry |
| 模块边界 | 三组错位的共享工具迁回业务库，调用方明确 |
| 业务逻辑 | 两条豁免申请入口共用预检，保留各自写入契约 |
| 复杂组件 | 提交回填模型、成员 AI 弹窗、内容对比请求分别独立维护 |
| 验证与恢复 | 各模块有定向验收入口，生产版本和恢复路径有证据 |

不纳入：权限规则改造、数据库迁移、全站 API 换壳、缓存平台、字段重命名、目录全面搬迁。原[架构债务地图](2026-09-16-架构债务地图.md)保留为诊断素材，其建议不自动成为任务；具体取舍见第 0 批。
