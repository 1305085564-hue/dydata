# 审批工作台哲学提纯与视觉降噪 · 施工计划

> **制定时间**：2026-10-08
> **指导思想**：以《Claude 设计哲学》（一间光线充足的工作室、全局容器律、高密度降噪）与《Claude 设计规范》（六档身份、全屏单光、留白四级）为唯一准绳。
> **核心目标**：彻底剥除无增益的外框、碟子、电路板式按钮与廉价装饰，把界面退居幕后，让审批心流如纸张般通透安静。

## 阶段一：空间通透与家具消框（看房间 + 看家具）

### 目标
解决宏观空间层级混乱，剥除外围辅助工具的“小碟子”和“套娃胶囊”，让整个工作台如同一本在充足自然光下摊开的高档画册。

### 施工范围
1. **抽掉多余夹层底色**（`src/components/unified-command-hub.tsx`）
   - 将工作台主体滑动区域的画布底色抽除，与大容器统一为纯净通透的白纸质感（L2），卡片间依靠纵向留白与微发丝线切分，消除“白-灰-白”三重底色冲突。
2. **摘掉标题图标的过度包装**（`src/components/command-hub/workbench-header.tsx`）
   - 剥除左上角图标外层的大圆角、浅砂底色、发丝线和卡片级微投影，让图标轻盈随行或直接以纯粹定名字体呈现。
3. **收敛滥发的星标微符 `✦` 与去冗余**（`workbench-header.tsx`、`undo-strip.tsx`、`unified-command-hub.tsx`）
   - 移除顶栏右上角的常驻说明与星标；
   - 移除 5 秒撤回条上的星标（撤回属于暂态，不借用完卷微符）；
   - 仅在工作台底栏保留一行极简纯粹的全局状态说明，消除上下两头一模一样的说明文字。
4. **理顺分类导航与字重规范**（`workbench-header.tsx`）
   - 解开三层嵌套的胶囊滑块，恢复轻盈利落的目录排版；
   - 修正激活状态下数字徽标的字重，严格从 500 降为元数据 400。
5. **筛选器降杂与批量按钮纠偏**（`src/components/command-hub/approvals-tab.tsx`）
   - 践行“默认最简”：当分类数量为 0 时隐藏括号与数字，杜绝信息噪音；
   - 批量裁决按钮去掉误导性的向右跳转箭头 `→`，文案与符号保持纯粹的就地裁决语义。

### 验收标准
- 工作台打开后通透开阔，无灰白交替的斑驳感；
- 标题行大气清爽，无多余外框；
- 全屏星标微符不再滥用，文案无重复说教。

## 阶段二：卡片降噪与告别电路板（动工具：卡片核心）

### 目标
彻底治理请假卡片内的“按键电路板轰炸”，纠正违规口径，归还全屏单点聚光灯，恢复审批极速闭环心流。

### 施工范围与执行细则

#### 0. [最高优先级 P0] 摘除违规出勤口径胶囊
- **位置**：`src/components/command-hub/exemption-approval-card.tsx`
- **执行规则**：立即摘除“本月已准 N 天 / 豁免 N 天”统计胶囊。该胶囊直接违反 10-03 施工单第 42 行明确禁令（“不放当月履约率/出勤统计，口径在审批瞬间会变”），性质重于视觉问题，优先摘除并同步清理该卡片的数据依赖。

#### 1. 焦点指示器撤销主色盗用
- **位置**：`exemption-approval-card.tsx`、`fulfillment-appeal-card.tsx`
- **执行规则**：将键盘 J/K 选中卡片时的左侧亮橙色竖条，替换为沉稳克制的深墨内凹微发丝线或轻柔层次上浮，把全屏唯一的橙色聚光灯归还给真正的主行动。

#### 2. 拔除卡片右上角悬浮便利贴
- **位置**：`exemption-approval-card.tsx`、`fulfillment-appeal-card.tsx`
- **执行规则**：移除卡片内部右上角绝对定位的快捷键胶囊（`A 同意 / R 拒绝`），依靠底栏全局恒定的快捷键指示，保全卡片右上角的对齐脊梁与留白。

#### 3. 坚决砍掉批注第三按钮，并清空死代码
- **位置**：`exemption-approval-card.tsx`
- **口径确认**：严格执行 10-03 施工单禁令，删除常态卡片右侧的第三按钮。组级批注由逐日批注（铅笔按钮）承接，**严禁在卡片上恢复任何常驻第三入口**。
- **闭环清理**：同步清理随之失效的 `isGroupFeedbackOpen` 等相关状态、props 与组级批注槽分支。严格执行项目铁律：前后端同步闭环，零垃圾残留。

#### 4. 剥除缺勤天数马甲
- **位置**：`fulfillment-appeal-card.tsx`
- **执行规则**：将“缺勤 N 天”等元数据脱去灰底和边框，作为普通文本与业务日期、账号自然对齐排版。

#### 5. 逐日切片按需揭示（覆盖三类交互）
- **位置**：`exemption-approval-card.tsx`
- **呈现规则**：常态下彻底移除日期方块内平铺的 3 个微型小按钮（勾、叉、笔），仅保留极简日期与已裁印记（✓ 已准 / ✗ 已拒）。
- **按需唤出三条件（纯 hover 判定不合格）**：
  1. 鼠标悬停（Hover）；
  2. 卡片键盘选中态（J/K 移动到的 `isFocused` 卡内焦点可通过 Tab / focus-visible 触达）；
  3. 触屏点选。
- **DOM 规范**：隐藏使用 `opacity` / `visibility` 类手段保留 DOM 结构与 `focus-visible`，**严禁条件卸载组件导致 Tab 键盘焦点丢失**；保留 `aria-expanded` 等既有无障碍属性。
- **移除说教**：删除旁边的冗余说明小字（“可直接点选单日进行快速裁决”）。

### 验收标准
- 无论多长天数的请假单，常态卡片绝无密集按钮阵列，视觉安静如纸；
- 键盘移动选卡时，不再触发刺眼的橙色竖条；
- 审批卡片右侧回归纯粹的双极动作，无认知分心；
- 键盘 Tab 操作在逐日方块上顺畅对焦，无障碍焦点不断流。

## 阶段三：内联槽规范与弹窗清理（打磨交互细节）

### 目标
打磨驳回与打回细节，规范控件圆角与输入墨度，彻底清除全站残存的二级遮罩大弹窗。

### 施工范围与执行细则

#### 1. 提纯内联批注槽
- **位置**：`src/components/inline-feedback-tray.tsx`
- **执行规则**：
  - 修正输入框圆角：从错误的容器大圆角（`rounded-xl`）修正为标准的控件圆角（`rounded-md`）；
  - 墨度归轨：将自造的占位符 `/60` 半透明收敛为规范的信号墨 `#A8A29E`；
  - 合并退出入口：移除重复的“收起”文本，统一保留底部的取消动线；
  - 驳回确认按钮取消红色实底，采用淡底红字或深墨次要按钮，不与主色争光。

#### 2. 打回确认去马甲与降光
- **位置**：`src/components/command-hub/history-appeal-card.tsx`、`history-tab.tsx`
- **执行规则**：
  - 移除打回确认时内嵌的黄色带框子卡片和禁用的 `rounded-lg`，改为在发丝线下方直接排版；
  - 将确认打回按钮从抢戏的橙色实底降为中性灰墨按钮；
  - 清理标题旁括号内的自言自语说明文字。

#### 3. 彻底拔除履约双入口遮罩大弹窗（行为改造）
- **涉及范围（明确定位两个调用点）**：
  1. `src/app/(app)/admin/fulfillment/components/fulfillment-member-sheet.tsx`
  2. `src/app/(app)/admin/fulfillment/components/fulfillment-action-dock.tsx`
- **改造形态**：彻底拔除 `AppealRejectionDialog` 模态弹窗，改为就地轻量批注槽，复用 10-03 标准模式：发丝线分隔、13px 输入、⌘Enter 提交、Esc 收起。
- **业务对账与防伪**：本改动为**真实业务行为改造，绝非纯样式**。提交必须直连现有驳回接口，严格核对前后端传参字段，禁止假接与伪造。
- **死代码清理**：彻底删除 `src/components/appeal-rejection-dialog.tsx`，全库检索确认零引用，零垃圾残留。

### 验收标准
- 批注输入框与全站控件规范严密同源；
- 打回体验无二次嵌套，按钮沉着得体；
- 履约抽屉（MemberSheet）与操作坞（ActionDock）各真实走一次驳回测试：全程无黑底遮罩、提交成功、卡片/行即时消解；
- 全库无 `AppealRejectionDialog` 遗留引用；
- `npm run gate:static` 退出码 0。

## 交付与回归门禁

1. **静态代码质量门禁**：`npm run gate:static` 确保零类型报错、零规范脱轨。
2. **设计规范走查**：对照《Claude 设计规范》§0 核心铁律自检：
   - 字号严格封闭在白名单内；
   - 字重严格只有 400 与 500；
   - 墨度四阶严格归轨，无自造透明度；
   - 全屏唯一单点主光，无借用主色；
   - 无任何非法圆角与带框嵌套。
3. **真实浏览器走查**：在管理员与普通成员两个视角下，完整走一遍请假、豁免、补交、打回、快捷键全流程，确认操作极速顺畅、界面彻底退居幕后。
