# AI 配置中心第一批优化实施计划

> 日期：2026-10-07  
> 范围：AI 配置中心 4 处微观体验与排版微调  
> 目标：在不改动业务逻辑和数据库的前提下，使文字秩序、排版呼吸与设备手感完全契合《Claude 设计哲学与规范》。

---

## 一、改动清单与设计规格

### 1. 顶部健康状态条呼吸排布（`ai-config-shell.tsx`）
- **现状**：在窄屏设备下，健康点、文字与多个业务状态徽章在同一行容易挤压变形。
- **改动**：
  - 外层容器使用 `flex flex-wrap items-center justify-between gap-y-2 gap-x-3`。
  - 左侧状态文字区与右侧动作区（刷新/体检）保持恒定对齐，在小屏下自然折行，保持舒适留白。
  - 最后核对时间戳与业务状态标签之间保留微弱发丝间隔，消除视觉粘连。

### 2. 业务功能调度表格字重与墨度统一（`business-functions-panel.tsx`）
- **现状**：“全局默认兜底”首行使用了 `font-medium`，而下方各业务行使用了 `font-normal`，出现不必要的粗细对比。
- **改动**：
  - 严格遵守《Claude 设计规范》§1.4（字重两档：定名 500，正文与单元格 400）。
  - 功能名称列（第一列）统一使用 `text-[13px] font-normal text-[#1F1E1D]`（定名墨在表头与大标题已宣告，行内保持沉着）。
  - 标签与说明统一使用 `text-[12px] text-[#78716C]`（元数据墨）。

### 3. 模型批量选型弹窗触屏与鼠标自适应（`sync-models-dialog.tsx`）
- **现状**：滑动选择事件使用原生 `onMouseDown` / `onMouseEnter`，在触屏设备（手机/平板）滑动翻页时可能误触发批量选择。
- **改动**：
  - 增加指针类型判断（`pointerType === "mouse"`）或仅在鼠标主键按下时激活滑动选型。
  - 在触摸滑动（touch / mobile scroll）时阻止误勾选，保留单点精准 Toggle，兼顾桌面端连选爽感与移动端防误触。

### 4. 截图识别试跑结果展示轻柔渐显（`screenshot-recognition-card.tsx`）
- **现状**：点击“试跑真实用例”后，底部连通性结果瞬间跳出，缺少丝滑过渡。
- **改动**：
  - 结果边注容器增加 `animate-in fade-in duration-150` 轻柔渐显动画。
  - 状态文案与耗时保持发丝边注排版，安静退居幕后。

## 三、验收标准

1. **视觉核对**：
   - 顶部健康条在宽屏与 375px 窄屏下均排布整齐，无重叠或溢出。
   - 业务调度表格所有行字体粗细一致，阅读体验平稳沉着。
2. **交互核对**：
   - 桌面端鼠标按住可正常滑动批量勾选模型；触屏模拟下滚动页面不发生误选。
   - 试跑用例结果呈现流畅渐显，耗时和状态标注准确。
3. **工程质量**：
   - `npm run lint` / `npm run test`（或受影响组件定向测试）通过，零报错零类型警告。
