## 2. 快捷键提示统一规范（全站新规则，W3/W5/所有新提示都遵守）

**规则一句话：界面上静态可见的快捷键文字 = 0 处；提示只在「用户正在与相关控件交互」时浮现，交互结束即消失。**

| 维度 | 规格 |
|------|------|
| 触发浮现 | 悬停（hover）控件 ≥150ms，或键盘焦点落在控件上 |
| 消失 | 指针离开 / 焦点移走 / Esc |
| 载体 | 复用 `src/components/ui/tooltip.tsx`（禁止新造浮层组件）；单条短提示也可用原生 `title` 属性（已有先例：`collaboration-workbench-toolbar.tsx:72`） |
| 提示文案格式 | `动作说明（快捷键 X）`，例：「上一篇（快捷键 [）」。禁止把快捷键单独作为一段文字排在界面上 |
| 样式（tooltip 内） | 键名用 `font-mono text-[#1F1E1D]`，其余文字 `text-[12px] text-[#78716C]`；浮层底 `bg-[#1F1E1D]`、字 `text-[#FCFCFB]`、圆角 `rounded-md`、内边距 `px-2.5 py-1` |
| 禁止 | 页脚常驻快捷键条、按钮旁括号写快捷键、卡片角落小字写快捷键、任何"帮助条"常驻 |

## 3. 施工项规格

### W1【视频复盘】抽屉内「上一篇 / 下一篇」（⭐ 头名，先做）

**目标**：看完一篇直接翻下一篇，不再关闭抽屉回列表找行。

**逻辑规格**（伪代码，按此结构照搬）：

```
// content-page-client.tsx 已有列表 videosWithLibraryStatus 与 selectVideo(videoId)
// 1. 计算当前索引
const currentIndex = videos.findIndex(v => v.id === currentVideoId);   // -1 = 未打开
const prevVideo = currentIndex > 0 ? videos[currentIndex - 1] : null;
const nextVideo = currentIndex < videos.length - 1 ? videos[currentIndex + 1] : null;

// 2. 换篇动作 = 复用现有 selectVideo(nextVideo.id)（URL videoId 替换，走 content-video-navigation.ts
//    新增的 buildStepContentVideoNavigation({ currentIndex + 1 })，method: "replace"，
//    除 videoId 外其余查询参数原样保留——这是 2026-10-11 审计 M1 定下的规矩，不得破坏）
// 3. 快捷键："[\" 上一篇、"]\" 下一篇；Alt+← / Alt+→ 同义
//    ⚠️ 禁止占用裸 ← / →：那两个键现在是抽屉内翻截图用的（content-detail-dialog.tsx:152-156）
// 4. 快捷键仅在抽屉打开时生效；e.target 是 input/textarea/contenteditable 时不劫持
```

**UI 规格**（放在 `SheetHeader` 右侧操作区、`X` 关闭按钮的左边，与「补录24h」等按钮同一排）：

```html
<div class="flex items-center gap-1">
  <!-- 上一篇 -->
  <button class="h-6 w-6 inline-flex items-center justify-center rounded-md
                 text-[#A8A29E] hover:text-[#141413] hover:bg-[#EBEBE9] transition-colors
                 disabled:opacity-40 disabled:pointer-events-none"
          title="上一篇（快捷键 [）">
    <ChevronLeft class="size-3.5" />
  </button>
  <!-- 篇数指示，tabular-nums -->
  <span class="text-[12px] text-[#78716C] tabular-nums">3 / 47</span>
  <!-- 下一篇 -->
  <button class="同上样式" title="下一篇（快捷键 ]）">
    <ChevronRight class="size-3.5" />
  </button>
</div>
```

**边界**：
- 第一篇时「上一篇」`disabled`；最后一篇时「下一篇」`disabled`，且 tooltip 文案改为「已是最后一篇，翻到底自动加载更多后再继续」；翻到最后一篇后不自动请求下一页（不引入新的取数逻辑），分页仍走列表现有分页器。
- `currentIndex === -1`（直接带 videoId 深链进来）时：以 `videosWithLibraryStatus` 当前内存列表为准计算；找不到就双按钮 `disabled`，只显示不带数字的占位 `— / —`。
- 换篇时抽屉保持打开，不闪烁；顶部 `ID: xxx` 与内容随新作品整体替换。
- 打开状态下列表底层跟随高亮当前行（表格已有选中态就复用，没有就只改 URL 不加行高亮，**不加新样式**）。

### W2【视频复盘】宽表十字准星（只做对齐，不做着色）

**目标**：横向扫表不串行。

**UI 规格**：
- 行：鼠标悬停所在 `<tr>` 加 `hover:bg-[#F7F7F5]`（若表格已有 hover 行底色，保留现有值不动）。
- 列：悬停单元格时，同列的 `<td>` 加 `bg-[#F7F7F5]/60`，该列 `<TableHead>` 加 `bg-[#EFEFEC]`。
- 实现方式：在单元格 `onMouseEnter` 里用 CSS 变量或 `data-col` 属性定位同列，**禁止**给每个格子绑独立 state 导致整表重渲染；整表 hover 态允许一次轻量重渲染，但不得触碰数据 fetch。
- 表头已有 sticky 就保留；没有**不要**加（不属本规格）。

**明确不做（重要）**：不做「高完播绿底 / 高跳出警示」的数据阶梯着色。理由：着色阈值会与全站评级标准线（`src/lib/breakout-rating.ts` 真值源）产生第二套口径。该项以后要做必须复用评级真值源，另立任务单独评审。

### W4【数据管理】展开行单开互斥

**逻辑规格**（`staff-tab.tsx:591` 与 `operator-tab.tsx:330` 两处 `toggleExpand` 同改）：

```
// 现状：setExpandedUserIds 用 Set，可多开 → 页面被拉长几千像素
// 改为：单开互斥
const toggleExpand = (userId: string) => {
  setExpandedUserIds((prev) => {
    const isOpen = prev.has(userId);
    // 关闭自己 → 空集；展开别人 → 只留新人（旧的自动收起）
    return isOpen ? new Set() : new Set([userId]);
  });
};
```

- ⚠️ **不做**「自动滚动把展开区顶到屏幕中间」。阿禅未拍板，且强制滚动会打扰对比场景。展开行为完全不动现有滚动位置。
- `expandedUserIds` 保留 `Set` 类型不动（`isExpanded` 判断逻辑零改动），只换写入策略——最小改动。
- 达人（talent）、文案、剪辑页签若无展开行则不碰；有则同规则（按 grep 结果只有 staff/operator 两处，以实测为准）。
- 个人档案卡（点姓名弹的抽屉）不动，它不在行内展开。
