## 目标

管理员打开导航栏铃铛 → 一眼看到"还有几件等我批、哪件最急" → 每件当场批完，不用去别的页面查情况。

## 改了什么（验收对照）

1. 标题就是答案：`还有 N 件等你批` / `申请都批完了，还有 M 件待处理` / `都处理完了`；普通成员是 `还有 M 件待办` / `没有待办了`。
2. 原来的五个类型标签没了，改成上下两段："等你批 · N"（请假、免交、补交混排）和 "等你处理 · M"（权限申请、提醒等待办）。
3. "等你批"按涉及日期从近到远排，补交的业务日期已经过去，会排在最前面；同一天的，先提交的排前面。
4. 请假/免交卡片右上角显示"本月已批假 N 天"或"本月已免交 N 天"。
5. 同一时刻只有一张卡被选中（浅灰底），它的"同意"按钮是陶土橙；鼠标移到哪张卡，选中就跟到哪张。键盘 ↑↓/J/K 移动选中，A 同意，R 拒绝，Z 撤回，Esc 关闭。
6. 单日申请不显示逐日按钮；多日申请每天带 ✓ ✗ 两个按钮，没有铅笔图标了。部分已审的卡片，按钮写"同意剩余 N 天"。
7. 点"拒绝"后就地展开原因输入框，Enter 确认，Esc 收起。补交的原因必填，请假/免交的可以不填。
8. 撤回固定在底栏（高 44px）：批完一件，底栏显示"已同意 某某的请假 · 撤回 5s"；没有可撤回的时候显示快捷键说明。批的时候列表不会被往下推。
9. 已在"等你批"里的补交，不会再以"补交审批"待办的形式重复出现在"等你处理"。
10. "已处理记录"按钮切到历史视图，每条有"打回重审"，点了先就地确认，并写明后果。

## 验证路径

**A. 布局与视觉（可以用本地 3000 端口，只读）**：用测试账号里的管理员登录，点铃铛打开工作台。**只看，不点**同意 / 拒绝 / 全部同意 / 打回 / 完成待办（本地连的是生产库）。检查以下几项：
- 宽屏（1440）和窄屏（375）、低矮视口（高 600）下都不溢出
- 标题字号 20px
- 同屏只有一个陶土橙按钮
- 鼠标在卡片间移动时，橙色按钮跟着走，且没有布局跳动
- "全部同意"会弹出确认框，弹出后点取消，只验证弹窗本身

**B. 审批交互（必须在隔离工作树 + 本地 Supabase 里做）**：造 1 条单日请假、1 条三日请假、1 条补交，逐项核对：
- 单日请假点同意：卡片消失，底栏出现撤回；5 秒内点撤回，卡片回到原位置；不撤回，到期后发布管理那边变成已批
- 三日请假只拒绝第 2 天并写原因：卡片保留，变成"同意剩余 2 天"
- 补交点拒绝不填原因：确认按钮不可点
- 批完一件立刻关闭工作台：这条审批照常提交（关面板时会把撤回窗口里的审批补发出去）
- 键盘只用 ↓、A、R、Z 走完一遍
