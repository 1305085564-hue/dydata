# 数据管理页面功能说明

> **一句话理解：**这个页面先决定“你能看哪些视频”，再决定“哪些视频值得先看”，最后提供“复盘、入库、回收”等处理入口。

## 先看这张图：一条视频是怎么被页面处理的

```text
这条视频在我的查看范围内吗？
  ├─ 否 → 不显示
  └─ 是
       ↓
它属于当前看的状态吗？
  ├─ 否 → 不显示
  └─ 是
       ↓
有最新的 24 小时数据吗？
  ├─ 否 → 仍显示，但指标留空，并提示“缺 24h 数据”
  └─ 是
       ↓
文案和拆段资料齐全吗？
  ├─ 否 → 显示缺少哪一项
  └─ 是 → 标记“数据齐全”
       ↓
有没有异常或指标告警？
  ├─ 有 → 提高优先级，建议先看
  └─ 没有 → 按普通视频处理
       ↓
管理者可以继续筛选、排序、打开详情和执行允许的操作
```

## 一、先看页面上的几个区域

| 页面区域 | 它在解决什么问题 |
|---|---|
| 数据范围 | 我现在看的是公司、小组，还是更小的范围？ |
| 异常提醒 | 当前范围里，哪些视频最值得先看？ |
| 筛选区 | 我只想看某个人、某个账号、某段时间或某个关键词怎么办？ |
| 视频列表 | 每条视频现在是什么状态，表现怎么样？ |
| 视频详情 | 这条视频为什么值得看，证据是什么？ |
| 选题库状态 | 这条视频是否已经进入选题库？ |
| 回收站 | 被移出的作品在哪里，能不能恢复或删除？ |

# 二、页面首先判断：我能不能看到这条视频

## 1. 数据范围

页面不是默认展示全公司的所有视频。

它先根据当前使用者的权限，确定可以查看的范围：

- 公司范围；
- 某个小组；
- 当前使用者被允许看到的成员或账号。

### 如果……那么……

- **如果视频不属于当前查看范围** → 页面不显示；
- **如果切换到某个小组** → 只显示这个小组的视频；
- **如果没有公司范围权限** → 不能通过切换方式看到公司全部数据；
- **如果选择了无权查看的小组** → 页面回到允许查看的范围。

### 维护时看什么

看到“别人能看见、我看不见”时，先确认是不是查看范围不同，不要先判断为数据丢失。

## 2. 全部视频和回收站

页面有两个状态：

| 视图 | 显示什么 |
|---|---|
| 全部 | 还在正常使用中的视频 |
| 回收站 | 已经移入回收站的视频 |

### 如果……那么……

- **如果视频移入回收站** → 它从“全部”中消失，进入回收站；
- **如果视频被恢复** → 它从回收站消失，回到“全部”；
- **如果没有视频管理权限** → 不能查看回收站；
- **如果视频被永久删除** → 不能再恢复。

# 三、页面如何判断资料是否齐全

系统会检查三样东西：

1. 24 小时数据；
2. 视频文案；
3. 内容拆段资料。

| 页面提示 | 实际意思 | 还能不能看视频 |
|---|---|---|
| 缺 24h 数据 | 表现数据还没有准备好 | 能看，但指标为空 |
| 缺文案 | 有表现数据，但没有文案可对照 | 能看 |
| 缺拆段 | 有数据和文案，但不能细看观众在哪一段流失 | 能看 |
| 数据齐全 | 三样资料都有 | 能做完整复盘 |

### 如果……那么……

- **如果没有 24 小时数据** → 视频仍显示，但指标留空；
- **如果没有文案** → 显示“缺文案”；
- **如果没有拆段** → 显示“缺拆段”；
- **如果三样都有** → 显示“数据齐全”。

### 最容易误解的一点

**指标为空，不等于指标是 0。**

- 空白：没有拿到数据；
- 0：拿到了数据，结果是 0。

# 四、页面上的筛选分别在筛什么

筛选只会从“本来就允许看到的视频”中继续缩小范围，不会扩大权限。

## 1. 负责人

页面按“当前归属负责人”筛选。

判断顺序是：

1. 先看账号绑定的负责人；
2. 账号没有负责人时，再看视频登记的负责人。

### 如果……那么……

- **如果账号负责人和视频上传人不同** → 页面按账号负责人归类；
- **如果负责人不在当前查看范围** → 不会出现在筛选选项中；
- **如果发现视频归错人** → 先检查账号负责人设置。

## 2. 账号

只显示指定账号的视频。

账号筛选是精确筛选，不会因为标题或负责人相同而混入其他账号。

## 3. 日期

日期筛选看**发布时间**。

不是上传时间，也不是录入时间。

### 如果……那么……

- **如果设置开始日期** → 只看这天及之后发布的视频；
- **如果设置结束日期** → 只看这天及之前发布的视频；
- **如果视频没有发布时间** → 使用日期筛选时不保留它。

## 4. 关键词

关键词只查两处：

- 视频标题；
- 视频文案。

### 如果……那么……

- **如果标题包含关键词** → 保留；
- **如果文案包含关键词** → 保留；
- **如果只在账号名、负责人名或链接里出现** → 不保留。

关键词不区分大小写。

## 5. 选题库状态

可以只看：

- 全部；
- 已入选；
- 已移出。

### 如果……那么……

- **如果状态还没加载回来** → 暂时没有状态标记；
- **如果没有状态标记** → 不能直接理解为“未入库”；
- **如果选择“已入选”** → 只保留已入选的视频；
- **如果选择“已移出”** → 只保留已移出的视频。

# 五、页面如何决定哪些视频值得先看

页面会综合四类信息：

1. 视频状态；
2. 播放量变化；
3. 指标是否触碰标准；
4. 复盘资料是否齐全。

优先级越高，越建议先处理。它不是最终结论。

## 1. 哪些情况会提高优先级

| 情况 | 页面理解 |
|---|---|
| 删稿、限流 | 高风险，优先查看 |
| 播放腰斩 | 表现明显下降 |
| 播放暴涨 | 表现明显变化，值得分析原因 |
| 投流、活动干预（已下线类型，只读旧行） | 历史行数据可能受到外部因素影响 |
| 缺数据、缺文案、缺拆段 | 资料不完整，需要补齐或确认 |
| 指标触碰标准 | 可能存在内容问题 |

## 2. 什么叫播放暴涨

要同时满足两个条件：

- 比同账号上一条视频多至少 **5,000 播放**；
- 增长至少 **100%**。

### 如果……那么……

- **如果只多了 200 播放** → 即使百分比涨得很高，也不算暴涨；
- **如果增长 50%** → 不算暴涨；
- **如果找不到同账号上一条正常视频** → 无法判断暴涨。

## 3. 什么叫播放腰斩

要同时满足两个条件：

- 当前播放量至少 **5,000**；
- 比同账号上一条视频下降至少 **50%**。

### 如果……那么……

- **如果当前只有 2,000 播放** → 即使下降 60%，也不算腰斩；
- **如果下降只有 30%** → 不算腰斩；
- **如果找不到同账号上一条正常视频** → 无法判断腰斩。

## 4. “直接去盘”会打开哪条视频

点击后，系统按这个顺序找：

1. 北京时间昨天发布的异常视频；
2. 最近 7 天发布的异常视频；
3. 当前异常视频中优先级最高的一条。

如果当前没有异常视频，就没有可直接打开的目标。

# 六、指标标准和样本不足

## 1. 当前默认标准

| 指标 | 什么时候需要注意 | 默认标准 |
|---|---|---:|
| 2 秒跳出率 | 高于 | 30% |
| 5 秒完播率 | 低于 | 50% |
| 平均播放时长 | 低于 | 30 秒 |
| 整体完播率 | 低于 | 5% |
| 播放量 | 低于 | 1,000 |

这五条标准现已**固定在代码内**（`src/lib/video-review-thresholds.ts` 的 `VIDEO_REVIEW_RULE_THRESHOLDS`），**不再提供页面配置入口**：原 `/admin/settings` 的阈值面板已于 2026-09-26 随该页退役一并删除，如需调整只能走代码发布。

## 2. 什么叫样本不足

如果播放量低于当前播放量标准，页面会把比例类指标变灰。

### 如果……那么……

- **如果播放量低于标准** → 比例变灰，提示样本不足；
- **如果播放量达到标准** → 按正常颜色展示；
- **无论是否样本不足** → 视频都不会被隐藏，也不会阻止打开详情。

样本不足表示“先别对这个比例下重结论”，不表示视频一定正常或一定异常。

## 3. 互动率怎么算

```text
互动率 =（点赞 + 评论 + 分享 + 收藏）÷ 播放量
```

### 如果……那么……

- **如果播放量大于 0，且四项互动数据都有** → 计算互动率；
- **如果缺少任何一项互动数据** → 互动率留空；
- **如果播放量为 0** → 互动率留空；
- **如果比例超过 100%** → 页面保留原值并标记数据异常。

超过 100% 的比例首先说明数据可能有问题，不等于视频内容异常。

# 七、打开视频详情后能看到什么

详情是用来回答：“这条视频为什么值得看？”

## 1. 视频基本信息

用于确认当前看的视频：标题、账号、负责人、发布时间、状态和原视频入口。

## 2. 24 小时指标

显示这条视频最新的 24 小时表现。

如果某项为空，先按“没有拿到数据”理解，不按 0 理解。

## 3. 流量曲线和留存脱落

- 流量曲线：看流量怎么变化；
- 留存脱落：看观众在哪个位置离开。

没有截图时，视频仍能打开，只是少了一类判断证据。

## 4. 视频文案

- 有文案 → 可以查看和复制；
- 没有文案 → 显示未录入；
- 复制文案 → 只复制到剪贴板，不修改系统内容。

## 5. 话题类型

不同类型看不同重点：

- 干货类 → 重点看收藏率；
- 复盘类和其他类型 → 重点看点赞率；
- 没识别出类型 → 不强行给评级。

如果评级看起来不合理，先确认视频被归到了哪种话题类型。

# 八、选题库状态怎么理解

## 1. 页面可能显示的状态

| 状态 | 意思 |
|---|---|
| 已入选选题库 | 当前已经在选题库里 |
| 已移出选题库 | 之前入选过，但现在被移出 |
| 暂未达到条件 | 当前还不满足自动入库标准 |
| 等待自动入库 | 已满足条件，但入库还未完成 |
| 复盘类型 | 不进入干货选题库 |
| 暂无状态 | 状态还没查回来 |

## 2. 什么时候能手动改

| 当前状态 | 可以做什么 |
|---|---|
| 已入选 | 移出选题库 |
| 已移出 | 恢复到选题库 |
| 暂未达标 | 不能强行入库 |
| 等待自动入库 | 不能强行改状态 |
| 复盘类型 | 不提供干货入库操作 |

当前页面提示的已知自动规则是：**24 小时播放达到 30,000 后，作品自动进入选题库。**

是否还存在其他条件，需要以选题库的业务规则为准。

# 九、复盘、回收站和删除

## 1. 复盘状态

复盘状态和异常状态是两件事：

- 视频可以正常，但还没复盘；
- 视频可以异常，但已经复盘；
- 标记已复盘，不会把异常改成正常；
- 取消复盘，不会改变播放量或指标。

### 如果……那么……

- **如果标记已复盘** → 记录复盘时间和处理人；
- **如果取消复盘** → 清除复盘时间和处理人；
- **如果没有内容复盘权限** → 不能修改复盘状态。

## 2. 移入回收站

### 如果……那么……

- **如果确认移入回收站** → 视频离开正常列表；
- **同时** → 页面提示相关成员绩效日报会作废；
- **这不是永久删除** → 后续仍可恢复。

## 3. 恢复视频

### 如果……那么……

- **如果确认恢复** → 视频重新出现在正常列表；
- **同时** → 页面提示相关成员绩效日报会恢复生效。

## 4. 永久删除

### 如果……那么……

- **如果确认永久删除** → 视频不能恢复；
- **同时** → 相关截图等资料会被清理；
- **如果还在 30 天保护期内** → 不能立即永久删除。

# 十、遇到问题时，先看这张表

| 页面现象 | 先检查什么 |
|---|---|
| 视频不见了 | 查看范围、全部/回收站、筛选条件 |
| 只有我看不到 | 我和其他人的数据范围是否不同 |
| 指标为空 | 24 小时数据是否已经生成 |
| 指标显示 0 | 确认是真的 0，还是实际为空 |
| 异常数量不对 | 当前范围、筛选条件、指标标准是否变化 |
| 没有暴涨/腰斩 | 是否找到同账号上一条视频，是否满足绝对值和百分比条件 |
| 指标变灰 | 播放量是否低于样本标准 |
| 比例标红 | 数据是否超过 0%-100% 的合理范围 |
| 视频归到错误负责人 | 账号负责人是否设置正确 |
| 选题库没有状态 | 状态是否还在加载，是否有内容复盘权限 |
| 不能移入选题库 | 当前状态是否允许手动操作 |
| 已复盘但仍显示异常 | 复盘状态和异常状态本来就是两套状态 |
| 回收站操作后日报不对 | 关联日报是否按预期作废或恢复 |
| 详情打不开 | 视频是否还属于当前视图和当前查看范围 |

# 十一、需要确认的业务标准

这些地方会直接影响页面判断结果，建议最终由业务确认：

1. 24 小时数据是否必须严格等到发布满 24 小时才算有效；
2. 播放变化是否一直用同账号上一条视频作比较；
3. 已下线类型（投流/活动干预）的历史行是否应该参与暴涨、腰斩比较；
4. 目前五条指标标准是否仍然有效；
5. 24 小时播放达到 30,000 是否是自动入选题库的唯一条件；
6. 移入回收站时，关联日报是全部作废还是只影响部分日报；
7. 30 天保护期从发布时间还是移入回收站时间开始计算；
8. 负责人最终应以账号负责人，还是视频实际提交人作为准。

## 与其他页面的关系

- **选题库**：这里显示和处理视频的入库/移出状态；
- **成员绩效日报**：视频回收和恢复会影响关联日报；
- **系统设置（2026-09-26 已退役）**：`/admin/settings` 现为受 `manage_system` 保护的重定向页（跳 `/admin/fulfillment`），旧阈值面板已删除；本页面用到的指标标准改由代码内固定规则 `VIDEO_REVIEW_RULE_THRESHOLDS` 决定，页面配置入口已不存在；
- **视频数据生成**：视频、文案和 24 小时数据没有生成时，本页面只能显示缺失；
- **权限和团队管理**：决定谁能看哪些视频、谁能执行哪些操作。
