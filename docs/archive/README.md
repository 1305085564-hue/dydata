# docs/archive 说明

只供追溯的历史原稿和过程材料，不作施工依据。搜索默认跳过本目录（仓库根 `.ignore`），要查历史用 `rg --no-ignore`。

## 已清理的截图（2026-11-20）

没有被现行文档引用的历史截图（`docs/archive/` 与 `docs/ux-audit/` 下共 215 张）已从工作区删除，图片仍在 git 历史里。找回方法（路径见同目录 `已清理截图清单-2026-11-20.txt`）：

```sh
git log --diff-filter=D --format=%h -1 -- <图片路径>      # 得到删除它的提交号
git show <提交号>^:<图片路径> > 找回.png
```

引用这些图片的历史稿正文不改，图片链接会显示为失效，这是预期的。

## 日志归档

`日志/` 只留最近 14 天，更早的按月放在 `日志/YYYY-MM/`，由 `npm run logs:archive` 搬运。
