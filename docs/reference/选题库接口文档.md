# 选题库接口文档

> 最后更新：2026-09-13
> 范围：选题库 V3 页面、Topics API、团队隔离、指标、写作状态与软移出契约。响应解析以 `src/lib/topics/v2-client-contract.ts` 及其测试为准。

## 一、身份与团队边界

- Topics 数据隔离只认 `profiles.team_id`，不使用 Group Scope、`dataScope` 或层级权限推导。
- 所有 `/api/topics/*` 读取要求当前用户 `membership_status = 'active'` 且有非空 `team_id`；未登录返回 401，未入团或已归档返回 403。
- 题目所属团队由 `sub_topics.created_by -> profiles.team_id` 判定；作品和写作成员也按相同 `team_id` 收口。
- 普通成员只能编辑、移出自己创建的题。具备 `review_content` 的管理员只能管理相同 `team_id` 的题目或来源视频；跨团队一律 403。
- 浏览器登录角色不能直接写 `sub_topics`、`sub_topic_claims`、`topic_import_batches`；写入统一经过已鉴权 API 和服务端通道。
- `topics_pool_aggregates(p_team_id uuid)` 只允许 `service_role` 执行。

成功响应直接返回业务 JSON，不包装 `{ ok, value }`；失败返回 `{ error }` 和对应 HTTP 状态码，不透出数据库原始错误。

## 二、核心数据与状态

- `topics`：母题。
- `topic_groups`：母题下分组。
- `sub_topics`：子题；`library_status` 为 `in_library` 或 `removed`，移出时写 `removed_at/removed_by`。
- `sub_topic_claims`：写作记录；`status` 只允许 `writing/cancelled/completed`。
- `videos.topic_id`：作品关联子题；移出题目时保持不变。

移出只做软移出：不删除题目、作品、写作记录、复盘或导入历史。状态变化与审计日志必须同成同败；恢复时清空移出字段并追加审计。

## 三、指标口径

- 每个作品的 `playCount` 取该作品全部快照的最大播放量。
- `internalMetrics.bestPlayCount` 是团队内全部真实作品的最高播放，不受 30,000 门槛影响。
- `qualifiedWorkCount` 只统计播放量不低于 30,000 的作品；最好达标文案和最近达标文案也只从达标作品中选。
- `workCount = 0` 才能显示“尚无作品”；`workCount > 0 && qualifiedWorkCount = 0` 显示“暂未达标”。关键字段缺失属于未知态，不能伪装成 0。
- `currentWritingCount` 是同团队当前仍为 `writing` 的去重人数，不受开始时间限制。
- 近 7 天热度只统计同团队近 7 天完成作品与近 7 天开始写作的人数；它与当前在写人数是两个指标。

## 四、用户接口

### 首屏与列表

- `GET /api/topics/bootstrap`：一次返回团队动态、母题选项、首组选题池、当前用户 ID 和本人正在写的题目 ID。
- `GET /api/topics/active`：返回近期开始写作与近期成片动态。
- `GET /api/topics/options`：返回按 `sort_order` 排序的母题。
- `GET /api/topics/pool`：返回团队内 `in_library` 题目及分页。

`pool` 参数：

- `view`：`all/my_claims/my_created/trending/high_potential/never_worked`。
- `time_range`：`3d/1w/1m/3m/all`。
- `topic_id`：可重复传入多个母题 UUID。
- `q`：标题或 hook 搜索，最长 100 字。
- `sort`：`latest/avg_play/claim_count`。
- `source_type/recent_heat/duration_range/performance`：更多筛选。
- `page/page_size`：默认 1/50，`page_size` 最大 100。

列表项包含 `internalMetrics`、`qualifiedWorkCount`、`currentWritingCount` 和近 7 天参与指标。旧 RPC 响应缺少新字段时客户端保留未知态。

### 子题详情与写作

- `POST /api/topics/sub-topics`：创建子题；`title/topic_id` 必填，`hook/emotion_tag/source/audience` 可选；按标题和 hook 自动归类分组。
- `GET /api/topics/sub-topics/:id`：获取题目详情。
- `PATCH /api/topics/sub-topics/:id`：作者或同团队具备 `review_content` 的管理员编辑。
- `DELETE /api/topics/sub-topics/:id`：作者或同团队具权管理员软移出，成功返回 `{ "removed": true }`。
- `POST /api/topics/sub-topics/:id/start-scripting`：幂等标记本人正在写。
- `POST /api/topics/sub-topics/:id/return`：取消本人当前写作，状态变为 `cancelled`。
- `GET /api/topics/sub-topics/:id/claims`：返回同团队当前写作成员和近 7 天摘要。
- `GET /api/topics/sub-topics/:id/works`：返回作品、相似参考和标准化汇总；作品播放量均已在服务端归并快照。

所有路径和请求体 UUID 在查询数据库前校验，非法值返回 400。

旧 `POST /api/topics/sub-topics/:id/claim` 仅作旧客户端迁移期兼容，语义等同 `start-scripting`，不再存在候选位、5 条上限或撞车阻断。确认部署无流量后删除。

### 飞书创作

- `GET /api/topics/feishu-workspace`：仅 active 团队成员可取安全 HTTPS 地址。
- 正常顺序固定为“复制提纲 → 标记在写 → 打开飞书”，成功路径不弹确认框。
- 复制失败立即停止；标记失败显示“已复制、未登记”并停止打开；浏览器拦截新页时保留复制结果并提供手动打开入口。

### 推荐、比较与导入

- `GET /api/topics/comparison`：按题目或账号比较团队内真实作品。
- `GET /api/topics/sub-topics/suggest`：按标题和内容返回最多 3 条已有题目匹配建议。
- `POST /api/topics/sub-topics/from-recommendation`：采纳已有建议数据，写入真实子题。
- 管理端批量导入按 `lower(btrim(title))` 幂等去重；并发唯一冲突计为 `skipped`。没有任何成绩字段时 `external_sample_count = 0`；批次计数更新失败时整次响应不得报告完整成功。
- `POST /api/admin/topics-library/evaluate` 与 `/toggle`：要求 `review_content`，并直接比较操作者和目标创建者/视频所属成员的 `profiles.team_id`。

## 五、错误码与回滚

- 400：参数、UUID 或请求体格式错误。
- 401：未登录。
- 403：未入团、已归档、无管理权限或跨团队。
- 404：题目、写作记录或目标不存在。
- 409：有效唯一约束冲突等业务冲突。
- 500：服务端完整操作失败。

数据库变更只通过新的前向 migration 修复，不改写历史 migration。若安全 migration 失败，应新增前向修复恢复上一版函数、policy 和 grant；不得通过删除表、题目、作品、claim 或历史数据回滚。
