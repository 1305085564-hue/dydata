# 岗位管理 · 接口约定

> 供 Antigravity 对接前端使用。
> 所有日报统计统一限制 `report_date >= '2026-07-27'`。
> 所有接口先经过管理员身份校验，并按当前用户的 `visibleUserIds` 限定数据范围。

## A · GET `/api/admin/collaboration/summary`

### Query 参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `year` | number | 年，如 2026 |
| `month` | number | 月，1-12 |

### 返回 JSON

```jsonc
{
  "total": 48,
  "attributed": 30,
  "selfHandled": 12,
  "unattributed": 6
}
```

## B · GET `/api/admin/collaboration/operators`

### Query 参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `year` | number | 年 |
| `month` | number | 月，1-12 |

### 返回 JSON

```jsonc
[
  {
    "userId": "uuid",
    "name": "王运营",
    "reportCount": 20,
    "totalPlay": 1500000,
    "avgPlay": 75000,
    "totalFollowerConvert": 320,
    "hitCount": 4,
    "momChange": 0.12,
    "accountCount": 3,
    "operatedProfileCount": 3,
    "accounts": [
      {
        "accountId": "uuid",
        "accountName": "账号A",
        "ownerName": "达人甲",
        "reportCount": 8,
        "totalPlay": 600000,
        "totalFollowerConvert": 120
      }
    ]
  }
]
```

`momChange` 在上月无记录或上月总播放为 0 时返回 `null`。运营只要当月存在归属作品就返回，不要求跨账号。爆款必须同时满足：播放至少 30,000、此前至少 3 条同账号样本、达到此前最多 5 条平均播放的 3 倍。

## C · GET `/api/admin/collaboration/staff`

### Query 参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `year` | number | 年 |
| `month` | number | 月，1-12 |
| `role` | `"writer" \| "editor"` | writer=文案，editor=剪辑 |

### 返回 JSON

```jsonc
[
  {
    "userId": "uuid",
    "name": "张文案",
    "reportCount": 15,
    "totalPlay": 900000,
    "avgPlay": 60000,
    "selfHandledCount": 3,
    "involvedAccounts": [
      { "accountId": "uuid", "accountName": "账号A" },
      { "accountId": "uuid", "accountName": "账号B" }
    ],
    "involvedAccountTotal": 2,
    "recentWorks": [
      {
        "reportId": "uuid",
        "reportDate": "2026-08-28",
        "title": "视频标题",
        "accountName": "账号A",
        "playCount": 120000
      }
    ]
  }
]
```

文案或剪辑只要当月存在归属作品就返回，不要求跨账号。`involvedAccounts` 最多返回前 3 个账号，完整数量看 `involvedAccountTotal`；`recentWorks` 最多返回最近 3 条作品，完整明细通过个人接口查看。

## D · GET `/api/admin/collaboration/person`

### Query 参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `userId` | string (UUID) | 目标人员 ID |
| `year` | number | 年 |
| `month` | number | 月，1-12 |

### 返回 JSON

```jsonc
{
  "userId": "uuid",
  "name": "李剪辑",
  "teamId": "uuid-or-null",
  "groupId": "uuid-or-null",
  "currentMonth": {
    "writerCount": 0,
    "editorCount": 12,
    "operatorCount": 0
  },
  "operatorSummary": {
    "reportCount": 8,
    "totalPlay": 600000,
    "avgPlay": 75000,
    "totalFollowerConvert": 120,
    "hitCount": 2,
    "momChange": 0.1,
    "accountCount": 2,
    "operatedProfileCount": 2
  },
  "trend": [
    { "year": 2026, "month": 3, "writerCount": 0, "editorCount": 5, "operatorCount": 0 }
  ],
  "records": [
    {
      "reportId": "uuid",
      "reportDate": "2026-07-28",
      "accountId": "uuid",
      "accountName": "账号A",
      "title": "视频标题",
      "playCount": 120000,
      "roles": ["editor"],
      "anomaly": "正常"
    }
  ]
}
```

`operatorSummary` 在当月没有运营记录时为 `null`；其中 `momChange` 也可能为 `null`。`trend` 固定返回含当月在内、从旧到新的 6 个月。视频软配对失败时 `anomaly` 为 `null`。

## E · PATCH `/api/admin/collaboration/attribution`

### Request Body

```jsonc
{
  "reportId": "uuid",
  "scriptAuthorUserId": "uuid-or-null",
  "videoEditorUserId": "uuid-or-null",
  "operatorUserId": "uuid-or-null"
}
```

三个岗位字段必须出现，值允许为 UUID 或 `null`。只有 owner / team_admin 可补录，且不能修改自己提交的日报。

### 返回 JSON

```jsonc
{
  "ok": true,
  "videoUpdated": true,
  "message": null
}
```

视频软配对失败时事务仍会提交日报更新：

```jsonc
{
  "ok": true,
  "videoUpdated": false,
  "message": "视频侧未找到对应记录，仅更新了日报"
}
```

失败结构：

```jsonc
{ "ok": false, "error": "错误说明" }
```
