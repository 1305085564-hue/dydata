# 岗位管理 · 接口约定

> 供 Antigravity 对接前端和维护服务端 loader 使用。
> 所有日报统计统一限制 `report_date >= '2026-07-27'`。
> 公开接口先经过管理员身份校验，并按当前用户的 `visibleUserIds` 限定数据范围。
> 2026-09-02：`summary` 与 `operators` 的公开 route 已按首屏服务端化重构移除；岗位页直接调用 `_shared.ts` 的 loader。下方 A/B 保留返回结构供 loader 维护参考，不应再从浏览器请求对应 URL。

## A · `loadSummaryData`（无公开 HTTP route）

### Query 参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `year` | number | 年，如 2026 |
| `month` | number | 月，1-12 |

### 返回 JSON

```jsonc
{
  "total": 48,
  "attributed": 30,
  "selfHandled": 12,
  "unattributed": 6
}
```

## B · `loadOperatorsData`（无公开 HTTP route）

### Query 参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `year` | number | 年 |
| `month` | number | 月，1-12 |

### 返回 JSON

```jsonc
[
  {
    "userId": "uuid",
    "name": "王运营",
    "reportCount": 20,
    "totalPlay": 1500000,
    "avgPlay": 75000,
    "totalFollowerConvert": 320,
    "hitCount": 4,
    "momChange": 0.12,
    "accountCount": 3,
    "operatedProfileCount": 3,
    "accounts": [
      {
        "accountId": "uuid",
        "accountName": "账号A",
        "ownerName": "达人甲",
        "reportCount": 8,
        "totalPlay": 600000,
        "totalFollowerConvert": 120
      }
    ]
  }
]
```

`momChange` 在上月无记录或上月总播放为 0 时返回 `null`。

运营口径：只统计为别人孵化、负责账号的日报；本人孵化本人账号属于达人，不进入运营岗。账号未绑定主人时按别人的账号计入。只运营一个别人的账号也返回，不设最低作品数。爆款必须同时满足：播放至少 30,000、此前至少 3 条同账号样本、达到此前最多 5 条平均播放的 3 倍。

## C · GET `/api/admin/collaboration/staff`

### Query 参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `year` | number | 年 |
| `month` | number | 月，1-12 |
| `role` | `"writer" \| "editor"` | writer=文案，editor=剪辑 |

### 返回 JSON

```jsonc
[
  {
    "userId": "uuid",
    "name": "张文案",
    "reportCount": 15,
    "totalPlay": 900000,
    "avgPlay": 60000,
    "selfHandledCount": 3,
    "involvedAccounts": [
      { "accountId": "uuid", "accountName": "账号A" },
      { "accountId": "uuid", "accountName": "账号B" }
    ],
    "involvedAccountTotal": 2,
    "recentWorks": [
      {
        "reportId": "uuid",
        "reportDate": "2026-08-28",
        "title": "视频标题",
        "accountName": "账号A",
        "playCount": 120000
      }
    ],
    "works": [
      {
        "reportId": "uuid",
        "reportDate": "2026-08-28",
        "title": "视频标题",
        "accountName": "账号A",
        "playCount": 120000
      }
    ]
  }
]
```

文案口径：当月至少有 1 篇是给别人账号写的才进入文案岗；入岗后，指标、`involvedAccounts` 和 `works` 统计本人当月署名的全部文案，包括给自己账号写的。只给自己账号写的人不返回。

剪辑口径：只统计给别人账号剪辑的日报；自剪本人账号不进入列表与指标。账号未绑定主人时按别人的账号计入。两种角色的 `recentWorks` 都保留最近 3 条摘要，`works` 返回口径范围内的当月全部篇目，供岗位行展开查看。

## D · GET `/api/admin/collaboration/person`

### Query 参数

| 参数 | 类型 | 说明 |
|---|---|---|
| `userId` | string (UUID) | 目标人员 ID |
| `year` | number | 年 |
| `month` | number | 月，1-12 |

### 返回 JSON

```jsonc
{
  "userId": "uuid",
  "name": "李剪辑",
  "teamId": "uuid-or-null",
  "groupId": "uuid-or-null",
  "currentMonth": {
    "writerCount": 0,
    "editorCount": 12,
    "operatorCount": 0
  },
  "operatorSummary": {
    "reportCount": 8,
    "totalPlay": 600000,
    "avgPlay": 75000,
    "totalFollowerConvert": 120,
    "hitCount": 2,
    "momChange": 0.1,
    "accountCount": 2,
    "operatedProfileCount": 2
  },
  "trend": [
    { "year": 2026, "month": 3, "writerCount": 0, "editorCount": 5, "operatorCount": 0 }
  ],
  "records": [
    {
      "reportId": "uuid",
      "reportDate": "2026-07-28",
      "accountId": "uuid",
      "accountName": "账号A",
      "title": "视频标题",
      "playCount": 120000,
      "roles": ["editor"],
      "anomaly": "正常"
    }

```

`operatorSummary` 在当月没有为别人负责的运营记录时为 `null`（与运营 tab 同口径，不含本人账号）；其中 `momChange` 也可能为 `null`。`currentMonth`、`trend`、`records` 统计该成员全部日报角色记录。`trend` 固定返回含当月在内、从旧到新的 6 个月。视频软配对失败时 `anomaly` 为 `null`。

## E · PATCH `/api/admin/collaboration/attribution`

### Request Body

```jsonc
{
  "reportId": "uuid",
  "scriptAuthorUserId": "uuid-or-null",
  "videoEditorUserId": "uuid-or-null",
  "operatorUserId": "uuid-or-null"
}
```

三个岗位字段必须出现，值允许为 UUID 或 `null`。只有 owner / team_admin 可补录，且不能修改自己提交的日报。

### 返回 JSON

```jsonc
{
  "ok": true,
  "videoUpdated": true,
  "message": null
}
```

视频软配对失败时事务仍会提交日报更新：

```jsonc
{
  "ok": true,
  "videoUpdated": false,
  "message": "视频侧未找到对应记录，仅更新了日报"
}
```

失败结构：

```jsonc
{ "ok": false, "error": "错误说明" }
```

## F · Work Groups（工种小队编制与按团队分组 · 2026-09-22）

### 1. 视图结构（`buildWorkGroupViews`）

由 `_shared.ts` 在 `loadCollaborationMonthDataset` 加载后聚合生成，供双模式中的「按团队」列表和详情使用。

```jsonc
{
  "ready": true, // 库是否已执行 work_groups migration
  "groups": [
    {
      "id": "uuid",
      "teamId": "uuid",
      "name": "短剧一组",
      "kind": "writer", // "writer" | "talent" | "operator"
      "memberCount": 4, // 编制内成员总数（含零产出在职成员）
      "aggregate": {
        "reportCount": 18,
        "effectiveCount": 14,
        "excellentCount": 2,
        "totalPlay": 340000,
        "avgPlay": 18888,
        "billingCount": 18, // 仅文案组（未认证个人为 null，合计只累加已认证）
        "accountCount": 3,  // 涉及账号并集去重
        "momChange": null   // 仅运营组（按组总播放月环比）
      }
    }
  ],
  "details": [
    {
      "summary": { /* 对应 groups 元素 */ },
      "members": [
        /* 组内成员列表（按对应岗位 builder 行组件形状，含零产出 0 / — 行） */
      ]
    }
  ]
}
```

### 2. 写接口 Server Actions（`work-group-actions.ts`）

所有写操作仅供服务端调用，门禁口径统一为 `manage_members + 限本公司`（操作人团队必须与小队/成员 teamId 匹配）。操作成功统一写 `audit_logs`。

| Action | 参数 | 审计类型 | 说明 |
|---|---|---|---|
| `createWorkGroupAction` | `{ name: string, kind: "writer"\|"talent"\|"operator" }` | `create_work_group` | 同公司组名唯一；挂操作人当前公司 |
| `renameWorkGroupAction` | `{ groupId: string, name: string }` | `rename_work_group` | 限改本公司小队；不能与同公司其他小队重名 |
| `deleteWorkGroupAction` | `{ groupId: string }` | `delete_work_group` | 删组后成员归属自动置空（ON DELETE SET NULL） |
| `assignWorkGroupMemberAction` | `{ groupId: string, userId: string }` | `assign_work_group` | 同槽位换组**就地自动替换**原归属（文案/达人二选一、运营至多一个），不要求先取消；运营可与文案/达人兼任；限本公司成员，跨公司一律 403；返回值含 `replacedGroupName` |
| `unassignWorkGroupMemberAction` | `{ groupId: string, userId: string }` | `unassign_work_group` | 清除该成员的小队槽位归属 |
