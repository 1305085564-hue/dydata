## 怎么看分数

每条打三个分，都是 1–10 分，越高越要紧：

- **现在有没有**：1 = 只是理论上可能；10 = 已经出过事。
- **破坏力**：真出事时伤多大。1 = 页面难看点；10 = 数字算错、数据丢了或泄露、全站用不了。
- **恶化速度**：不管它，会不会越来越糟。1 = 基本不变；10 = 每多开发一周就更糟。

**综合分**是我按三项权衡给的结论分，不是简单平均。

**证据**一栏写的是我凭什么这么判断：
- 实测：这次亲手查过、跑过。
- 记录：历史日志或文档里写过，这次没有重新验证。
- 推断：凭经验判断，没有直接证据。

**建议**一栏只有三种：
- 立即：现在就该处理。
- 观察：先不动，定期看。
- 不投入：不值得花成本。
