## 怎么看分数

每条打三个分，都是 1–10 分，越高越要紧：

- **现在有没有**：1 = 只是理论上可能；10 = 已经出过事。
- **破坏力**：真出事时伤多大。1 = 页面难看点；10 = 数字算错、数据丢了或泄露、全站用不了。
- **恶化速度**：不管它，会不会越来越糟。1 = 基本不变；10 = 每多开发一周就更糟。

**综合分**是按三项权衡后的结论分，不是简单平均。

### 合并后的分数怎么重算

1. 每个合并项先以原成员在三个维度中的较高分为基线。
2. 两个风险会互相放大时，只在确实被放大的维度加 1，最高不超过 10。
3. 综合分重新判断，不把成员分数相加，也不把高风险平均掉。
4. 没有合并的项目保留原分数。
5. 同分时按原编号靠前者在前；这只是展示顺序，不代表同分项目之间存在精确的先后差距。

**证据**一栏写的是我凭什么这么判断：
- 实测：原审查记录中有实际命令或检查结果；不等于本轮重新复测。
- 记录：历史日志或文档里写过，本轮没有重跑。
- 推断：凭经验判断，没有直接证据。

**建议**一栏只有三种：
- 立即：现在就该处理。
- 观察：先不动，定期看。
- 不投入：不值得花成本。

## 怎么用这张表

- 每月体检时按这张 25 项表重新打分，只看哪些分数变高了，以及证据是否发生变化。
- 综合分 8 分及以上的，单独讨论解决方案；6–7 分的跟着日常改动顺手收；5 分及以下的不主动投入。
- 分数是排序工具，不是自动施工授权；涉及生产数据、不可逆操作或重要业务行为，仍需单独确认。
