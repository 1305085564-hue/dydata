# 视频复盘接口文档

> 当前边界：视频复盘只帮助管理者定位作品问题，不负责向员工投递反馈、追踪回复或沉淀反馈案例。

## 通用规则

- 所有接口沿用 `requireScopedAdminVideo` 和 `review_content` 权限校验。
- 比率字段使用百分数，例如 `22.5` 表示 `22.5%`。
- 缺数据返回 `null`，不能用 `0` 冒充。

## 一、内容归因

### `GET /api/admin/content-attribution/:videoId`

- 支持 `refs=self,team,top,user` 多参照并列；指定成员时传 `refUserId`。
- 返回当前视频与账号历史、团队或指定成员的指标差异。
- `points_to` 和 `locate` 只做问题定位，不生成员工反馈话术。
- 样本不足时返回明确的样本状态，不伪造结论。

## 二、内部内容分析

### `POST /api/admin/content-analysis`

- 由管理者手动触发，只生成内部分析。
- 返回字段：

```jsonc
{
  "ok": true,
  "video_id": "…",
  "insight_result_id": "…",
  "input_bundle_id": "…",
  "cached": false,
  "data_summary": "…",
  "suspected_stage": ["opening"],
  "key_metric_evidence": ["…"],
  "copywriting_reason": "…",
  "abnormal_points": ["…"]
}
```

- 不再返回 `feedback_draft`、`message_for_member` 或 `reusable_experience`。
- 历史 AI JSON 即使包含旧字段，也只读取并返回上述内部分析字段。

## 三、视频复盘列表

### `GET /api/admin/content/list`

- 返回当前权限范围内的视频、24 小时快照、成员和分析就绪状态。
- `pending` 表示尚无 `content_analysis` 成功结果，不再由反馈卡状态决定。
- 就绪状态只表达：缺 24 小时数据、缺文案、缺拆段、可分析、已有分析。

## 四、已下线接口

以下接口和对应前端入口已删除，不得恢复：

- `/api/admin/content-feedback-cards/*`
- `/api/dashboard/content-feedback-cards/*`
- `/api/admin/content-experience-marks`

通用通知系统仍在使用，只删除了内容反馈卡的通知桥接。

## 五、错误语义

- `400`：参数错误。
- `403`：无权查看或分析该视频。
- `404`：视频不存在。
- `422`：分析所需数据不足或 AI 输出无法解析。
- `500`：服务端处理失败，页面保留旧数据并允许重试。
