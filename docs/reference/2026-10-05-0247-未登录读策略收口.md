## 六、角色实测（anon / authenticated）

```sql
begin;
set local role anon;
select count(*) from public.script_document;
select count(*) from public.tag_definition;
reset role;
set local role authenticated;
select count(*) from public.script_document;
select count(*) from public.tag_definition;
reset role;
rollback;
```

结果：`anon` 与 `authenticated` 均返回 `0`。

> **证据强度说明（如实）**：这两张表**当前总行数均为 0**，故行级读数无法区分"RLS 拦截"与"表本为空"。本次收口的决定性证据是 `pg_policies` 的角色列（策略已从 `{public}` 变为 `{authenticated}`），行级探针只作为辅助。若需更强的匿名拒绝证据，需在表内存在数据时复测，或走 PostgREST 接口层未登录请求。

## 八、回滚方式

```sql
begin;
drop policy script_document_authenticated_read on public.script_document;
create policy script_document_public_read on public.script_document
  for select using (true);
drop policy tag_definition_authenticated_read on public.tag_definition;
create policy tag_definition_read on public.tag_definition
  for select using (true);
commit;
```

回滚即恢复"未登录可读"状态，属回退到更宽松策略，仅在确认需要公开读取时使用。
