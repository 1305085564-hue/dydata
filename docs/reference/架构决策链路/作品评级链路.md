## 0011 互动留存三档评级与主指标下线

**状态**：有效，2026-11-16 定稿。

**决定**：达人岗与文案岗共用互动达成、留存达成两项评级，综合只输出优/良/普；播放低于 2000 直接评普，历史缺平均播放占比时按均播时长独占组合权重。主指标从展示和计算概念中移除，点赞率、收藏率、转粉率只作参考。

**后果**：质量均值使用 2000 播放线，颜色使用 5000 播放线；接受均播折算可能偏向长视频，本轮不修正。数据库先保留兼容列并返回空值，待新页面核对后再删列。

## 0013 以综合评级「优」取代爆款与按条数计费

**状态**：有效，2026-11-19 本地完成，尚未 push。取代数据口径第 3 节的爆款系数口径与第 11 节「岗位质量与文案计费（2026-09-07）」。

**背景**：爆款规则和有效条数服务于旧的按条计费：文案按署名条数扣 25 条基准算钱，播放不足 500 的不算有效。现在拿钱看综合评级「优」，内容好是目的，流量是附带结果。旧概念并存会让同一页面出现两套"好"的定义，其中爆款系数在生产代码里早已无调用方。

**决定**：删除爆款系数、账号基线冷启动、岗位管理「爆款数」和数据口径页的爆款判定；删除岗位表的「有效作品」「优秀作品」及文案的绩效条数、计费明细与对账；文案表新增「优条数」，与良优率同源。文案结算只看优条数，单价不入系统。评级播放门槛不变：低于 2000 评普且不进均值，5000 以下最高普，5000 至不足 15000 最高良，15000 起不封顶。复盘页「昨日爆款」改名「昨日评优」，其筛选本来就是综合评级为优。同日追加：删除达人表「独立完成」（达人几乎都自己包办，数字区分不出差别）与运营表、运营个人档案的「环比」（只看总播放涨跌），连带删除仅为环比服务的上月日报载入；文案、达人表的「互动数据」列改名「互动达成」；转粉率、导粉、账号排行、岗位归属提示、运营与剪辑页签经阿禅确认保留。第三轮：区分「定量的数」（互动率、赞评转藏率、2 秒跳出率等原始值）和「相对标准的达成比值」（互动达成、留存达成），文案、达人表的「留存数据」列实为达成比值，改名「留存达成」；小队表的「内容质量」改称「综合达成」（= 互动达成 + 留存达成），默认只看合并总数，点「展开明细」拆出互动四项（点赞、评论、转发、收藏率，四项相加等于互动率）和留存五项（2 秒跳出率、5 秒完播率、均播时长、播放占比、整体完播率；按作品算术平均，样本与留存达成相同）。点赞率、收藏率因此从默认表头收进明细。文案表、达人表本轮未加展开。

**后果**：旧计费口径只留在 git 历史。岗位表不再有按播放量判断的指标。运营个人档案少一格。`historyRows` 仅服务爆款数，一并从数据集与个人档案载入中移除，不影响取数范围（月报日报一次查询的范围不变）。文案岗位本身与认证流程保留。

**日期**：2026-11-19
