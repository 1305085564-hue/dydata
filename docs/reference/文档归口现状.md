## 四、判定规则

新增或搬动材料时先归类：

- 当前规则 → `docs/系统架构与设计/` 原稿，只维护一处；
- 可复用证据或契约 → `docs/reference/`，注明日期与适用范围；
- 还有未完成事项 → `docs/plans/`，写清已完成部分和待办；
- 只供追溯 → `docs/archive/`，页首标历史。

拿不准时写"待核"，不默认现行，也不删除原件。
