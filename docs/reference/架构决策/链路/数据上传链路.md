## 0010 发布时间来源与补交判重

**状态**：有效，取代 2026-10-01“发布时间锁死”决定。

**背景**：截图识别失败时仍需让成员完成填报。手填或修改识别值会改变发布时间可信度，必须进入与超 72 小时相同的补交审批路径；重复作品也不应先创建申请再在续交阶段失败。

**决定**：发布时间可手填。识别值被修改同样记为手工来源，统一返回 `requires_appeal`，原因使用 `manual_published_at`。普通提交接口和申请补交接口都先复用 `resolveCreateSubmissionConflict` 判重，命中直接返回“这条已经上传过,无需重复提交”，不创建申请。补交暂存数据保留发布时间来源和 OCR 原值，审批卡片展示触发原因与原值。

**后果**：72 小时阈值、编辑和异常跳过门禁、错误码 `PUBLISH_TIME_CONFIRM_REQUIRED` 保持不变；日报的手工标签不受发布时间来源影响。

**日期**：2026-11-16
