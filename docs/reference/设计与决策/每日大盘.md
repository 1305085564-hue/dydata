## 现行设计

> 系统现在怎么做，以这里为准；为什么这样定，看下面的历史决策。最后对过代码：2026-10-31。

<a id="现行-入口"></a>

### 一、入口、代码与验证

- 入口：`/admin/pulse` → `loadAdminContentPageData` → 本页的 `pulse-filters.ts` 汇总。按上海发布日查看作品与指标趋势；日期工具复用发布日工具，质量评级沿用复盘数据（见[作品评级链路](作品评级链路.md#现行设计)）。
- 必须保持：上海发布日一致；缺失保留为空，不当 0；不恢复已退役的复盘工单。范围用 `resolveReadOnlyCompanyScope` 的一般公司范围，不套视频复盘的项目扩展。
- 验证（旧场景：跨上海午夜、跨月选日；无数据不伪造 0）：

  ```sh
  npx tsx --test 'src/app/(app)/admin/pulse/pulse-dates.test.ts' 'src/app/(app)/admin/pulse/review-retirement.test.ts'
  ```

## 历史决策

<a id="第1条"></a>

### 1 大盘独立成页，单条作品复用视频复盘的详情

**分类**：业务　**状态**：有效　**日期**：2026-10-21　**拍板人**：阿禅
**背景**：视频复盘的详情里已经有留存、完播、异常证据，再做一套会出现第二套详情界面，口径也会走偏。
**决定**：每日大盘单独做一页，不并进视频复盘，暂不改管理层默认落地页；点单条作品直接打开视频复盘的详情。明确不做：第二套作品详情、第二套好坏评级标准、强制签字的考核罚款、自定义报表生成器、改动底层数据存储（大盘只读汇总）。
**证据**：[每日大盘完整产品方案（评审确认段、红线段）](../../archive/2026-11-09-A批文档治理/计划原稿/2026-11-09-计划收尾/2026-10-21-每日大盘与内容透视完整产品方案.md)；[10-21 日志](../../archive/日志/2026-10/2026-10-21.md)。

<a id="第2条"></a>

### 2 默认看昨天，没有「今天」

**分类**：业务　**状态**：有效，取代方案原稿里「今天可看、顶部黄字提示」　**日期**：2026-10-22　**拍板人**：阿禅
**背景**：组员下班前才发作品，当天的数据当晚甚至第二天才上传，早上不可能有今天的数据，「今天看今天」是伪命题。
**决定**：删掉「今天」入口和黄条；默认是昨天，可选日期最晚到昨天。
**证据**：[日期入口调整与上线核对](../../archive/2026-11-09-A批文档治理/参考原稿/2026-10-22-每日大盘日期入口调整与上线核对.md)。

<a id="第3条"></a>

### 3 谁能进大盘：负责人看全公司，组长看本团队，组员不开放

**分类**：业务　**状态**：有效（「组长只看本团队」的实现未核）　**日期**：2026-10-21　**拍板人**：阿禅（整份方案确认，权限表没有单独逐条确认）
**背景**：原文只写「创作者首版不开放，以后再评估是否开放脱敏版」。
**决定**：负责人看全公司数据，组长看本团队数据，组员不给入口。
**证据**：[每日大盘完整产品方案（权限设计）](../../archive/2026-11-09-A批文档治理/计划原稿/2026-11-09-计划收尾/2026-10-21-每日大盘与内容透视完整产品方案.md)。

<a id="第4条"></a>

### 4 人员日战报默认按合计播放量从高到低

**分类**：设计　**状态**：有效　**日期**：2026-10-21　**拍板人**：阿禅
**背景**：进来就直奔主题，不用先筛。
**决定**：进页面锁定昨天，人员表默认按合计播放量降序，可改按发片数、留存排；作品列表的排序沿用视频复盘，不另建一套。
**证据**：[每日大盘完整产品方案（排序）](../../archive/2026-11-09-A批文档治理/计划原稿/2026-11-09-计划收尾/2026-10-21-每日大盘与内容透视完整产品方案.md)。

<a id="第5条"></a>

### 5 大盘不派复盘任务

**分类**：业务　**状态**：有效，取代 2026-10-21「从大盘给组员派复盘待办」　**日期**：2026-10-27　**拍板人**：阿禅
**背景**：原文没写理由，只写阿禅授权下线、不保留工单。
**决定**：删掉大盘的「派发复盘」和工作台的「复盘待办」，已有工单一并清掉。
**证据**：[复盘待办下线与大盘核查](../../archive/2026-11-09-A批文档治理/参考原稿/2026-10-27-复盘待办下线与大盘核查.md)；[10-27 日志](../../archive/日志/2026-10/2026-10-27.md)。

<a id="第6条"></a>

### 6 没评级的作品不进红黑榜，单独放

**分类**：业务　**状态**：有效　**日期**：2026-10-21　**拍板人**：阿禅（整份方案确认）
**背景**：没数据不能被当成表现差。
**决定**：没有平台快照或没评级的作品不进红黑榜，单独收在「未评级（N）」里，点开跳到视频复盘的「未评级」筛选。
**证据**：[每日大盘完整产品方案（边界场景）](../../archive/2026-11-09-A批文档治理/计划原稿/2026-11-09-计划收尾/2026-10-21-每日大盘与内容透视完整产品方案.md)。
