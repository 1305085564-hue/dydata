# 创作者历史作品：接口与联调验收

最新状态（2026-10-30）：已推送 `main` 并上线，生产版本 `aa23ad37`。前文保留开发阶段验收时点，生产证据见末节。

## 范围与已确认口径

阿禅已确认第一版只按账号归属人查作品，与复盘大盘一致：`accounts.profile_id ?? videos.user_id`，不扩展文案/剪辑署名。Antigravity 提供界面，Codex 接通数据、权限、分页与刷新。保留其现有视觉设计。

- 作品数：所选周期内、当前可见范围、未移入回收站的作品数，按真实发布日期与上海自然日筛选。
- 条均播放：每篇取最新24h快照；发布已满24小时且播放量有效的作品参与分母，向下取整。0播放是有效样本，缺快照、缺播放、未满24小时不参与。没有有效样本返回 `null`，页面显示 `—`。
- 整体完播达标数：使用同一份公司评价标准 `completionRate.good` 与播放门槛；缺失/非法指标不计。复盘完播字段已经是百分数（17.2表示17.2%），不再乘100。
- 优质作品数：有效24h数据作品中，沿用大盘综合评级为「优」的数量；不得用高播放量替代评级。原「爆款代表作」称谓不再用于此画像。
- 画像覆盖完整所选周期，排序和当前加载页不会改变画像；画像随周期变化。

## 接口

`GET /api/admin/content/author`

| 参数 | 含义 |
|---|---|
| `userId` | 必填，账号归属人的profile UUID |
| `timeRange` | `30d`（默认，含今天共30个上海自然日）/ `thisMonth` / `lastMonth` / `all` |
| `sortField` | `published_at`（默认）/ `play_count`，沿用大盘排序与同值顺序 |
| `sortDir` | `desc`（默认）/ `asc` |
| `pageSize` | 默认100，整数1～500 |
| `page` | 默认1，正整数，继续加载时递增 |

示例（替换成可见范围内的实际UUID）：

```text
/api/admin/content/author?userId=11111111-1111-4111-8111-111111111111&timeRange=lastMonth&sortField=play_count&sortDir=desc&pageSize=100&page=1
```

标准类型在 `src/lib/content/author-works-domain.ts`，客户端入口 `src/lib/content/author-works.ts` 同时导出类型。

```typescript
import {
  fetchAuthorContentWorks,
  createAuthorWorksClient,
  type AuthorWorksResponse,
} from "@/lib/content/author-works";

const result = await fetchAuthorContentWorks({
  userId: visibleAuthorId,
  timeRange: "all",
  page: 1,
});

// 有状态视图使用独占客户端，合并在途请求并短暂缓存。
const client = createAuthorWorksClient();
const firstPage = await client.fetch({ userId: visibleAuthorId });
client.invalidate(); // 作品写操作成功后清除所有周期/排序的缓存
```

返回结构示意；`works` 复用大盘作品结构，相关指标仍以 `snapshots` 数组和质量映射配套返回，不伪造另一个作品模型：

```typescript
  },
  works: [/* 当前页完整大盘作品结构 */],
  snapshots: [/* 当前页最新24h快照；数组，使用video_id关联 */],
  contentQualityByVideoId: {/* 当前页大盘质量结果 */},

  evaluationStandards: {/* 同一公司的当前评价标准 */},
  total: 87, page: 1, pageSize: 100, hasNextPage: false,

```

## 查询、权限与刷新

- 原列表API默认筛选、分页和数据库结构未修改，无migration。作者加载器复用 `loadAdminContentListData` 的现有分页；显式日期区间避免把 `all` 误解释成大盘「最近一天」。
- 每批500篇、最多20批（10000篇），服务端25秒超时。超限要求缩小周期；部分加载失败、重复作品或统计期间总数变化会明确失败，不返回截断的画像。每次分页请求重新核对权限并统计，不设置跨请求服务端缓存。
- 登录与页面访问权限沿用原复盘门禁；服务端根据当前账号构造范围，作者必须在 `visibleUserIds` 中。浏览器传入公司/团队参数不能扩大范围。只读成员可以读，写权限仍由原详情接口控制。
- 列表新增范围内归属人姓名映射，使账号归属与提交人不同时仍能点对作者；人员下拉仍只展示原有在职范围。
- 抽屉内150ms防抖；每个已鉴权页面/作者视图独占10秒、最多20条缓存，合并同参数在途请求；失败不缓存，写后失效。账号/公司变化重新挂载，缓存不跨账号共享。切周期与旧请求返回用请求序号隔离。
- 列表「加载更多」追加下一页。详情上一篇/下一篇沿当前作者、周期和排序翻阅；到已加载末尾时按需请求下一页。
- 移入回收站、补录24h或选题状态操作成功后：失效作者缓存、重新读取已加载页及完整画像、清理并重取独立详情、后台刷新大盘。作品被移出当前列表时退出该详情；返回/关闭保留原大盘筛选。请求失败显示错误和重试入口。
