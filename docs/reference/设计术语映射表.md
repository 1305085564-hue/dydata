# 设计术语映射表

> 本文档用于人类理解 DYData 设计系统在国际设计语境中的定位。
> AI 不需要阅读本文档，直接阅读《Claude 设计哲学》和《Claude 设计规范》即可。

---

## 核心流派定位

**DYData 设计系统 = Data-Driven Editorial Design**  
（数据驱动的出版物设计）

**设计史源流**：
- 基底：Swiss Design（国际主义平面设计）的秩序感
- 叠加：Editorial Design（出版物设计）的装帧与质感
- 融入：Information Design（信息设计）的数据密度
- 剔除：Material Design 的过度装饰、Bootstrap 的廉价感

## 参考案例

**最接近的设计系统**：

1. **Linear** (项目管理工具)
   - 克制的黑白灰 + 单点色彩
   - 极致的秩序与对齐
   - 渐进式揭示

2. **Stripe Dashboard** (支付后台)
   - 数据密集但不拥挤
   - 无边框表格
   - 清晰的信息层级

3. **Bloomberg Terminal** (金融终端)
   - 高密度专业工具
   - 数据优先
   - 功能性秩序

4. **Notion** (早期版本)
   - 出版物感
   - 无边框表格
   - 安静界面

5. **iA Writer** (写作工具)
   - 排版质感
   - 负空间运用
   - 内容是唯一主角

6. **Claude.ai** (对话界面)
   - 功能性装饰（该强调时用颜色）
   - 系统化但有表现力
   - 形式服从功能

## 进一步阅读

### 设计史经典文献

- **Form Follows Function**：Louis Sullivan, 1896
- **Swiss Design / International Typographic Style**：Josef Müller-Brockmann, *Grid Systems in Graphic Design*, 1981
- **Information Design**：Edward Tufte, *The Visual Display of Quantitative Information*, 1983
- **Proximity Principle**：格式塔心理学，20世纪初

### 现代设计系统参考

- **Material Design**：Google, 2014（我们借鉴了 Elevation 概念，但剔除了过度装饰）
- **Human Interface Guidelines**：Apple（我们借鉴了空间层级概念）
- **Carbon Design System**：IBM（数据密集型产品的典范）
