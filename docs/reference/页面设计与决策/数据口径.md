## 历史决策

<a id="第1条"></a>

### 1 评价标准全公司一套，只有负责人能改

**分类**：业务　**状态**：有效，取代 10-24「阈值第一期写死在代码里」　**日期**：2026-10-24，2026-10-28　**拍板人**：阿禅
**背景**：每个人看到的颜色必须一致。
**决定**：评价标准全公司一套，不做按人配置；只有负责人能改，普通管理员只读；入口在本页「评价标准」，不放在视频复盘的筛选栏里。
**证据**：[视频复盘阈值与颜色分档补充单](../../archive/2026-11-09-A批文档治理/计划原稿/2026-11-09-计划收尾/2026-10-24-视频复盘阈值与颜色分档-补充单.md)；[10-28 日志](../../../日志/2026-10-28.md)；[评价标准本地验收](../../archive/2026-11-09-A批文档治理/参考原稿/2026-10-28-评价标准本地验收.md)。

<a id="第2条"></a>

### 2 异常提醒的线固定，不跟评价标准变

**分类**：业务　**状态**：有效（现行做法）　**日期**：2026-09-26 起　**拍板人**：待核
**背景**：原文只写「固定」，没写理由。
**决定**：视频复盘队列的异常提醒固定用播放 5000、2 秒跳出 30%、5 秒完播 50%、均播 30 秒、整体完播 5%，不随公司评价标准变。
**证据**：[作品评级链路·标准线与颜色](../链路设计与决策/作品评级链路.md#现行-颜色)。

<a id="第3条"></a>

### 3 页面上的数字只从一个地方读

**分类**：代码　**状态**：有效　**日期**：2026-10-15　**拍板人**：CC（规划方案）
**背景**：页面手写数字的话，代码改了页面没改，老板会拿着错的规则做决策，比没有说明更危险。
**决定**：口径页只读系统统一的口径常量，页面文案里不手写任何数字。
**后果**：评价标准的颜色阈值现在存在公司设置里，不在口径常量里，两处并存，改口径时两边都要看。
**证据**：[数据口径说明页与一致性修复](../../archive/2026-11-09-A批文档治理/计划原稿/历史-方案/2026-10-15-数据口径说明页与一致性修复.md)。
