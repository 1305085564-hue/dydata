## 历史决策

<a id="第1条"></a>

### 1 列表去掉「主要指标」，只留互动、留存、综合

**分类**：业务　**状态**：有效　**日期**：2026-11-16　**拍板人**：阿禅
**背景**：阿禅原话：「主指标直接去除吧，以后这个指标我们都用不上了。」全站已不再有「主指标」（见[作品评级链路第 1 条](../链路设计与决策/作品评级链路.md#第1条)）。
**决定**：选题库删掉「主要指标」，保留互动、留存、综合；点赞率、收藏率只作参考数据。
**证据**：[互动留存三档评级与主指标下线评审稿](../../archive/2026-11-18-计划归档/计划原稿/2026-11-16-互动留存三档评级与主指标下线-评审稿.md)。

<a id="第2条"></a>

### 2 首屏不放推荐卡，不做花哨入口

**分类**：设计　**状态**：有效　**日期**：2026-08-03，2026-08-15　**拍板人**：阿禅
**背景**：释放首屏高度，聚焦选题本身。
**决定**：顶部不放「今日聚焦」推荐卡，只保留团队最新认领和最新成片两块动态；不做独立的「近期高热」视图、AI 推荐前台入口、母题折叠和复杂显示偏好。
**证据**：[08-03 日志](../../../日志/2026-08-03.md)；[08-15 日志](../../../日志/2026-08-15.md)。

<a id="第3条"></a>

### 3 顶部三个视角：全部选题 / 我的选题 / 在写选题

**分类**：设计　**状态**：有效　**日期**：2026-08-29　**拍板人**：待核（写在「已确认的产品方向」段，没附阿禅原话）
**背景**：原文只写定义。
**决定**：「我的选题」是本人手动录入的题，「在写选题」是本人当前正在写的题。
**证据**：[选题库 V3 五批进度](../../archive/2026-11-09-A批文档治理/计划原稿/历史-报告/2026-08-29-Topics-V3-五批进度.md)。

<a id="第4条"></a>

### 4 「近 7 天热度」只算近 7 天真实参与的人

**分类**：业务　**状态**：有效　**日期**：2026-08-29　**拍板人**：待核（同上）
**背景**：不能拿历史累计认领数冒充 7 天热度。
**决定**：分别算近 7 天写过的人数和仍在写的人数，同一个人只算一次。
**后果**：选题池热度另有两套时间窗口没统一（2026-11-17 架构治理列为待阿禅拍板）。
**证据**：[选题库 V3 五批进度](../../archive/2026-11-09-A批文档治理/计划原稿/历史-报告/2026-08-29-Topics-V3-五批进度.md)。

<a id="第5条"></a>

### 5 去飞书创作一次点击直达，不弹确认

**分类**：业务　**状态**：有效　**日期**：2026-09-12　**拍板人**：阿禅
**背景**：原文没写理由。
**决定**：顺序固定为「复制提纲 → 标记在写 → 打开飞书」，成功不弹确认框；失败要明确说失败，不报假成功。
**证据**：[09-12 日志](../../../日志/2026-09-12.md)；[选题库接口文档](../选题库接口文档.md)。

<a id="第6条"></a>

### 6 不做站内播放、图片、原视频链接和站内编辑器

**分类**：业务　**状态**：有效　**日期**：2026-08-29　**拍板人**：阿禅
**背景**：阿禅原话：「直接不做站内视频弹窗播放，图片和链接也不要了。」
**决定**：选题确认后复制必要内容，打开团队固定的飞书空间，员工自己选文档写。
**证据**：[选题库 V3 五批进度](../../archive/2026-11-09-A批文档治理/计划原稿/历史-报告/2026-08-29-Topics-V3-五批进度.md)。
