## 一、场景 → 读哪个文件

| 我要做什么 | 读哪个文件 |
|---|---|
| 改权限、判断越权、RLS | [权限链路](链路设计与决策/权限链路.md)，再看该页面文件里的特例 |
| 改指标计算、判定逻辑 | [作品评级链路](链路设计与决策/作品评级链路.md#现行设计)、[数据上传链路](链路设计与决策/数据上传链路.md#现行设计)的「现行设计」 |
| 理解业务流程怎么流转、遇到异常怎么办 | [设计与决策](设计与决策.md)里对应链路的「现行设计」（上传、审批、评级等） |
| 定位模块、判断牵连、查已废弃机制、理解表关系和唯一规则来源 | [设计与决策总目录](设计与决策.md)、[工程底座·数据表关系](全站设计与决策/工程底座.md#现行-数据表) |
| 查性能预算、技术栈、部署、环境变量 | [工程底座](全站设计与决策/工程底座.md)（代码、性能）、[上线与运维](全站设计与决策/上线与运维.md)（部署、门禁、环境变量） |
| 写后端代码（查询 / 错误处理 / 缓存 / 重试 / 发布 / 告警） | [后端工程规范](全站设计与决策/后端工程规范.md) |
| 做前端界面（先读主卷 §0 内核 + §4 任务型路由，再按决策树走；冲突时以主卷为准） | [全站 / 效率美学](全站设计与决策/效率美学.md) → 需要数值与组件契约时查 [美学宝典](全站设计与决策/美学宝典.md) |
| 查当前待办、技术债 | [通用管理 / 待办清单](../通用管理/待办清单.md) |
| 会话交接 | [通用管理 / 上下文交接](../通用管理/上下文交接.md)。交接供续工，确认后的结论按用途写回原稿 |
| 文档归属、事实回写、证据归档 | [全站 / 文档与维护规范](全站设计与决策/文档与维护规范.md) |
| 判断某份材料是当前依据、历史还是待核 | [文档归口现状](文档归口现状.md) |
| 同一问题反复改、要查已沉淀的手势 | [全站 / 纠错索引](全站设计与决策/纠错索引.md) |
| 写 CLAUDE.md 或 AGENTS.md | [全站 / CLAUDE.md写作指南](全站设计与决策/CLAUDE.md写作指南.md) |
| 要测试账号、登录凭据 | 测试账号见本机的凭据文件（文件名为“测试账号.md”，不入库） |
| 查单个功能的接口契约、响应字段或已完成验收证据 | 先看[设计与决策](设计与决策.md)里对应页面文件的「入口、代码与验证」，已确认的证据在 `docs/reference/` 下按日期命名的记录 |
| 建立或维护模块地图 | 总览改[设计与决策](设计与决策.md)文件清单；模块的入口、唯一来源、不变量和验证写回该页面或链路文件的「入口、代码与验证」；全站性的写进[工程底座](全站设计与决策/工程底座.md) |
| 改某个页面前查已拍板的取舍、被取代的约束 | [设计与决策目录](设计与决策.md)：读该页面文件和它列出的链路文件 |
| 查性能历史实测与优化记录 | `docs/archive/`（只保留历史，不作施工依据） |
