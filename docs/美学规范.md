## 1. 色彩

### 行动色与位置色

| 色名 | 色值 | 职责 |
|---|---|---|
| 暖橙 | `#D97757` | 唯一行动色："去操作"。主按钮、链接、Tab 选中。Hover `#C46A4D` |
| 暴雨灰蓝 | `#43718E` | 唯一位置色："你在这"。侧栏选中、当前步骤、面包屑 |

两者不在同一组件混用。

### 状态色与行情色——命名隔离

系统状态与数据趋势用不同 CSS 变量，禁止跨领域引用：

| Token | 色值 | 语义 | 禁止 |
|---|---|---|---|
| `system.error` | `#DC2626` | 失败、拒绝 | 禁用于数据下跌 |
| `system.success` | `#16A34A` | 通过、完成 | 禁用于数据上涨 |
| `market.up` | `#DC2626` | 上涨/增长 | 仅限行情指标 |
| `market.down` | `#16A34A` | 下跌/减少 | 仅限行情指标 |

### 表达色

图表数据系列、分类标签：

| 色名 | 色值 |
|---|---|
| 苔藓深绿 | `#405740` |
| 紫罗兰 | `#7B6BA5` |

同一图表最多 2 表达色 + 暴雨灰蓝共 3 色。超过 3 系列拆图表。

### 灰阶

| 色值 | 用途 |
|---|---|
| `zinc-950` | 页面大标题、Hover/Active 态 |
| `zinc-800` | 正文、按钮文字、输入框已填 |
| `zinc-600` | 表头、时间戳、辅助说明（小字最低底线） |
| `zinc-400` | Placeholder、Disabled |
| `zinc-200` | 1px 分割线（仅限表格防串行） |
| `zinc-100` | Hover 衬底、标签背景 |
| `zinc-50` | 页面基底 |

## 2. 层次

4 层全局统一：

| 层 | 角色 | 色值 |
|---|---|---|
| L0 基底 | 页面大背景 | `zinc-50` |
| L1 容器 | 内容承载 | `white` |
| L2 边界 | 分隔 | 色差 + 间距（仅表格保留 1px 线） |
| L3 焦点 | 行动/状态 | 品牌色/状态色 |

靠色差与间距分层，阴影是最后手段。

---

## 3. 尺度

### 圆角

| 级别 | 类 | 像素 | 场景 |
|---|---|---|---|
| 行级 | `rounded-md` | 6px | 按钮、输入框、选择器 |
| 小容器 | `rounded-lg` | 8px | 小卡片、Badge、弹层 |
| 大容器 | `rounded-2xl` | 16px | 模态框、主卡片 |
| 胶囊 | `rounded-full` | — | 状态标签、头像 |

### 字号

| 元素 | 字号 | 字重 | 行高 |
|---|---|---|---|
| 页面标题 | 24px | 600 | 1.3 |
| 区域标题 | 18px | 600 | 1.3 |
| 正文 | 14px | 400 | 1.5 |
| 次级文字 | 13px | 400 | 1.5 |
| 标签/徽章 | 12px | 500 | 1.3 |

### 中文排版三条铁律

1. **等宽隔离** — 含中文容器禁止 `font-mono`，混排用 `tabular-nums`
2. **字重三锁死** — 600 仅限大标题；500 用于列表锚点/Badge；400 覆盖全站正文
3. **小字底线** — 所有可读文字用色不得浅于 `zinc-600`，`zinc-200` 严禁用于文字

## 4. 去盒子化

| 消灭 | 替代 |
|---|---|
| Tab/筛选套独立白卡 | 微气垫（`bg-zinc-100/70 p-1 rounded-xl`）+ 呼吸竖线 |
| 每个下拉带硬边框 | 透明底（`border-0 bg-transparent`） |
| 搜索框厚重边框 | 微胶囊（`bg-zinc-100/70`），聚焦白底微光 |
| 多层套娃卡片 | 至多 1 层业务实体微岛屿，内部纯排版 |
| 标题下横贯线 | 去线，用 24px 留白断层 |

## 5. 交互

三层反馈，时间线不重叠：

| 层 | 表现 |
|---|---|
| Hover | `hover:bg-zinc-100 hover:text-zinc-950`，`transition-all duration-150` |
| Active | `active:scale-[0.97]`，松手即消失 |
| Selected 常规 | 菜单 `bg-zinc-100`；Tab 微气垫；列表行 `zinc-50` |
| Selected 标题级 | `text-zinc-950` + `font-semibold` + `scale-[1.03]` |

主 CTA：暖橙实底 + 白字 + `shadow-sm`，每屏至多 1 个。

---

## 6. 数据表格

- 数字右对齐 + `tabular-nums`，空值显示「—」
- 复合信息单行内联，用「·」连接
- 行高 32~36px
- 宽屏平铺全部并行指标列，文本列弹性伸缩

---

## 7. 组件

**Toast**：仅在操作结果不可见时使用（结果可见则省略）。底部偏右，单行不超 20 字，3 秒消失。

**Tag**：最小点击高度 20px，`rounded-md`。

**图表标注**：贴线标注 > 独立图例。≥3 系列才引入图例。

**操作按钮**：核心操作常态可见（幽灵态），Hover 提亮；辅助操作平时隐藏，Hover 浮现；破坏性操作收至二级菜单。

**控制栏**：去框平铺，功能群之间用 16px 微竖线隔离。
