## 1. 色彩

### 行动色与位置色

| 色名 | 色值 | 职责 |
|---|---|---|
| 暖橙 | `#D97757` | 唯一行动色："去操作"。主按钮、链接、Tab 选中。Hover `#C46A4D` |
| 暴雨灰蓝 | `#43718E` | 唯一位置色："你在这"。侧栏选中、当前步骤、面包屑 |

两者不在同一组件混用。

### 状态色与行情色——命名隔离

系统状态与数据趋势用不同 CSS 变量，禁止跨领域引用：

| Token | 色值 | 语义 | 禁止 |
|---|---|---|---|
| `system.error` | `#DC2626` | 失败、拒绝 | 禁用于数据下跌 |
| `system.success` | `#16A34A` | 通过、完成 | 禁用于数据上涨 |
| `market.up` | `#DC2626` | 上涨/增长 | 仅限行情指标 |
| `market.down` | `#16A34A` | 下跌/减少 | 仅限行情指标 |

### 表达色

图表数据系列、分类标签：

| 色名 | 色值 |
|---|---|
| 苔藓深绿 | `#405740` |
| 紫罗兰 | `#7B6BA5` |

同一图表最多 2 表达色 + 暴雨灰蓝共 3 色。超过 3 系列拆图表。

### 灰阶

| 色值 | 用途 |
|---|---|
| `zinc-950` | 页面大标题、Hover/Active 态 |
| `zinc-800` | 正文、按钮文字、输入框已填 |
| `zinc-600` | 表头、时间戳、辅助说明（小字最低底线） |
| `zinc-400` | Placeholder、Disabled |
| `zinc-200` | 1px 分割线（仅限表格防串行） |
| `zinc-100` | Hover 衬底、标签背景 |
| `zinc-50` | 页面基底 |

## 2. 层次

4 层全局统一：

| 层 | 角色 | 色值 |
|---|---|---|
| L0 基底 | 页面大背景 | `zinc-50` |
| L1 容器 | 内容承载 | `white` |
| L2 边界 | 分隔 | 色差 + 间距（仅表格保留 1px 线） |
| L3 焦点 | 行动/状态 | 品牌色/状态色 |

靠色差与间距分层，阴影是最后手段。

### 2.1 容器边界四范式

原则（详见审美哲学 §4.1）：**主角裸铺，配角有壳，表格永远有壳。纸内无套娃。**

配角容器的"壳"不限于边线——底色差、留白、微竖线、色块都可以。以下四种范式覆盖全部场景：

| 范式 | 适用场景 | 实现方式 | 数值参考 |
|---|---|---|---|
| 微气垫 | 配角小卡片、统计面板、常态内容块 | 弱底色差，零边框 | `bg-zinc-100/70 rounded-lg p-4`，内部标题 `text-[14px] font-medium text-zinc-950`，辅助字 `text-[13px] text-zinc-600` |
| 表格防串行 | 数据列表、参数对照、审计日志 | 1px 细线框（全站唯一许可的边线场景） | `border border-zinc-200 rounded-lg`，表头 `bg-zinc-100/60 text-[12px] font-medium text-zinc-600`，行高 `h-9`，数值列 `text-right tabular-nums` |
| 呼吸断层 | 工具栏、控制群、视图切换 | 纯留白断层，彻底去框 | 容器 `bg-transparent`，组间 `gap-5`，按钮 `h-7 px-2.5 rounded-md hover:bg-zinc-100` |
| 状态色便签 | 待办预警、错误提示、临时说明 | 弱色底，左竖线可选，用完即撕 | `bg-red-50/80 rounded-lg p-4`（错误），`bg-amber-50/50 rounded-lg p-4`（预警），可选 `border-l-2 border-red-400`，文案 ≤ 20 字 |

**落地口诀：常规配角用微气垫，数据列表用细线框，工具栏用呼吸断层，临时便签用色弱底。**

## 3. 尺度

### 圆角

| 级别 | 类 | 像素 | 场景 |
|---|---|---|---|
| 行级 | `rounded-md` | 6px | 按钮、输入框、选择器 |
| 小容器 | `rounded-lg` | 8px | 小卡片、Badge、弹层 |
| 大容器 | `rounded-2xl` | 16px | 模态框、主卡片 |
| 胶囊 | `rounded-full` | — | 状态标签、头像 |

### 七级字阶与墨度五线谱

同字号靠“字重+墨深”拉开层级是维持高信息密度的秘密。字号、字重、颜色严格锁死，禁止越界：

| 层级 | 语义与场景示例 | 字号 | 字重 (防糊核心) | 墨度 (暗色参考) |
|---|---|---|---|---|
| **H1 页面级** | 页面大标题 (Page Hero) | `24px` | `600` (Semibold) | `zinc-950` (`zinc-50`) |
| **H2 区域级** | 侧边栏/抽屉主标题、独立面板 | `18px` | `600` (Semibold) | `zinc-950` (`zinc-50`) |
| **H3 容器级** | 卡片标题、弹窗(Dialog)标题 | `16px` | `500` (Medium) | `zinc-900` (`zinc-100`) |
| **H4 内容级** | 卡片内部子模块（如"数据范围"） | `14px` | `500` (Medium) | `zinc-900` (`zinc-100`) |
| **H5 辅助标头**| 表头(Table Header)、微型分组名 | `13px` | `500` (Medium) | `zinc-500` (`zinc-400`) |
| **Body 正文** | 列表数据、大段描述、输入框 | `14px` | `400` (Normal) | `zinc-800` (`zinc-300`) |
| **Caption 次级**| 次级副标题、时间戳、元数据 | `13px` | `400` (Normal) | `zinc-600` (`zinc-400`) |
| **Badge 微缩** | 状态徽章、极小提示、占位符 | `12px` | `500` / `400` | `zinc-500` / `zinc-400` |

### 中文排版禁令与铁律

1. **渲染与等宽隔离** — 全局强制开启 `antialiased` 抗锯齿以保证字阶清透；含中文容器禁止 `font-mono`，数字混排必须用 `tabular-nums`。
2. **字重防糊锁死** — `font-semibold (600)` 仅特许给 H1/H2 大标题使用，H3 及以下严禁使用 600；全站正文严禁脱离 400。
3. **小字可读底线** — 常规可读文字颜色不得浅于 `zinc-600`；`zinc-500` 与 `zinc-400` 仅限用于占位符、禁用态与微缩徽章。
4. **绝不妥协** — 禁止以"视觉平衡"或"均匀分布"为由，擅自打破空间留白语法与以上字阶关系。

## 4. 去盒子化

| 消灭 | 替代 |
|---|---|
| Tab/筛选套独立白卡 | 微气垫（`bg-zinc-100/70 p-1 rounded-xl`）+ 呼吸竖线 |
| 每个下拉带硬边框 | 透明底（`border-0 bg-transparent`） |
| 搜索框厚重边框 | 微胶囊（`bg-zinc-100/70`），聚焦白底微光 |
| 多层套娃卡片 | 至多 1 层业务实体微岛屿，内部纯排版 |
| 标题下横贯线 | 去线，用 24px 留白断层 |

## 5. 交互

三层反馈，时间线不重叠：

| 层 | 表现 |
|---|---|
| Hover | `hover:bg-zinc-100 hover:text-zinc-950`，`transition-all duration-150` |
| Active | `active:scale-[0.97]`，松手即消失 |
| Selected 常规 | 菜单 `bg-zinc-100`；Tab 微气垫；列表行 `zinc-50` |
| Selected 标题级 | `text-zinc-950` + `font-semibold` + `scale-[1.03]` |

主 CTA：暖橙实底 + 白字 + `shadow-sm`，每屏至多 1 个。

## 6. 数据表格

- 数字右对齐 + `tabular-nums`，空值显示「—」
- 复合信息单行内联，用「·」连接
- 行高 32~36px
- 宽屏平铺全部并行指标列，文本列弹性伸缩

## 7. 组件

**Toast**：仅在操作结果不可见时使用（结果可见则省略）。底部偏右，单行不超 20 字，3 秒消失。

**Tag**：最小点击高度 20px，`rounded-md`。

**图表标注**：贴线标注 > 独立图例。≥3 系列才引入图例。

**操作按钮**：核心操作常态可见（幽灵态），Hover 提亮；辅助操作平时隐藏，Hover 浮现；破坏性操作收至二级菜单。

**控制栏**：去框平铺，功能群之间用 16px 微竖线隔离。
