# 设计规范

> 本规范目标：让所有 AI 写出的前端代码在视觉上像同一个设计师的作品。
>
> **写法约束：** 每条规则只描述正确做法。AI 按正向描述执行比按否定清单排除更准确。
>
> **遵守优先级：** 设计方向 > 视觉骨架 > 组件规则 > 场景指南。冲突时高优先级裁决。

---

## 1. 设计方向

> **这一章是整个规范的"宪法"。** 当具体规则覆盖不到的场景，用这里的目标反推答案。规则是死的，目标是活的。

### 设计目标

冷灰纸感工作舱。以冷灰与冷白为基底（zinc 色系），构建如冷压纸张般的排版秩序。全站 95% 面积保持冷静灰阶，仅用极少的色彩作为视觉信号。对标世界级视觉品味，追求信息密度与呼吸感的平衡。用户打开就能用，上手即震撼，用完就合上。

一切设计与交互决策服务于三大终极目标：

1. **世界级视觉品味** —— 以极致色阶与通透层次呈现顶级大厂质感；让核心重点靠位置、留白、字号与字重自然”站出来”，周围的空白就是最好的聚光灯。
2. **人机一体的流畅交互** —— 超越单点动效，追求预判意图、连续无断点的心流体验与物理级掌控感，让全站每一次响应都如同直觉的延伸。
3. **零摩擦的高效体验** —— 清除一切认知噪音与繁琐路径，用最白话的表达与无缝回应，实现极低心智成本的极客级高效操作。

### 规范哲学

这份规范是设计师，也是底座。

- **定方向，不定路径** — 规范把控设计哲学与品味标准，实现路径由执行 AI 自主判断
- **设底座，不封上限** — 规范定义美学的下限，创意的上限由 AI 自己发挥
- **正向引导** — 每条规则描述正确做法，正向执行比否定排除更准确
- **理解优先** — 理解设计哲学后自由发挥，比逐条对照规则更有效

## 2. 视觉骨架

颜色和层次共同构成页面的视觉骨架。颜色按职责分组，层次按 4 层统一。

### 2.1 色彩系统

> **灰阶梯度优先** —— 暖橙负责行动引流，石青负责坐标定位，其余一律灰阶静默。

颜色按职责分组，不按色值平铺。每种颜色只承担一种语义，互不侵犯。

**行动色（暖橙 #D97757）—— 召回注意力："去操作"**

唯一行动色。告诉用户"这里是可交互的"。用于主按钮、链接、Tab 选中文字、Badge。Hover 态 #C46A4D。暖橙的价值在于精准——每次出现都承载明确的行动意图。

行为逻辑：暖橙按场景递减"重量"——主 CTA 实底按钮（最重）、链接文字变色（中等）、Badge 小色块（最轻）。同一语义，三种分量。禁用态：`--admin-action-disabled`（暖橙降灰，保留色相但降低饱和度+明度）。

**位置色（石青 #5F82A8）—— 静态坐标："你在这"**

唯一位置色。告诉用户当前位置。用于侧栏选中、当前步骤、面包屑当前位置。

暖橙负责引流交互（"去操作"），石青负责静态坐标（"在此处"），各有分工，不在同一组件混用。石青是安静的指示色——提供视线定轨，不承担交互引导。禁用态：`--admin-current-disabled`。石青只出现在位置指示，不出现在按钮或状态。

**状态色 —— "发生了什么"**

| 状态 | 色值 | 语义 |
|---|---|---|
| 错误/下降 | `#DC2626` | 失败、拒绝、下跌、违规 |
| 成功/增长 | `#16A34A` | 通过、完成、上涨、合规 |
| 警告/中性增长 | `#F59E0B` | 待处理、审批中、微量变化 |
| 信息 | `#2563EB` | 提示、链接、帮助 |
| 禁用 | `#A1A1AA` | 不可操作、已过期 |

涨 = 红，跌 = 绿（A 股惯例）。微量变化归入中性增长（警告色）。当数值波动无法区分涨跌方向时，同样归入中性增长。

行为逻辑：状态色承载业务判断，同一红色出现在状态灯和图表装饰上会让用户误判。状态色只在状态指示组件里出现，图表和分类标签用表达色。

**表达色 —— "区分同类"**

用于图表数据系列、分类标签、图标。6 个色，视觉重量均等（HSL 明度 45-55%，饱和度 55-70%）。

| 序号 | 色名 | 色值 |
|---|---|---|
| 1 | 绛红 | `#B84C5C` |
| 2 | 琥珀 | `#C4873B` |
| 3 | 青绿 | `#3D8B7A` |
| 4 | 深天蓝 | `#4A7FB5` |
| 5 | 紫罗兰 | `#7B6BA5` |
| 6 | 暖灰 | `#8A7F72` |

同一图表内最多使用 6 色。超过 6 条数据系列时拆分图表。表达色仅用于图表、标签和分类，不承载操作语义。

行为逻辑：表达色是"区分"语言，承担分类标记。6 色视觉重量与明暗均等，职责是清晰分辨平行维度（如"这条线与那条线"），为信息分类提供安静的底色。标签、图例、分类筛选器统一复用这 6 色。

**灰阶 —— 层次骨架**

| 用途 | 色值 |
|---|---|
| 页面背景 | `zinc-50` |
| 容器/卡片 | `white` |
| 边框/分割线 | `zinc-200` |
| 次级文字 | `zinc-500` |
| 正文 | `zinc-800` |
| 标题 | `zinc-900` |

### 2.2 层次系统

> **视觉层级** —— 多焦点并存时，必须有明确的主次——主要元素靠位置与留白自然突出，次要元素用灰阶静默后退。

4 层，全局统一。所有页面、所有组件遵守同一套层次逻辑。

| 层 | 角色 | 色值 | 出现位置 |
|---|---|---|---|
| L0 基底 | 页面大背景 | `zinc-50` | 整个页面 |
| L1 容器 | 内容承载 | `white` | 卡片、面板、内容区 |
| L2 边界 | 分隔 | `zinc-200` 1px 线 | 卡片边框、表格线 |
| L3 焦点 | 行动/状态 | 品牌色/状态色 | 按钮、选中态、状态灯 |

具体归属：
- **L0：** 页面背景 `zinc-50`、顶栏底色 `zinc-50`、Agent 左侧任务区 `zinc-100`
- **L1：** 内容区白色背景、卡片、弹窗内容区、表格区域
- **L2：** 卡片 `border-zinc-200`、表格行线 `border-zinc-200`、顶栏底部边线、分割线
- **L3：** 暖橙按钮、选中态变色、状态指示灯（红/绿/黄）、Badge

**顶栏：** `zinc-50` 浅冷灰底板，和内容区 `white` 有色差，天然分层，不需要分割线或阴影。

**Agent 页面特例：** 左任务区维持 `zinc-100` 浅灰衬底，右对话区维持 `white` 纯白底板。空间秩序统一：操作/控制区偏灰，内容承载区纯白。

层次靠色差与间距自然呼吸；阴影是最后手段，优先用色差和间距分层。1px 淡灰线仅用于结构裁切。

**悬浮微面板：** 二级/三级菜单（侧栏展开、上下文菜单）浮起时，白底 + `zinc-200` 1px 边框 + 8px 圆角 + `shadow-md`。明亮干净，层级清晰。

浮层（弹窗/下拉）可用 `backdrop-blur-xl bg-white/70`，Toast 用 `backdrop-blur-xl bg-zinc-900/50`。

## 3. 组件规则

选中态、间距、圆角、排版——组件怎么画。

### 3.1 选中与激活态

不同场景用不同表达，逻辑一致：**用最轻量的有效表达让用户知道"你在这"。** 灰阶优先，彩色用于信号；背景色差优于边框分割。每种场景找到"够用但不过分"的平衡点。

| 场景 | 选中态 |
|---|---|
| 分段控制器 | `zinc-100` 浅灰槽底包裹，选中项为实色胶囊滑块（`zinc-900` 黑底白字或白底黑字），选项间无分割线，靠滑块移动标示位置 |
| 悬浮菜单选项 | `zinc-200/70` 浅灰微高亮胶囊 + `zinc-900` 文字 |
| 顶栏一级导航 | 石青文字 + 底部 2px 石青指示条 |
| 列表行 | `zinc-50` 微灰底 |
| 按钮组 | 暖橙文字 + font-semibold |

**主 CTA 按钮：** 暖橙实底 + 白色文字，带 `shadow-sm` 浮起。每屏至多 1 个。

### 3.2 间距与圆角

基于 4px 网格。全站统一使用：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 px。

| 元素 | 圆角 |
|---|---|
| 按钮 | 4px |
| 输入框 | 4px |
| 卡片 | 6px |
| 浮层（弹窗/下拉） | 8px |

圆角越小越严谨专业，越大越圆润亲和。作为数据工具，全站统一微圆角（4px / 6px / 8px）。

### 3.3 文字排版

全站使用系统字体栈，不加载外部字体文件：

```css
font-family: -apple-system, BlinkMacSystemFont, 'PingFang SC', 'Source Han Sans CN', system-ui, sans-serif;
```

| 元素 | 字号 | 字重 | 行高 | 用途 |
|---|---|---|---|---|
| 页面标题 | 24px | 600 | 1.3 | 页面顶部主标题 |
| 区域标题 | 18px | 600 | 1.3 | 模块/区域标题 |
| 正文 | 14px | 400 | 1.5 | 主要内容文字 |
| 次级文字 | 13px | 400 | 1.5 | 辅助说明、时间戳 |
| 标签/徽章 | 12px | 500 | 1.3 | Tag、Badge、角标 |

字间距不额外设置，系统字体自带。

## 4. 场景指南

> **动效原则** —— 敏捷、无过冲、带有微小的物理阻尼感。显示即刻到位，退场干净利落，绝不让用户多等一帧。
>
> **键盘操控** —— 全站浮层与弹窗统一支持 `Esc` 阻尼收起；焦点切换清晰可预测，高频路径支持全键盘无缝直达。

### 4.1 顶栏导航

顶栏保持 `zinc-50` 浅冷灰底板，一级导航横向平铺，二级选项 hover 时平滑展开毛玻璃浮层。

选中态：石青文字 + 底部 2px 石青指示线。未选中态保持 `zinc-500` 次级文字色。

顶栏右侧放头像、通知等全局操作。

**面包屑：** 页面标题下方显示 `首页 > 模块 > 当前页面`。当前位置用石青文字。全站统一使用。

### 4.2 卡片与表格

**卡片：** 纯白纸感底板 + `zinc-200` 1px 极细边框 + 6px 微圆角。卡片内标题 18px/600，正文 14px/400。

**表格：** 表头背景后退（`zinc-50` 底 + `zinc-500` 文字 + 12px 字号）。数据行使用正文主色（`zinc-800`）。行间以 `zinc-200` 1px 极细线有序分隔。

### 4.3 图表

6 个表达色按序领用。坐标轴用 `zinc-400`，网格线用 `zinc-200` 极淡细线，数值标签保持 `zinc-500` 静默态。图表背景保持透明，继承容器纯白底板。

标注优先级：**贴线直接标注 > 独立图例**。单系列标注线尾，双系列左右分置，仅在 ≥3 系列时才引入独立图例。面积图渐变保持极淡通透（强度 40% → 5%）。

### 4.4 对话界面（Agent 页面）

左侧任务区维持 `zinc-100` 浅灰衬底，右侧对话区维持 `white` 纯白底板。空间秩序统一：操作/控制区偏灰，内容承载区纯白。

此页面为低频场景，样式复用全局 token 即可，不需要额外组件规范。

### 4.5 空白态

空白态是引导而非冷场。用单色极简线稿 + 白话因果说明 + 暖橙行动按钮。保持清晰秩序（标题 → 说明 → 引导按钮），有序呈现。

### 4.6 组件规格

**Toast：** 固定于右上角（导航下方，距右 16px）。8px 语义状态圆点 + 简短白话，单行不超过 20 字，3 秒平滑消失，同位置自动替换。

**Tag / Badge：** 最小点击高度 20px。Tag 使用 `rounded-full` 胶囊圆角，着色统一调取表达色。

**操作按钮：** 次要操作平时静默隐藏，hover 或聚焦时平滑浮出。保持平时界面纯净无噪，需要时随时响应。

**折叠面板：** 信息量大的页面（设置、详情）用可折叠分组，默认只展开当前需要的部分。用户按需展开，不被无关内容打扰。

## 5. 设计检查清单

新增页面前逐条核对：

1. **一屏一焦点** —— 这屏的主角是谁？有没有其他元素在抢？
2. **灰阶优先** —— 除了行动色和状态色，还有没有装饰性彩色？
3. **层次清晰** —— L0-L3 四层是否分明？有没有"全白"或"全灰"混成一片？
4. **暖橙精准** —— 行动色只在需要用户操作的地方
5. **选中态统一** —— 同类场景是否用了同一种选中表达？
6. **间距与圆角** —— 是否在 4px 网格上？按钮 4px、卡片 6px、浮层 8px 有没有混用？
7. **动效与键盘** —— 动效是否即刻到位无过冲？`Esc` 能否收起浮层？焦点是否可预测？
