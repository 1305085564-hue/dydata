# 抖音达人数据采集使用手册

> 当前采用「本地 Chrome + 社媒助手 + Codex 直连」方式。不会再启动新的浏览器，也不会重启你的日常 Chrome。

## 你怎么用

把抖音达人主页链接发给 Codex，例如：

```text
https://www.douyin.com/user/MS4wLjABAAAA...
```

Codex 会先打开独立 Chrome profile，第一次可能需要你在那个浏览器里手动登录和安装「社媒助手」：

1. 打开达人主页。
2. 唤起社媒助手。
3. 点击「采集本页视频」。
4. 自动滚动加载全部作品。
5. 确认采集。
6. 导出或生成 Excel 表格。

对应命令：

```bash
npm run douyin:collect -- --url="https://www.douyin.com/user/..."
```

## 文件保存位置

Excel 统一保存到：

```text
/Users/mac/Projects/dydata/output/douyin-exports/
```

## 重要说明

- 不下载视频原文件，只生成视频数据表。
- 不再使用旧的 `chrome:debug`，也不再要求你重新登录抖音。
- 如果社媒助手没有直接导出 Excel，Codex 会用页面上已经加载出来的作品卡片生成兜底 Excel。
- 兜底 Excel 包含：视频链接、标题、点赞数、话题标签、视频 ID、达人主页、原始文本。
- 兜底 Excel 不包含评论数、收藏数、转发数、发布时间等详情页字段。
