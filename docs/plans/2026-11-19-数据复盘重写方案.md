## 改了什么

| 位置 | 原来 | 现在 | 依据 |
|---|---|---|---|
| 页头 | 固定标题「数据复盘」+ 诗性导语（篇数、优良、榜首、异常都塞在导语里，部分可点） | 标题即答案：「11月18日 周三 · 23 篇，优 3 · 良 5」；筛选后「命中 5 / 23 篇」；区间「11月12日 – 11月18日 · 156 篇」（多页时不统计优良，避免拿一页冒充全部）；归档「归档 · 12 篇」。手机同样显示 | §2.1 |
| 重复状态 | 当天篇数在导语和日期按钮各说一遍；异常、只看优各有两个入口 | 篇数只在页头；日期按钮只写日期；异常只留工具栏「只看异常」；只看优走「评级」列排序或筛选 | §1.5 |
| 桌面列序 | 状态 → 标题 → 播放 → 涨粉 → 四项互动 → 五项留存 → 互动率 → 留存达成 → 评级 → 时间 | 作品 → **评级** → 播放 → 互动率 → 留存达成 → 涨粉 → 四项互动（完整视图）→ 五项留存 → 时间。先结论、再成因、后明细 | §1.4 |
| 状态列 | 每行一块徽标，正常作品也显示「正常」 | 删掉整列；只有删稿 / 限流 / 异常 / 未满24h 在标题前出徽标 | 定律 1 |
| 列定义 | 表头、表体各写一遍（出过第 14–16 列错位） | `content-list-columns.ts` 一份定义，表头表体都从它生成 | 一条规则一个来源 |
| 列悬停十字高亮 | 鼠标每移一格重渲染整表 | 删掉；改为当前排序列整列浅底（与协作管理同配方） | §2.3 |
| 负责人 | 悬停时标题浮层和负责人浮层叠两层 | 负责人不再单独出浮层，只有标题一个 | 浮层契约 |
| 手机卡片 | 状态 + 综合评级两枚徽标；指标为播放/涨粉/完播/互动率/点赞 | 评级字打头；指标与桌面同序：播放/互动率/留存达成/涨粉/完播 | §1.4 |

| 作者作品抽屉 | 头像圆、「创作者作品档案」标签、说明行、4 张带图标卡片、「✦ 档案完卷」；评级另写一套颜色，没评级的显示成「普」（错） | 名字 + 四个数字一行；时间/排序裸铺分段；列序与主表一致并加「留存达成」；评级统一配色，未评级显示「—」；出错时给正式按钮 | 定律 1、§3.9 |
