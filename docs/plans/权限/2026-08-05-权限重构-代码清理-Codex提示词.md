# 权限 V2 代码清理（较难）

## 背景

权限 V2 已合并到 main 且线上运行。但代码里残留了几类松散兼容写法，会导致类型系统形同虚设，也有两处引用已删除的旧权限 key `"edit_data"`。本次任务是一次性收紧这些松散点。

## 要做的事（4 项）

### 1. 收紧 `hasPermission` 函数签名

文件：`src/lib/permission-utils.ts`

当前：
```ts
export function hasPermission(
  role: import("@/types").UserRole | string | undefined,
  permissions: import("@/types").Permissions,
  key: import("@/types").PermissionKey | string,
): boolean
```

改为：
```ts
export function hasPermission(
  role: import("@/types").UserRole | undefined,
  permissions: import("@/types").Permissions,
  key: import("@/types").PermissionKey,
): boolean
```

同文件内所有其他导出函数的 `role` 参数也做同样处理——去掉 `| string`。

### 2. 收紧 `Permissions` 类型

文件：`src/types/index.ts` 第 24 行

当前：
```ts
export type Permissions = Partial<Record<PermissionKey, boolean>> & Record<string, boolean | undefined>;
```

改为：
```ts
export type Permissions = Partial<Record<PermissionKey, boolean>>;
```

### 3. 替换 `"edit_data"` 引用

文件：`src/app/(app)/admin/actions.ts`

第 323 行和第 339 行：
```ts
if (!hasPermission(perm.role, perm.permissions, "edit_data")) return { error: "无权限" };
```

替换为：
```ts
if (!hasPermission(perm.role, perm.permissions, "review_content")) return { error: "无权限" };
```

（`edit_data` 已从系统中删除；这两处是编辑/删除日报的权限检查，对应新权限体系中的 `review_content`。）

### 4. 修复因以上改动导致的编译错误

前三步改完后跑 `npx tsc --noEmit`。预期会在测试文件和少量业务文件中报错，原因是：

- 使用了旧 key 字符串（`view_all_data`、`edit_data`、`manage_violations`、`view_conversion_hub`、`view_content_review`、`manage_video_assets`、`use_ai_copywriting`、`use_ai_management`）
- 给 `role` 参数传了任意字符串而非 `UserRole` 联合

修复规则：
- `view_all_data` / `edit_data` → 删除该行（不再是权限 key）
- `manage_violations` → `review_violations`
- `view_conversion_hub` → `view_conversion`
- `view_content_review` → `review_content`
- `manage_video_assets` → `manage_videos`
- `use_ai_copywriting` → `use_ai_copy`
- `use_ai_management` → `use_ai_assist`
- `role` 参数如果传了 `"team_admin"` 或 `"group_leader"` 等旧值 → 改为 `"admin"` 或 `"member"`

**特殊文件**：`src/lib/data-access-scope.ts` 第 45 行有 `permissions?.view_all_data`。这是数据库尚未跑 migration 时的兼容逻辑。在行末加注释 `// TODO: remove after migration confirmed`，不要删除此行。

**`src/lib/publish-drafts/types.ts`**：`PublishDraftBusinessRole` 类型里有重复的 `"admin"`，改为 `"owner" | "admin" | "member"`。`BUSINESS_ROLE_SET` 也同步修改（删去重复项）。
