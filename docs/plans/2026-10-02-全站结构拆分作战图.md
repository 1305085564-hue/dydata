## 1. 排名方法与可复现输出

排名使用仓库已跟踪的 `src/**` 文件。行数为当前 `wc` 等价计数，改动次数为 `git log --since='90 days ago' --format=%H -- <file>` 的提交数；测试接缝为测试文件对该文件路径/文件名的直接引用。评分定义为 `行数 × 90 天改动次数 × 接缝系数`，已有接缝=1，无接缝=0.5；这样无接缝文件不会因为缺测试而被隐藏。实际命令：

```sh
python3 - <<'PY'
import subprocess,pathlib,re
files=subprocess.check_output(['git','ls-files','src'],text=True).splitlines(); tests=[]
for tf in files:
  if re.search(r'\.(test|spec)\.(ts|tsx|js|jsx)$',tf): tests.append((tf,pathlib.Path(tf).read_text(errors='ignore')))
rows=[]
for f in files:
  p=pathlib.Path(f)
  try: lines=sum(1 for _ in p.open())
  except: continue
  changes=len(subprocess.check_output(['git','log','--since=90 days ago','--format=%H','--',f],text=True).splitlines())
  refs=[tf for tf,t in tests if f in t or p.name in t or p.stem in t]
  seam='有' if refs else '无'; score=lines*changes*(1 if refs else .5)
  rows.append((score,lines,changes,seam,f))
for i,(score,lines,changes,seam,f) in enumerate(sorted(rows,reverse=True)[:12],1):
 print(f'{i:02d}\t{f}\t行={lines}\t90天改动={changes}\t测试接缝={seam}\t评分={score:.0f}')
PY
```
