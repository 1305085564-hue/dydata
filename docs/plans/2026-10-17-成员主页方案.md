# 成员主页（成长档案）产品设计方案

> **设计定位**：为“人”提供一份完整的成长与实战表现档案——回答“他现在干得怎么样、擅长什么、在变好还是变坏”。  
> **设计方法**：基于目标导向设计（Goal-Directed Design），彻底消除“页面跳飞”与“两套卡片”的割裂感，兼顾管理就地查看与外部专属分享。  
> **状态**：方案定稿，待施工拆解（CX 承接数据与接口，An 承接视觉与组件）。

## 一、用户真实目标与痛点对账

### 1. 真实角色与目标（End-Goals）

| 角色 | 核心使用场景 | 真实目标（End-Goal） | 现有阻碍（Excise 垃圾动作） |
| :--- | :--- | :--- | :--- |
| **主管 / 阿禅** | 在数据管理大盘排查小队或岗位表现 | 快速评估某个成员近半年的成长趋势与胜任题材，做出排期/考核决策 | 抽屉只有当月数据和 30 天，想看趋势要自己翻历史月拼凑；点名字跳走又打断当前大盘审查心流 |
| **管理协同** | 主管在飞书/微信/会议中向阿禅或组长汇报 | 一键指代某个成员的完整战报，不截几十张碎图 | 抽屉无法复制直达链接，只能截图或口头报数 |
| **组员本人** | 关注自己的近期表现与历史代表作 | 了解自己的优势题材，看自己是在进步还是退步 | 权限上只能在受限大盘找自己，缺乏沉浸式个人画像 |

### 2. 核心设计原则（不割裂、零跳飞）

1. **一套档案，双重视图（In-place + Direct URL）**：
   * **站内默认就地展开（抽屉视图）**：在数据管理、四榜单、小队详情等任何地方点击人名，**原地滑出全量成长档案抽屉**（宽度可宽幅展开），视线不离座，背景大盘不丢失。
   * **外部直达/独立查看（页面视图）**：打开 `/people/[userId]` 时，以通透的独立档案页呈现，具备完整的 URL 状态，支持复制链接、微信/钉钉分享与组员直达。
   * **组件完全同构**：内部核心渲染卡片 (`PersonProfileContent`) 100% 共享，维护同一套逻辑与视觉。
2. **彻底废除双重卡片**：
   * 废除原有“阉割版当月抽屉”+“完整版主页”的双重概念；
   * 点开人名就是**完整档案**，头部首屏即是当月成绩，往下滚动/切换即是长期趋势。

## 二、产品形态与交互心流

### 1. 站内查看心流（就地展开）
```
[数据管理 / 榜单 / 成员列表]
       │
       ▼ 点击人名
[原地滑出宽幅档案抽屉（URL 同步追加 ?personId=xxx）]
       │
       ├── 顶部工具栏：[复制分享链接] [新标签页打开] [关闭]
       ├── 第一屏：人物身份概览 + 本月实战战报（同源榜单）
       ├── 第二屏：6 个月成长轨迹（作品数 / 条均播放 / 良优率）
       ├── 第三屏：题材与形式胜任力（擅长什么、哪类拉垮）
       └── 第四屏：巅峰代表作（3~5 篇，点开进作品详情二级抽屉）
       │
       ▼ 按 Esc 或点击空白
[抽屉收起，URL 干净回退，大盘筛选和滚动位置 0 丢失]
```

### 2. 外部直达与组员心流（独立链接）
* 访问路径：`/people/[userId]`
* 页面呈现：全屏工作室画卷（极净暖白底 `L1` + 居中定宽卡盘），自上而下阅读，沉浸、从容、有装帧感。
* 权限拦截：组员仅能看自己，主管可看其可见团队成员，越权直接原地呈现安静的无权限提示。

## 三、档案结构与内容模块（自上而下）

### 模块 1：人物身份章印（Profile Header）
* **定位**：明确“他是谁、什么角色、在职状态”。
* **内容要素**：
  * 姓名（Sans 18px / 500 / `#141413`）
  * 岗位身份印章（一人可多岗：达人 / 文案 / 剪辑 / 运营，淡暖橙底 `bg-[#D97757]/10 text-[#D97757]`）
  * 所属小队 / 团队标签
  * 在职状态（在职 / 已归档；归档用信号灰 `#78716C` 标注）
  * 右侧快捷操作：`[复制主页链接]`、`[新窗口打开]`

### 模块 2：当月战报（Current Month Scorecard）
* **定位**：快速交代“本月干得怎么样”，与数据管理当月四榜单完全同源同口径。
* **核心指标组合（紧凑数字排版，20px 指标大数）**：
  * **产能与触达**：作品数（条）、总播放（万）、条均播放（万）
  * **质量与转化**：综合良优率（%）、互动率（%）、转粉率（%）、完播/转评赞比率
* **状态提示**：若当月无数据或缺快照，比率明确显示 `—`，绝不假造为 0%。

### 模块 3：成长轨迹（6-Month Growth Trend - 档案核心）
* **定位**：彻底解决原抽屉只能看 30 天的硬伤，回答“最近半年是向上走还是向下走”。
* **交互与展示**：
  * 切换 Tab：**「条均播放」**（影响力）、**「综合良优率」**（稳定性）、**「月度产出」**（工作饱和度）
  * 表现形式：平滑趋势曲线或温润柱状图，标示 6 个月走势，虚线指示团队平均线或基准线。
  * 洞察边注：系统根据斜率给出一行极简判断（如：“近 3 个月条均播放持续攀升，良优率稳定在 65% 以上”）。

### 模块 4：题材与形式胜任力（Strengths & Focus）
* **定位**：回答“他擅长做什么”，给派活排期、带教考核提供直接依据。
* **维度拆解**：
  * 按题材分类（如：剧情搞笑、干货测评、情感共鸣、日常 Vlog 等）
  * 分组度量：作品总数、条均播放量、良优率
  * 视觉强化：良优率最高的题材标为“优势题材”，明显拉垮的标为“待提升”，主管一眼看透。

### 模块 5：巅峰代表作（Milestone Works）
* **定位**：展示该成员实战天花板。
* **呈现规格**：
  * 筛选出历史评级最优的 3~5 篇作品（优 / 良优先，按播放量排序）；
  * 封面微缩图 + 标题 + 发布日期 + 播放量 + 评级徽章（优/良/平/差）；
  * **交互闭环**：点击代表作，原地滑出**作品详情二级抽屉**，不离座即可复盘作品数据与原视频。

## 四、数据口径与同源铁律

严格遵守 DYData 业务规则，严禁前端重新造轮子或私自算数：

1. **作品归属口径**（严格复用 `report-rules.ts`）：
   * 达人：名下绑定的抖音账号产出的作品；
   * 文案：日报中署名为文案的作品（包含自己账号）；
   * 剪辑 / 运营：日报中署名对应角色且非本人名下账号的作品。
2. **综合评级与良优率**：
   * 统一读取 `breakout-rating.ts` 现行常量与播放门槛，禁止页面写死数字。
3. **三率计算**：
   * 汇总数据必须遵循“先加总再相除”，调用统一的 `video-metrics` 计算方法，确保与数据管理榜单分毫不差。
4. **禁止死灰复燃**：
   * 严禁复活已废弃的“六维能力雷达图”和“加权互动率”。

## 五、权限与安全边界（只读隔离）

| 访问主体 | 权限边界 | 越权防护策略 |
| :--- | :--- | :--- |
| **组员本人** | 仅允许查看自身的档案 | 打开其他人员 URL，直接拦截并呈现“暂无权限查看此成员档案” |
| **主管 / 所有者** | 允许查看所管辖团队内的成员档案（`visibleUserIds` 范围） | 页面与抽屉数据加载由后端统一校验 `visibleUserIds`，不靠前端隐藏入口防越权 |
| **已归档成员** | 历史数据只读保留，供复盘与追溯 | 顶部明显挂印“已归档”灰色标签，停用“当月战报”，走势图锁定至归档当月 |

## 六、视觉与排版设计规格（Claude 设计规范适配）

严格执行《Claude设计哲学》与《Claude设计规范》，杜绝通用后台粗糙感：

1. **色彩与单光控制**：
   * 背景为极净温润暖白（`L1`）；
   * 全屏至多一处实体聚光灯主色（暖陶土橙 `bg-[#D97757]`），仅给主动作（如“复制链接”成功或核心切换）；
   * 标签与状态一律采用**极淡透明底 + 同色墨字**（如：优级作品用淡绿底绿色字，岗位印章用淡橙底），严禁大面积饱和色块。
2. **字阶与墨度封闭**：
   * 姓名：Sans 18px / 字重 500 / `#141413`；
   * 指标大数：Sans 20px / 字重 500 / `#141413`；
   * 模块标题：Sans 14px / 字重 500 / `#1F1E1D`；
   * 数据与正文：Sans 13px / 字重 400 / `#1F1E1D`；
   * 表头与说明：Sans 12px / 字重 400 / `#78716C`；
   * 空值信号：Sans 12px / `#A8A29E`（严格使用 `—`）。
3. **排版呼吸律**：
   * 配角直接裸铺，严禁外围控件再套厚重 Card；
   * 模块之间使用留白断层（24px）与单像素发丝线（`border-stone-200/60`）划分，拒绝“卡片套卡片”的电路板感。

## 七、分期交付规划

### P1（核心闭环，本次落地）
* 宽幅档案抽屉（`PersonProfileSheet`） + 原地滑出与 URL 静默同步；
* 独立档案路由（`/people/[userId]`），支持分享与直达；
* 核心五模块：人物印章 + 当月战报 + 6 个月走势 + 题材胜任力 + 巅峰代表作；
* 代表作点击打通二级作品详情抽屉。

### P2（后续迭代与深化）
* 同岗位分位定位（在文案/剪辑团队中处于前 10% 还是中游）；
* 最佳协作搭档（与哪个文案/剪辑搭档时作品爆款率最高）。
