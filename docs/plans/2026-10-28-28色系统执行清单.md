## 三、AI执行路径(不查色表)

### 当前任务:写一个"播放量上涨"的文字

**旧路径(查色表):**
```
1. 判断"这是成功语义" 
2. 打开《规范》§2.2
3. 在表格里找"成功对应的hex" → #6FAA7D
4. 写 text-[#6FAA7D]
```

**新路径(决策树):**
```
1. 判断"这是成功语义" → success
2. 判断"这是文字角色" → -text
3. 拼出 text-status-success-text
```

**对比:**
- 旧:1个判断+1次查表+记住hex
- 新:2个判断+0次查表+不记hex

## 六、约束重申

1. **状态色不上实底** — 见《哲学》原则4"单点聚光灯"
2. **异常文字统一用正文墨** — `text-status-danger-text`实际是`#1F1E1D`
3. **状态淡底默认用独立hex；同一语义需要 2–3 档强度时，允许用主色的 /5、/8、/10 透明度，不新增 hex** — 新组件默认单一档；存量多档按原强度保留，见《哲学》原则1"封闭系统"
4. **弱圆点不可删** — 正常状态的视觉定位锚点,见《哲学》原则2"同档内分层"
5. **表格选中底不合并** — `bg-surface-selected`与`bg-surface-row-hover`是两种状态
