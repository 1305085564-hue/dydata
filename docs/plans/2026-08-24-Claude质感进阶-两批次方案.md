| 批次 | 主题 | 内容 | 为什么放一起 |

## 改造项一：去盒化裸铺（本批次最重要）

### 要消灭什么
页面区块被装进白色圆角矩形的写法，典型长相：

    <div className="rounded-2xl border border-[#E5E0D6] bg-white p-6">

### 判断标准（对每个盒子问一次）
**这个盒子删掉，里面内容会散掉吗？**
- 不会散（统计区、说明区、表单区、图表区）→ **去掉壳**，改用留白/发丝线分隔
- 会散（数据表格、浮层、临时便签）→ **保留壳**

### 怎么改
去掉 `bg-white`、`border`、`rounded-2xl`、`p-6`，改成规范 §6.2 的分隔手段，
按优先级从高往低选：

    1. 大留白断层    gap-10（40px），强断层 gap-12（48px）
    2. 单条发丝线    border-b border-[#ECE7DE]/80 pb-10
    3. 弱底色微气垫  bg-[#F5F3EE] rounded-lg p-4（零边框）
    4. 边框          仅表格与浮层可用

示例：

    ❌ <div className="rounded-2xl border border-[#E5E0D6] bg-white p-6">
         <h2 className="text-lg font-semibold text-[#1C1917]">本周概览</h2>
         <div className="mt-4">...</div>
       </div>

    ✅ <section className="border-b border-[#ECE7DE]/80 pb-10">
         <h2 className="text-lg font-semibold text-[#1C1917]">本周概览</h2>
         <div className="mt-6">...</div>
       </section>

注意：外壳 padding 去掉后，内部原有的 `mt-4` 要按四级留白语义升到 `mt-6`（呼吸）。

## 改造项二：状态色全面降饱和（聚光灯法则）

### 目标
一屏之内只允许**一个**饱和色焦点——那唯一的主 CTA（`bg-[#D97757]`）。
其余所有彩色一律降级为「低饱和字色 + 微透明底」。

### 照表替换（规范 §6.8）

| 语义 | 改成 |
|---|---|
| 成功 / 正常 | `text-[#6FAA7D] bg-[#6FAA7D]/10` |
| 警示 / 待处理 | `text-[#B98A54] bg-[#B98A54]/10` |
| 异常 / 失败 | `text-[#C0685C] bg-[#C0685C]/10` |
| 中性 / 已归档 | `text-[#78716C] bg-[#F5F3EE]` |

### 特别注意
- **红涨绿跌不变**：行情涨跌色是业务语义，保持现有涨红跌绿方向，只把饱和度
  按上表降下来，不要把涨跌反过来。
- 次要按钮、次要链接、Tab、标签的彩色一律收缴，回归墨阶
  （`text-[#292524]` / `text-[#78716C]`）。
- 一个页面里如果有两个 `bg-[#D97757]` 实底按钮，留最主要那一个，
  另一个降为幽灵态（`text-[#D97757]` 无底色）。

### 自检
    grep -rE "bg-(green|red|blue|amber|yellow|emerald|sky|indigo|violet)-[45678]00" src/
    grep -rE "text-(green|red|blue|amber|yellow|emerald|sky|indigo)-[5678]00" src/
命中的每一处都要处理干净。

## 改造项一：阴影 Token 化（先做这个，后面要用）

### 第一步：在全局 CSS 定义两个 Token

在 `globals.css` 的 `:root` 里加（规范 §6.3）：

    --shadow-claude-float:  0 1px 3px rgba(0,0,0,0.02), 0 8px 24px -4px rgba(28,25,23,0.05);
    --shadow-claude-dialog: 0 1px 3px rgba(0,0,0,0.02), 0 12px 32px -4px rgba(28,25,23,0.06);

在 `tailwind.config.ts` 的 `theme.extend.boxShadow` 里加：

    'claude-float':  'var(--shadow-claude-float)',
    'claude-dialog': 'var(--shadow-claude-dialog)',

### 第二步：全站替换硬阴影

| 组件类型 | 改成 |
|---|---|
| Dropdown / Popover / Tooltip / Select 面板 | `shadow-claude-float` |
| Dialog / Modal / Drawer / Sheet | `shadow-claude-dialog` |

必须清零：`shadow-lg`、`shadow-xl`、`shadow-2xl`、以及任何自己写的
`box-shadow: 0 10px 15px...` 硬阴影。

`shadow-sm` 保留不动（主 CTA 按钮在用，规范 §4.3 要求）。

自检：`grep -rE "shadow-(lg|xl|2xl)" src/`

## 改造项二：物理阻尼动效

按规范 §6.4 逐项落地：

| 场景 | 改成 |
|---|---|
| 所有可点击按钮的按压 | `active:scale-[0.985] active:duration-75` |
| 抽屉 / 折叠面板 / 手风琴展开收起 | `duration-300 ease-[cubic-bezier(0.16,1,0.3,1)]` |
| 所有输入框、按钮、可聚焦元素的键盘聚焦 | `focus-visible:ring-1 focus-visible:ring-[#D97757]/30 focus-visible:ring-offset-2 focus-visible:ring-offset-[#FBF9F5]` |
| 常规 hover 过渡 | `duration-150`（前批次已达标，别改） |

注意：
- 原来写 `active:scale-[0.98]` 的改成 `[0.985]`（更含蓄）。
- 聚焦光晕必须用 `focus-visible` 而不是 `focus`，否则鼠标点击也会出现光圈。
- **不要删掉任何 `focus-visible` 样式改成完全无反馈**，那是可访问性倒退。

自检：`grep -rE "focus:ring|active:scale-\[0\.9[0-7]\]" src/`

## 改造项六：文案去工业化

按哲学 §7.4 梳理界面微文案。**只改展示给用户看的字符串，不改任何变量名、
key、日志、注释。**

| 改掉 | 改成 |
|---|---|
| 请填写 XXX（必填） | 输入 XXX |
| 操作成功 / 操作已成功完成 | 删掉 Toast（详见下方） |
| 系统检测到异常 | 发现 N 条异动 |
| 请配置参数 | 设置 XXX |
| 批量标记 | 标记选中项 |
| 保存成功！ | 已保存（去掉感叹号） |

规则：去掉「请 / 系统 / 成功 / 操作」这类机器词；能陈述事实就不下命令；
全站禁用感叹号。

### Toast 精简（谨慎，这条最容易改错）

只删「结果已经肉眼可见」的成功 Toast：

    ❌ 该删：删除后列表已刷新，还弹「删除成功」
    ❌ 该删：编辑后数值已就地更新，还弹「保存成功」
    ✅ 必须留：提交后台任务、导出文件、发送通知等结果不可见的操作
    ✅ 必须留：所有失败 / 错误 Toast，一个都不许删

判断方法：这次操作后，用户在屏幕上能直接看到变化吗？能看到 → 删 Toast。

`Cmd+K` 命令盘、`J/K` 行间穿梭、`Esc` 收起——涉及全局事件监听、快捷键冲突、
路由跳转、焦点管理，是逻辑活不是审美活。两批次验收通过后单独派 Codex。

## 执行顺序

1. 新对话发**批次六提示词**给 Antigravity
2. 它交付后，发**验收元提示词 + 批次六提示词**给 Codex
3. 有返工项 → 把 Codex 报告丢回 Antigravity 修 → 再验；零返工 → 进批次七
4. 批次七同上流程
5. 两批通过后，键盘流单独派 Codex
