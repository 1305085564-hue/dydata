# 二、施工包详情

## 4A · 公共 UI primitive 与视觉 token 收口

- 目标：Button/Input/Select/Table/Toast/ErrorState/状态色/字体等公共基元回到统一规范。
- 包含问题：P2-04；F-09、F-10、F-11、F-13、F-14、F-15、F-17、F-18、F-24、F-25。
- 不包含范围：不拍板品牌风格；不一次迁移全站所有手写 table；纯视觉交 Antigravity。
- 预计影响模块：`src/components/ui/*`、tokens、topics toast、后台表格、错误状态组件。
- 依赖关系：等 3C；可拆成 Button/Input/Select、Table、Toast/ErrorState、状态色四个小包。
- 风险等级：中。
- 当前状态：未开始。
- 开工前计划：先改公共基元，再迁移页面引用；每个小包做受影响页面浏览器抽查。
- 完成标准：公共组件不再含已知规范违例；迁移页面无明显回归；纯视觉变更有 Antigravity 或用户确认。
- 当前进度：未开始。
- 下一步：决定是否交 Antigravity 做视觉 token 细节。

## 4B · 页面版心、局部布局、历史组件和死分支清理

- 目标：低风险页面布局和历史前端组件清理，不让旧分支继续误导施工。
- 包含问题：P2-05；F-05、F-06、F-07、F-12、F-19、F-22、F-26。
- 不包含范围：不重做 `/growth` 或 `/content-tools/rewrite`；不直接删除仍有类型引用的文件。
- 预计影响模块：`/topics`、`/content-tools/rewrite`、`/admin/fulfillment`、豁免旧弹窗、暗色模式死分支、无引用组件。
- 依赖关系：等 3A/3B，避免版心/布局交叉冲突。
- 风险等级：低。
- 当前状态：未开始。
- 开工前计划：逐项查 route、import、测试、类型引用和外部手动触发；局部布局只做最小对齐。
- 完成标准：已确认死代码安全清理；`data-manager.tsx` 类型引用处理完再删；低风险版心问题浏览器通过。
- 当前进度：未开始。
- 下一步：清理前重新生成引用清单。

## 4C · A-E 遗留 P2 体验和清理尾巴

- 目标：处理非核心交互体验、死字段、旧路由、刷新尾巴和通知现状复核。
- 包含问题：P2-01、P2-02；D-11、D-14、E-03、C1/C3/C4/C5/C6/C7/C8、B2、B6。
- 不包含范围：不处理已归入第三阶段的 F-P1；不改业务口径未确认项。
- 预计影响模块：日报作废口径、豁免旧字段、刷新路径、发布管理快捷确认、rewrite、成员弹窗、topics 创建/导入、视频删除确认、协作展开表。
- 依赖关系：回收站/作废是否扣实发需要阿禅确认；通知 feed 下线后现行链路需复核。
- 风险等级：低。
- 当前状态：未开始。
- 开工前计划：先问清口径和现行通知链路，再拆小包修。
- 完成标准：每个低风险项有明确修复或“不改原因”；浏览器抽查覆盖受影响页面。
- 当前进度：未开始。
