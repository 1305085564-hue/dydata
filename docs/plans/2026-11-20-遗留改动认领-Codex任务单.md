## 二、怎么分类

每个文件、每笔提交都归进下面五类之一，并附证据（命令和输出，或日志原文）：

| 类 | 判据 | 处理 |
|---|---|---|
| A 已在线上 | 内容与 `origin/main` 相同 | 不用处理 |
| B 已被线上取代 | 线上之后有提交改过同一处，或日志写明该处已重写或撤销 | 不用处理，写明是哪笔提交、哪条日志 |
| C 未上线的有效改动 | 能在 `日志/` 里找到对应任务，线上没有，而且改动本身完整 | **不合入**，写清属于哪个任务、哪个 Agent、改了什么，附一句建议（合 / 不合，理由） |
| D 来历不明 | 找不到对应任务或作者 | 不合入，列出 |
| E 个人文件 | 不属于项目的东西（例如根目录的 html 小实验） | 不合入，写明备份位置 |
