# 交互体验升级：现状对照与真实清单

> 本文档对照外部报告的 8 项方案与 DYData 实际已完成的功能，输出"真正要做的清单"。

## 一、反重力纠正的核心问题

外部报告质量很高，但有三大问题：

1. **很多功能已经做完了**（表格对齐、截图常驻、全局贴图、审批撤回、视频复盘网址同步）
2. **有些建议直接踩红线**（审批不做独立页、操作不藏悬停、卡片不放履约统计）
3. **真正卡的点漏了**（发布管理翻月 48 秒、协作管理卡顿、缺失截图闪"点击重试"）

## 三、待办清单里"真正卡的点"

外部报告漏掉了三个用户真正体感"卡"和"烦"的大头：

### 1. 发布管理翻月性能：约 48 秒
- **现状**：本地 3000 端口连接生产库实测切换上个月的日历读取约 47.8 秒
- **用户体感**：翻月等待过长，前端加载态可用但等待难忍受
- **证据**：[待办清单](../plans/待办清单.md#业务待办)

### 2. 协作管理页卡顿
- **现状**：首屏和个人档案打开慢、同一数据重复加载、悬停提示叠成多层不消失
- **用户体感**：阿禅截图为证
- **证据**：[待办清单](../plans/待办清单.md#业务待办)

### 3. 缺失截图先闪约 1.8 秒"点击重试"
- **现状**：缺失截图会先闪约 1.8 秒"点击重试"再变"原图已丢失"
- **用户体感**：闪烁让人以为系统出错
- **证据**：[待办清单](../plans/待办清单.md#架构整改残余)

## 四、踩红线的建议（不能做）

### 1. 审批工作台改成"左列表右详情分栏"
- **外部建议**：左队列右详情、顺手附近 7 天履约小日历和本月已豁免次数
- **红线**：审批工作台第 1 条"不做独立审批页面，审批只在导航栏待办面板里做"（面板宽度放不下左右双栏）

### 2. 操作藏进右键菜单或悬停才出现
- **外部建议**：Linear 右键菜单、Raycast 悬停更多
- **红线**：美学宝典 §3.1"操作列常显，不做「悬停才出现」——触屏点不到，用户也得猜哪里能点"

- **外部建议**：Vercel 亮点"不提前置灰提交按钮"
- **红线**：数据上传（工作台）第 2 条"发布时间一确定，提交按钮就提前变成「提交审批」并写明原因"
- **可行做法**：补"缺必填项时点击能直接跳到漏填格并提示"，但不能把提前预警拆掉

### 4. 截图对照栏把整页拉宽
- **外部建议**：左右分栏
- **红线**：数据上传（工作台）第 5 条"页面外框保持 1024、表单位置不变；屏幕不窄于 1330 时，对照栏伸进右侧页边留白显示"

## 六、顶尖产品拆解的可借鉴亮点（补强机制）

### 1. Linear 右键菜单 + 安全三角区
- **适用场景**：作品大表、审批列表
- **红线**：只能当熟手的额外锦上添花，不能替代常显操作按钮
- **落地方式**：作为 P1 或 P2 的增强项，不单独立项

### 2. Vercel 隐形稳态规范
- **适用场景**：全站
- **内容**：等宽数字对齐、150-300ms 防闪烁加载、报错自动跳焦、抽屉滚动隔离
- **落地方式**：作为全站基础组件验收红线，纳入 P0 和 P1 各项

### 3. 飞书审批分类隔离
- **适用场景**：审批工作台
- **内容**：先点"请假/补交"分栏，再显示批量勾选；只开放"批量同意"，驳回强制单条填理由
- **落地方式**：纳入 P0 第 3 项"审批乐观更新"

## 八、结论

外部报告的 8 项方案，实际情况是：

- **4 项已部分完成**（方案 1/2/3/5）：补齐缺失部分即可
- **2 项待核实现状**（方案 6/8）：核实后补齐
- **1 项靶子打偏**（方案 4）：合并到方案 1
- **1 项已完成 2 组**（方案 7）：补齐剩余 3 组

真正要做的是 **10 项具体任务**（P0 三项 + P1 三项 + P2 三项 + P3 一项），不是外部报告的 8 项方案。

**核心纪律**：先解决性能卡顿（翻月 48 秒、协作管理卡顿），再做视觉优化。
