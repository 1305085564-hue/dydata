## 二、UI 视觉规格（像素级，响应式三档：手机 <sm / 平板 sm–md / 桌面 ≥lg）

### 项1：异常详情合一（content-list-view-controls.tsx）

现状：「异常」按钮内部嵌一个数字 `<span>` 角标，右侧另有独立「详情」文字按钮（`onDirectReview`）。
目标：**「异常」按钮只做开关；数字角标变成紧贴其右的独立小按钮，一步直达异常详情；「详情」按钮整块删除。**

1. 「异常」按钮：样式 class **原样保留**（激活态 `bg-status-danger/10 border-status-danger/30` 等全部不动），只做两处改动：
   - 删除按钮内 `{anomalyCountForTime > 0 && (<span …>{anomalyCountForTime}</span>)}` 这段角标；
   - `title` 文案改为：`点击仅看异常作品（按当前时间范围实时统计）；点右侧数字查看最需关注异常详情`。
2. 数字角标改成**独立 `<button>`**（不能嵌在「异常」button 里——按钮套按钮是非法 HTML）：
   ```tsx
   {anomalyCountForTime > 0 && onDirectReview && (
     <button
       type="button"
       onClick={onDirectReview}
       title="直接打开当前时间范围内最需关注的异常视频"
       aria-label={`查看最需关注异常详情（${anomalyCountForTime} 条）`}
       className={cn(
         "inline-flex min-h-[44px] min-w-[44px] sm:min-h-0 sm:min-w-0 sm:h-7 items-center justify-center rounded-md px-1.5 text-[12px] tabular-nums font-normal transition-colors cursor-pointer",
         filters.onlyAnomaly
           ? "bg-status-danger/15 text-status-danger hover:bg-status-danger/20"
           : "bg-status-danger/10 text-status-danger hover:bg-status-danger/15"
       )}
     >
       {anomalyCountForTime}
     </button>
   )}
   ```
   - 与「异常」按钮同容器 `inline-flex items-center gap-1`（保持现有容器，间距 4px）。
   - 数字沿用 `tabular-nums`，字号 `text-[12px]`，颜色 `status-danger` 系（与现角标一致）。
3. **删除**「详情」按钮整块 JSX（现 `anomalyCountForTime > 0 && onDirectReview &&` 下的第二个 button）。`onDirectReview` 的 props 类型、传递链、`content-page-client.tsx` 里的 `handleDirectReview` **全部保留不动**——只是入口从「详情」按钮换到数字角标。

### 项2：日期行合并（content-list-toolbar.tsx / content-list.tsx / date-pagination.tsx）

目标排版（桌面一行三段，阿禅拍板）：

```

←———————————— 左段（日期） ————————————→  ←——— 中段（视图控件） ———→                    ←———————— 右段（筛选） ————————→
```

1. `content-list-toolbar.tsx`：FilterBar 三个子节点从左到右依次为 `DatePagination`（有 `dateNav` 才渲染）→ `ContentListViewControls` → `ContentListFiltersView`。FilterBar 的 sticky class 原样保留，另确保具备 `flex-wrap`（FilterBar 自带则不动，没有就在 className 补 `flex-wrap`）。
2. `content-list.tsx`：删除现在独立渲染 `<DatePagination …/>` 的整段 JSX；把原有计算打包成一个对象传给工具栏：
   ```tsx
   const dateNav = currentDate && availableDates.length > 0
     ? {
         currentDate,
         availableDates,
         availableCounts,
         rangeStart: isRangeMode ? effectiveDates.effectiveStartDate : undefined,
         rangeEnd: isRangeMode ? effectiveDates.effectiveEndDate : undefined,
         isLoading: props.isViewLoading,
         onDateChange: handleDateChange,
         onShiftRange: handleShiftRange,
       }
     : null;
   ```
   `ContentListToolbarProps` 增加可选字段 `dateNav?: React.ComponentProps<typeof DatePagination> | null`（工具栏**不重复计算**日期逻辑，全部吃这个对象）。
3. `date-pagination.tsx` 三处减法：
   - **「第 N / 共 M 天」并入日期按钮**：PopoverTrigger 内主文案后追加
     ```tsx
     <span className="hidden sm:inline text-[11px] text-[#A8A29E]">{positionLabel}</span>
     ```
     （主文案 `10月22日 周四 · 18 条` 保持 `text-[13px] font-medium text-[#141413]` 不变）；**删除**现在独立的 `<span className="px-1 text-[12px] text-[#78716C]">{positionLabel}</span>`。
   - **「今天」「最新」窄屏收进浮层**：两个快捷按钮的 className 追加 `hidden lg:inline-flex`；日期浮层（PopoverContent）底部把现有「跳到今天」改成两行按钮：「跳到今天」「跳到最新」（后者 onClick = `availableDates[0] && pickDate(availableDates[0])`，与现外层「最新」按钮同逻辑），按钮样式沿用现有「跳到今天」的 class。
   - 左右箭头（前一天/后一天、区间平移）**不动**。
4. 右段（`content-list-filters-view.tsx` 根 div）：保留 `ml-auto`，追加 `w-full sm:w-auto`——手机上筛选组独占第二行，达成阿禅拍板的「手机端两行」；桌面三段同排。**手机端所有控件 `min-h-[44px]` 触控规格一律保留。**

### 项3：页头留白收紧（page.tsx，仅视频复盘页）

`<AdminWorkspaceLayout …>` 增加 `className="sm:space-y-6"`（`cn` 基于 tailwind-merge，会覆盖组件默认的 `sm:space-y-10`，即页头与正文间距 40px → 24px）。`space-y-2`（手机）与页头内部 `gap-3 sm:gap-4`、标题/描述的 `mt-1.5 sm:mt-2` 全部不动。**禁改共享组件。**

### 项4：~~标题/账号固定槽位~~ 已撤销（阿禅裁定，勿做）

**原因（记档，防止外部评审建议再次混入）**：表格除标题外所有列都是钉死宽度，标题是唯一吃剩余空间的弹性列；给账号再钉固定宽度是在最窄处抢地盘，空间一窄标题被挤没甚至溢出。这条是外部评审基于截图的"对齐审美"，没算我们表格的宽度账，收益低、风险实。

**执行要求：标题/账号单元格（`content-list-table.tsx` 标题列 JSX 与表头列宽）一个字符不动。** 现状即正确形态：标题自适应、超长自动省略号；账号 `max-w-[75px] 2xl:max-w-[100px]` 封顶自动截断，占多宽由内容定。Tooltip 不动，手机卡片不动。

### 项5：小修打包

a. **右侧控件高度统一**（filters-view / member-select / secondary-filters）：桌面端所有控件统一 `sm:h-7`（28px）、间距统一 `gap-2`（8px）（Select `size="sm"` 已自带 `h-7` 的核对即可，不一致的补上）；移动端 `min-h-[44px] min-w-[44px]` 一律保留。已一致的控件**不动**。
b. **时间下拉选中值不发灰**（filters-view 时间 Select）：给 `<SelectValue>{timeRangeLabel}</SelectValue>` 加 `className="text-[#1F1E1D]"`（幂等，即使原本不灰也无害）；若该组件不透传 className，退而给这个 SelectTrigger 的 className 加 `text-[#1F1E1D]`。**只改色，「全部时间」四个字不许动。** 验收以浏览器实测：选中值颜色与「全公司」「成员」选中值一致。
c. **行线弱化**（content-list-table.tsx 桌面 tbody）：`divide-y divide-[#E2E2DF]` → `divide-y divide-[#E2E2DF]/60`（与表头 `border-[#E2E2DF]/60` 同一淡度）。手机卡片的 `divide-[#E2E2DF]/60` 已是对的，不动。
d. **导航与正文对轴**（navigation-header.tsx）：顶导航容器 `mx-auto w-full max-w-7xl px-4 sm:px-6 lg:px-8` 的 padding 改为 `px-3.5 sm:px-6`，与正文 `app-main`（`src/app/(app)/layout.tsx` 的 `px-3.5 sm:px-6`）逐档对齐（决策理由：正文密度刚调校完，动导航一处即可，避免全站正文位移）。此改动**全站导航生效**——若浏览器实测发现导航容器另有实际渲染的 wrapper（在 `src/components/navigation/navigation-shell.tsx` 链路里），以实际渲染容器为准做一处对齐；若对齐后其他页面导航出现明显异常，**停下来报备，不许继续发挥**。

## 四、验收标准（可执行清单，逐条过）

### 功能测试（8 条，浏览器 localhost:3000/admin/content 实测）

1. 点「异常」按钮：列表切「只看异常」/再点恢复全部——与改前行为一致。
2. 点数字角标：**一步**打开最需关注的异常作品详情抽屉；且**不会**顺带切换「只看异常」。
3. 全页搜索不到独立的「详情」按钮；DOM 里无「button 套 button」。
4. 日期翻页器不再单独占一行，与工具栏同排：左日期、中全部/归档/异常/完整/宽松、右时间/成员/筛选/搜索；桌面不换行挤压到难用。
5. 日期按钮文案为「10月22日 周四 · 18 条 · 第 1 / 共 177 天」样式（小字淡色）；窄屏（<sm）小字隐藏、界面不挤爆。
6. 窄屏下「今天/最新」不在工具栏占位；点日期浮层内「跳到今天」「跳到最新」可用。
7. 切「近7天」：日期按钮变成区间文案，左右箭头整体平移前后一个窗口（现有功能不回归）。
8. 标题/账号单元格与改前**逐像素一致**（项4 撤销回归确认）：标题超长省略号截断、账号封顶截断，把窗口拉窄到表格刚要出横向滚动的程度，标题列不溢出、账号不换行。

### 视觉走查

- 页头（内容管理/视频复盘/描述）与工具栏之间间距为 24px 档（不再是大空白）。
- 表格行线比改前更淡（与表头下边线同淡度）。
- 时间下拉的选中值（「最近一天」等）与团队/成员选中值同色，不发灰。
- 顶导航左缘与页面正文（页头、表格）左缘在同一条垂直线上。
- 三个暂缓/撤销项确认**没被做**：按钮仍是独立按钮（非单切）；「全部时间」文案原样；标题/账号无固定槽位（与改前一致）。

### 边界 case

- 无异常作品（角标与数字按钮都消失，「异常」按钮仍可点）。
- 某天无任何作品：DatePagination 整体不渲染，页面不报错。
- 归档视图（view=trash）：异常/完整/宽松不渲染（现状），日期导航仍正常。
- 手机宽度（<640px）：控件 44px 触控高度保留，筛选组在第二行，无裁切、无横向溢出。
