# 视频复盘功能修复计划（合并版）
**基于**：Kiro UX 审计报告 + Antigravity 严苛体验走查  
**交付人**：Antigravity（前端执行）  
**验收人**：阿禅  
**生成日期**：2026-09-14

---

## 执行摘要

**问题根源**：视频复盘工作台像"仪器精密但动线混乱的化验室" — 管理者看一条视频要 2-3 分钟，连续看 10 条大脑严重疲劳。

**修复策略**：分两周执行，P0 先止血（功能不可用问题），P1 再优化（体验问题）。

**预期效果**：看一条视频从 2-3 分钟降到 30-60 秒，管理者可以流畅地连续复盘 20 条。

**现象**：

**修复方案（只做第一步）**：

#### 第一步（本周）：默认折叠次要指标（2h）
```typescript
// src/app/(app)/admin/content/content-diagnosis-workbench.tsx

// 在归因卡片区域（约 1240 行）添加状态：
const [showAllMetrics, setShowAllMetrics] = useState(false);

// 定义首屏展示的关键指标（差异最大的 3 个）
const primaryMetrics: MetricKey[] = useMemo(() => {
  if (!multiAttribution) return ["bounce_rate_2s", "completion_rate_5s", "avg_play_duration"];
  
  // 计算所有指标的最大差异百分比
  const metricDiffs = METRIC_MAP.map(entry => {
    const findings = multiAttribution[entry.metric];
    if (!findings || findings.length === 0) return { metric: entry.metric, maxDiff: 0 };
    
    const maxDiff = Math.max(...findings.map(f => Math.abs(f.diff_pct || 0)));
    return { metric: entry.metric, maxDiff };
  });
  
  // 按差异排序，取前 3
  return metricDiffs
    .sort((a, b) => b.maxDiff - a.maxDiff)
    .slice(0, 3)
    .map(item => item.metric);
}, [multiAttribution]);

// 渲染时：
<div className={cardCols === 3 ? "grid grid-cols-1 sm:grid-cols-3 gap-2" : "grid grid-cols-2 sm:grid-cols-4 gap-1.5"}>

  {primaryMetrics.map(metricKey => (
    <MultiRefMetricCard key={metricKey} metricKey={metricKey} {...props} />
  ))}
  
  {/* 折叠区：其他指标 */}
  {showAllMetrics && (
    <>
      {METRIC_MAP.filter(m => !primaryMetrics.includes(m.metric)).map(entry => (
        <MultiRefMetricCard key={entry.metric} metricKey={entry.metric} {...props} />
      ))}
    </>
  )}
</div>

{/* 展开/收起按钮 */}
```

```typescript
const handleMarkReviewedAndNext = useCallback(async () => {

    handleNext();
  }
}, [video, hasNext, handleNext]);

// 添加键盘快捷键
useEffect(() => {
  const handleKeyDown = (e: KeyboardEvent) => {
    if (e.key === "Enter" && !e.ctrlKey && !e.metaKey && !e.altKey) {
      const target = e.target as HTMLElement | null;
      // 排除输入框
      if (target?.tagName.toLowerCase() === "input" || target?.tagName.toLowerCase() === "textarea") {
        return;
      }
      
      e.preventDefault();
      handleMarkReviewedAndNext();
    }
  };
  
  window.addEventListener("keydown", handleKeyDown);
  return () => window.removeEventListener("keydown", handleKeyDown);
}, [handleMarkReviewedAndNext]);
```

```typescript
          <span className="flex-shrink-0 inline-flex items-center justify-center size-5 rounded-full bg-[#B98A54]/10 text-[#B98A54] font-semibold text-[10px]">3</span>
          <span>看<strong>截图</strong> = 观众在哪里流失</span>
        </li>
      </ol>
      <button
        type="button"
        onClick={() => {
          localStorage.setItem("content-review-onboarding-seen", "true");
          setShowOnboarding(false);
        }}
        className="w-full rounded-lg bg-[#1C1917] px-4 py-2.5 text-[13px] font-semibold text-white hover:bg-[#292524] transition-colors"
      >
        知道了，开始复盘
      </button>
    </div>
  </div>
)}
```

- ✅ 可以通过清除 localStorage 重新触发引导

**现象**：

```typescript
// src/app/(app)/admin/content/content-diagnosis-workbench.tsx

// 引入 Tooltip 组件
import { Tooltip, TooltipContent, TooltipTrigger } from "@/components/ui/tooltip";
```
