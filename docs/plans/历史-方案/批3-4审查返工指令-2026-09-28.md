## 三、这 12 个页面现在能不能说是同一个产品？

**部分能，但骨架一处在断、形态三处在散。**

**能的地方（已经统一，实测证据）**
- 页头槽位全部走壳，H1 全部为 `28px / 500 / rgb(20,20,19) / 衬线 / -0.7px`；7 个渲染页面各自**有且仅有 1 个 H1**（`/admin/content` 从 0 → 1，已补齐）。`TopicHubV2.tsx:581` 与 `video-submit-panel-v2.tsx:524` 埋在子组件里的 h1 已归到壳。
- 两个壳的 H1 写法完全一致：`text-[20px] sm:text-[28px] … text-[#141413]`（改前 `app-shell` 用 `#1C1917` 不一致，已修）。
- 页头操作全站右对齐，无页面把主 CTA 放左边。
- 内容宽度：`/dashboard` `/topics` `/admin/modules` `/admin/collaboration` `/admin/ai-config` 五页 `max-w-7xl` 1280，与导航 1280 / left 80 完全同轴；无人使用 `width="full"` / `max-w-none`。
- 分隔线只有 `#E2E2DF/60` 一种（236 处）；徽标只有一种形态（DOM 实测统一 `h 20px / padding 2px 8px / radius 6px / 12px`）。
- 横向无溢出（7 页 `scrollWidth === clientWidth === 1440`）；控制台 0 error / 0 warning，无任何 4xx。

**不能的地方**
1. **`/admin/content` 与 `/admin/fulfillment` 不在这条脊梁上**：H1 左轴 24、内容右边界 1416，导航是 80 / 1360。截图并排看，这两页的页头明显比导航"更靠左、更宽"。这是本次审查最该修的一处（R1）。
2. **列表里"名字"这个身份丢了**（S1）：数据管理/成员管理的表格里，名字与它旁边的数字同为 13px/400，墨度仅差 2% 亮度；而选题库的卡片标题走 `ItemHeading`（14px/500）是对的。三个页面并排看，只有选题库能一眼认出"这是条目名"。
3. **筛选器没有恒定槽位**（S7）：左轴 80 / 100 / 333 三种，形态四种（裸排 / 卡内 / 有框条内 / 带独立月份行）。
4. **橙色实底在泄漏**（R7 / S5）：落地页同屏 3 处；`/admin/ai-config` 同屏 5 个橙色开关。哲学 §1.2 的"单点聚光灯"在这两处不成立。
5. **形状同源律在 CSS 层没落地**（R5）：圆角在类层面干净（只有 6/12/full），但 CSS 里另有 20 / 17.6 / 15.2 / 13.6 / 4px 五档——**类层面合规、CSS 层面不合规**，这正是 grep 型自检最大的盲区。
6. **空状态 5 种形态**（S2）。
