### 4.1 P0 权限/scope（最高危，先做）

**D-PERM-1 角色→权限模板三处封装链**
- 现状链：`src/lib/permission-contract.ts`（声明契约 `ROLE_PERMISSIONS/GROUP_MODE_PERMISSIONS/DATA_SCOPE_RULES`）→ `src/lib/company-permissions.ts`（`fixedPermissionsForRole`/`hasFixedPermission`）→ `src/lib/permission-utils.ts`（`hasCompanyPermission`/`fixedPermissions`）。
- 收口方向：调用方统一走**一个入口**（建议 `hasFixedPermission` 为唯一对外门面，`permission-utils` 内部委托或删除其重复映射）。
- 约束：A-32 已删 `isPermissionKey/getPermissionsForRole/COMPANY_ROLES/isCompanyRole/canOperateCurrentMembership` 五个死导出——勿复活；`fixedPermissionsForRole/hasFixedPermission` 是活函数。
- 验收：`rg -n "fixedPermissions\b" src` 无跨层重复实现；三文件职责一句话可描述且不重叠；tsc/test 全绿。

**D-PERM-2 两套路由门禁 + 第三种可见性判断**
- 现状：权威 `src/lib/route-permissions.ts:canAccessRoute` vs `src/lib/analytics-access.ts` 的 `canAccessAdminPath`/`canAccessAdmin`/`getNavigationAccess`；`restrictPersonRows` 用 `role==="admin"||"owner"` 原始角色串绕开固定权限模型。
- 收口方向：全部路由/导航门禁收敛到 `canAccessRoute` + 固定权限模型；`restrictPersonRows` 改为基于 `hasFixedPermission`（或既有权限键）判定，**禁止再出现原始角色串比较**。
- 边界：组长之间不可互相归档/恢复/调配/降职（仅老板可动组长）——放行分支改动时逐条核对这条边界，验收用例必须覆盖。
- 停止条件：若某门禁与 RLS/写路径耦合且 BLK-1 快照无法覆盖其判定 → 停该项，留证据卡。

**D-PERM-3 API 鉴权 helper 8+ 套**
- 现状：`requireAdminActor`（约 19 路由）、`requireActiveTeamContext`（约 14）、`requireExemptionManagerActor`、`requireOwnerOrAdminActor`、`requireSignedInUser`、`requireGlobalProductionActor`、`requireVisibleProductionUser`、`requireAdminModulesAccess`、`requireAdminServiceClient`、`requireSystemActor`、`requireOwnerOrAdminRole` 等。
- 收口方向：统一 `requireActor(scope)` 门面（新公共模块，如 `src/lib/api-auth/`），旧 helper 变为其薄包装或直接迁移调用方；**分两步**：先建门面+迁移 2~3 个低风险路由试点，再全量迁移。
- 约束：不改任何 helper 的**判定语义**（只收口结构）；`auth.context` 相关行为不变；外部触发入口路由（红线 5.5）的鉴权**只包不改**。
- 验收：`rg -c "export async function require" src/app/api src/lib` 统计下降；每路由鉴权行为与改前逐条一致（对试点路由写行为快照测试）。

**D-PERM-4 局部 scope 实现游离**
- 现状：`dashboard-data-scope.ts`、`admin-tools/scope.ts`、`admin-scoped-video.ts`、`topics/team-scope.ts`、`/api/dashboard/operator-members` 自定义 team_id 过滤。
- 收口方向：登记进统一权限索引（`docs/权限与安全说明.md` 或代码内索引），能用 `inferDataScope`/公共 scope helper 的替换之；确有特殊语义的保留但**必须注释说明差异原因**。
