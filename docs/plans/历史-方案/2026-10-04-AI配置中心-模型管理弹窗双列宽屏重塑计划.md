## 一、用户真实意图与审查闭环

- **阿禅拍板方向**：
  1. 采纳推荐方案：弹窗宽度升至 **960px**，高度限定为 **640px**（1.5:1 黄金横屏视窗）；
  2. 布局由单列纵向列表升级为**双列并排卡片（Grid 2 Columns）**；
  3. 目标：单屏可见模型数量由 6~7 个翻倍至 **12~14 个**，实现“两屏扫清全池 58 个模型”；
- **审查意见全盘采纳**：
  1. **阻断项根除**：补齐 `sm:max-w-[960px]` 击穿基类 `sm:max-w-md` 覆盖；移除容器 `divide-y` 彻底杜绝隔行横线；
  2. **《设计规范》严格对齐**：
     - 六档字阶封闭律：严禁 `text-[11px]`，统一收敛为 `text-[12px]`；
     - 留白与圆角：禁半档 `gap-2.5`，全站统一 `gap-2`；禁裸 `rounded`，一律 `rounded-md`；
     - 条目定名：卡片名严格为 `14px / 500 / #1F1E1D`；原始 ID 采用 `#78716C`（元数据墨）；
     - 聚光灯合规：移除非主行动橙 `hover:border-[#D97757]/40` 与 `focus-visible:ring-[#D97757]`，悬停回退规范暖灰 `#F7F7F6`；
     - 组件契约：删除业务层覆盖字号，`DialogTitle` 走组件默认；删除确认按钮改用 `variant="destructive"` 淡底红字，禁 `#C0685C` 饱和实底；
  3. **信息降噪与密度兑现**：
     - 数字去重：移除 Header 与 Footer 重复出现的计数，仅在状态药丸保留「现役在册 (10)」「储备待开启 (48)」，「全部」不挂数学推导计数；
     - 渠道药丸降级：卡片常态展示「N 个渠道支持」，具体渠道列表通过原生 `title` 悬停提示，消除几百个常驻 pill 的“电路板感”；
     - 卡片高度收敛至 ~52-56px，实现单屏 12~14 个、两屏完整浏览 58 个模型的真实物理保证；
     - 双列网格统一采用 `items-start` 或两行固定高度，杜绝高低参差。

## 三、发丝级设计与交互规格

### 1. 视口骨架与层级
- **外框尺寸**：
  `w-[960px] max-w-[95vw] sm:max-w-[960px] h-[640px] max-h-[85vh] flex flex-col p-6 gap-4`；
- **容器与阴影**：
  大容器 `rounded-2xl border border-[#E2E2DF] bg-white shadow-claude-dialog`。

### 2. 顶部工具栏（单行贯通）
- **左侧**：三段式 Segmented 药丸控制器：
  - `全部` · `现役在册 (10)` · `储备待开启 (48)`
  - 激活态白底微投影（`bg-white font-medium text-[#141413] shadow-input`），未激活态暖灰（`text-[#78716C]`）；
- **右侧**：
  - 紧凑搜索框（`pl-8 pr-7 text-[12px]`，带放大镜与一键清除 `X`，走组件默认 ring）；
  - 定制服务商筛选框（`appearance-none` 消除原生粗黑三角，内置 `ChevronDown` 细线图标）。

### 3. 双列卡片（Single Model Card）微架构（两行紧凑型）
在 960px 宽度下，单卡宽度约为 450px，严格限制为两行紧凑布局：
```
┌────────────────────────────────────────────────────────┐
│ [✓] claude-3-5-sonnet-20241022               [现役中]  │
│     (claude-3-5-sonnet) · 3 个渠道支持                 │
└────────────────────────────────────────────────────────┘
```
- **第一行（条目定名）**：
  - 左侧：复选框（Checkbox）+ 模型显示名（`text-[14px] font-medium text-[#1F1E1D] truncate`）；
  - 右侧：
    - 已开启：复用 `ui/badge.tsx` 的 `variant="success"`（`现役中`，12px / 400 字重）；
    - 储备中：悬停时显现彻底删除图标（垃圾桶 `Trash2`，带二次确认弹窗防误触）；
- **第二行（元数据整合行）**：
  - 整合格式：`{modelId !== displayName ? `(${modelId}) · ` : ''}{items.length} 个渠道支持`；
  - 字阶：`text-[12px] text-[#78716C]`；
  - 提示：整行设置 `title="支持渠道: api1, api7, apitang"`，鼠标悬停即见完整渠道，不占用常态界面空间；
- **交互与动效**：
  - 卡片整块可点击，悬停采用合规暖灰：`hover:bg-[#F7F7F6] border-[#E2E2DF]`；
  - 杜绝 `hover:border-[#D97757]/40`，保护主行动聚光灯。

### 4. 空状态与二次确认弹窗
- **空状态**：直接复用 `components/ui/empty-state.tsx`，居中跨两列，不手写临时 div；
- **删除确认弹窗**：确认删除按钮使用 `Button variant="destructive"`（淡底红字），杜绝自造饱和红色实底。
