## 三、风险点与预案

### 风险 1：删除 ModelManagerDialog 可能影响其他功能

**检查结果：**
```bash
grep -r "ModelManagerDialog\|setModelManagerOpen" src/app/(app)/admin/ai-config
# 结果：只在 compute-pool-panel.tsx 使用，无其他依赖
```

**结论：** ✅ 可以安全删除

---

### 风险 2：原地编辑可能和现有的编辑弹窗冲突

**解决方案：**
- 删除 `KeyDialog` 的编辑入口（保留创建功能）
- 删除 `ProviderDialog` 的编辑入口（保留创建功能）
- 模型视角的卡片不再显示"编辑密钥"按钮

---

### 风险 3：API 地址属于 provider，不是 key

**问题：**
- 一个 provider 下可能有多个 key
- 如果在某个 key 的详情里改 API 地址，会影响该 provider 下的所有 key

**解决方案：**
- 在 UI 上明确提示："修改 API 地址会影响该供应商下的所有密钥"
- 或者：只在"添加供应商"时设置 API 地址，之后不允许修改

**推荐方案：** 允许修改，但加提示
