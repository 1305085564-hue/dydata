# 数据管理抽屉交互与文案改造方案

## 一、改造背景与目标

### 1. 现状痛点
- **抽屉双层叠加（Drawer over Drawer）**：在数据管理页面点击员工打开“个人档案卡”（672px 宽）后，再点击作品明细，系统又在最上层滑出“视频工作舱抽屉”（896px 宽）。两扇右侧抽屉同侧挤压，双层灰色遮罩叠在一起让底层暗得发黑，关闭时容易造成焦点与状态混淆。
- **文案与上下文错位**：从数据管理/个人档案卡点进来的作品，左上角依然机械地显示`视频复盘 · 视频工作舱`，没有体现出“个人作品诊断”的上下文，让用户产生“我是不是跳到了另一个模块”的疑惑。

### 2. 改造目标
- **单抽屉视口导航（Single-Drawer Stack Navigation）**：右侧始终只有**一只抽屉、一层遮罩**。进入作品诊断时，档案卡平滑让位，顶部提供清晰的`[← 返回 张三 的档案]`，点击后无缝返回。
- **上下文文案精准化**：
  - 从个人档案点入：左上角显示`个人档案 · 作品诊断`，并带有返回档案按钮；
  - 从数据管理直接点入（如员工看板）：显示`数据管理 · 作品诊断`；
  - 从视频复盘主页面打开：保持原有的`视频复盘 · 视频工作舱`不变。

## 二、交互链路设计（Before vs After）

### 链路对比

```mermaid
graph TD
  subgraph 改造前 [改造前: 双抽屉硬重叠]
    A1[数据管理主界面] -->|点击成员| B1[个人档案卡抽屉 672px]
    B1 -->|点击作品| C1[视频工作舱抽屉 896px 直接覆盖在上面]
    note1[两层黑遮罩叠加 / 空间挤压 / ESC混乱 / 标题写着视频复盘]
  end

  subgraph 改造后 [改造后: 单抽屉平滑导航栈]
    A2[数据管理主界面] -->|点击成员| B2[个人档案卡抽屉 720px]
    B2 -->|点击作品| C2[作品诊断抽屉 896px 独占视口]
    C2 -->|点 [← 返回 张三的档案]| B2
    C2 -->|点右上角 ✕| A2
    note2[单层遮罩 / 顶部明确返回 / 文案对齐上下文 / 零干扰]
  end
```

### 交互细节规范
1. **单层遮罩锁定**：当打开作品诊断抽屉时，底层个人档案卡自动隐藏，不渲染第二层 backdrop，彻底消除黑屏感。
2. **返回键与关闭键分工**：
   - 抽屉左上角：`[← 返回 张三 的档案]`，点击后退回个人档案卡；
   - 抽屉右上角：`✕` 关闭按钮，点击后完全关闭抽屉，退回数据管理主界面；
   - 键盘 `ESC`：在作品诊断状态下，按一次 `ESC` 优先返回档案卡，再按一次 `ESC` 关闭抽屉。

## 三、涉及文件与修改范围

1. **`src/app/(app)/admin/content/content-detail-dialog.tsx`**
   - 增加支持 `titlePrefix?: string`（默认 `视频复盘 · 视频工作舱`）；
   - 增加支持 `onBack?: () => void` 与 `backLabel?: string`，若传入则在左上角渲染返回面包屑按钮。
2. **`src/components/admin/collaboration-work-review-link.tsx`**
   - 扩展 `openDiagnosisByReportId(reportId: string, options?: { sourcePersonName?: string })` 签名。
3. **`src/app/(app)/admin/collaboration/collaboration-workbench.tsx`**
   - 记录 `sourcePersonName` 上下文；
   - 抽屉受控互斥：当 `diagnosisDetail` 存在时，`PersonalCard` 暂停渲染/隐藏，由 `ContentDetailDialog` 单独展示；
   - 传入定制化的 `titlePrefix="个人档案 · 作品诊断"` 与返回动作 `onBack={() => setDiagnosisDetail(null)}`。
4. **`src/app/(app)/admin/collaboration/personal-card.tsx`**
   - 触发作品点击时附带成员姓名 `data.name`；
   - 清理与双抽屉叠加相关的 hack 代码。
5. **`src/app/(app)/admin/collaboration/writer-quality-chart.tsx`**
   - 触发作品点击时附带成员姓名。
