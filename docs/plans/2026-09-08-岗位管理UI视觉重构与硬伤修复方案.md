# 岗位管理工作台（admin/collaboration）顶级 UI 重构与硬伤修复方案

> 日期：2026-09-08
> 执行目标：基于《Claude 设计哲学》与《Claude 设计规范》，彻底治理岗位管理页面 13 项全量视觉与结构硬伤，打造出版物级温润工作台。

---

## 一、改造原则与阿禅拍板结论

1. **结构绝不散架（关于第 4 项展开明细）**：
   - 阿禅核心要求：“担心如果不加盒子拆开就散了”。
   - 解决方案：采用**“精装薄信笺 + 灰蓝学者边注导轨”**设计。保留 1px 细线完整包裹闭合（`border border-[#ECE7DE] rounded-xl bg-white`），确保明细有明确的物理盒感绝不散架；同时在左侧引入垂直学者导轨线，去掉原先厚重的黑粗框和多层嵌套卡片。
2. **聚光灯单点回归**：全屏仅主行动保留陶土橙；Tab、排序、展收箭头、爆款徽章等一律收敛为水墨灰阶与浅砂微气垫。
3. **彻底清除全站 `#FAF8F4`**：违规脏黄底色全面清退，代之以透光、浅砂微气垫（`#F5F3EE`）或纯白。
4. **表格语义对齐**：彻底修复 `operator-tab` 表头与数据列错位的核心 Bug。

## 三、全量 13 项改造细节与代码基准

### 1. Tab 选态与陶土橙滥用收敛
- **位置**：`collaboration-workbench.tsx` 中的 Tab 按钮。
- **改动**：
  - 选中态由 `bg-[#D97757]/10 text-[#D97757] font-semibold` 改为 `bg-[#F5F3EE] text-[#1C1917] font-medium`（规范 4.1：Selected Tab 用浅砂微气垫）；
  - 未选中态保持 `text-[#78716C] hover:text-[#1C1917] hover:bg-[#F5F3EE]/60`。
  - 表头排序箭头活跃态改用中性浓墨 `text-[#1C1917]`，非活跃态 `text-[#78716C]/40`。

### 2. 达人列表移除全员常驻金星
- **位置**：`talent-tab.tsx` 第 174-179 行。
- **改动**：
  - 彻底移除每行姓名左侧的 `<Star className="size-3.5 text-[#B98A54] fill-[#B98A54]" />`，消除 24 个黄色噪点；
  - 姓名保持 `font-medium text-[#1C1917] hover:text-[#D97757]`。

### 3. 清理所有 `#FAF8F4` 野生底色
- **涉及文件**：
  - `collaboration-workbench.tsx` 错误提示条：改用 `@/components/ui/alert` 标准组件。
  - `health-bar.tsx` 提示条与展开区：替换为 `bg-[#F5F3EE]/60 border-[#ECE7DE]`。
  - `personal-card.tsx`：4 个概览小卡片替换为 `bg-white border border-[#ECE7DE]/80 shadow-card-ring`。

### 4. 表格展开明细重构（薄信笺 + 边注导轨，绝不散架）
- **位置**：`operator-tab.tsx` 与 `staff-tab.tsx` 的展开行。
- **改动**：
  - 外层容器：`p-4 pl-10 bg-[#FBF9F5]/40 border-b border-[#ECE7DE]/60 relative`；
  - 导轨装饰：在展开容器左侧加一条纵向导轨线 `absolute left-7 top-0 bottom-4 w-[2px] bg-[#43718E]/30 rounded-full`，明确标识归属，视觉锚定极强；
  - 明细卡片：`rounded-xl border border-[#ECE7DE] bg-white overflow-hidden shadow-2xs`，内部明细表表头为浅砂灰 `text-[#78716C]`，行内用发丝线 `border-[#ECE7DE]/50` 分隔，彻底去厚重感。

### 5. 修复 `operator-tab` 表头与数据列错位（核心结构 Bug）
- **位置**：`operator-tab.tsx` 第 201-286 行。
- **改动**：
  - 坚决废弃 `<td colSpan={11}><div className="flex-1 grid grid-cols-10 ...">`；
  - 改为标准的 `TableRow` 与 `TableCell` 结构；
  - 为表头和单元格设置统一样式与列宽基准（如 `w-10`、`w-28`、`text-right tabular-nums`），确保表头文字与下方数值 100% 垂直严丝合缝对齐。

### 6. 补齐达人表遗漏样式
- **位置**：`talent-tab.tsx` 第 134-135 行与 193-194 行。
- **改动**：
  - 为“有效作品”和“优秀作品”补齐 `py-2.5 px-2 text-right font-medium text-[#78716C]` 表头类；
  - 单元格补齐 `py-2.5 px-2 text-right tabular-nums text-[#292524]`；
  - 补齐点击排序逻辑。

### 7. 全站小字字重治理（防中文糊黑）
- **规则**：H3 及以下严禁 `font-semibold`（600），正文与小标签必须使用 `font-medium`（500）或 `font-normal`（400）。
- **改动**：
  - 替换表头、Tab、月份文字、抽屉子标题中散落的 `font-semibold` 为 `font-medium`。

### 8. 统一空值与数字排版
- **改动**：
  - 无数据列统一使用 em dash「—」（`\u2014`），杜绝半角减号 `-`；
  - 环比持平使用 `text-[#78716C] tabular-nums` 显示 `0.0%` 或 `—`；
  - 所有指标强制 `tabular-nums`。

### 9. 顶部月份控制栏降噪
- **位置**：`collaboration-workbench.tsx` 第 251-290 行。
- **改动**：
  - 移除下拉框右侧机械重复的 `<span>{year} 年 {month} 月 岗位月报</span>` 大黑字；
  - 控制舱左侧保留精致紧凑的年月切换器，以出版物留白呼吸提升工作台开阔感。

### 10. 健康度（HealthBar）胶囊与指派抽屉品质提升
- **位置**：`health-bar.tsx`。
- **改动**：
  - 胶囊在 100% 完备时呈现低饱和中性微印记；
  - 抽屉内文案/剪辑/运营补录下拉选择器，高度从局促的 24px（`h-6`）提升至标准 S 级 28px（`h-7`），字体由 11px 规范为 12px。

### 11. 个人档案抽屉（PersonalCard）出版物化
- **位置**：`personal-card.tsx`。
- **改动**：
  - 头部去碎屑彩色药丸：改为单行内联信息流 `<span>{year} 年 {month} 月 · 文案 {writerCount} · 剪辑 {editorCount} · 运营 {operatorCount}</span>`；
  - 柱状图常态展示（阿禅拍板）：柱状图常态展示，不作少于 3 个月的降级隐藏；三岗位颜色保持经典高辨识度：文案蓝 `#3B82F6`、剪辑紫 `#8B5CF6`、运营暖橙 `#D97757`；
  - 经手作品明细表格防截断与整行可点：采用 `table-fixed` + 严格列宽 + 标题溢出截断保护，确保 5 列完整平铺展示；整行设为通屏点击热区，支持点击任意位置直接唤起视频诊断大抽屉。

### 12. 修复 `loading.tsx` 骨架屏剧烈跳闪（消灭 CLS）
- **位置**：`src/app/(app)/admin/collaboration/loading.tsx`。
- **改动**：
  - 彻底删除已废弃的 `<Skeleton className="h-12 w-full rounded-xl" />`（原整行 HealthBar 遗留）；
  - 严格镜像当前页面：顶栏控制骨架 + 4 个 Tab 骨架（达人/运营/文案/剪辑）+ 1 个标准高度表格骨架，实现切换月份 0 抖动。

### 13. 爆款作品徽章克制化
- **位置**：全 Tab 爆款展示。
- **改动**：
  - 抛弃大块亮橙色块 `bg-[#D97757]/10 text-[#D97757]`，改为温和的中性微气垫带发丝框 `bg-[#F5F3EE] text-[#292524] px-1.5 py-0.5 rounded text-[12px]`，有爆款时可带一粒微符（✦）。
