## 二、UI 视觉规格

通用铁律（《规范》§0）：字号只用 `text-[28|20|18|14|13|12px]`；字重只 400/500（激活态可 500）；文字墨度只用 `#141413/#1F1E1D/#78716C/#A8A29E`；状态色只上文字+淡底（`/8`、`/10`），禁饱和实底；`#D97757` 全屏唯一主 CTA，本页第一波无主 CTA，任何选中态/聚焦环不得借用它；元素间距只用 `gap-1/2/3/5`（禁 `gap-1.5/2.5/3.5`，内边距允许半档）；圆角只用 `rounded-md/xl/2xl/full`；阴影只用 `shadow-input/card-ring/claude-float/claude-dialog`；新表格一律用 `@/components/ui/table` 原语（Table/TableHeader/TableHead/TableBody/TableRow/TableCell），不手写 `<table>`；空状态一律 `@/components/ui/empty-state` 的 `EmptyState variant="compact"`；页头一律走 AdminWorkspaceLayout。

### 3.2 日期归属（pulse-filters.ts，全站唯一口径=复盘页谓词同源）


### 3.3 聚合计算（pulse-filters.ts 纯函数，容器调用）

```ts
export interface PulseDayPoint { date: string; totalPlay: number | null; worksCount: number }
export interface PulseSummary { date: string; totalPlay: number | null; dayOverDayRate: number | null; worksCount: number; series: PulseDayPoint[] }
export interface PulseMemberRow { userId: string; userName: string; publishedCount: number; totalPlay: number | null; avgBounce2s: number | null; avgCompletion5s: number | null }
export interface PulseVideoMetrics { playCount: number | null; bounceRate2s: number | null; completionRate5s: number | null }
```
- 归属人 = `video.accounts?.profile_id ?? video.user_id`（与 `filterContentVideos:153`、loader:473 同源）；成员名 = `data.profiles` 的 id→name，缺失显示"未命名成员"。
- `snapshotByVideoId = new Map(data.snapshots.map(s => [s.video_id, s]))`。
- 日总播放 = 当日归属作品中 `play_count != null` 之和；全部无快照 → null（显示 `—`，不是 0）。
- 环比 = `(cur - prev) / prev * 100`；prev 为 null 或 0 → null。
- 30 天序列：`for (i=29..0) shiftDay(date,-i)`，`shiftDay(dateStr, n)` = `new Date(dateStr+"T12:00:00+08:00")` 加减天后用 Intl `Asia/Shanghai` formatToParts 取 `YYYY-MM-DD`（实现同 `content-list-filters.ts:72-87` 的 getShanghaiDateString，参数化版本放 pulse-filters.ts）。
- 人员加权留存：`weightedAvg(items:{play:number|null; value:number|null}[])`：仅 play>0 且 value 有限者计入，`Σ(play*value)/Σplay`；分母 0 → null。2s 用 `bounce_rate_2s`、5s 用 `completion_rate_5s`。

### 3.4 红黑胶囊谓词（pulse-video-list.tsx / pulse-client.tsx）

**直接 import 复盘页谓词，禁止重写任何判定：**
```ts
import { DEFAULT_CONTENT_LIST_FILTERS, filterContentVideos,
  type ContentListFilterValue } from "../content/content-list-filters";
export type PulseCap = "all" | "hot" | "anomaly" | "unrated";
export function buildCapsuleFilters(date: string, cap: PulseCap): ContentListFilterValue {
  const base: ContentListFilterValue = { ...DEFAULT_CONTENT_LIST_FILTERS,
    timeRange: "custom", startDate: date, endDate: date };
  if (cap === "hot") return { ...base, qualityGrade: "excellent" };   // 爆款=综合评级"优"
  if (cap === "anomaly") return { ...base, onlyAnomaly: true };        // 内部即 classifyVideoAnomalyBucket
  if (cap === "unrated") return { ...base, qualityGrade: "unrated" };  // 复盘页现行口径：overallGrade=null 且排除 unlinked/无质量记录
  return base;
}
```
胶囊列表与计数 = `filterContentVideos(dayVideos, buildCapsuleFilters(date,cap), playCountById, qualityByVideoId)`，dayVideos 为容器按 `attributionDate === date` 预筛的作品数组（谓词内日期检查对 dayVideos 恒通过，命中差异只可能来自评级/异常谓词，即与复盘页严格同源）。⚠️ 已知事实：复盘页"未评级"筛选排除 unlinked（`content-list-filters.ts:190-191`），本波以复盘页真值为准，不自创"含 unlinked"口径。

### 3.6 深链跳复盘详情

作品行点击 → `router.push(\`/admin/content?videoId=${video.id}\`)`。复盘页 `page.tsx:45` 读 `videoId` → 容器 `loadAdminContentVideoDetail` 服务端取详情并自动开弹窗（`content-page-client.tsx:100-101`），无需 startDate/endDate。返回：浏览器返回即回到 `/admin/pulse?date=…&cap=…`（状态都在 URL，天然恢复）。

### 3.7 排序（本地内存，pulse-filters.ts 比较器）

人员表可排序字段：`publishedCount | totalPlay | avgBounce2s | avgCompletion5s`，默认 `totalPlay desc`；作品列表默认 `playCount desc`。比较器统一：`null/undefined 永远排最后（与方向无关）`，数值差乘方向；标题列不排序。实现照 `content/data/content-list.ts` 的 null 置底思路，本地 state `{field, dir}`，点击同列翻转。

### 3.8 边界

- 无发布日作品：不进晴雨表/人员表/胶囊列表任何日视图（同复盘页日期筛选行为，见 3.2）。
- 选定日全员无发片：走 ⑦ 空状态。
- date=今日：黄条（§二③）；数据照常显示（回流中缺快照的条目自然为 `—`）。
- 留存字段缺失：人员/作品该列 `—`。
- 非法 `?date=abc` / `?cap=xxx`：回落默认（3.5）。
- 已删除/回收站作品：不出现（loader `view:"all"` 只取 active）。
