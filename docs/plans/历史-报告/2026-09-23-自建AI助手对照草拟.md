# 自建 AI 助手（QwenPaw / odysseus）—— 对照草拟（给阿禅决策用）

> 一句话：这是"二类"里跟你日常相关的两个自建 AI 助手。这份照口径层那份的格式，说清它能帮你们干哪几件事、要投多少人、跟你们已经在用的千问办公有什么重叠、怎么先小范围试。仅为草拟评估，不代表已决定要做。

## 0. 先给结论（看这段就够）

- **它们不是"更强的 AI"，而是"把 AI 请进你自己公司、数据不出门"的方式**。核心卖点是：装在你自己机器上、能常驻钉钉、帮你派活做重复事务（周报、资料整理、读写 Word/Excel/PPT、盯消息、定时任务）。
- **必须先诚实说一句：它和千问办公高度重叠**。你现在用的千问办公已经能做钉钉集成、文档、定时这些。自建这套**真正多给你的只有两点**——① 数据**绝对留在自己服务器**、不经外部；② 你**完全自己掌控**（换模型、加技能、不被额度和别人账号限制）。如果这两点你不在乎，那就是重复建设，**没必要**。
- **只挑一个看就够**：优先 **QwenPaw**（跟钉钉/千问系最顺、README 标 Apache-2.0、有人维护）；**odysseus 功能更全但更重、且许可证至今没查清楚**，适合以后真要"整套自建"时再考虑，不必两个都上。

## 1. 这俩到底是啥（同屏对比）

| | QwenPaw | odysseus |
|---|---|---|
| 一句话 | 住进钉钉的"私人 AI 助理" | 自建的"AI 一站式办公室" |
| 主打 | 日常派活 + 多渠道（钉钉/飞书/微信/QQ）常驻 | 聊天+深度调研+文档+邮箱整理+待办日历，一锅端 |
| 记忆 | 三层：当下上下文 + 逐字历史 + 会自己沉淀的知识库 | 有会话/记忆，偏"工作台"而非个人成长 |
| 用模型 | 自带免费小模型（不联网也能跑），也能接你已有的 14+ 云模型 | 自带模型推荐与管理，偏重（可上 GPU） |
| 上手 | 桌面端/命令行都有，接钉钉是关键一步 | 一台服务器 Docker 起，靠界面操作 |
| 活跃度 | 今年 2 月出、至今活跃，但**未关闭问题 955 条**（多，说明边角毛病不少） | 今年 5 月出、活跃，**未关闭问题 1276 条**（更多） |
| 授权 | README 标 **Apache-2.0**（GitHub 未自动识别到，接入前再确认 LICENSE 文件） | **未查到许可证**——商用前是硬风险，必须先问清 |

## 2. 能帮你们干哪几件事（现在 vs 用它）

| 你现在的痛点场景 | 现在怎么做 | 用自建 AI 助手 |
|---|---|---|
| 每周一份团队数据/内容周报 | 人肉拉数、拼文档 | 设成定时任务，自动整理草稿推到你钉钉 |
| 一堆 Word/Excel/PPT 要读、要改、要转格式 | 手动开文件来回弄 | 让它批量读改写、转格式 |
| 同事在钉钉里反复问同一类事（口径、流程、查资料） | 你或老员工反复答 | @ 机器人，按你喂给它的资料答 |
| 敏感经营数据想用 AI，但不放心传到外部 | 干脆不用 AI | 全程在自己机器上算，不出门 |

**提醒**：它擅长"重复性事务 + 资料整理 + 问答"，**不擅长替你做判断**；涉及口径的数，仍要接上第 5 节那份口径能力才靠得住。

## 3. 要多投入什么（诚实成本）

| 投入项 | 谁来做 | 量级 | 备注 |
|---|---|---|---|
| 选机器/装一套（本地或云） | 工程 | 小-中 | 用免费自带模型可先不买 GPU |
| 接进钉钉、配权限、划谁能用 | 工程 | 中 | 安全边界要划清楚，别让它乱碰数据 |
| 喂资料、教它你们的流程和口径 | 产品/你 | 持续 | 决定它答得准不准，最容易被忽略 |
| 盯"毛病"和后续维护 | 工程 | 持续 | 未关闭问题上千，早期工具需人陪跑 |

## 4. 做之前你要先拍板的问题

1. **重叠问题**：你日常那套千问办公够不够？自建只为了"数据不出门 + 完全自主"——**这两点你到底要不要**？
2. **给谁用**：只你一个人用，还是开放给同事在钉钉里用？（越开放，权限和安全投入越大）
3. **碰不碰生产数据**：只处理文档/资料，还是也要它查你们的经营数字？后者得配口径层和权限，别裸接。

## 5. 我的建议（分档，最终你定）

- **一定要做**：先回答第 4 节的"重叠问题"。若你说不上"数据不出门/完全自主"具体帮到你什么，**就先别做**，这是典型的重复建设。
- **尽量要做**：若确实想要，先**只在隔离环境、不给生产数据**地小范围试 QwenPaw，一周内测三件真事（一份周报草稿、批量读写几个文档、接进钉钉问答），好用来再谈推广。
- **可做可不做**：odysseus（功能与 QwenPaw 重叠、更重、授权未明），暂缓。
- **不用做**：一上来就全公司铺开、直接喂经营数据、两个工具都装。

> 目标：低成本验证"自建 AI 助手"对我们有没有增量价值，先不碰生产数据、不对外开放。请在隔离环境部署一套 QwenPaw（用自带模型即可，不接外部 API），完成三件事并回报效果：① 生成一份团队周报草稿（用脱敏样例数据）；② 批量读取并改写 3～5 个 Word/Excel/PPT；③ 接入一个测试钉钉群做资料问答。同时确认其 LICENSE 与数据留存机制。验收标准：三件事里至少两件明显省人力，且能说清"这套比现有千问办公多解决了什么"。先出评估，不动生产。
