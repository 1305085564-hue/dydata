## 批次二：选中态统一（中风险）

### 目标
选中态只用「文字色 + 字重」表达，不加背景色、描边、阴影。

### 改动范围

| 组件/页面 | 当前选中态 | 目标 |
|---|---|---|
| `ui/tabs.tsx` | `bg-white shadow-sm` | 去掉背景和阴影，保留文字色+字重 |
| `ui/select.tsx` 选中项 | `bg-stone-50` | 去掉背景色，用文字色+字重 |
| `topics/page.tsx` 弹窗选项 | `bg-[#D97757]/12` | 去掉背景色 |
| `topics/page.tsx` 母题筛选 | `border-[#D97757]/40 bg-[#D97757]/10 shadow-2xs` | 去掉边框、背景色、阴影 |
| `topics/page.tsx` 主 tab | `text-[#D97757] font-semibold` | ✅ 已符合，不动 |

### 判断规则
规范定义的选中态工具箱（最轻量的有效表达）：
- **文字色 + 字重**（font-semibold + 品牌色/深色）
- **底部短线**（2px，品牌色，宽度 ≤60%）
- **微型胶囊块**（极轻品牌色背景，圆角 pill）

具体场景用哪种，由执行 AI 根据「最轻量的有效表达」原则自行判断。核心约束：不同时加边框和阴影。

### 执行顺序
1. `ui/tabs.tsx` → 截图验证
2. `ui/select.tsx` → 截图验证
3. `topics/page.tsx` 筛选器 → 截图验证
4. 检查其他页面是否有类似模式，一并处理

### 不确定项

## 批次三：导航指示器改为下划线（中风险）

### 目标
顶栏导航选中态用下划线指示，不用背景块+边框+阴影。

### 改动范围

| 文件 | 当前选中态 | 目标 |
|---|---|---|
| `nav-bar-client.tsx` | `bg-white border rounded-lg shadow-[...] border-[#D97757]/15` | 底部下划线 `border-b-2 border-[#D97757]` |

### 判断规则
- 导航项如果只有一行文字，下划线足够
- 如果导航项有图标+文字两行，下划线可能不够明显，可以加 `text-[#D97757] font-semibold` 辅助
- hover 态：`text-stone-500` → `text-stone-800`，不加下划线

### 执行顺序
1. 改 `nav-bar-client.tsx` 选中态
2. 截图验证所有页面顶部导航
3. 移动端导航如果是侧边抽屉，选中态同步调整

## 批次四：stone → zinc 全局替换（高风险）

### 目标
全站灰色体系从 stone（暖灰）切换到 zinc（冷灰），对齐「冷灰极简浅色工作站」定位。

### 为什么放最后
stone 和 zinc 虽然都是中性灰，但色温不同：
- stone 偏暖（带黄棕底）
- zinc 偏冷（带蓝灰底）

替换后整体气质会变——从"温暖"变"冷静"。这个改动影响**所有文件**，如果前面的选中态、导航还没稳，叠加起来会很难排查问题。

### 改动范围
全局搜索替换 `stone` → `zinc`，涉及：
- `design-tokens.css` / `tokens.css` / `globals.css`
- 所有 UI 组件（`src/components/ui/`）
- 所有页面文件（`src/app/`）
- `tailwind.config.ts` 如果有 stone 相关配置

### 风险点
1. **对比度变化**：stone-200 和 zinc-200 的视觉深度略有不同，可能某些边界线变淡或变重
2. **与品牌色的协调**：行动色 #D97757（暖橙）在冷灰底上可能比暖灰底上更跳——这通常是好事，但需要验证
3. **图表配色**：如果图表硬编码了 stone 色值，替换后可能与新色板冲突

### 执行策略
1. 先在 `tokens.css` 和 `design-tokens.css` 中替换 CSS 变量
2. 逐页面验证效果（优先 Dashboard、排行榜、选题库）
3. 确认无问题后再批量替换所有文件中的硬编码 `stone-*` 类名
4. 最后检查图表组件

### 回滚方案
如果 zinc 效果不理想，`stone` → `zinc` 是纯文本替换，git revert 即可回滚。
