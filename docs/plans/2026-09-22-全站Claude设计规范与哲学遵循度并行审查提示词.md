### 二、审查裁决准则：硬底线 vs 允许发散

在审查过程中，必须严格区分「不可逾越的硬底线」与「允许业务合理发挥的发散空间」，严禁对正常业务编排做机械教条式挑刺：

#### 🛑 严格遵守（硬底线 · 零容忍违规）
1. **字阶物理底线（严禁半像素）**：
   - 严禁出现任何带小数点的字号（`10.5px`、`11.5px`、`12.5px`、`13.5px` 等）；
   - 必须规整为标准整数阶梯：`11px`（微标）、`12px`（辅助徽标/元数据）、`13px`（紧凑正文/工具栏）、`14px`（标准正文）。
2. **字重防糊锁死**：
   - `≤14px` 的小字、正文段落、表单输入框、说明文字严禁加粗（脱离 400）；
   - `H3` 及以下容器严禁使用 `600+`（Semibold/Bold）；
   - 仅特许 `H1/H2` 页面/区域级大标题使用 `580/600`。
3. **字系边界隔离（小字不逞强 · 过程归黑）**：
   - 衬线体（`font-serif`）**仅限**用于"被郑重宣告为结论"的四大神圣时刻：
     ① 页面大标题 Hero
     ② 核心顶级大舱名牌
     ③ AI 洞察/诊断金句
     ④ 归档完成与调养立意寄语
   - **严禁**：输入框、普通表单、表格列表、按钮、数据指标、普通弹窗使用衬线体；
   - **严禁**：小字（≤14px）使用宋体等细小衬线（中文宋体小字横笔必发虚）；
   - **严禁**：中文使用机械仿斜体（`italic`），必须端庄立直（`not-italic`）。
4. **色彩与墨度纯净度**：
   - 严格遵循暖墨体系：Ink 950 (`#1C1917`)、Ink 800 (`#292524`)、Ink 600 (`#78716C`)；
   - 彻底清除历史违规泥色与偏黄暗色（如 `#FAF8F4`、`#FAF6ED`、`#E5E0D6`、`#D9D3C7` 等）；
   - 状态色必须遵循规范降饱和度（成功 `#6FAA7D`、警示 `#B98A54`、异常 `#C0685C`、灰蓝 `#43718E`），严禁刺眼荧光与生硬高饱和。
5. **去盒子化与容器克制**：
   - 单页面至多 1 层业务实体岛屿（大底 `bg-[#FCFCFB]` 上托一层白色纸层 `bg-white`）；
   - 严禁卡片套卡片（白卡套灰卡套白卡）；严禁无意义的粗灰边框（一律使用发丝线 `#E2E2DF` 或无框平铺）。

#### 🌿 允许合理发散（软指引 · 业务自由度）
1. **业务微文案与立意表达**：在保持出版物克制语感的前提下，文案可结合具体业务心流自由表达，不设死板字数限制；
2. **卡片内信息网格组织**：2列、3列、4列等栅格布局，由各业务信息密度自行决定；
3. **图标与插画意象**：在遵循单线轻量（1.25~1.5px 笔画）、无彩色描边的前提下，业务可按需选用合适的 Lucide 图标；
4. **轻量交互形态**：根据场景频次，可自主选用微胶囊、文字幽灵链接、轻气垫 Popover 或侧滑抽屉。

### 三、严重程度分级标准 (Severity Levels)

- **P0（体验破坏 / 物理破相）**：
  - 高频核心链路（如首页录入、登录、主要导航）中出现半像素字号，导致严重毛边发糊；
  - 核心文本在特定屏幕上对比度缺失导致不可读（如白底浅灰细字）；
  - 出现大面积布局坍塌或视觉重大撕裂。
- **P1（规范硬伤 / 禁令突破）**：
  - 任意位置的非整数半像素字号（`10.5px/11.5px/12.5px/13.5px`）；
  - ≤14px 小字加粗（违背防糊禁令）；
  - 表单/表格/普通弹窗违规滥用 `font-serif` 衬线；
  - 出现历史禁用的偏黄泥色硬编码；
  - 出现双层以上的套娃卡片盒子。
- **P2（质感折损 / 呼吸不纯）**：
  - 空间留白未遵循“头顶 ≥ 脚下”悬空定律（出现上下等距慵懒 padding）；
  - 边框使用了非标准色或过深阴影（未用发丝线与微气垫）；
  - 控制栏高度脱离 S(24px) / M(28px) / L(40px) 三档标准。
- **P3（微调建议 / 雕琢润色）**：
  - 辅助说明的文字色彩可进一步提亮加深增强可读性；
  - 圆角层级可以进一步精细收敛（如 6px / 8px / 12px 归正）。

### 四、5 个并行 Subagent 派工拆解

请主调度 Agent 同时派发 5 个并行代理，各自独立扫描对应代码域：

```
┌─────────────────────────────────────────────────────────────┐
│                      主调度 Agent                            │
└──────┬──────────────┬─────────────┬─────────────┬───────────┘
       │              │             │             │           │
   Agent 1        Agent 2       Agent 3       Agent 4     Agent 5
  全局与基础UI   首页与数据录入 选题与复盘中心 增长与数据看板 管理与协作体系
```

#### 🔹 Agent 1：全局基础体系与公共 UI 组件
- **审查范围**：
  - `src/app/globals.css`, `src/styles/*`
  - `src/components/ui/*` (Button, Dialog, Popover, Select, Tooltip, Alert, Table 等)
  - `src/components/editorial/*`
  - `src/components/nav-bar-client.tsx`, `src/components/user-workspace-popover.tsx`
- **重点扫描**：全局字体抗锯齿规则、半像素字号残留、基础组件默认样式是否锁死规范、Toast 与 Popover 视觉通透度。

#### 🔹 Agent 2：核心业务首页与数据录入工作台
- **审查范围**：
  - `src/app/(app)/dashboard/**/*`
  - `src/components/submission/**/*`
- **重点扫描**：录入表单所有 input/label 字号字重、截图槽位区小字是否半像素、分段控件、请假/报备弹窗、日历控件。

#### 🔹 Agent 3：选题工作台与创作复盘中心
- **审查范围**：
  - `src/app/(app)/topics/**/*`
  - `src/components/topics-v2/**/*`
  - `src/app/(app)/content/**/*`
  - `src/app/(app)/creative-review/**/*`
- **重点扫描**：选题池卡片、筛选抽屉、新建选题弹窗、复盘详情页、是否有衬线体滥用、微标签字号字重。

#### 🔹 Agent 4：成长分析中心与数据看板
- **审查范围**：
  - `src/app/(app)/growth/**/*`
  - `src/app/(app)/data/**/*`
  - `src/components/charts/**/*`
- **重点扫描**：图表标注、KPI 指标排版（tabular-nums）、对标同事便签卡、雷达面板、趋势图 Tooltip 样式。

#### 🔹 Agent 5：管理后台与团队协作体系
- **审查范围**：
  - `src/app/(app)/admin/**/*`
  - `src/components/admin-*`
  - `src/app/(auth)/**/*` (登录/注册页)
- **重点扫描**：成员管理列表、协作矩阵、AI 配置抽屉、登录表单按钮与提示、是否有双层套娃卡片与泥黄色块。
