## 二、必修项（P0）

### P0-1 同步弹窗无限循环打接口

**现象（实测）**：`/api/admin/ai-config` 95 次请求、每 1.8 秒一次、几乎无缝衔接；关闭弹窗后仍在继续。

**实测调用栈**：
```
fetchWithTimeout ← syncKeyModels (use-ai-config.ts:379) ← SyncModelsDialog.useEffect
```

**根因**：
- `sync-models-dialog.tsx:76-101`：`loadData = useCallback(..., [onSync])`
- `sync-models-dialog.tsx:103-113`：`useEffect(..., [open, keyId, loadData])`
- `use-ai-config.ts`：`syncKeyModels` 是 **return 对象里的内联箭头函数**，未用 `useCallback` 包装 → 每次渲染都是新引用

闭环：`loadData` 执行 → `setLoading(true)` / `setInventory` → 重渲染 → 父组件 `useAiConfig()` 重渲染 → `syncKeyModels` 新引用 → `onSync` 新引用 → `loadData` 新引用 → effect 重跑 → 回到起点。

**危害**：`sync_key_models` 会真实请求上游 `/models` 并写库。弹窗开着的每秒都在打上游 API、都在写库。

**修法（两条都做）**：
1. `use-ai-config.ts`：把 `syncKeyModels`、`testKeyAllModels`、`testKeyConnection` 等对外函数改用 `useCallback` 包装，依赖数组保持稳定（不引入会变的对象/函数）。
2. `sync-models-dialog.tsx`：`onSync` 用 `useRef` 持有，effect 依赖只留 `[open, keyId]`；同一 `keyId` 在途请求时不得重复触发。

**验收判据**：
- 打开同步弹窗后**静止 30 秒**，`/api/admin/ai-config` 的请求数 **≤ 2**（打开一次 + 可选的刷新一次）。
- 网络面板不得出现连续无缝的重复请求。

### P0-2 「检测此渠道全部模型」按钮点不动

**现象（实测）**：采样 12 次状态 `DEDDDEDDDDDD`——10 次禁用、2 次可点。

**根因**：同 P0-1。每次循环请求都会 `setLoading(true)` → 再 `false`，按钮跟着闪烁禁用。

**修法**：修好 P0-1 即自动恢复。另需保证：**刷新期间不得禁用检测按钮**——只在「首次拉取」时禁用，后台刷新时按钮保持可用。

**验收判据**：打开弹窗后，「检测此渠道全部模型」在 10 秒内**至少 9 秒可点击**，点击后能真正执行并返回结果。

## 三、小修项（P1）

### P1-1 「全部模型检测」结果是空的

**位置**：`compute-pool-panel.tsx:327-344`

**问题**：前端仍读旧字段 `data.results`，而后端 `test_all_keys_all_models` 已改返回 `totalKeys / totalModels / successCount / failureCount / failures[]`。字段对不上 → `mappedResults` 恒为空 → 误判「0 === 0」→ toast 显示「全部渠道模型检测通过（0/0）」，失败原因全部丢失。

**修法**：改读新结构，按 `totalKeys / totalModels / successCount / failureCount` 呈现，`failures[]` 逐条展示（渠道名 + 模型 + 失败原因）。

**验收判据**：点「全部模型检测」后，结果明确显示「测了几个 / 通过几个 / 失败几个」，失败项可展开看原因，**不得出现 0/0 的假通过**。

### P1-2 计数文案缺字

**位置**：`sync-models-dialog.tsx:277`

**问题**：显示「已勾选 2 / 8 个」，规格要求「已勾选 2 / **共** 8 个」。

**修法**：补一个「共」字。

### P1-3 拉取约 15 秒，期间状态自相矛盾

**现象**：拉取期间同时显示「正在拉取该渠道全部模型列表...」和已渲染的 8 个模型数据。

**修法**：区分两种状态——
- **首次拉取**：显示进度/骨架，不渲染列表。
- **后台刷新**：列表保持可见，顶部显示轻量「正在刷新」，不阻塞操作。

**验收判据**：任何时刻界面上不会同时出现「正在拉取」和「完整模型列表」。
