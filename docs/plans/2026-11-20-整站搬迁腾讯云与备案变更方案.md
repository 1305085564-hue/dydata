### 备案变更（腾讯云客服已答复，2026-11-20；可与搬家同步进行，不影响切换，不属第三节验收）

腾讯云客服的答复（三个问题已经问清，不用再问）：

1. **ICP 备案不用重新申请，原备案号保留。** 在[ICP 备案控制台](https://console.cloud.tencent.com/beian/manage)「我的备案」→ 对应网站 →「变更服务」，把绑定的云资源改为对应的云开发环境。**经营性备案必须办变更；非经营性备案同一腾讯云内换资源通常不要求立即变更。** 阿禅先在控制台确认自己是哪一类。
2. **公安备案的服务器 IP 不填 CNAME、默认域名或容器内网 IP，要填 CloudBase 环境的固定公网 IP。** 先在云开发控制台对应环境开启「固定公网 IP」（开启后有效期内不变，**可能收费，开之前先看价格**），同时确认 ICP 备案里的云资源也已切到该环境。填写参考[填写新办网站信息](https://cloud.tencent.com/document/product/243/19142)。
3. **公安备案是否撤回：** 申请里填的是旧服务器 IP（`118.89.72.250`）且旧服务器已停用 → 在全国互联网安全管理服务平台撤回，等 ICP 变更完成并拿到固定公网 IP 后重新提交；填的已经是当前 CloudBase 固定公网 IP 且网站可正常访问 → 不撤回，等审核。公安备案属公安侧系统，腾讯云无法代改或查看审核状态。

**第二轮答复（2026-11-20，腾讯云，以此为准，覆盖上面第 1、2 条的口径）：**

- **ICP 换云资源的入口**：ICP 备案控制台 →「我的备案」→ `dydata.cc` →「变更」→「变更服务信息」→「互联网信息服务」→ 该服务「变更信息」→ 网站信息里的「云资源」重新选「云开发」环境 → 提交审核。不要选「接入备案/新增接入」（同一腾讯云内换资源不走它），也不要碰「变更主体信息」。变更期间网站照常访问，备案号不变。
- **选得到云开发环境的前提**：环境套餐为**个人版及以上**、**剩余有效期大于 6 个月**、**已开启固定公网出口 IP**（云开发控制台 → 环境管理 → 环境设置 → 固定公网出口 IP）。

- **固定公网 IP 是环境的"出口 IP"，不是用户访问时命中的网关 IP**；公安备案按腾讯云说明填它，ICP 控制台显示的备案云资源 IP 要与之一致，但公安侧最终是否通过腾讯云不能保证。

- **公安在审申请**：审核中通常不能改 IP；去公安平台看该申请有没有「撤回/修改」入口，有再决定。
- **Cloudflare**：解析只用「仅 DNS」（灰云），CNAME 指云托管给的地址，**不要填固定公网 IP，不开橙色云朵代理**（与 S7 一致）。
