# plans 文件夹约定

> 2026-08-22 文档瘦身：历史方案已整体移入 `docs/archive/2026-08-22-文档瘦身/plans/`。本目录只放「还没做的事」。
> 2026-08-22 二次精简：删除全部空模块文件夹，只保留 `_跨模块/`（常驻台账）。

## 放置规则

- 新方案 → 按需新建模块子文件夹（用完即归档，不留空壳），命名 `YYYY-MM-DD-主题.md`，多文件加后缀（`-规格书`/`-Codex后端规格`/`-Antigravity前端规格`/`-提示词`）
- 一次性提示词（给 Codex/Antigravity 的任务 prompt）→ 执行完直接删除（git 历史可查）
- 模块完成 → 整个文件夹移到 `docs/archive/`
- 一次性施工产物（.sql/.json 快照、回滚脚本）→ 不提交，用完即删
- 跨模块/基础设施类 → 放到 `_跨模块/`；长期维护的台账类文件（如性能优化台账）常驻 `_跨模块/` 不归档

## 给 AI 的提示

写新方案文件时，按上面的规则放到对应子文件夹。不要把文件堆在 plans 根目录。
