# plans 文件夹约定

## 命名规则
- 文件名格式：`YYYY-MM-DD-<模块名>-<简述>.md`
- 模块名与子文件夹名一致（选题库/权限/协作管理/视频复盘/团队人效/成员生命周期）

## 放置规则
- 新方案 → 放到对应模块子文件夹下
- 一次性提示词（给 Codex/Antigravity 的任务 prompt）→ 执行完直接删除（git 历史可查）
- 模块完成 → 整个文件夹移到 `_已完成/`
- 跨模块/基础设施类 → 放到 `_跨模块/`

## 子文件夹

| 文件夹 | 状态 | 说明 |
|---|---|---|
| 选题库/ | 活跃 | 选题库功能相关方案 |
| 权限/ | 活跃 | 权限机制重构相关 |
| 协作管理/ | 活跃 | 协作管理功能相关 |
| 视频复盘/ | 活跃 | 视频复盘重构相关 |
| 团队人效/ | 活跃 | 团队人效功能相关 |
| 成员生命周期/ | 活跃 | 成员生命周期管理 |
| _已完成/ | 归档 | 已交付的旧方案，按模块分子目录 |
| _跨模块/ | 基础设施 | 架构治理、数据库迁移、死代码清理等 |

## 给 AI 的提示
写新方案文件时，按上面的规则放到对应子文件夹。不要把文件堆在 plans 根目录。
