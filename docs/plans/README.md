# 计划目录约定

本目录放待做和在办材料。方案按 `YYYY-MM-DD-主题.md` 平铺，注明当前状态和仍需完成的工作。正在续工的会话材料放 `上下文交接/`，写法见[交接模板](../通用管理/上下文交接.md)。

完成后按材料用途分流：

- 后续还会用的已确认结论和证据，优先补入 `docs/reference/` 的现有原稿。整份报告仍有独有价值时，可以直接归参考，并保留日期、适用版本和验收范围。
- 旧施工规格、派令、过程记录和只需留底的报告，归 `docs/archive/`。移走原件，顺手更新引用。
- 还有未完事项的计划留在当前区，写清已完成部分和待办。复核批量材料时用实际完成、撤案或替代证据判定状态。

目录职责以[文档与维护规范](../通用管理/文档与维护规范.md)为准。
