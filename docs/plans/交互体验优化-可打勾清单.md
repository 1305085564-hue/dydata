# 交互体验优化：可打勾清单（收敛版 · 共 10 项）

> 基于《网页交互体验升级方案》和《顶尖产品拆解》，对照现行代码、设计红线与最新业务口径（**每日大盘入口已下线并计划删除或合并，不再对每日大盘做任何改造**）收敛后的最终可执行清单。
>
> 选型原则：**只做高性价比项**——第二批为 8 项低成本高收益，第三批为 2 项中高成本极高收益（第一、二批跑稳后再排期）。

---

## 一、第二批：8 项低成本高收益（立即排期）

### ☐ 1. 全站固定滚动条槽位（Windows 零抖动）

- [ ] 页面主滚动区预留 Windows 实体滚动条宽度（`scrollbar-gutter`）
- [ ] 切换长短页面时页面中轴不左右晃动
- [ ] 展开/收起弹窗或抽屉时底层页面不左右晃动

**验收标准**：Windows Chrome / Edge 100% 与 125% 缩放下切页、开关抽屉，页面内容中轴纹丝不动。

---

### ☐ 2. 全站弹窗与抽屉内部滚动隔离
- [ ] 通用弹窗（`ui/dialog.tsx`）与通用抽屉（`ui/sheet.tsx`）滚动区开启滚动隔离
- [ ] 在视频复盘详情、协作档案或选题抽屉内滑到底部时，不连带滚动底层大表格

**验收标准**：在长内容弹窗或抽屉内用鼠标滚轮滑到底后继续往下滚，背后表格位置纹丝不动。

---

### ☐ 3. 审批撤回条悬停暂停 + 工作台报错自动把光标送进出错格
- [ ] 审批工作台底部 5 秒撤回条：鼠标悬停到提示条上时暂停倒计时，移开后再继续
- [ ] 数据上传工作台点击提交遇到漏填或校验拦截时：在滚动到提示位置的同时，自动把输入光标聚焦到第一个出错/漏填格

**验收标准**：
- 审批点同意后把鼠标停在底部撤回条上超过 5 秒，提示条不消失、仍可点击撤回
- 工作台漏填点提交，不用手动点框，直接敲键盘即可在第一个出错格输入

---

### ☐ 4. 工作台识数小抛光（不动已有计时与 `Tab` 顺序）
- [ ] 补齐单项指标（点赞 / 评论 / 分享 / 收藏 / 涨粉）大于播放量时的白话提醒（如「高于播放量，请确认」）
- [ ] 提示文案全用白话，不展示「置信度 XX%」
- [ ] 点进标有「请核对」的存疑数字格时，自动全选当前数字方便直接覆写
- [ ] **红线**：不劫持 `Tab` 键跳过正常必填项；保留已有的识别实时计时与计数提示

**验收标准**：
- 点赞/涨粉大于播放量时在对应格下方看到明确白话提示
- 点进存疑格数字自动全选，可直接敲字替换
- 从标题/发布时间按 `Tab` 仍按自然顺序进入各必填项

---

### ☐ 5. 表格精准冻结（仅单表长矩阵冻表头，宽表冻首列）
- [ ] **发布管理月历**：表头冻结（向下滚看多人排班时日期表头钉住；已有前两列冻结保持不动）
- [ ] **成员主页作品表**：仅在横向溢出需要左右滚动时冻结首列（作品标题），不强行加表头冻结
- [ ] **红线**：每日大盘不做；数据管理、成员主页等一页多表页面不硬加表头冻结，避免出现双层小滚动框

**验收标准**：
- 发布管理长月历向下滚动时顶部日期栏稳稳钉住
- 成员主页宽表横向滚动时首列不跑偏，整页保持单一顺滑的竖向滚动

---

### ☐ 6. 长文案粘贴自动清洗 + 复制按钮原地小对勾
- [ ] 工作台文案框与选题库写作区粘贴长文案时，自动剥离源文档隐藏字符与首尾冗余空白，同时保留正常段落空行（不折成附件卡片）
- [ ] 视频复盘、个人主页链接、选题库等「一键复制」按钮统一为：点击后原地变成小对勾并提示「已复制」，约 2 秒后安静复原（不弹全屏大横幅）

**验收标准**：
- 从飞书 / Word / 公众号复制带格式或多余空行的文案贴入，排版干净且分段正常
- 点击各处复制按钮，均在按钮原地看到小对勾反馈后自动复原

---

### ☐ 7. 关键列表支持 Windows 原生新标签页打开
- [ ] 梳理视频复盘、成员主页作品列表、选题库等需要多条横比的核心跳转入口，补充原生链接语义
- [ ] 支持 Windows 高频习惯：`Ctrl+左键` 或鼠标中键直接在浏览器后台新开标签页，同时不破坏原有左键点击打开详情的体验

**验收标准**：在列表上按住 `Ctrl+左键` 或鼠标中键点击多个条目，可在浏览器上方连续开出对应详情标签页。

---

### ☐ 8. 两项收尾核对补齐（先核再改，避免重复）
- [ ] **数据管理排序进网址**：核实协作管理/数据管理页当前排序是否已写入 URL；如确实缺失且有跨同事对齐需要，按现有网址同步方式补齐（**每日大盘彻底不做**）
- [ ] **成员主页原生气泡替换**：核实成员主页作品表中残余的原生 `title` 气泡是否已被第一批覆盖；如未覆盖，统一替换为全站标准的 `TruncatedTooltip` / `SimpleTooltip`（**不使用协作页私有的 `OneTip`**）

**验收标准**：
- 数据管理如补齐了排序参数，刷新页面与复制链接给同事后排序完全一致
- 成员主页长标题/账号名悬停气泡样式、100ms/400ms 延迟与全站一致

## 二、第三批（储备）：2 项中高成本极高收益（第一、二批稳妥落地后再排期）

### ☐ 9. 视频复盘改为「右侧不遮挡抽屉 + 跨行点选无缝切换」
- [ ] 将视频复盘当前的居中遮罩弹窗，重构为右侧不遮挡主表的详情抽屉
- [ ] 抽屉开启期间，点击左侧表格其他行时保持抽屉展开并原地切换为该条作品详情（保留顶部上一条/下一条与全屏查看入口）
- [ ] **前提**：保持全站抽屉规格统一（[美学宝典 §3.3](../reference/美学宝典.md#33-浮层uidialogtsx--uisheettsx)），不引入多模式切换开关

**预期收益**：管理者连续复盘几十条作品时始终看得见前后行数据上下文，不再被居中弹窗遮挡打断。

---

### ☐ 10. 作品复盘「文案/截图就地打点批注」
- [ ] 管理者在视频复盘详情内，支持直接划选文案片段或在作品截图上打点留下批注
- [ ] 批注自动沉淀在作品复盘档案内，并触发通知直达对应编导/创作者查看与标记「已处理」
- [ ] **边界**：只做轻量「图钉定位 + 通知当事人 + 解决归档」人际闭环，不做自动代理改写

**预期收益**：彻底取代「截屏 → 切飞书群找人 → 画红圈点评 → 事后找不到历史记录」的割裂流程。

## 明确砍掉 / 不做清单（防返工红线）

- ❌ **每日大盘任何优化**（页面待删除或合并，不做表格冻结、不做排序同步、不做预设）
- ❌ **个人常用预设视图弹窗与顶部标签栏**（成本高且添噪音；做好 URL 同步后直接用浏览器书签平替）
- ❌ **劫持 `Tab` 键只跳存疑格**（会跳过正常必填项导致漏填）
- ❌ **一页多表硬加表头冻结**（每日大盘/数据管理/成员主页强冻表头会产生双层小滚动框）
- ❌ **全局单字母热键或右键多级菜单替代常显按钮**（易与 Windows 中文输入法冲突，且违背操作列常显原则）
- ❌ **审批卡片加回请假/补交分类或塞入当月履约统计**（违反已拍板的[审批工作台](../reference/设计与决策/审批工作台.md)第 3、5 条）
