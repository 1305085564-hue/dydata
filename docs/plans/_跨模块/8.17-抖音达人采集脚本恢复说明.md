## 五、已经删除的旧脚本

旧脚本不要恢复、不要参考执行。

已删除：

```text
tools/douyin-creator-export/archive/旧版-playwright-错误实现.ts.disabled
tools/douyin-creator-export/archive/旧版-start-chrome-debug.sh.disabled
```

删除原因：

- 旧脚本试图用 `--remote-debugging-port=9222` 接管默认 Chrome 用户目录；新版 Chrome 下不可用且会干扰日常浏览器。
- 旧脚本会尝试启动/重启 Chrome，导致用户反复登录。
- 旧脚本在抖音页面 DOM 里找「导出 Excel」，但社媒助手主要是插件注入层/侧边栏能力，定位对象错误。

## 六、当前脚本入口

当前入口：

```text
tools/douyin-creator-export/collect.ts
```

命令：

```bash
npm run douyin:collect -- --url="https://www.douyin.com/user/..."
```

脚本职责：

1. 使用独立采集 Profile，不碰用户日常 Chrome。
2. 第一次运行时让用户在专用浏览器里登录抖音和社媒助手。
3. 后续复用该专用 Profile。
4. 打开达人链接。
5. 等待 `smzs-user` 出现，必要时按 `Alt+C`。
6. 点击「采集本页视频」。
7. 点击「自动滚动」，直到检测数等于页面作品数。
8. 点击「确认采集」。
9. 优先监听插件是否下载 Excel。
10. 如果插件没下载 Excel，就从页面作品卡片提取数据，调用 `create-excel.ts` 同口径生成 Excel。

## 七、关键边界

必须遵守：

- 不碰默认 Chrome Profile。
- 不重启用户日常 Chrome。
- 不再使用 `chrome:debug`。
- 不再使用 `--remote-debugging-port=9222` 接管默认 Chrome。
- 不把采集工具放进 `src/`。
- 不把登录态 Profile 提交 Git。
- 不下载视频原文件，只导出数据表。

建议本地目录：

```text
tools/douyin-creator-export/.profile/
tools/douyin-creator-export/.tmp/
output/douyin-exports/
```

下次做脚本前，应把下面目录加入 `.gitignore`：

```text
tools/douyin-creator-export/.profile/
tools/douyin-creator-export/.tmp/
```

## 八、兜底采集口径

如果插件不下载 Excel，就用页面卡片兜底。

可提取字段：

- 视频 ID：从 `/video/<id>` 提取；
- 视频链接：`https://www.douyin.com/video/<id>`；
- 点赞数：卡片首个数字，如 `1097`、`1.2万`；
- 标题：卡片文本去掉点赞数；
- 话题标签：标题里的 `#...`；
- 达人主页：用户输入链接；
- 原始文本：卡片完整文本。

已知限制：

- 不能保证拿到评论数、收藏数、转发数、发布时间；
- 如果要这些字段，需要社媒助手官方 Excel 成功，或逐条打开详情页补采。
