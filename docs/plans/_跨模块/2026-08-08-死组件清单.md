### 1. `admin-layout/admin-top-nav.tsx`

### 2. `admin-secondary-nav.tsx`

- 被 `app-shell/index.ts` barrel 再导出（`export { AdminSecondaryNav, ... } from "../admin-secondary-nav"`），但 **无任何文件从 barrel 消费 `AdminSecondaryNav`**。
  - barrel 的消费者（`dashboard/page.tsx`、`growth-client.tsx`、`content-tools-client.tsx`）只导入了 `AppShell`、`AppShellHero`、`AppShellMetricStrip`、`AppShellSection`，均未导入 `AdminSecondaryNav`。
- 也无任何文件直接 `import ... from "@/components/admin-secondary-nav"`。
- 仅有 `admin-secondary-nav.test.tsx` 测试文件引用。
- 可能是导航重构后该组件不再被使用，但 barrel 的再导出未清理。

### 3. `ui/motion-card.tsx`

- **零代码引用**：全局搜索 `MotionCard`、`ui/motion-card`、`./motion-card`，无任何生产代码 import。
- 仅有 `ui/motion-card.test.tsx` 测试文件和 `src/lib/design-system-README.md` 文档提及。
- 可能是被普通 `ui/card` 或其他布局方案替代后遗留。

### 4. `ui/toast.tsx`

- 文件内容仅一行：`export { Toaster as Toast } from "@/components/ui/sonner"`。
- **零代码引用**：无任何文件 `import ... from "@/components/ui/toast"` 或 `from "./toast"`。
- `ui/sonner` 直接被 `route-toaster.tsx` 消费，不需要经过此中间层。
- 可能是早期封装的 toast 入口，后续直接用 sonner 后遗留。
