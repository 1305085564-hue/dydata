## 4. Model Knowledge

- **移动端 50/50 左右对称紧凑卡片的黄金法则**：
  1. **避免在卡片内使用原生 select 或 absolute 下拉**：在 ~160px 的紧凑卡片内展开绝对定位菜单极易溢出或遮挡下方元素；而在 Mac/Webkit 嵌套 relative 容器中原生 select 会计算错视口坐标导致弹层飞到顶部。**最佳实践是使用 Portal 渲染的受控 Dialog**，居中弹窗展示搜索框和成员列表，点击即选即关，稳定丝滑。
  2. **卡片即纸张（去套娃框）**：右侧卡片本身已经有 `rounded-xl border border-[#ECE7DE] bg-white/90`，内部的 Textarea 必须设置为 `bg-transparent border-0 outline-none p-0 focus:ring-0 focus-visible:ring-0`，使内容直接书写在卡片白底上，杜绝“框中框”。
  3. **Gestalt 亲密性与标题梯次**：指标矩阵内部行距必须小于区块与区块之间的间距；标题头顶留白必须明显大于脚下留白，使层次一目了然。
