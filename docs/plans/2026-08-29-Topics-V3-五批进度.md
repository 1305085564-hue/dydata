# Topics V3 目标与关联施工进度

> 最后整理：2026-08-30。
> 用途：这是选题库后续施工的唯一进度与交接文档。上下文压缩后，先读本文件即可恢复产品方向、历史决策、当前代码状态、验收结果和下一步；对话、日志和临时执行记录只作为来源，不再另建一套平行结论。原始需求曾按五批讨论，正式施工改为三个关联施工包，不机械保留“第五批”。完成一项就更新状态，不另建重复计划。

## 总目标

选题库只沉淀被数据验证过的干货选题，帮助员工快速选题并去飞书创作。允许多人重复写同一好题，持续累积成绩。

固定边界：保留现有八大母题；不做站内编辑器、飞书嵌入、原视频图片/播放/链接；内部和外部成绩不能混成一个平均值；视觉不能代替真实接口和数据。

## 已确认的产品方向（后续以此为准）

- 选题库的唯一目标：从真实数据验证过的优质干货中，让创作者按现有八大母题和视频时长快速挑题，然后去固定的飞书空间创作。
- 选题库只收“干货”内容；复盘视频，即使播放量很高，也不进入选题库。选题库不提供“干货/复盘”筛选项，因为复盘根本不是选题来源。
- 好选题永久保留：可以反复写、反复产生爆款，历史成绩持续累积，不因被写过一次就消失。
- 允许多人写同一题。“认领”不是抢占和排他锁，页面最终使用“在写”表达；不再做撞车阻断、名额限制、替换认领。
- 近 7 天热度的含义是最近真实参与：分别记录近 7 天写过的人数和近 7 天仍在写的人数，同一个人只算一次；不能用历史累计认领数冒充七天热度。
- 三条进货入口：①内部日报/视频数据库达到标准后自动进入；②管理员批量导入 Excel/CSV；③成员在选题库页面手动录入。内部自动入库仍只认精确“干货”标签、24 小时播放达到 3 万且视频有效。
- 不做站内视频播放、图片、原视频外链或站内脚本编辑器。选题确认后复制必要内容并打开团队固定飞书空间，员工自己选择具体文档。
- 顶部三个视角固定叫“全部选题 / 我的选题 / 在写选题”；其中“我的选题”对应本人手动录入的选题，“在写选题”对应本人当前 writing 状态。
- 卡片里到底优先显示哪些数据、显示几项、如何排序，暂不定。本轮先保证数据真实和接口接通，卡片信息取舍与最终视觉统一留到后续优化。
- 日报业务日期按周/月统计；通常是第二天上传。`report_date` 是业务归属日，`uploaded_at` 只是上传时间；不能把“当天是否上传”当成业务完成标准。
