# 视频复盘与素材库合并 — 实施计划

> 日期：2026-09-20  
> 目标：废掉素材库页面，保留视频复盘页面，用素材库的抽屉替换复盘抽屉，底部加双截图功能  
> 预计工期：2-3 天

---

## 一、核心方案

**视频复盘的列表 + 素材库的抽屉（底部加双截图）**

### 保留功能
- ✅ 视频复盘列表（12 项核心指标）
- ✅ 筛选器（按人员、账号、日期、关键词）
- ✅ 异常状态标记（红/橙/绿颜色提示）
- ✅ 素材库抽屉的完整指标 + 文案复制 + 外链
- ✅ 双截图对比（从复盘抽屉搬到素材库抽屉底部）
- ✅ 选题库入库按钮
- ✅ 回收站操作（删除、恢复、永久删除）

### 删除功能
- ❌ AI 诊断分析（调试残留，零真实使用）
- ❌ 多参照对比（近3条、7天均值、最高、指定成员）
- ❌ 复制诊断话术
- ❌ 素材评级 S/A/B/C（零使用）
- ❌ 人工备注输入框
- ❌ 资产统计条（已入库/待整理/已评级）
- ❌ 素材库页面的视频标签展示区块（⚠️ 只删展示，保留标签表和投稿流程）
- ❌ 人工复盘状态字段的前端显示（review_status/reviewed_at/reviewed_by 零使用）
- ❌ 素材库独立页面 `/admin/videos`

**执行内容**：

2. 迁移到 `src/app/(app)/admin/content/content-list.tsx`
3. 筛选项：
   - 按人员筛选（profiles 下拉）
   - 按账号筛选（accounts 下拉）
   - 按日期范围筛选（起止日期选择器）
   - 关键词搜索（标题/内容搜索框）

4. 保留异常状态颜色标记（红/橙/绿）

**技术细节**：
- 复用素材库的筛选逻辑（loader 层支持筛选参数）
- 保持视频复盘现有的 12 项指标列不变
- URL 参数传递筛选状态（可分享链接）

**输出**：
- 视频复盘列表顶部出现完整筛选器
- 筛选功能正常工作（按人员/账号/日期过滤）

**交付标准**：

### 阶段 3：抽屉替换与双截图迁移（1天）

**目的**：用素材库的抽屉替换复盘抽屉，底部加双截图

**执行内容**：

#### 3.1 抽屉主体替换
1. 从 `src/app/(app)/admin/videos/video-detail-dialog.tsx` 复制抽屉组件
2. 重命名为 `content-detail-dialog.tsx`，放入 `src/app/(app)/admin/content/`
3. 保留功能：
   - 完整数据指标展示（18 项指标）
   - 视频文案查看和一键复制
   - 外链跳转到原视频按钮
   - 选题库入库按钮（从复盘抽屉保留）
   - 回收站操作按钮（移入/恢复/永久删除）

#### 3.2 双截图功能迁移
1. 从 `src/app/(app)/admin/content/content-diagnosis-workbench.tsx` 提取双截图对比组件
2. 提取逻辑：
   - 读取 `video_metrics_snapshots.traffic_curve_url`（流量曲线）
   - 读取 `video_metrics_snapshots.retention_chart_url`（留存脱落图）
   - 并排显示两张截图
3. 插入到新抽屉底部（折叠面板，标题"手机截图对比"）

#### 3.3 删除不用的功能
- 删除 AI 诊断分析区块
- 删除多参照对比区块
- 删除复制诊断话术按钮
- 删除素材评级 S/A/B/C 选择器
- 删除人工备注输入框

**输出**：
- 点击列表任意视频，打开新的抽屉
- 抽屉包含完整指标 + 文案 + 外链 + 选题库 + 回收站
- 抽屉底部折叠面板显示双截图（如有上传）
- 不再显示 AI 诊断、对比、评级等旧功能

**交付标准**：
- 新抽屉功能完整可用
- 双截图正常显示（有截图时）
- 所有删除的功能全仓 grep 零引用

### 阶段 4：素材库页面废弃与重定向（0.5天）

**目的**：删除素材库独立页面，设置 301 重定向

**执行内容**：
1. 修改 `/admin/videos/page.tsx` 为服务端重定向：
   ```typescript
   import { redirect } from 'next/navigation';
   
   export default function VideosRedirectPage() {
     redirect('/admin/content');
   }
   ```
2. 删除导航菜单中的"素材库"入口（`src/lib/nav-bar-items.ts`）
3. 保留"视频复盘"作为唯一入口
4. 保留素材库的所有 API 路由（抽屉功能依赖它们）：
   - `/api/admin/videos/list`（查询用）
   - `/api/admin/video-assets/[videoId]`（详情用）
   - `/api/admin/videos/{videoId}/lifecycle`（回收站用）

**输出**：
- 访问 `/admin/videos` 自动跳转到 `/admin/content`
- 导航菜单只剩"视频复盘"一个入口
- 旧链接全部可达（兼容性）

**交付标准**：
- 重定向正常工作
- 导航菜单无"素材库"项
- 抽屉功能不受影响（API 保留）

## 三、风险与缓解

| 风险 | 等级 | 缓解措施 |
|------|------|----------|
| 误删有人使用的功能 | 高 | 阶段 1 数据验证，阿禅确认后再删 |
| 抽屉替换破坏现有功能 | 中 | 保留所有 API 路由，只改前端 UI |
| 筛选器性能问题 | 中 | 复用素材库已验证的筛选逻辑 |
| 截图迁移后无法显示 | 低 | 保持截图读取逻辑不变，只改位置 |
| 旧链接断裂 | 低 | 301 重定向保证兼容性 |
