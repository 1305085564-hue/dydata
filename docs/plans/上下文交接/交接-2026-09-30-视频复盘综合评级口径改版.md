**已确认（读代码/文档得出，非推测）：**

- 现行实现于 **2026-09-29 上线**，commit `20f3a017`（`feat: KPI 综合评级接入视频复盘抽屉`）。
- 现行算法 `overallBreakoutGrade(playCount, items)` 三步：
  1. `播放 < 5,000` → 直接判**劣**，不看指标；
  2. `播放 ≥ 5,000` → 取参与项（互动率 / 第四格 / 转粉率）评级里**最低**一档（短板原则）；
  3. 评「**优**」需 `播放 ≥ 12,000` 且三项全优；`5,000–12,000` 区间三项全优封顶**良**。
- 常量：`KPI_PLAY_FLOOR = 5000`、`KPI_PLAY_EXCELLENT = 12000`（`src/lib/breakout-rating.ts:107-108`）。
- 单项档位 `breakoutGrade()`：达成率 `≥100 优 / ≥80 良 / ≥60 普 / <60 劣`；达成率 = 实际值 ÷ 该话题标准线 × 100，**不封顶**。
- 第四格按「话题」标签切换，唯一判定入口 `breakoutTargetsFor(topicKind)`：**干货 = 收藏率，复盘及其他 = 点赞率**。
- 标准线（`BREAKOUT_TARGETS`）：干货 互动率 3.2% / 收藏率 2% / 转粉率 1%；复盘 互动率 2.7% / 点赞率 2% / 转粉率 1%。
