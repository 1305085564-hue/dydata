### 三、已确认事实与待验证判断

- **已确认**：
  1. 「筛选」胶囊未激活态此前是 `text-[#78716C]` 浅灰 + `size-3` 箭头，与「时间 / 人员」的 `text-[#1F1E1D]` 深炭黑 + `size-4` 箭头不一致，现已完全对齐。
  2. 宽度写死 `w-28`（112px）或 `min-w-32` 会导致在短词下右侧留出 40~50px 丑陋空洞；采用 `w-fit` 自适应包裹后无论选 2 字还是 5 字均紧凑得体。
  3. 基于 `@base-ui/react/menu` 的 `DropdownMenuSub` 具备原生安全的对角线滑动容错算法，右飞出的交互体验远优于大块堆砌的表单面板。
  4. 全仓自动化单测通过率：`1,836 passed, 0 failed`；生产打包 `npm run build` 耗时 5.1s 零告警通过。
  5. 本地分支 `main` 领先 `origin/main` 24 个提交。目前**未 push**。

### 四、已做决策与禁止重做

- **已确定的方案及原因**：
  - 横排筛选栏优先采用 `w-fit` 紧凑自适应包裹，禁止写死固定宽度。
  - 次级筛选主菜单固定 `w-56` 单列 4 维度，子菜单 `w-36` ~ `w-48` 自适应，鼠标划入平滑向右展开。
  - 自定义播放量输入框嵌套在流量子菜单中，保留输入状态和冒泡拦截。
  - 规范收敛为严格 1 行，杜绝长篇抽象空话。
- **已失败、被否决或确认无效的方案及原因**：
