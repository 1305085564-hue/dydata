## 1. 本轮只做到什么程度

### 1.1 完整适配

只对最高频入口做完整移动体验：

- 全局导航、顶部栏、底部栏、抽屉、弹窗。
- `/dashboard` 当前 V2 填报流程。
- `/topics` 列表、筛选、详情和深链。

### 1.2 保证能用

管理端核心页面保证手机能查看和完成主要操作，但不要求全部重做成精致卡片：

- `/admin/fulfillment`
- `/admin/content`
- `/admin/collaboration`
- `/admin/videos`

复杂宽表允许保留清晰、可控的横向滚动，只要首列、主要操作和返回路径可用，不再强制为每张表开发独立移动视图。

### 1.3 只修阻塞

以下低频或待重做页面，只修横向爆版、按钮点不到、内容被遮挡等阻塞问题，不做视觉重构：

- `/growth`
- `/content-tools/rewrite`
- `/admin/modules`
- `/admin/ai-config`
- `/admin/settings`

### 1.4 不做

- 不做原生 App、PWA、离线缓存、系统推送。
- 不预建 `ResponsiveDataView`、`MobileFilterSheet`、`MobileActionBar` 等抽象体系。
- 不单独重做角色导航架构；只修明显的入口重复、埋藏或不可达问题。
- 不复制移动端 API、权限、缓存或业务状态。
- 不改数据库、RLS、数据口径和现有权限模型。
- 不为了移动端顺手做性能重构或代码治理。

6. 现有静态响应式测试不能证明真实手机页面可用。

## 3. 最小改造原则

### 3.1 默认只改现有页面

- 优先使用同一套 DOM 做响应式调整。
- 不为了“架构漂亮”先拆 Controller、Desktop View、Mobile View。
- 只有一个页面用普通响应式确实无法完成任务时，才局部增加移动视图。
- 桌面和移动继续共享现有 Loader、API、权限和业务动作。

### 3.2 页面处理方式

- 表单和普通卡片：改单列、间距、按钮宽度和弹窗尺寸。
- 详情抽屉：继续扩展现有 `AdaptiveSheet`。
- 普通表格：优先隐藏次要列、换行和横向滚动。
- 核心宽表：主要操作必须在手机上可达；必要时只为该表做简单卡片，不抽象成全站组件。
- 固定层：只统一底部安全区和软键盘遮挡，不建设新的全局层级系统。

### 3.3 数据和性能边界

- 不新增移动专用请求。
- 不同时挂载两套会重复拉数的视图。
- 详情继续按需加载。
- 保持 `docs/架构与性能总纲.md` 的现有预算。
- `/growth` 和 `/content-tools/rewrite` 已计划重做，本轮只修使用阻塞。

## 6. 精简验收标准

### 6.1 视口

每个施工包只跑三个主尺寸：

- `390×844`：手机主验收。
- `768×1024`：平板边界。
- `1440×900`：桌面回归。

`320×568` 只在 P1 和 P6 做全局外壳抽查，不要求每页重复跑。

### 6.2 必须通过

- 页面没有导致主任务无法完成的横向爆版。
- 主要按钮、输入框和返回入口不被底栏或软键盘遮挡。
- 主要操作按钮容易点中；不要求逐个扫描所有非关键小图标。
- Drawer、Dialog、Toast 和底栏不遮住主要操作。
- Dashboard 填报、Topics 浏览详情以及管理端主要操作是真实闭环。
- Loading、空态、错误态至少在核心页抽查，不要求每个低频页穷举所有状态。
- 桌面端主要流程和布局不回退。
- 不新增移动专用 API，不重复请求同一业务数据。

### 6.3 允许的折中

- 低频管理宽表可以横向滚动。
- 平板可以继续使用桌面布局，只要不爆版且操作可达。
- 低频页面允许视觉一般，但不能白屏、遮挡或无法提交。
- 不为一次适配专门建设新的通用组件库或完整移动测试平台。

### 6.4 测试

通用门禁继续使用：

```bash
npm run gate:static
npm run gate:browser
```

每批再用 Playwright 或真实浏览器跑对应路由的三个主视口。只有反复出现同类回归时，才考虑增加轻量移动脚本；本轮不预设“先造测试平台”。

验收记录必须写清：环境、路由、视口、角色、成功操作、失败项和是否实测生产。截图只作辅助，不能代替功能验证。

## 7. 提示词规则

每份提示词只需要包含：

1. 当前施工包 ID 和目标。
2. 必读文件。
3. 允许修改的页面或文件范围。
4. 禁区。
5. 验收命令和三个主视口。
6. 更新本总纲任务状态与执行记录。
7. 是否允许提交、是否允许推送。

新会话第一次参与时完整读取本总纲；同一连续会话后续只需读取当前施工包、验收标准和新增执行记录。

共享文件按顺序施工，不让 Antigravity 与 GLM 同时修改导航、Layout、Token、AdaptiveSheet 或同一个页面。
