# 决策 0003：审批不承诺跨表原子事务

**背景**：审批核心 RPC 与通知、待办、审计写入属于不同对象，当前方案没有具备 migration、RLS、补偿和线上回滚证据的跨表事务。
**决定**：审批不承诺跨表数据库原子事务；用分层结果字段、结构化日志、幂等键、重试或人工补偿表达非原子后置结果。
**后果**：核心业务成功与审计、通知、待办结果必须分别返回和观测；若未来消除窗口，另立事务/Outbox 方案。
