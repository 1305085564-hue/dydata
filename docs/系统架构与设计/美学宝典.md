## §1 数值档位

### 1.1 字号五档

**页面定名** → 28px（`sm:` 以下 20px）, 行高 1.20, `#141413`, Serif + `tracking-tight`  
**空间定名** → 20px, 行高 1.30, `#141413`, 区块/抽屉用 Serif, 弹窗用 Sans  
**正文与条目名** → 14px, 行高 1.60（条目名 1.40）, 正文 `#1F1E1D` / 条目名 `#141413`, Sans  
**高密度内容** → 13px, 行高 1.40（表格）/ 1.60（长文）, `#1F1E1D` / `#78716C`, Sans  
**元数据** → 12px, 行高 1.50, `#78716C`, Sans  
**无内容信号** → 12px, 行高 1.50, `#A8A29E`, Sans  
**指标大数** → 20px, 行高 1.20, `#141413`, Sans

**封闭律**：五档之外不得出现。唯一豁免：落地页 Hero 32 → `sm:`36 → `lg:`41.6px。

**条目名写法**：与正文同字号、同字重，不靠字重区分。承重手段：① 独占一行；② 紧跟 12px 元数据，`gap-1`；③ 头顶留白 > 脚下留白。

**字重一档**：全站只有 400。500/600 不存在于基线环境（Windows 雅黑只有 400/700），不入系统。层级不得只靠字重承载。

### 1.2 墨度四阶

**定名墨** → `#141413` → 页面定名、空间定名、条目名、指标大数、表格核心指标列、激活态  
**正文墨** → `#1F1E1D` → 正文、表格主键列、常规数据  
**元数据墨** → `#78716C` → 表头、字段名、单位、表格次要列、辅助说明  
**信号墨** → `#A8A29E` → **只承载「这里没有内容」**：占位符、空值 `—`、禁用态

四阶之外的文字灰不得出现。定名墨与正文墨相差极微，只作辅助信号，不单独承担层级。

### 1.3 留白四级

**断层** → 20px → `gap-5` / `space-y-5` → 页头与主工作区间、跨章节大模块间  
**呼吸** → 12px → `gap-3` / `space-y-3` → 章节标题与下方内容间、筛选栏与表格间  
**紧凑** → 8px → `gap-2` / `space-y-2` → 筛选栏内各控件间、同级列表项/按钮组间  
**亲密** → 4px → `gap-1` / `space-y-1` → 大数与单位、标题与描述、图标与文字间

**元素间距禁半档**：`gap` / `space-y` / `space-x` 的 1.5/2.5/3.5/4.5 全禁。

**内边距不受四级管辖**：撑控件高度与容器呼吸，允许 `py-1.5` / `px-2.5`。

**头顶 > 脚下**：标题头顶留白 > 标题到内容留白。

### 1.4 圆角三档

**控件**（按钮/输入/徽标） → 6px → `rounded-md`  
**容器**（卡片/面板/空态块） → 12px → `rounded-xl`  
**浮层**（弹窗/抽屉） → 16px → `rounded-2xl`  
**头像与状态点** → 全圆 → `rounded-full`

禁用：`rounded-lg`(8px)、裸 `rounded`(4px)、`rounded-sm`、`rounded-3xl`、自定义像素。

### 1.5 衬线白名单

**页面定名**（28px，`sm:` 以下 20px） → 每页唯一  
**空间定名**（20px） → 仅为空间定名（抽屉主标、区块标题），弹窗标题用 Sans  
**AI 结论金句** → 仅 20px 且 ≤30 字  
**完卷微符** → `✦`

**核心判据**：过程用 Sans，宣告用 Serif。

**禁区**：表格/表单/按钮/导航/徽标、小于 20px、标点单独衬线、超过 30 字成段。

**衬线间距**：锁死 `tracking-tight`。

### 1.6 字体栈

**基线环境**：Windows 10/11，显示缩放 100%–125%。

**Sans**（拉丁 / 中文）：Segoe UI / 微软雅黑 UI  
**Serif**（拉丁 / 中文）：Georgia / 中易宋体

只用系统字体，不引入 webfont。字重回退：写 500 取 400，写 600 在雅黑取 700。

## §2 色值系统

### 2.1 背景三层

**Canvas** → `#FCFCFB` → 页面大背景（L1），仅最外层  
**Surface** → `#F1F1F0` → 展示气垫（下沉），只读区下沉分区  
**Surface Interactive** → `#FFFFFF` → 交互触点（上浮），**只给文本输入框与承载状态色的特殊按钮**

配角筛选器（时间/成员 Select）裸铺 Canvas，不上浮——能下拉不等于要边框，看它是表单字段还是视图工具。

### 2.2 主色

**Action** → `#D97757` → 同一活跃层唯一主 CTA，`bg-[#D97757] text-white`  
**Action Hover** → `#C46A4D` → 主 CTA 悬停，保持白字

### 2.3 状态色

**4 语义 × 3 角色**：

**成功/涨/达标** → success  
**异常/跌/错误/删稿** → danger  
**待处理/警告/待审** → warning  
**进行中/位置/信息** → info

**3 角色**：  
主色（圆点/图表） → 无后缀  
文字 → `-text`  
淡底 → `-bg`

**拼接规则**：`text-status-{语义}{角色}` / `bg-status-{语义}{角色}`

**示例**：  
播放量上涨文字 → `text-status-success-text`  
删稿状态圆点 → `before:bg-status-danger`  
待审标签淡底 → `bg-status-warning-bg`

**约束**：
- 状态色不上实底
- 异常文字统一用正文墨 `text-status-danger-text`（`#1F1E1D`）
- 弱圆点 `#D6D3D1` 用于正常状态，不可删除

**状态色分层**（数据指标 vs 状态标签共存时）：

| 层级 | 配方 | 场景 |
|---|---|---|
| 数据指标 | 饱和色字，无底或微淡底 | 红涨绿跌（核心决策） |
| 状态标签（异常级） | 淡底 + 正文墨字 + 饱和色圆点 | 异常/删稿/限流 |
| 状态标签（正常） | 无底 + 信号墨字 + 弱圆点 | 正常状态 |

### 2.4 边框与悬停

**Border** → `#E2E2DF` → 发丝线、表格行底、输入框边框  
**Hover** → `#EBEBE9` → 悬停态背景  
**Row Hover** → `#F7F7F6` → 表格行悬停  
**Row Selected** → `#E4E4E1` → 表格行选中

**纯白触点物理凸出律**：纯白落在暖白桌面上，必须配发丝边 `#E2E2DF` 与微投影。

### 2.5 阴影四档

**shadow-input** → 交互触点（输入框、次按钮）  
**shadow-card-ring** → 托盘（主卡片、主表格）  
**shadow-claude-float** → 浮层（下拉、气泡）  
**shadow-claude-dialog** → 弹窗与抽屉

禁用 Tailwind 原生阴影（`shadow-2xs/xs/sm/md/2xl`）。

## §3 组件契约

### 3.1 表格（ui/table.tsx）

**表头** → 12px/400/`#78716C`, `h-9`, `px-3`  
**单元格** → 常规表 14px；高密度表 13px，主键列显式 14px，核心锚点列可显式 14px 定名墨。均 `py-2.5`, `px-3`  
**表尾合计行** → 定名墨 `#141413`, `border-t`, 数值右对齐，不靠字重  
**行底** → `border-b border-[#E2E2DF]/60`  
**根容器** → 带 `tabular-nums`  
**无斑马纹、无竖向列线**

**列对齐与墨度**：  
文本列左对齐；数值列右对齐。  
主键列 → `text-[#1F1E1D]`  
核心指标列 → `text-[#141413]`  
辅助列 → 14px `text-[#78716C]`  
时间列（唯一例外）→ 12px `text-[#1F1E1D]` + `tabular-nums`

**操作列**：常态 `opacity-0`，行 hover 时 `opacity-100`，`transition-opacity duration-150`。

**用法样板**：`src/app/(app)/admin/content/content-list-table.tsx`

### 3.2 按钮（ui/button.tsx）

**字重** → 400（所有按钮）  
**三档** → S `h-6` / 12px · M `h-7` / 14px（默认）· L `h-10` / 14px  
**实底档** → 用 `shadow-input`，禁 `shadow-sm`

**主 CTA** → `bg-[#D97757] text-white hover:bg-[#C46A4D]`  
**次要行动**（同层已有主 CTA）→ `border-[#D97757] text-[#D97757] hover:bg-[#D97757]/5`

### 3.3 浮层（ui/dialog.tsx / ui/sheet.tsx）

**Dialog（弹窗）**：  
容器 → `rounded-2xl` + `shadow-claude-dialog`  
标题 → 20px **Sans** / 400 / `#141413`

**Sheet（抽屉）**：  
容器 → `rounded-l-2xl` + `shadow-claude-dialog`  
主标 → 20px **Serif** / 400 / `#141413`  
SheetHeader → 默认横排两端对齐

**Popover / DropdownMenu / Select**（控件级浮层）：  
不设标题，内部只有分组标签 + 可点条目。

### 3.4 表单（ui/input.tsx / ui/select.tsx）

**适用范围**：以下规格只适用表单输入字段。视图工具与上下文显示裸铺，不伪装成操作。

**字号** → 14px（唯一例外：AI 配置「系统提示词」长文编辑框用 13px）  
**高度** → `h-8`  
**背景** → `bg-white`  
**边框** → `border-[#E2E2DF]`  
**阴影** → `shadow-input`  
**圆角** → `rounded-md`  
**聚焦态** → `focus-visible:border-[#1F1E1D] focus-visible:ring-2 focus-visible:ring-[#1F1E1D]/10 outline-none`

**下拉宽度按语境定**：  
横排筛选栏 → `w-fit`  
纵向表单与抽屉 → `w-full`  
表格行内 → 受列宽约束

### 3.5 卡片（ui/card.tsx）

**容器** → `rounded-xl` + `shadow-card-ring` + `bg-white`  
**内边距** → `p-5` / `p-6`（按内容密度）  
**标题** → 20px Serif（空间定名）或 14px Sans（区块标题）

### 3.6 徽标（ui/badge.tsx）

**字号** → 12px  
**高度** → `h-5`  
**内边距** → `px-2`  
**圆角** → `rounded-md`  
**字重** → 400

**状态变体** → 8% alpha：`bg-status-*/[0.08]`（只作为该组件固定配方，不外推）  
**计数徽章降级** → 灰底灰字：`bg-[#F1F1F0] text-[#78716C]`

### 3.7 空态（ui/empty-state.tsx）

**标题** → 14px Sans `#1F1E1D`（不用衬线）  
**说明** → 14px `#78716C`  
**容器** → 垂直居中，`py-12`  
**图示**（可选）→ 暖墨单线手稿插图

**用法样板**：`src/components/ui/empty-state.tsx`

### 3.8 AI 结论（仅当结论 ≤30 字）

**金句** → 20px Serif `#141413`  
**普通结论** → 14px Sans + 左线 / `✦`

### 3.9 激活态

**文字激活** → 定名墨 `#141413`，不靠字重  
**背景激活** → `bg-[#F1F1F0]`（浅砂）  
**边框激活** → `border-[#1F1E1D]`

不得只靠字重承载激活态。

**行选中** → `bg-[#E4E4E1]`（从 `ui/selection.ts` 取）；不得用浅砂或悬停色冒充，白底上分不出来。
**主表格** → 放进托盘 `bg-white rounded-xl shadow-card-ring`，不直接铺在页面底色上。

## §4 页头与布局

### 4.1 页头槽位

**左槽** → 页面定名（28px Serif）+ 描述行（14px `#78716C`，前置微印记）  
**右槽** → 主操作按钮 / 筛选器  
**底槽**（可选）→ Tab / 分段控件

**页面定名下方描述行**：单行案头导语，前置抽象有机手绘几何微印记（可模仿延展，不锁死为固定 `✦`），同行融合「诗性人文底色 —— 实时案头脉络」。

**页头不自建**：复用 AdminWorkspaceLayout 或已有页头组件。

### 4.2 内容宽度

**Normal** → `max-w-[1180px]`（默认，数据表页）  
**Wide** → `max-w-[1400px]`（宽表格）  
**Narrow** → `max-w-[960px]`（表单页、详情页）

### 4.3 导航同轴

顶部导航、页头、主内容区左对齐，保持视觉脊梁。

## §5 动效与交互

### 5.1 动效节奏

**档位**（`design-tokens.css`）：  
150ms → 悬停/按压/菜单  
200ms → 弹窗与淡入淡出  
240ms → 抽屉与面板  
封顶 300ms（仪式节点除外）

**曲线**：`--ease-smooth`（定义在 `globals.css @theme`）

### 5.2 微交互

**悬停**：背景色渐变 150ms，禁位移/缩放/阴影变化（防止布局跳动）  
**点击**：乐观更新，省略全屏阻塞等待  
**加载**：等高骨架呼吸，完成立即撤出，布局零跳动

### 5.3 禁止项

**禁动效**：  
表格行悬停位移/缩放（导致数字错位）  
自动轮播/脉冲红点/自动刷新跳动  
无数据真实变化的自行运动

**禁交互**：  
Interactive 标签 `-i` 用在静态展示（防 hover 闪烁）

## §6 验收与门禁

### 6.1 门禁命令

```bash
npm run gate:design        # 机械规则门禁（字号/墨度/间距半档/字重/衬线下限/圆角/阴影）
npm run gate:static        # 含 design 门禁的静态检查
```

**门禁强制项**：  
字号封闭（28/20/14/13/12）  
墨度四阶（`#141413 / #1F1E1D / #78716C / #A8A29E`）  
间距禁半档（`gap-1.5/2.5/3.5/4.5` 全禁）  
字重一档（只有 400）  
衬线下限（≥20px）  
圆角三档（6/12/16px + `rounded-full`）  
阴影四档（禁 Tailwind 原生阴影）

### 6.2 页面验收清单（5 秒测试）

**第一层检查**：  
□ 标题回答了「一页一问」里那个问题  
□ 机器能填的没摆成空框  
□ 步数是最少的（没有多余跳页/回填）  
□ 视线顺序 = 决策顺序  
□ 同一个状态只在一处说

**第二层检查**：  
□ 同屏只有一个主角（陶土橙实底）  
□ 焦点会跟着任务走  
□ 布局零跳动（交互后其他元素位置不变）

**第三层检查**：  
□ 门禁全绿（`npm run gate:design`）  
□ 数值全部来自白名单  
□ 组件契约照抄，没自造

### 6.3 样板页索引

**数据表页** → `src/app/(app)/admin/content/`  
**工作台页**（表单+卡片）→ `src/app/(app)/dashboard/form-v2/`  
**空态组件** → `src/components/ui/empty-state.tsx`  
**落地页 Hero**（唯一字号豁免）→ `src/app/page.tsx`

## §7 场景决策路径

**不知道该做成什么形状时，按这个顺序问自己**：

1. 这是在给用户看数据，还是让用户填数据？→ 看数据用表格/卡片，填数据用表单
2. 数据有多少条？→ <10 条用卡片，≥10 条用表格
3. 每条数据有几个字段？→ ≤3 个字段用简单列表，>3 个字段用表格/卡片
4. 用户要对比吗？→ 要对比用表格（横向扫视），不对比用卡片
5. 用户要编辑吗？→ 要编辑用表单（一次改一条），不编辑用表格（只看）

**选完型 → 查 §3 对应组件契约 → 照抄样板页（§6.3）→ 微调数值（§1–§2）**

## 附录：常见违规速查

| 违规写法 | 正确写法 |
|---|---|
| `text-gray-600` | `text-[#78716C]`（元数据墨） |
| `font-medium` / `font-semibold` | 删除，用字号/位置/墨度区分 |
| `gap-2.5` | `gap-2` 或 `gap-3` |
| `rounded-lg` | `rounded-xl`（容器）或 `rounded-md`（控件） |
| `shadow-md` | `shadow-card-ring` 或 `shadow-claude-float` |
| 15px 字号 | 14px 或 20px |
| 小于 20px 用衬线 | 改 Sans |
| 状态色饱和实底 | 淡底 + 饱和色圆点 |
| 同屏两个陶土橙实底 | 次要的改 outline |
