## §1 封闭系统档位表

### 1.1 字号四档（场景 → 数值映射）

四个字号、六种身份：

| 身份 | 字号 | 行高 | 字重 | 墨度 | 字体 | 使用场景 |
|---|---|---|---|---|---|---|
| **页面定名** | 28px（`sm:` 以下 20px） | 1.20 | 400 | `#141413` | Serif + `tracking-tight` | 每页唯一 H1 |
| **空间定名** | 20px | 1.30 | 400 | `#141413` | 区块标题/抽屉主标用 Serif；弹窗标题用 Sans | 统领一个空间 |
| **正文与条目名** | 14px | 1.60（条目名 1.40） | 400 | 正文 `#1F1E1D`；条目名 `#141413` | Sans | 正文、表格单元格、按钮文字；条目名（列表行名、卡片名、表单段落标题）写法见下 |
| **元数据** | 12px | 1.50 | 400 | `#78716C` | Sans | 表头、字段名、时间戳、单位、Badge |
| **无内容信号** | 12px | 1.50 | 400 | `#A8A29E` | Sans | 占位符、空值 `—`、禁用态 |
| **指标大数** | 20px | 1.20 | 400 | `#141413` | Sans | 统计面板的核心数字本体，不含标签与单位 |

**封闭律**：表内四个字号（28/20/14/12）之外，一律不得出现。

**唯一豁免**：落地页 Hero 32 → `sm:`36 → `lg:`41.6px（`src/app/page.tsx` 首屏主标题）。

**贴身反差判据**：定名/核心大数（`#141413`）与伴随它的元数据（标签/单位/副标）成对出现时，取亲密档 `gap-1`(4px) 贴身排布。

**条目名写法**：条目名与正文同字号、同字重，**不靠字重区分**。承重手段只有三样：① 独占一行（位置）；② 其后紧跟 12px 元数据，`gap-1`（邻居反差）；③ 头顶留白大于脚下（`space-y-5` 对 `space-y-3`，见 §1.3）。定名墨 `#141413` 只是辅助。最弱的场景是表单段落标题（紧挨 14px 正文），全靠留白与位置，Windows 目检时重点看。表格里没有"条目名"这一身份：主键列与核心指标列按 §3.1 的墨度分工。

**字重一档**：全站只有 400（`font-normal`）。500、600 不存在于基线环境（回退事实见 §1.6），中英混排还会粗细不一，不入系统：`font-medium` / `font-semibold` / `font-bold` / `font-[数字]` / 内联 `fontWeight` 全禁。唯一非 UI 例外：OG 分享图（`opengraph-image.tsx`，渲染器自带字体，不走浏览器字体栈）。**层级不得只靠字重承载**；这条与激活态配方（§3.9）互为表里。

### 1.2 墨度四阶（性质 → 色值映射）

| 墨度 | 色值 | 承载 |
|---|---|---|
| **定名墨** | `#141413` | 页面定名、空间定名、条目名、指标大数、表格核心指标列、激活态 |
| **正文墨** | `#1F1E1D` | 正文、表格主键列、常规数据 |
| **元数据墨** | `#78716C` | 表头、字段名、单位、表格次要列、辅助说明、表格外时间戳（表内时间列见 §3.1） |
| **信号墨** | `#A8A29E` | **只承载"这里没有内容"**：占位符、空值 `—`、禁用态、图标装饰 |

**四阶之外的文字灰一律不得出现**（含 Tailwind 原生灰阶类名，由门禁强制，见 §7.1）。

**信号墨判据一句话**：这块浅墨是在说「这里没有内容」，还是「这里有内容但想写淡一点」？后者即违规，不得浅于 `#78716C`。

**辅助信号声明**：定名墨与正文墨相差极微（肉眼几乎不可分），**只作辅助信号**——给细心的读者多一分余味，不得单独承担层级或激活态；承重的是字号、字体族、位置与后三阶墨度。

### 1.3 留白四级（关系 → 间距映射）

| 语义 | 间距 | Tailwind | 典型绑定场景 |
|---|---|---|---|
| **断层 Rift** | 20px | `gap-5` / `space-y-5` | 页头与主工作区间、跨章节大模块之间（标题头顶） |
| **呼吸 Breath** | 12px | `gap-3` / `space-y-3` | 章节标题与下方受控内容间（标题脚下）、筛选栏与受控表格间 |
| **紧凑 Tight** | 8px | `gap-2` / `space-y-2` | 筛选栏内各控件间、同级列表项/按钮组间 |
| **亲密 Intimate** | 4px | `gap-1` / `space-y-1` | 大数与单位、标题与描述、图标与文字间 |

**元素间距禁半档**：`gap` / `space-y` / `space-x` 的 1.5/2.5/3.5/4.5 全禁（由门禁强制，见 §7.1）。

**内边距不受四级管辖**：它的职责是撑出控件高度与容器呼吸，由组件规格决定，允许 `py-1.5` / `px-2.5` 这类半档。

**梯次律**：`gap(父) > gap(子)`，违反即错。容器**左右内边距必须相等**（表格列为对齐数字取 `pl-4 pr-2` 属合规）。

**头顶 > 脚下**：章节容器外部间距用 `space-y-5`(20px)，章节内部（标题到内容）用 `space-y-3`(12px)。

### 1.4 圆角三档 + 全圆（容器 → 圆角映射）

| 元素 | 圆角 | Tailwind |
|---|---|---|
| 控件（按钮/输入/徽标/内嵌提示） | 6px | `rounded-md` |
| 容器（主托盘/卡片/面板/空态块） | 12px | `rounded-xl` |
| 浮层大容器（弹窗 Dialog / 抽屉 Sheet） | 16px | `rounded-2xl` |
| 头像与状态点 | 全圆 | `rounded-full` |

**禁用**：`rounded-lg`(8px)、裸 `rounded`(4px)、`rounded-sm`、`rounded-3xl`、自定义像素圆角（由门禁强制，见 §7.1）。

**形状同源**：同一类元素全站只有一个圆角。

### 1.5 衬线白名单

| 场景 | 判据 |
|---|---|
| 页面定名（28px；`sm:` 以下 20px） | 每页唯一 |
| 空间定名（20px） | 仅当它是**为一个空间定名**（抽屉主标、区块标题）；弹窗标题一律用 Sans |
| AI 结论金句 | 仅 20px 且 ≤30 字；平常的 AI 结论走 §3.8 的 14px Sans + 左线 / `✦` |
| 完卷微符 `✦` | 装帧符号 |

**核心判据：这是过程，还是宣告？** 宣告用衬线，过程用 Sans。

**衬线禁区**：表格 / 表单 / 按钮 / 导航 / 徽标；**小于 20px（含空态指引，空态用 14px Sans）**；标点单独衬线；超过 30 字成段。

**衬线间距锁死 `tracking-tight`**（约 -0.025em），禁 `tracking-normal` 与正间距。

**20px 下限**即表内空间定名档，不新增字号（缘由见《哲学》定律3；Windows 实机目检记录见《纠错索引》）。

### 1.6 渲染基线与字体栈

**基线环境**：Windows 10/11 + Chrome/Edge，显示缩放 100%–125%（DPR 1–1.25）。macOS 是增强环境，设计走查以基线为准。

| 环境 | sans（拉丁 / 中文） | serif（拉丁 / 中文） | 实际可用字重 |
|---|---|---|---|
| Windows（基线） | Segoe UI / 微软雅黑 UI | Georgia / 中易宋体 | 雅黑 400·700；宋体仅 400；Segoe UI 400·600·700（无 500） |
| macOS | SF Pro / 苹方 | Iowan Old Style 等 / 宋体-简 | 多档齐全 |

**字体栈规则**：
- 只用系统字体，不引入 webfont（性能优先，首屏零字体下载）。
- 历史残留 `Inter`、`--font-display`、按 DPR 回退 Sans 的规则均已从 globals.css 删除，由 `src/styles/css-tokens.test.ts` 反向断言防回写，不得再写回。
- **字重回退事实**：写 500 取 400；写 600 在雅黑取 700、在 Segoe UI 取 Semibold。这是 §1.1「字重一档」的依据，设计时不得假设 500 存在。
- **中文衬线钉栈**：Windows 统一落系统必装的中易宋体（笔画更实），Mac 命中 Songti SC；STSong、NSimSun 已删除（随 Office 才命中、观感逐机漂移），由 css-tokens.test.ts 断言防回写。定案缘由与目检记录见《纠错索引》。

### 2.2 主色与状态色

| Token | 色值 | 用法 |
|---|---|---|
| **Action** | `#D97757` | **同一活跃层唯一**主 CTA，`bg-[#D97757] text-white` |

|---|---|---|
| **Border** | `#E2E2DF` | 发丝线，表格行底、输入框边框 |

### 2.4 阴影四档

```css
--shadow-input:         0 1px 2px 0 rgba(28,25,23,0.04);
--shadow-card-ring:     0 0 0 1px rgba(28,25,23,0.08), 0 1px 2px 0 rgba(28,25,23,0.05);
--shadow-claude-float:  0 1px 2px rgba(28,25,23,0.04), 0 10px 28px -4px rgba(28,25,23,0.12), 0 3px 8px -2px rgba(28,25,23,0.06);
--shadow-claude-dialog: 0 1px 3px rgba(28,25,23,0.04), 0 18px 42px -6px rgba(28,25,23,0.16), 0 6px 18px -2px rgba(28,25,23,0.08);
```

| 用途 | Token |
|---|---|
| 交互触点（输入框、次按钮） | `shadow-input` |
| 托盘（主卡片、主表格） | `shadow-card-ring` |
| 浮层（下拉、气泡、浮出面板） | `shadow-claude-float` |
| 弹窗**与抽屉** | `shadow-claude-dialog` |

**禁用** Tailwind 原生阴影（`shadow-2xs/xs/sm/md/2xl`，由门禁强制，见 §7.1）。

## §3 组件契约（直接用默认值，要改去改组件）

### 3.1 ui/table.tsx（数据密集页核心）

**已定契约**：
- **表头**：12px/400/`#78716C`、`h-9`、`px-3`
- **单元格**：14px、`py-2.5`、`px-3`（行高随字号自增约 1.6px，不调 padding）
- **表尾合计行（TableFooter）**：定名墨 `#141413`、`border-t border-[#E2E2DF]`、数值右对齐，不靠字重
- **行底**：`border-b border-[#E2E2DF]/60`
- **根容器**：带 `tabular-nums`（等宽数字）
- **无斑马纹**、**无竖向列线**

**列对齐与墨度**：
- 文本列：左对齐
- 数值/金额/百分比列：强制右对齐（`text-right`）
- 每行唯一主键列：`text-[#1F1E1D]`（正文墨）
- 核心结果指标列：`text-[#141413]`（定名墨）
- 操作人/状态等辅助列：14px `text-[#78716C]`（元数据墨）
- **时间列（表内唯一例外）**：12px `text-[#1F1E1D]` + `tabular-nums`——12px 配元数据墨在 Windows 上过淡，时间列升用正文墨（2026-10-27 按线上现状定案，实测基准 content-list-table.tsx）

**操作列特殊规则**：
- 常态：`opacity-0`
- 行 hover：`opacity-100`
- 过渡：`transition-opacity duration-150`

**用法样板**（照抄真实页面，不再维护文档内示例）：`src/app/(app)/admin/content/content-list-table.tsx`——主键列/核心指标列/辅助列的墨度分工与操作列渐进揭示均以该文件为准。

### 3.2 ui/button.tsx（三档尺寸）

**已定契约**：
- **字重**：400（所有按钮文字）
- **三档**：S `h-6` / 12px · **M `h-7` / 14px（默认）** · L `h-10` / 14px
- **实底档**（default / destructive）：用 `shadow-input`，禁 `shadow-sm`

**特殊规则**：
- 主 CTA：`bg-[#D97757] text-white hover:bg-[#C46A4D]`
- 次要行动（同层已有主 CTA）：`border-[#D97757] text-[#D97757] hover:bg-[#D97757]/5`

### 3.3 ui/dialog.tsx / ui/sheet.tsx（浮层容器）

**Dialog（弹窗）**：
- 容器：`rounded-2xl` + `shadow-claude-dialog`
- 标题：20px **Sans** / 400 / `#141413`

**Sheet（抽屉）**：
- 容器：`rounded-l-2xl` + `shadow-claude-dialog`
- 主标：20px **Serif** / 400 / `#141413`
- `SheetHeader`：默认横排两端对齐（标题左、操作右）

**浮层内部层级（通则）**：
- **20px 标题档只属于本节这两个浮层大容器**（Dialog Sans / Sheet Serif）；页面与空间定名见 §1.5，同样是 20/28 档。
- **Popover / DropdownMenu / Select 下拉等控件级浮层不设标题**：内部只有"分组标签 + 可点条目"两种身份，档位与墨度按 §3.6「容器阻尼律」执行，不在本节重复。
- 同一屏内两个浮层，同角色标签不得出现两种墨度（判据与例外见 §3.6）。

### 3.4 ui/input.tsx / ui/select.tsx（表单控件）

**已定契约**：
- 字号：14px
- 高度：`h-8`（按钮 M 档 `h-7` 矮 1px，不强求等高）
- 背景：`bg-white`
- 边框：`border-[#E2E2DF]`
- 阴影：`shadow-input`
- 圆角：`rounded-md`
- 聚焦态：`focus-visible:border-[#1F1E1D] focus-visible:ring-2 focus-visible:ring-[#1F1E1D]/10 outline-none`
  - 禁用浏览器默认蓝框与主色橙框

**下拉宽度按语境定**：
- 横排筛选栏：优先 `w-fit` 紧凑自适应（禁写死定宽防大空白）
- 纵向表单与抽屉：优先 `w-full` 严整对齐
- 表格行内：受列宽约束

### 3.5 ui/card.tsx（内容托盘）

**已定契约**：
- 容器：`rounded-xl`(12px) + `shadow-card-ring`
- `CardTitle`：14px/400/`#141413`（条目名写法，见 §1.1）

**使用场景**：
- ✓ 数据主托盘、看板/网格类子项
- ✗ 分页/筛选等外围工具（必须裸铺）

**`CardTitle` 不得当章节标题用**（那是空间定名 20px Serif）。

### 3.6 ui/label.tsx / ui/badge.tsx（元数据呈现）

**Label（字段名）**：
- 12px / `#78716C`

**Badge（徽标）**：
- 12px、`px-1.5 py-0.5 leading-none rounded-md`

**容器阻尼律（通则，2026-10-26 实测入规）**：

**定义**：容器尺度反向压制内部可用档位——**容器越小，能用的字号档位越少**。20px 与衬线是"浮层大容器 / 页面与空间定名"的专属（§1.5、§3.3），控件级容器内部一律不出现。

**控件级浮层（Popover / DropdownMenu / Select 下拉，宽度通常 128–320px）内部只有两种身份，没有"标题"**：

| 身份 | 档位 | 说明 |
|---|---|---|
| 分组标签 | 12px / `#78716C` | 即本节 Label 档；独占一行，下面跟它统领的内容 |
| 可点条目 / 选项 | 14px / `#1F1E1D` | 悬停 `#141413` + `bg-[#F1F1F0]`（§3.9） |
| 条目右侧回显 | 12px / `#78716C` | 选中后 `#141413` + `bg-[#F1F1F0]` |

**层级手段**：字号差（标签 12 / 内容 14）＋ 位置 ＋ 留白（组内 `gap-1`，组间 12px）；墨度只作辅助（§1.2）。

**两条硬条款**：
- **同角色同墨**：同一个浮层里，同类分组标签只允许一个墨度——出现"一个 `#78716C`、一个 `#1F1E1D` 的两个标题"，即违规。
- **不拿字号换标题**：不得把分组名做成 14px 正文墨"伪标题"（与 14px 选项同级，层级归零）；也不得把可点选项压到 12px 去换"标题更大"（Windows 100% 下小字发虚，且与 §3.4 控件 14px 打架）。

**判据一句话**：**这是控件级浮层吗？是——标签 12 灰、内容 14 墨，没有标题。**

### 3.7 ui/empty-state.tsx（空状态统一走它）

**已定契约**：
- 居中 `✦` 微符或极简暖墨单线手稿
- `14px Sans #1F1E1D` 温和指引（≤30字；衬线不得小于 20px，见 §1.5）
- 下方 `gap-3` 唯一操作入口

**暖墨线描风格卡**（素材库：`src/components/editorial/editorial-illustrations.tsx`，AI 只选不创作）：
- 单色暖墨（信号墨或元数据墨档），禁彩色、渐变、3D、投影
- 线宽 1–1.5px，圆头端点与圆头连接，允许轻微不规则（手绘感，不用完美几何）
- 题材限场景相关的具体静物（灯、桌、纸页、器物），一张图只说一件事
- 出现节点仅《哲学》1.1 所列关键心理节点（迎宾、洞察、空态、归档）

### 3.8 卷首寄语 / 学者边注（装帧元素）

**寄语（AI 结论块）**：
- 无底色无外框
- 左侧 `border-l-2 border-[#43718E]`（或前置 `✦`）
- 默认配 `14px Sans #1F1E1D`；结论金句（≤30字）可配 `20px Serif #141413`

**边注（行内/侧边提醒）**：
- `bg-[#43718E]/10 rounded-md px-2.5 py-1.5` 或无底色
- 配 `12px Sans #78716C`

**结论必须带依据**：AI 结论后附一句"因为…"（数据来源或推理路径）；推测出的结论用边注标明"这是推测"，不假装全知（语气见《哲学》1.3）。

### 3.9 激活态配方（选中 / 当前 / 排序中）

**硬条款**：激活态必须同时有**墨度变化**与**底色变化**（排序表头以方向箭头代替底色）；**字重不得作为任何激活信号**（缘由见 §1.6）。

| 场景 | 未选中 | 选中 |
|---|---|---|
| 分段 / Tab / 筛选胶囊 / 视图切换（有下沉槽 `#F1F1F0`） | 透明底 + `#78716C` | `bg-white` + `shadow-input` + `#141413` |
| 同上（无槽） | 透明底 + `#78716C` | `bg-[#F1F1F0]` + `#141413` |
| 一级导航（`aria-current`） | `#78716C` | `bg-[#F1F1F0]` + `#141413` |
| 下拉菜单项 / 列表选中项（工作区等） | `#1F1E1D` | `bg-[#F1F1F0]` + `#141413` + 深炭墨色 `✓`（不借主色） |
| 分页当前页码（`min-w-7` 框内） | `#78716C` | `bg-[#F1F1F0]` + `#141413` |
| 表头排序列 | `#78716C` | `#141413` + 方向箭头（常显） |

未选中项的悬停沿用 §2.3 `Hover` 底色。

**组件落实**：组件里"仅切换字重"的激活写法一律改走本表（补底色与墨度变化）。

## §4 页头与布局

### 4.1 页头一律走壳

| 壳 | 适用 |
|---|---|
| `components/app-shell/app-shell.tsx` | 前台页面 |
| `components/admin-workspace-layout.tsx` | 后台页面 |

**槽位顺序与侧位锁死**：

| 槽位 | 位置 |
|---|---|
| Eyebrow（所属模块） | 页面定名之上（`gap-1` 4px） |
| 页面定名（H1） | 页头左上第一位，**每页必有** |
| 描述 | 定名之下（`gap-1` 4px） |
| 主 CTA 与页头操作 | 与定名同行，**右对齐**（全站唯一侧） |
| 筛选器 | 页头之下（距页头 `20px`）、受控表格之上（距表格 `12px`），左对齐同轴 |

用 `eyebrow` / `title` / `description` / `actions` 传值，不自建页头。

**已知例外仅三类**：落地页、认证页（`auth-shell`）、错误与空态页（`not-found` / `global-error`）。

### 4.2 内容宽度与导航同轴

内容区最大宽统一 `max-w-7xl`(1280px)，与导航栏一致；宽表页（列数 ≥12）可放宽至 `max-w-screen-2xl`，但**导航栏须同步加宽**。

**任何情况下内容不得宽于导航。**

## §5 动效

### 5.1 基础交互

- **按压**：`active:scale-[0.99] duration-75`
- **悬停**：`transition-colors duration-150`
- **淡入淡出**：`transition-opacity duration-200`

### 5.2 页面级动效（提升质感但不打扰）

- **抽屉滑入**：`ease-[cubic-bezier(0.16,1,0.3,1)] duration-300`
- **卡片入场**（首屏加载）：错开 50ms `animation-delay`，营造呼吸感
- **骨架加载**：`#F1F1F0` → `#EBEBE9` 呼吸，等高占位，数据到达原地淡入、零布局跳动
- **仪式节点慢动效**：迎宾、洞察呈现、归档定卷可用 400–600ms 缓入缓出（像呼吸，不像赶工），一屏至多一处；其余一律用 5.1 的利落节奏
- **减弱动效兜底**：一切动效须提供 `prefers-reduced-motion` 回退（关闭或缩短为直接切换）——尊重注意力也包含尊重生理需要

### 5.3 微交互（不影响效率的细节）

- **表格行悬停**：只做背景变色（`#F7F7F6`），**禁位移与缩放**（防止等宽数字错位与点击脱靶）
- **按钮加载**：Spinner 只准出现在按钮内部，配 `animate-pulse`
- **Toast 入场**：`slide-in-from-top-2` + `fade-in`

### 5.4 禁止

- 结果直接可见时不弹 Toast
- 禁 `transition-all`（会让翻页/筛选时列宽行高慢动作变形）
- 禁浮夸弹跳、无限循环、过度缓动、阻塞交互的动画

**判据**：动效是为了告知状态变化（反馈）或引导视线（层次），不是装饰。每个动效必须回答"它让用户更快理解了什么"。

## §6 常见场景决策路径（轻量查表）

### 6.1 数据密集页（表格为主）

**典型场景**：用户列表、视频复盘、订单管理、数据监控

**决策路径**：
```
页面定名："用户管理" → 28px Serif 400 #141413（H1）
页头操作："导出" / "新建用户" → 右对齐，新建用主 CTA

筛选器：裸铺、gap-2 紧凑排列、w-fit 自适应
  ↓ (gap-3 呼吸)
表格：ui/table.tsx、纯白托盘 bg-white rounded-xl shadow-card-ring
  表头：12px #78716C（姓名、手机、注册时间、状态、操作）
  主键列（姓名）：14px #1F1E1D 左对齐
  核心指标列（无）：若有播放量/金额用 14px #141413 右对齐
  辅助列（状态等）：14px #78716C；时间列：12px #1F1E1D tabular-nums（见 §3.1）
  操作列：常态 opacity-0，行 hover opacity-100
```

**结构样板**：`src/app/(app)/admin/content/`（视频复盘页）——页头走壳、筛选栏裸铺、表格托盘与呼吸间距均以该页为准。

### 6.2 工作台页（表单 + 卡片）

**典型场景**：用户详情、内容编辑、设置页面

**结构样板**：`src/app/(app)/dashboard/form-v2/`（创作表达录入页）——表单裸铺、底部唯一主 CTA 的单点聚光灯以该页为准。

**决策路径**：
```
页面定名："用户详情" → 28px Serif 400 #141413
描述（可选）："查看和编辑用户基本信息" → 14px #78716C

内容区：
  IF 表单内有大量输入框（>3个）
    THEN 表单直接裸铺于 L1 Canvas (#FCFCFB)
      → 输入框纯白上浮，背景透明避免白套白
  ELSE IF 只读信息展示
    THEN 用浅砂气垫 bg-[#F1F1F0] rounded-xl 下沉

字段名：12px #78716C（Label）
输入框：14px、h-8、bg-white、shadow-input
按钮组：底部、gap-2、主按钮在最右
```

### 6.3 引导页（落地页、空态）

**典型场景**：首页 Hero、空状态、404、登录注册

**结构样板**：空态一律用 `src/components/ui/empty-state.tsx`（实际用法见 content-list-table.tsx）；落地页 Hero 见 `src/app/page.tsx`（唯一字号豁免所在）。

**决策路径**：
```
装帧比例可提高：衬线占比可达 40%
暖墨线描插图：允许在关键心理节点出现
微符装饰：✦ 可用于视觉引导

空态标准格式：
  居中 ✦ 或暖墨单线手稿
  ↓ (gap-2)
  14px Sans #1F1E1D 温和指引（≤30字）
  ↓ (gap-3)
  唯一操作入口（主 CTA）
```

## §7 验证清单（实现后执行）

### 7.1 自动检查（门禁强制）

机械规则（字号/墨度/间距半档/字重/衬线下限/圆角/阴影）已由 `scripts/design-token-gate.mjs` 固化为门禁：`npm run gate:design`（已串入 `gate:static`）。基线棘轮模式：存量违规记录在 `scripts/design-token-baseline.json`，任何文件新增违规即红灯；下调基线须走《哲学》定律2（阿禅确认+纠错索引留档）。

**覆盖范围声明不变**：单点聚光灯、凹凸分明、配角裸铺、装饰必要性不在门禁覆盖内，必须对照 §7.2 逐条目视自查——**门禁全绿 ≠ 合规**。

### 7.2 目视检查

- [ ] 当前活跃层是否有 >1 个饱和色实底？
- [ ] 外层 gap 是否 > 内层 gap？
- [ ] 筛选器/分页器是否套了 Card？（应裸铺）
- [ ] 表单内是否白底套白框？（应裸铺或下沉浅砂）
- [ ] 表格行悬停是否有位移/缩放？（应只变背景色）
- [ ] 操作成功后是否弹了不必要的 Toast？（结果可见时应原地更新）
- [ ] 激活/选中态是否同时有墨度与底色变化？（字重不算）
- [ ] 条目名是否独占一行并紧跟元数据？
- [ ] 改动涉及层级时，是否在 Windows 实机（100% / 125%）看过？
