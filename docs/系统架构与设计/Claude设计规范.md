# Claude 设计规范（数值与契约）

> 本卷只写具体数值与组件契约——《Claude 设计哲学》里的抽象原则，在这里变成可执行的档位表、色值、尺寸与代码示例。
> 
> 度量立在本产品的真实密度上——13px 正文、12px 元数据、紧凑留白、发丝表格。

**两卷关系**：哲学定方向（为什么），规范给数值（是多少）。冲突时以哲学为准。**单一详写律**：同一规则只在一处详写——原则与"为什么"归《哲学》，数值、契约与检查命令归本卷；其余位置只留一行引用，改规则时只改详写处。

---

## §0 核心铁律（AI 开工前必读）

这 6 条各自对应《哲学》的原则或章节，每次实现前端时必须过一遍：

### 0.1 字号封闭律 (原则1: Closed Systems)

**只能用 28/20/18/14/13/12px，写法必须是 `text-[Npx]`**；禁 `text-xs/sm/base/lg` 等别名与 `rem`。档位、豁免与写法唯一律详见 §1.1，检查命令见 §7.1。

### 0.2 字重两档 (原则2: Single Responsibility)

**全站只有 400 与 500**；600 仅限状态驱动的激活态。详规见 §1.1「字重两档」，检查命令见 §7.1。

### 0.3 墨度四阶 (原则2: Single Responsibility)

**`#141413` / `#1F1E1D` / `#78716C` / `#A8A29E`，四阶之外不得出现**；信号墨只承载"这里没有内容"。判据与禁用类名详见 §1.2，检查命令见 §7.1。

### 0.4 同层单光 (原则4: Single Focal Point)

**`bg-[#D97757]` 同一活跃交互层至多一处**；状态色不上实底，只用淡底 + 同色文字。色值与用法详见 §2.2。

### 0.5 组件规格不覆盖 (原则1: Closed Systems)

**用 `ui/table.tsx` 就别在业务页改它字号**——要改去改组件本身；新表格一律用 `ui/table.tsx`。各组件契约详见 §3。

### 0.6 配角裸铺与凹凸分明 (《哲学》§4 空间三层)

**外围控件（分页/筛选）严禁套 Card，必须透明裸铺**；只读区下沉 `#F1F1F0`，交互触点上浮 `#FFFFFF`，严禁同色相套。三层职责详见《哲学》§4 与本卷 §2.1。

## §1 封闭系统档位表

### 1.1 字号六档（场景 → 数值映射）

| 身份 | 字号 | 行高 | 字重 | 墨度 | 字体 | 使用场景 |
|---|---|---|---|---|---|---|
| **页面定名** | 28px（`sm:` 以下 20px） | 1.20 | 500 | `#141413` | Serif + `tracking-tight` | 每页唯一 H1 |
| **空间定名** | 18px | 1.30 | 500 | `#141413` | 区块标题/抽屉主标用 Serif；弹窗标题用 Sans | 统领一个空间 |
| **条目定名** | 14px | 1.40 | 500 | `#1F1E1D` | Sans | 列表行名、卡片名、表单段落标题 |
| **正文与数据** | 13px | 1.60 | **400** | `#1F1E1D` | Sans | 正文、表格单元格、按钮文字 |
| **元数据** | 12px | 1.50 | **400** | `#78716C` | Sans | 表头、字段名、时间戳、单位、Badge |
| **无内容信号** | 12px | 1.50 | 400 | `#A8A29E` | Sans | 占位符、空值 `—`、禁用态 |

**封闭律**：表内六个字号之外，一律不得出现。包括 9 / 10 / 11 / 15 / 16 / 17 / 19 / 21 / 22 / 24 / 30px。

**两个豁免（仅此两处）**：
- 落地页 Hero：32 → `sm:`36 → `lg:`41.6px（`src/app/page.tsx` 首屏主标题）
- 仪表盘指标大数：20px / 500 / `#141413`（统计面板的核心数字本体，不含标签与单位）

**贴身反差判据**：定名/核心大数（`#141413`）与伴随它的元数据（标签/单位/副标）成对出现时，取亲密档 `gap-1`(4px) 贴身排布。

**字重两档**：全站只有 400 与 500。400 是默认，500 只给三处：六档表里的三种「定名」、控件激活态、品牌字标。`font-semibold`(600) 仅限状态驱动的激活态（`data-active` / `aria-selected` / `:checked` / 三元分支），且未选中态必须是 400 或 500 形成对比；静止态禁用 600。`font-bold`、`font-[550]`、`font-[600]` 全禁。

### 1.2 墨度四阶（性质 → 色值映射）

| 墨度 | 色值 | 承载 |
|---|---|---|
| **定名墨** | `#141413` | 页面定名、空间定名、指标大数、表格核心指标列 |
| **正文墨** | `#1F1E1D` | 条目定名、正文、表格主键列、常规数据 |
| **元数据墨** | `#78716C` | 表头、字段名、时间戳、单位、表格次要列、辅助说明 |
| **信号墨** | `#A8A29E` | **只承载"这里没有内容"**：占位符、空值 `—`、禁用态、图标装饰 |

**四阶之外的文字灰一律不得出现。** 严禁使用 Tailwind 原生 `text-stone-*` / `text-zinc-*` / `text-slate-*` 类名。

**信号墨判据一句话**：这块浅墨是在说「这里没有内容」，还是「这里有内容但想写淡一点」？后者即违规，不得浅于 `#78716C`。

### 1.3 留白四级（关系 → 间距映射）

| 语义 | 间距 | Tailwind | 典型绑定场景 |
|---|---|---|---|
| **断层 Rift** | 20px | `gap-5` / `space-y-5` | 页头与主工作区间、跨章节大模块之间（标题头顶） |
| **呼吸 Breath** | 12px | `gap-3` / `space-y-3` | 章节标题与下方受控内容间（标题脚下）、筛选栏与受控表格间 |
| **紧凑 Tight** | 8px | `gap-2` / `space-y-2` | 筛选栏内各控件间、同级列表项/按钮组间 |
| **亲密 Intimate** | 4px | `gap-1` / `space-y-1` | 大数与单位、标题与描述、图标与文字间 |

**元素间距禁半档**：`gap-1.5`(6px)、`gap-2.5`(10px)、`gap-3.5`(14px) 及 `space-y` 同档全禁。

**内边距不受四级管辖**：它的职责是撑出控件高度与容器呼吸，由组件规格决定，允许 `py-1.5` / `px-2.5` 这类半档。

**梯次律**：`gap(父) > gap(子)`，违反即错。容器**左右内边距必须相等**（表格列为对齐数字取 `pl-4 pr-2` 属合规）。

**头顶 > 脚下**：章节容器外部间距用 `space-y-5`(20px)，章节内部（标题到内容）用 `space-y-3`(12px)。

### 1.4 圆角三档 + 全圆（容器 → 圆角映射）

| 元素 | 圆角 | Tailwind |
|---|---|---|
| 控件（按钮/输入/徽标/内嵌提示） | 6px | `rounded-md` |
| 容器（主托盘/卡片/面板/空态块） | 12px | `rounded-xl` |
| 浮层大容器（弹窗 Dialog / 抽屉 Sheet） | 16px | `rounded-2xl` |
| 头像与状态点 | 全圆 | `rounded-full` |

**禁用**：`rounded-lg`(8px)、裸 `rounded`(4px)、`rounded-sm`、`rounded-3xl`、自定义像素圆角。

**形状同源**：同一类元素全站只有一个圆角。

### 1.5 衬线白名单

| 场景 | 判据 |
|---|---|
| 页面定名（28px） | 每页唯一 |
| 空间定名（18px） | 仅当它是**为一个空间定名**（抽屉主标、区块标题）；弹窗标题一律用 Sans |
| AI 结论金句 / 空态指引 | ≥14px 且 ≤30 字 |
| 完卷微符 `✦` | 装帧符号 |

**核心判据：这是过程，还是宣告？** 宣告用衬线，过程用 Sans。

**衬线禁区**：表格 / 表单 / 按钮 / 导航 / 徽标；小于 14px；标点单独衬线；超过 30 字成段。

**衬线间距锁死 `tracking-tight`**（约 -0.025em），禁 `tracking-normal` 与正间距。

**Windows 低密度屏回退**：DPR < 1.5 时 14px 以下衬线一律回退 Sans，已在 `globals.css` 配置 `@media (max-resolution: 1.5dppx)`；**新增字号档时须同步扩充该清单**。

## §2 颜色系统

### 2.1 背景三层（Z轴 → 色值映射）

| Token | 色值 | 场景 |
|---|---|---|
| **Canvas** | `#FCFCFB` | 页面大背景（L1），仅最外层 |
| **Surface** | `#F1F1F0` | 展示气垫（下沉），只读区 |
| **Surface Interactive** | `#FFFFFF` | 交互触点（上浮），输入框/按钮 |

**L3 容器内部统一 `bg-transparent`，严禁同色套同色。**

### 2.2 主色与状态色

| Token | 色值 | 用法 |
|---|---|---|
| **Action** | `#D97757` | **同一活跃层唯一**主 CTA，`bg-[#D97757] text-white` |
| **Action Hover** | `#C46A4D` | 主 CTA 悬停 |
| **成功 / 涨** | `#6FAA7D` | 文字本色 `text-[#6FAA7D]` + `/8` 透明底 `bg-[#6FAA7D]/8` |
| **异常 / 跌** | `#C0685C` | 同上 |
| **待处理** | `#B98A54` | 同上 |
| **进行中 / 位置** | `#43718E` | 同上 |
| **信息高亮** | `#43718E` | 文字本色 + `/10` 透明底（引用块、提示信息、次要强调） |

**状态色只上文字与淡底，不上实底**：禁 `bg-[#6FAA7D]` 这类饱和实底——**换个 hex 不改变它是一块饱和实底的事实**，它会跟唯一的主 CTA 抢光。

### 2.3 边框与悬停

| Token | 色值 | 场景 |
|---|---|---|
| **Border** | `#E2E2DF` | 发丝线，表格行底、输入框边框 |
| **Hover** | `#EBEBE9` | 悬停态背景 |
| **Row Hover** | `#F7F7F6` | 表格行悬停 |
| **Row Selected** | `#E4E4E1` | 表格行选中 |

**纯白触点物理凸出律**：纯白落在暖白桌面上，必须配发丝边 `#E2E2DF` 与微投影，严禁裸落。

### 2.4 阴影四档

```css
--shadow-input:         0 1px 2px 0 rgba(28,25,23,0.04);
--shadow-card-ring:     0 0 0 1px rgba(28,25,23,0.08), 0 1px 2px 0 rgba(28,25,23,0.05);
--shadow-claude-float:  0 1px 2px rgba(28,25,23,0.04), 0 10px 28px -4px rgba(28,25,23,0.12), 0 3px 8px -2px rgba(28,25,23,0.06);
--shadow-claude-dialog: 0 1px 3px rgba(28,25,23,0.04), 0 18px 42px -6px rgba(28,25,23,0.16), 0 6px 18px -2px rgba(28,25,23,0.08);
```

| 用途 | Token |
|---|---|
| 交互触点（输入框、次按钮） | `shadow-input` |
| 托盘（主卡片、主表格） | `shadow-card-ring` |
| 浮层（下拉、气泡、浮出面板） | `shadow-claude-float` |
| 弹窗**与抽屉** | `shadow-claude-dialog` |

**禁用** Tailwind 原生阴影：`shadow-2xs` / `shadow-xs` / `shadow-sm` / `shadow-md` / `shadow-2xl` / 裸 `shadow`。

## §3 组件契约（直接用默认值，要改去改组件）

### 3.1 ui/table.tsx（数据密集页核心）

**已定契约**：
- **表头**：12px/400/`#78716C`、`h-9`、`px-3`
- **单元格**：13px、`py-2.5`、`px-3`
- **行底**：`border-b border-[#E2E2DF]/60`
- **根容器**：带 `tabular-nums`（等宽数字）
- **无斑马纹**、**无竖向列线**

**列对齐与墨度**：
- 文本列：左对齐
- 数值/金额/百分比列：强制右对齐（`text-right`）
- 每行唯一主键列：`text-[#1F1E1D]`（正文墨）
- 核心结果指标列：`text-[#141413]`（定名墨）
- 时间/操作人等辅助列：`text-[#78716C]`（元数据墨）

**操作列特殊规则**：
- 常态：`opacity-0`
- 行 hover：`opacity-100`
- 过渡：`transition-opacity duration-150`

**代码示例**：
```tsx
<Table>
  <TableHeader>
    <TableRow>
      <TableHead className="text-left">姓名</TableHead> {/* 主键列 */}
      <TableHead className="text-right">播放量</TableHead> {/* 核心指标 */}
      <TableHead className="text-left">创建时间</TableHead> {/* 辅助列 */}
      <TableHead className="text-right w-24">操作</TableHead>
    </TableRow>
  </TableHeader>
  <TableBody>
    <TableRow className="group">
      <TableCell className="text-[#1F1E1D] font-normal">阿禅</TableCell>
      <TableCell className="text-[#141413] text-right tabular-nums">1,234,567</TableCell>
      <TableCell className="text-[#78716C]">2026-10-22</TableCell>
      <TableCell className="text-right">
        <Button variant="ghost" size="sm" className="opacity-0 group-hover:opacity-100">
          编辑
        </Button>
      </TableCell>
    </TableRow>
  </TableBody>
</Table>
```

**已定契约**：
- **字重**：400（所有按钮文字）

### 3.4 ui/input.tsx / ui/select.tsx（表单控件）

**已定契约**：

- 阴影：`shadow-input`
- 圆角：`rounded-md`

### 3.5 ui/card.tsx（内容托盘）

**已定契约**：
- 容器：`rounded-xl`(12px) + `shadow-card-ring`
- `CardTitle`：14px/500/`#1F1E1D`

**使用场景**：
- ✓ 数据主托盘、看板/网格类子项
- ✗ 分页/筛选等外围工具（必须裸铺）

**`CardTitle` 不得当章节标题用**（那是空间定名 18px Serif）。

### 3.6 ui/label.tsx / ui/badge.tsx（元数据呈现）

**Label（字段名）**：
- 12px / `#78716C`

**Badge（徽标）**：
- 12px、`px-1.5 py-0.5 leading-none rounded-md`

### 3.7 ui/empty-state.tsx（空状态统一走它）

**已定契约**：
- 居中 `✦` 微符或极简暖墨单线手稿
- `14px Serif #1F1E1D` 温和指引（≤30字）
- 下方 `gap-3` 唯一操作入口

### 3.8 卷首寄语 / 学者边注（装帧元素）

**寄语（AI 结论块）**：
- 无底色无外框
- 左侧 `border-l-2 border-[#43718E]`（或前置 `✦`）
- 配 `14px Serif #141413`（≤30字）或 `13px Sans #1F1E1D`

**边注（行内/侧边提醒）**：
- `bg-[#43718E]/10 rounded-md px-2.5 py-1.5` 或无底色
- 配 `12px Sans #78716C`

## §4 页头与布局

### 4.1 页头一律走壳

| 壳 | 适用 |
|---|---|
| `components/app-shell/app-shell.tsx` | 前台页面 |
| `components/admin-workspace-layout.tsx` | 后台页面 |

**槽位顺序与侧位锁死**：

| 槽位 | 位置 |
|---|---|
| Eyebrow（所属模块） | 页面定名之上（`gap-1` 4px） |
| 页面定名（H1） | 页头左上第一位，**每页必有** |
| 描述 | 定名之下（`gap-1` 4px） |
| 主 CTA 与页头操作 | 与定名同行，**右对齐**（全站唯一侧） |
| 筛选器 | 页头之下（距页头 `20px`）、受控表格之上（距表格 `12px`），左对齐同轴 |

用 `eyebrow` / `title` / `description` / `actions` 传值，不自建页头。

**已知例外仅三类**：落地页、认证页（`auth-shell`）、错误与空态页（`not-found` / `global-error`）。

### 4.2 内容宽度与导航同轴

内容区最大宽统一 `max-w-7xl`(1280px)，与导航栏一致；宽表页（列数 ≥12）可放宽至 `max-w-screen-2xl`，但**导航栏须同步加宽**。

**任何情况下内容不得宽于导航。**

### 4.3 工具栏宽度预算与降级阶梯（2026-10-24 定，阿禅拍板）

**一行是硬要求**：含日期、视图切换、筛选的工具栏，任何档位都必须单行；折成两行、右侧筛选组悬空＝缺陷，不是"可接受的退化"。

**预算表先量后改**：改工具栏前先实测每个档位三段占宽（**必须包含最宽档位，如"自定义日期"，不能只测最常见的"近7天"**），可用宽度取 1332 宽窗口下的内容宽 1200，余量目标 ≥80px。

实测基准（1332 宽窗口，2026-10-24 修复后）：日期段 324 ＋ 视图段 288 ＋ 筛选段 498 ＝ 1110，余量 90。修复前正常档位占 1197（余量仅 3），自定义档位 1286（超宽 86→折行）。

**降级阶梯**（空间不足时按序收起，功能必须有弹层兜底，不许直接删除；当前已落地第 1 级，2-4 级按需落地）：

1. < 1536：把「今天/最新」收进日期弹层（弹层内为「跳到今天/跳到最新」）
2. < 1280：日期按钮上的「第 N / 共 M 天」收起
3. < 1024：「完整/宽松」收进视图组弹层
4. < 768：搜索框收成图标，点击展开

**兜底**：任何宽度下宁可把一整组收进"更多"，也不出现第二行。

**自动检查**：至少断言 1280 与 1332 两个宽度下工具栏只有一行（待补）。

## §5 动效

### 5.1 基础交互

- **按压**：`active:scale-[0.99] duration-75`
- **悬停**：`transition-colors duration-150`
- **淡入淡出**：`transition-opacity duration-200`

### 5.2 页面级动效（提升质感但不打扰）

- **抽屉滑入**：`ease-[cubic-bezier(0.16,1,0.3,1)] duration-300`
- **卡片入场**（首屏加载）：错开 50ms `animation-delay`，营造呼吸感
- **骨架加载**：`#F1F1F0` → `#EBEBE9` 呼吸，等高占位，数据到达原地淡入、零布局跳动

### 5.3 微交互（不影响效率的细节）

- **表格行悬停**：只做背景变色（`#F7F7F6`），**禁位移与缩放**（防止等宽数字错位与点击脱靶）
- **按钮加载**：Spinner 只准出现在按钮内部，配 `animate-pulse`
- **Toast 入场**：`slide-in-from-top-2` + `fade-in`

### 5.4 禁止

- 结果直接可见时不弹 Toast
- 禁 `transition-all`（会让翻页/筛选时列宽行高慢动作变形）
- 禁浮夸弹跳、无限循环、过度缓动、阻塞交互的动画

**判据**：动效是为了告知状态变化（反馈）或引导视线（层次），不是装饰。每个动效必须回答"它让用户更快理解了什么"。

### 6.1 数据密集页（表格为主）

**典型场景**：用户列表、视频复盘、订单管理、数据监控

```
筛选器：裸铺、gap-2 紧凑排列、w-fit 自适应
  ↓ (gap-3 呼吸)

  主键列（姓名）：13px #1F1E1D 左对齐
  核心指标列（无）：若有播放量/金额用 13px #141413 右对齐
```

**典型场景**：用户详情、内容编辑、设置页面


## §7 验证清单（实现后执行）

### 7.1 自动检查（可执行）

**覆盖范围声明**：以下命令只覆盖机械规则（字号/墨度/半档留白/字重/圆角）。单点聚光灯、凹凸分明、配角裸铺、装饰必要性不在命令覆盖内，必须对照 §7.2 逐条目视自查——**命令全绿 ≠ 合规**。

```bash
# 字号封闭系统（已排除 Hero 豁免文件）
rg -o --no-filename "text-\[[0-9.]+px\]" src/ -g '!**/app/page.tsx' | sort -u | grep -vE "\[(12|13|14|18|20|28)px\]"

# 墨度封闭系统
rg "text-(slate|zinc|gray|stone)-\d+" src/

# 留白封闭系统
rg "gap-(1\.5|2\.5|3\.5|4\.5)" src/

# 字重滥用
rg "font-(semibold|bold)" src/ | grep -v "data-active\|aria-selected\|checked"

# 圆角违规
rg "rounded-(sm|lg|3xl)" src/
```

### 7.2 目视检查

- [ ] 当前活跃层是否有 >1 个饱和色实底？
- [ ] 外层 gap 是否 > 内层 gap？
- [ ] 筛选器/分页器是否套了 Card？（应裸铺）
- [ ] 表单内是否白底套白框？（应裸铺或下沉浅砂）
- [ ] 表格行悬停是否有位移/缩放？（应只变背景色）
- [ ] 操作成功后是否弹了不必要的 Toast？（结果可见时应原地更新）
