# 设计一页纸（视觉速查卡 · 前端任务常驻）

> 本卡是《Claude设计哲学》《Claude设计规范》的开工前置速查，不含任何数值；与两卷冲突以两卷为准。价格表为速查副本，唯一详写在《哲学》原则2。

## 立场（一切判断的根）

尊重注意力是目的，功能性秩序是方法，惊艳是秩序的自然结果。

- **可停留检验**：用户停在页面什么都不做，是否被打扰——自动轮播、脉冲红点、自动刷新跳动、抢焦点都算。
- **基线环境**：Windows + 雅黑/中易宋体，字重全站仅 400；层级靠字号、字体族、位置、留白立住。

## 注意力价格表（想强调，从便宜档开始花）

| 档 | 手段 | 花法 |
|---|---|---|
| 免费 | 位置、留白、墨度梯次、出现顺序 | 便宜够用就停在便宜 |
| 中等 | 字号档位、字体族（衬线=宣告）、淡底与下沉、阴影与发丝线 | 不够才升一档 |
| 昂贵 | 主色实底、动效、插画与装帧符号 | 同屏省着花；同层实底主色至多一处 |

## 三问自检（动手改任何 UI 前过一遍）

1. 这是在服务用户理解，还是在争夺用户注意？
2. 页面静止不动时看着舒服吗？（静止为默认：无用户动作、无数据真实变化，界面不自行运动）
3. 有没有更便宜的手段达到同样强调效果？
