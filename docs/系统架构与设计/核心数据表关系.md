# 核心数据表关系

> 本文件回答：核心表是什么、它们怎么关联。只记最关键的，详细外键看代码。
> 行数上限：100行 | 最后核对：2026-10-14

## 1. 核心表关系

```
profiles (用户)
  ├→ daily_reports (日报)
  ├→ videos (视频)
  ├→ exemption_requests (豁免申请)
  ├→ fulfillment_appeal (补交申请)
  ├→ topic_child_claims (选题认领)
  └→ notifications (待办)

videos (视频)
  ├→ video_metrics_snapshots (快照)
  ├→ video_tags (标签)
  ├→ video_topic_claims (选题绑定)
  └→ video_screenshot_replacement_history (截图替换)

teams (团队)
  ├→ profiles (成员)
  ├→ work_groups (小队)
  └→ fulfillment_records (履约记录)

topic_parent_items (母题)
  └→ topic_child_items (子题)
       ├→ topic_child_claims (认领)
       └→ video_topic_claims (作品绑定)
```

## 2. 数据流转链路

### 2.1 视频上传
```
填表 → daily_reports → videos → 
→ video_metrics_snapshots (24h) →
→ fulfillment_records 更新 →
→ notifications（可选）
```

### 2.2 豁免申请
```
exemption_requests → exemptions →
→ fulfillment_records 更新 →
→ notifications 关闭
```

### 2.3 选题库
```
topic_parent_items → topic_child_items →
→ topic_child_claims → video_topic_claims →
→ 撞车检测（同子题多人）
```

## 3. 命根子表（牵一发动全身）

### daily_reports
- **依赖**：dashboard、fulfillment、collaboration、export、video-submit
- **风险**：动结构/口径 = 动全站

### videos
- **依赖**：admin/content、video-submit、快照、标签、选题库
- **风险**：lifecycle_state 影响多个模块

### profiles
- **依赖**：所有用户相关操作
- **风险**：lifecycle_state 影响 visibleUserIds
