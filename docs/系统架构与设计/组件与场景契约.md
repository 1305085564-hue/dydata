# 组件与场景契约（组件手册 · 辅卷二）

> **主卷是《Claude设计哲学》**——它承担立场、原则、判据与执行主链。本卷只回答"这个组件怎么做"，是照抄与查表用的手册，不需要理由陪读。
> **读法**：先按主卷第 1 章的执行主链走完判断，再来本卷查组件契约。
> **边界**：本卷不写"为什么这样定"（那在主卷），不写"字号/墨度/色值是多少"（那在《视觉与数值手册》）。
> **冲突裁决**：主卷（为什么）→ 数值手册（是什么）→ 本卷（怎么做）。
> **单一详写律**：同一规则只在一处详写——原则与"为什么"归主卷，数值归数值手册，组件契约归本卷；其余位置只留一行引用，改规则时只改详写处。

---

## §0 使用方式

- 动到具体组件（表格 / 按钮 / 浮层 / 表单 / 卡片 / 徽标 / 空态 / 激活态）→ §3
- 动到页头、内容宽度、导航同轴 → §4
- 动到动效 → §5
- 不知道该做成什么形状 → §6 场景决策路径（先选型，再照抄样板页）
- 改完验收 → §7

## §3 组件契约（直接用默认值，要改去改组件）

### 3.1 ui/table.tsx（数据密集页核心）

**已定契约**：
- **表头**：12px/400/`#78716C`、`h-9`、`px-3`
- **单元格**：14px、`py-2.5`、`px-3`（行高随字号自增约 1.6px，不调 padding）
- **表尾合计行（TableFooter）**：定名墨 `#141413`、`border-t border-[#E2E2DF]`、数值右对齐，不靠字重
- **行底**：`border-b border-[#E2E2DF]/60`
- **根容器**：带 `tabular-nums`（等宽数字）
- **无斑马纹**、**无竖向列线**

**列对齐与墨度**：
- 文本列：左对齐
- 数值/金额/百分比列：强制右对齐（`text-right`）
- 每行唯一主键列：`text-[#1F1E1D]`（正文墨）
- 核心结果指标列：`text-[#141413]`（定名墨）
- 操作人/状态等辅助列：14px `text-[#78716C]`（元数据墨）
- **时间列（表内唯一例外）**：12px `text-[#1F1E1D]` + `tabular-nums`——12px 配元数据墨在 Windows 上过淡，时间列升用正文墨（2026-10-27 按线上现状定案，实测基准 content-list-table.tsx）

**操作列特殊规则**：
- 常态：`opacity-0`；行 hover 或键盘焦点进入该行时：`opacity-100`
- 无 hover 的触屏场景提供常显或等效可直接操作的入口；操作须可通过键盘聚焦
- 过渡：`transition-opacity duration-150`

**用法样板**（照抄真实页面，不再维护文档内示例）：`src/app/(app)/admin/content/content-list-table.tsx`——主键列/核心指标列/辅助列的墨度分工与操作列渐进揭示均以该文件为准。

### 3.2 ui/button.tsx（三档尺寸）

**已定契约**：
- **字重**：400（所有按钮文字）
- **三档**：S `h-6` / 12px · **M `h-7` / 14px（默认）** · L `h-10` / 14px
- **实底档**（default / destructive）：用 `shadow-input`，禁 `shadow-sm`

**特殊规则**：
- 主 CTA：`bg-[#D97757] text-white hover:bg-[#C46A4D]`（主色为《视觉与数值手册》§2.2 的 Action）
- 次要行动（同层已有主 CTA）：`border-[#D97757] text-[#D97757] hover:bg-[#D97757]/5`

### 3.3 ui/dialog.tsx / ui/sheet.tsx（浮层容器）

**Dialog（弹窗）**：
- 容器：`rounded-2xl` + `shadow-claude-dialog`
- 标题：20px **Sans** / 400 / `#141413`

**Sheet（抽屉）**：
- 容器：`rounded-l-2xl` + `shadow-claude-dialog`
- 主标：20px **Serif** / 400 / `#141413`
- `SheetHeader`：默认横排两端对齐（标题左、操作右）

**浮层内部层级（通则）**：
- **20px 标题档只属于本节这两个浮层大容器**（Dialog Sans / Sheet Serif）；页面与空间定名见《视觉与数值手册》§1.5，同样是 20/28 档。
- **Popover / DropdownMenu / Select 下拉等控件级浮层不设标题**：内部只有"分组标签 + 可点条目"两种身份，档位与墨度按 §3.6「容器阻尼律」执行，不在本节重复。
- 同一屏内两个浮层，同角色标签不得出现两种墨度（判据与例外见 §3.6）。

### 3.4 ui/input.tsx / ui/select.tsx（表单控件）

**已定契约**：
- 字号：14px
- 高度：`h-8`（按钮 M 档 `h-7` 矮 1px，不强求等高）
- 背景：`bg-white`
- 边框：`border-[#E2E2DF]`
- 阴影：`shadow-input`
- 圆角：`rounded-md`
- 聚焦态：`focus-visible:border-[#1F1E1D] focus-visible:ring-2 focus-visible:ring-[#1F1E1D]/10 outline-none`
  - 禁用浏览器默认蓝框与主色橙框

**下拉宽度按语境定**：
- 横排筛选栏：优先 `w-fit` 紧凑自适应（禁写死定宽防大空白）
- 纵向表单与抽屉：优先 `w-full` 严整对齐
- 表格行内：受列宽约束

### 3.5 ui/card.tsx（内容托盘）

**已定契约**：
- 容器：`rounded-xl`(12px) + `shadow-card-ring`
- `CardTitle`：14px/400/`#141413`（条目名写法，见《视觉与数值手册》§1.1）

**使用场景**：
- ✓ 数据主托盘、看板/网格类子项
- ✗ 分页/筛选等外围工具（必须裸铺）

**`CardTitle` 不得当章节标题用**（那是空间定名 20px Serif）。

### 3.6 ui/label.tsx / ui/badge.tsx（元数据呈现）

**Label（字段名）**：
- 12px / `#78716C`

**Badge（徽标）**：
- 12px、`px-1.5 py-0.5 leading-none rounded-md`

**容器阻尼律（通则，2026-10-26 实测入规）**：

**定义**：容器尺度反向压制内部可用档位——**容器越小，能用的字号档位越少**。20px 与衬线是"浮层大容器 / 页面与空间定名"的专属（《视觉与数值手册》§1.5 与本卷 §3.3），控件级容器内部一律不出现。

**控件级浮层（Popover / DropdownMenu / Select 下拉，宽度通常 128–320px）内部只有两种身份，没有"标题"**：

| 身份 | 档位 | 说明 |
|---|---|---|
| 分组标签 | 12px / `#78716C` | 即本节 Label 档；独占一行，下面跟它统领的内容 |
| 可点条目 / 选项 | 14px / `#1F1E1D` | 悬停 `#141413` + `bg-[#F1F1F0]`（§3.9） |
| 条目右侧回显 | 12px / `#78716C` | 选中后 `#141413` + `bg-[#F1F1F0]` |

**层级手段**：字号差（标签 12 / 内容 14）＋ 位置 ＋ 留白（组内 `gap-1`，组间 12px）；墨度只作辅助（《视觉与数值手册》§1.2）。

**两条硬条款**：
- **同角色同墨**：同一个浮层里，同类分组标签只允许一个墨度——出现"一个 `#78716C`、一个 `#1F1E1D` 的两个标题"，即违规。
- **不拿字号换标题**：不得把分组名做成 14px 正文墨"伪标题"（与 14px 选项同级，层级归零）；也不得把可点选项压到 12px 去换"标题更大"（Windows 100% 下小字发虚，且与 §3.4 控件 14px 打架）。

**判据一句话**：**这是控件级浮层吗？是——标签 12 灰、内容 14 墨，没有标题。**

### 3.7 ui/empty-state.tsx（空状态统一走它）

**已定契约**：
- 居中 `✦` 微符或极简暖墨单线手稿
- `14px Sans #1F1E1D` 温和指引（≤30字；衬线不得小于 20px，见《视觉与数值手册》§1.5）
- 下方 `gap-3` 唯一操作入口

**暖墨线描风格卡**（素材库：`src/components/editorial/editorial-illustrations.tsx`，AI 只选不创作）：
- 单色暖墨（信号墨或元数据墨档），禁彩色、渐变、3D、投影
- 线宽 1–1.5px，圆头端点与圆头连接，允许轻微不规则（手绘感，不用完美几何）
- 题材限场景相关的具体静物（灯、桌、纸页、器物），一张图只说一件事
- 出现节点仅《Claude设计哲学》§2.1 所列关键心理节点（迎宾、洞察、空态、归档）

### 3.8 卷首寄语 / 学者边注（装帧元素）

**寄语（AI 结论块）**：
- 无底色无外框
- 左侧 `border-l-2 border-[#43718E]`（或前置 `✦`）
- 默认配 `14px Sans #1F1E1D`；结论金句（≤30字）可配 `20px Serif #141413`

**边注（行内/侧边提醒）**：
- `bg-[#43718E]/10 rounded-md px-2.5 py-1.5` 或无底色
- 配 `12px Sans #78716C`

**结论必须带依据**：AI 结论后附一句"因为…"（数据来源或推理路径）；推测出的结论用边注标明"这是推测"，不假装全知（语气见《Claude设计哲学》§2.3）。

### 3.9 激活态配方（选中 / 当前 / 排序中）

**硬条款**：激活态必须同时有**墨度变化**与**底色变化**（排序表头以方向箭头代替底色）；**字重不得作为任何激活信号**（缘由见《视觉与数值手册》§1.6）。

| 场景 | 未选中 | 选中 |
|---|---|---|
| 分段 / Tab / 筛选胶囊 / 视图切换（有下沉槽 `#F1F1F0`） | 透明底 + `#78716C` | `bg-white` + `shadow-input` + `#141413` |
| 同上（无槽） | 透明底 + `#78716C` | `bg-[#F1F1F0]` + `#141413` |
| 一级导航（`aria-current`） | `#78716C` | `bg-[#F1F1F0]` + `#141413` |
| 下拉菜单项 / 列表选中项（工作区等） | `#1F1E1D` | `bg-[#F1F1F0]` + `#141413` + 深炭墨色 `✓`（不借主色） |
| 分页当前页码（`min-w-7` 框内） | `#78716C` | `bg-[#F1F1F0]` + `#141413` |
| 表头排序列 | `#78716C` | `#141413` + 方向箭头（常显） |

未选中项的悬停沿用《视觉与数值手册》§2.3 `Hover` 底色。

**组件落实**：组件里"仅切换字重"的激活写法一律改走本表（补底色与墨度变化）。

## §4 页头与布局

### 4.1 页头一律走壳

| 壳 | 适用 |
|---|---|
| `components/app-shell/app-shell.tsx` | 前台页面 |
| `components/admin-workspace-layout.tsx` | 后台页面 |

**槽位顺序与侧位锁死**：

| 槽位 | 位置 |
|---|---|
| 页面定名（H1） | 页头左上第一位，**每页必有** |
| 描述 | 定名之下（`gap-1` 4px） |
| 主 CTA 与页头操作 | 与定名同行，**右对齐**（全站唯一侧） |
| 筛选器 | 页头之下（距页头 `20px`）、受控表格之上（距表格 `12px`），左对齐同轴 |

**页头不设眉标（Eyebrow）**：所属模块由导航栏告知，眉标额外占一行且常与定名重复，白耗注意力。

用 `title` / `description` / `actions` 传值，不自建页头。

**已知例外仅三类**：落地页、认证页（`auth-shell`）、错误与空态页（`not-found` / `global-error`）。

### 4.2 内容宽度与导航同轴

内容区最大宽统一 `max-w-7xl`(1280px)，与导航栏一致；宽表页（列数 ≥12）可放宽至 `max-w-screen-2xl`，但**导航栏须同步加宽**。

**任何情况下内容不得宽于导航。**

## §5 动效

### 5.1 基础交互

- **按压**：`active:scale-[0.99] duration-75`
- **悬停**：`transition-colors duration-150`
- **淡入淡出**：`transition-opacity duration-200`

### 5.2 页面级动效（提升质感但不打扰）

- **抽屉滑入**：`ease-[cubic-bezier(0.16,1,0.3,1)] duration-300`
- **卡片入场**（首屏加载）：错开 50ms `animation-delay`，营造呼吸感
- **骨架加载**：`#F1F1F0` → `#EBEBE9` 呼吸，等高占位，数据到达原地淡入、零布局跳动
- **仪式节点慢动效**：迎宾、洞察呈现、归档定卷可用 400–600ms 缓入缓出（像呼吸，不像赶工），一屏至多一处；其余一律用 5.1 的利落节奏
- **减弱动效兜底**：一切动效须提供 `prefers-reduced-motion` 回退（关闭或缩短为直接切换）——尊重注意力也包含尊重生理需要

### 5.3 微交互（不影响效率的细节）

- **表格行悬停**：只做背景变色（`#F7F7F6`），**禁位移与缩放**（防止等宽数字错位与点击脱靶）
- **按钮加载**：Spinner 只准出现在按钮内部，配 `animate-pulse`
- **Toast 入场**：`slide-in-from-top-2` + `fade-in`

### 5.4 禁止

- 结果直接可见时不弹 Toast
- 禁 `transition-all`（会让翻页/筛选时列宽行高慢动作变形）
- 禁浮夸弹跳、无限循环、过度缓动、阻塞交互的动画

**判据**：动效是为了告知状态变化（反馈）或引导视线（层次），不是装饰。每个动效必须回答"它让用户更快理解了什么"。

## §6 常见场景决策路径（组合结构，不重抄组件数值）

### 6.1 数据密集页（表格为主）

**典型场景**：用户列表、视频复盘、订单管理、数据监控。

**决策路径**：
1. 页头定名靠左，主行动靠右；筛选置于受控表格上方（§4.1）。
2. 筛选器紧凑裸铺；核心数据表放纯白主托盘，不用额外容器层层包裹。
3. 表格列、数值对齐、操作列鼠标/键盘/触屏入口统一走 §3.1，不重写规格。

**结构参照**：`src/app/(app)/admin/content/`；样板与现行契约冲突时，以契约为准。

### 6.2 工作台页（表单 + 卡片）

**典型场景**：用户详情、内容编辑、设置页面。

**决策路径**：
1. 页头走 §4.1，描述仅在能帮助当前操作时出现。
2. 多输入项（通常超过 3 个）表单裸铺，不套白框；只读信息可下沉浅砂槽（《视觉与数值手册》§2.1）。
3. 字段、卡片分别遵循 §3.4/§3.5；主提交置底部右侧，反馈按 §7.2 验收。

**结构参照**：`src/app/(app)/dashboard/form-v2/`，默认复用其操作顺序，不机械复制有问题的布局。

### 6.3 引导页（落地页、空态）

**典型场景**：首页 Hero、空状态、404、登录注册。

**决策路径**：
1. 迎宾、引导等关键心理节点可增加衬线（占比最高约 40%）和暖墨线描；日常控件不加装帧。
2. 空态走 §3.7（指引 + 唯一操作入口），不另建样式；出错页须交代下一步。
3. 落地页 Hero 参照 `src/app/page.tsx`，字号豁免见《视觉与数值手册》§1.1。

**结构参照**：`src/components/ui/empty-state.tsx`；不以装饰代替真实反馈。

## §7 验证清单（实现后执行）

### 7.1 自动检查（门禁强制）

机械规则（字号/墨度/间距半档/字重/衬线下限/圆角/阴影）已由 `scripts/design-token-gate.mjs` 固化为门禁：`npm run gate:design`（已串入 `gate:static`）。基线棘轮模式：存量违规记录在 `scripts/design-token-baseline.json`，任何文件新增违规即红灯；下调基线须走《Claude设计哲学》定律2（阿禅确认+纠错索引留档）。

**覆盖范围声明不变**：单点聚光灯/有声区排序、凹凸分明、配角裸铺、装饰必要性不在门禁覆盖内，必须对照 §7.2 逐项页面自查——**门禁全绿 ≠ 合规**。

### 7.2 页面验收（AI 主动执行；缺少实机或浏览器条件须标「未验证」）

- [ ] 当前活跃层是否列出全部有声元素并排序？主声部是否唯一，相邻两个是否有可见落差？（饱和色实底 >1 即违规）
- [ ] 外层 gap 是否 > 内层 gap？
- [ ] 筛选器/分页器是否套了 Card？（应裸铺）
- [ ] 表单内是否白底套白框？（应裸铺或下沉浅砂）
- [ ] 表格行悬停是否有位移/缩放？（应只变背景色）
- [ ] 操作成功后是否弹了不必要的 Toast？（结果可见时应原地更新）
- [ ] 激活/选中态是否同时有墨度与底色变化？（字重不算）
- [ ] 条目名是否独占一行并紧跟元数据？
- [ ] 改动涉及层级时，是否在 Windows 实机（100% / 125%）看过？
- [ ] 任务闭环：关键操作是否可发现、可完成，并能看到可信的完成反馈？
- [ ] 状态真实：加载、成功、失败、空结果是否可区分？失败不得假装成功，未保存内容不得无故丢失。
