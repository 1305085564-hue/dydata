# 决策 0005：账实分叉期禁止 `supabase db push`

**状态**：有效（仅账实分叉期间适用；本次未连接生产核账，不断言当前分叉状态）

**背景**：线上存在已执行但未登记或已登记但对象缺失的迁移版本，整体推送可能重跑历史策略并把数据库卡在半迁移状态。
**决定**：账实分叉期禁止 `supabase db push`；上线只能取单个迁移在事务内手工执行，随后向 `supabase_migrations.schema_migrations` 幂等登记，并用 `pg_policy`、`pg_proc` 等真实对象核验。
**后果**：迁移发布步骤变长但可回滚、可逐对象核实；账本记录不能单独证明线上生效。
**证据**：[迁移账与对象核账手势](../../通用管理/纠错索引.md#补交审批迁移账与函数对象对账)；[任务总纲](../../plans/历史-项目/根治工程/2026-10-02-全站架构根治工程-任务总纲.md)「三、跨阶段硬边界」。
