# 视觉与数值手册（数值字典 · 辅卷一）

> **主卷是《Claude设计哲学》**——它承担立场、原则、判据与执行主链。本卷只回答"这个值是多少"，是查表用的字典，不需要理由陪读。
> **读法**：先按主卷第 1 章的执行主链走完判断，再来本卷查数值。
> **边界**：本卷不写"为什么这样定"（那在主卷），不写"组件怎么做"（那在《组件与场景契约》）。
> **冲突裁决**：主卷（为什么）→ 本卷（是什么）→ 契约卷（怎么做）。
> **单一详写律**：同一规则只在一处详写——原则与"为什么"归主卷，数值归本卷，组件契约归契约卷；其余位置只留一行引用，改规则时只改详写处。

---

## §0 使用方式

- 查字号 / 墨度 / 留白 / 圆角 / 衬线 / 字体栈 → §1
- 查背景层 / 主色 / 状态色 / 边框 / 阴影 → §2
- 改现有页面时，**仅沿用符合现行规范的既有写法**；发现旧写法不合规，不继续复制。范围内修正，范围外指出，不借机全量整改。
- 机械规则由门禁强制：`npm run gate:design`（`scripts/design-token-gate.mjs`），基线棘轮模式，见《组件与场景契约》§7.1。

## §1 封闭系统档位表

### 1.1 字号四档（场景 → 数值映射）

四个字号、六种身份：

| 身份 | 字号 | 行高 | 字重 | 墨度 | 字体 | 使用场景 |
|---|---|---|---|---|---|---|
| **页面定名** | 28px（`sm:` 以下 20px） | 1.20 | 400 | `#141413` | Serif + `tracking-tight` | 每页唯一 H1 |
| **空间定名** | 20px | 1.30 | 400 | `#141413` | 区块标题/抽屉主标用 Serif；弹窗标题用 Sans | 统领一个空间 |
| **正文与条目名** | 14px | 1.60（条目名 1.40） | 400 | 正文 `#1F1E1D`；条目名 `#141413` | Sans | 正文、表格单元格、按钮文字；条目名（列表行名、卡片名、表单段落标题）写法见下 |
| **元数据** | 12px | 1.50 | 400 | `#78716C` | Sans | 表头、字段名、时间戳、单位、Badge |
| **无内容信号** | 12px | 1.50 | 400 | `#A8A29E` | Sans | 占位符、空值 `—`、禁用态 |
| **指标大数** | 20px | 1.20 | 400 | `#141413` | Sans | 统计面板的核心数字本体，不含标签与单位 |

**封闭律**：表内四个字号（28/20/14/12）之外，一律不得出现。

**唯一豁免**：落地页 Hero 32 → `sm:`36 → `lg:`41.6px（`src/app/page.tsx` 首屏主标题）。

**贴身反差判据**：定名/核心大数（`#141413`）与伴随它的元数据（标签/单位/副标）成对出现时，取亲密档 `gap-1`(4px) 贴身排布。

**条目名写法**：条目名与正文同字号、同字重，**不靠字重区分**。承重手段只有三样：① 独占一行（位置）；② 其后紧跟 12px 元数据，`gap-1`（邻居反差）；③ 头顶留白大于脚下（`space-y-5` 对 `space-y-3`，见 §1.3）。定名墨 `#141413` 只是辅助。最弱的场景是表单段落标题（紧挨 14px 正文），全靠留白与位置，Windows 目检时重点看。表格里没有"条目名"这一身份：主键列与核心指标列按《组件与场景契约》§3.1 的墨度分工。

**字重一档**：全站只有 400（`font-normal`）。500、600 不存在于基线环境（回退事实见 §1.6），中英混排还会粗细不一，不入系统：`font-medium` / `font-semibold` / `font-bold` / `font-[数字]` / 内联 `fontWeight` 全禁。唯一非 UI 例外：OG 分享图（`opengraph-image.tsx`，渲染器自带字体，不走浏览器字体栈）。**层级不得只靠字重承载**；这条与激活态配方（《组件与场景契约》§3.9）互为表里。

### 1.2 墨度四阶（性质 → 色值映射）

| 墨度 | 色值 | 承载 |
|---|---|---|
| **定名墨** | `#141413` | 页面定名、空间定名、条目名、指标大数、表格核心指标列、激活态 |
| **正文墨** | `#1F1E1D` | 正文、表格主键列、常规数据 |
| **元数据墨** | `#78716C` | 表头、字段名、单位、表格次要列、辅助说明、表格外时间戳（表内时间列见《组件与场景契约》§3.1） |
| **信号墨** | `#A8A29E` | **只承载"这里没有内容"**：占位符、空值 `—`、禁用态、图标装饰 |

**四阶之外的文字灰一律不得出现**（含 Tailwind 原生灰阶类名，由门禁强制，见《组件与场景契约》§7.1）。

**信号墨判据一句话**：这块浅墨是在说「这里没有内容」，还是「这里有内容但想写淡一点」？后者即违规，不得浅于 `#78716C`。

**辅助信号声明**：定名墨与正文墨相差极微（肉眼几乎不可分），**只作辅助信号**——给细心的读者多一分余味，不得单独承担层级或激活态；承重的是字号、字体族、位置与后三阶墨度。

### 1.3 留白四级（关系 → 间距映射）

| 语义 | 间距 | Tailwind | 典型绑定场景 |
|---|---|---|---|
| **断层 Rift** | 20px | `gap-5` / `space-y-5` | 页头与主工作区间、跨章节大模块之间（标题头顶） |
| **呼吸 Breath** | 12px | `gap-3` / `space-y-3` | 章节标题与下方受控内容间（标题脚下）、筛选栏与受控表格间 |
| **紧凑 Tight** | 8px | `gap-2` / `space-y-2` | 筛选栏内各控件间、同级列表项/按钮组间 |
| **亲密 Intimate** | 4px | `gap-1` / `space-y-1` | 大数与单位、标题与描述、图标与文字间 |

**元素间距禁半档**：`gap` / `space-y` / `space-x` 的 1.5/2.5/3.5/4.5 全禁（由门禁强制，见《组件与场景契约》§7.1）。手机端表单为省屏高，可保留 16px。

**内边距不受四级管辖**：它的职责是撑出控件高度与容器呼吸，由组件规格决定，允许 `py-1.5` / `px-2.5` 这类半档。

**关系判据**：遵循主卷原则5；本表提供既有间距档位，不要求代码嵌套逐层扩大间距。容器**左右内边距必须相等**（表格列为对齐数字取 `pl-4 pr-2` 属合规）。

**头顶 > 脚下（常用映射）**：章节容器外部间距可用 `space-y-5`(20px)，章节内部（标题到内容）可用 `space-y-3`(12px)。具体组合仍须符合主卷原则5的感知分组判据，不以固定 20/12 代替页面判断。

### 1.4 圆角三档 + 全圆（容器 → 圆角映射）

| 元素 | 圆角 | Tailwind |
|---|---|---|
| 控件（按钮/输入/徽标/内嵌提示） | 6px | `rounded-md` |
| 容器（主托盘/卡片/面板/空态块） | 12px | `rounded-xl` |
| 浮层大容器（弹窗 Dialog / 抽屉 Sheet） | 16px | `rounded-2xl` |
| 头像与状态点 | 全圆 | `rounded-full` |

**禁用**：`rounded-lg`(8px)、裸 `rounded`(4px)、`rounded-sm`、`rounded-3xl`、自定义像素圆角（由门禁强制，见《组件与场景契约》§7.1）。

**形状同源**：同一类元素全站只有一个圆角。

### 1.5 衬线白名单

| 场景 | 判据 |
|---|---|
| 页面定名（28px；`sm:` 以下 20px） | 每页唯一 |
| 空间定名（20px） | 仅当它是**为一个空间定名**（抽屉主标、区块标题）；弹窗标题一律用 Sans |
| AI 结论金句 | 仅 20px 且 ≤30 字；平常的 AI 结论走《组件与场景契约》§3.8 的 14px Sans + 左线 / `✦` |
| 完卷微符 `✦` | 装帧符号 |

**核心判据：这是过程，还是宣告？** 宣告用衬线，过程用 Sans。

**衬线禁区**：表格 / 表单 / 按钮 / 导航 / 徽标；**小于 20px（含空态指引，空态用 14px Sans）**；标点单独衬线；超过 30 字成段。

**衬线间距锁死 `tracking-tight`**（约 -0.025em），禁 `tracking-normal` 与正间距。

**20px 下限**即表内空间定名档，不新增字号（缘由见《Claude设计哲学》定律3；Windows 实机目检记录见《纠错索引》）。

### 1.6 渲染基线与字体栈

**基线环境**：Windows 10/11 + Chrome/Edge，显示缩放 100%–125%（DPR 1–1.25）。macOS 是增强环境，设计走查以基线为准。

| 环境 | sans（拉丁 / 中文） | serif（拉丁 / 中文） | 实际可用字重 |
|---|---|---|---|
| Windows（基线） | Segoe UI / 微软雅黑 UI | Georgia / 中易宋体 | 雅黑 400·700；宋体仅 400；Segoe UI 400·600·700（无 500） |
| macOS | SF Pro / 苹方 | Iowan Old Style 等 / 宋体-简 | 多档齐全 |

**字体栈规则**：
- 只用系统字体，不引入 webfont（性能优先，首屏零字体下载）。
- 历史残留 `Inter`、`--font-display`、按 DPR 回退 Sans 的规则均已从 globals.css 删除，由 `src/styles/css-tokens.test.ts` 反向断言防回写，不得再写回。
- **字重回退事实**：写 500 取 400；写 600 在雅黑取 700、在 Segoe UI 取 Semibold。这是 §1.1「字重一档」的依据，设计时不得假设 500 存在。
- **中文衬线钉栈**：Windows 统一落系统必装的中易宋体（笔画更实），Mac 命中 Songti SC；STSong、NSimSun 已删除（随 Office 才命中、观感逐机漂移），由 css-tokens.test.ts 断言防回写。定案缘由与目检记录见《纠错索引》。

## §2 颜色系统

### 2.1 背景三层（Z轴 → 色值映射）

| Token | 色值 | 场景 |
|---|---|---|
| **Canvas** | `#FCFCFB` | 页面大背景（L1），仅最外层 |
| **Surface** | `#F1F1F0` | 展示气垫（下沉），只读区需要下沉分区时使用；不因信息只读或属于辅助内容而自动铺底 |
| **Surface Interactive** | `#FFFFFF` | 交互触点（上浮）。**只给文本输入框与承载状态色的特殊按钮**；配角筛选器（时间/成员等 Select）裸铺 Canvas，不上浮——能下拉不等于要边框，看它是表单字段还是视图工具 |

**L3 容器内部统一 `bg-transparent`，严禁同色套同色。**

### 2.2 主色与状态色

**主色（2026-10-28 阿禅实机目检后维持现状，深砖橙方案 B 不采用）：**

| Token | 色值 | 用法 |
|---|---|---|
| **Action** | `#D97757` | **同一活跃层唯一**主 CTA，`bg-[#D97757] text-white` |
| **Action Hover** | `#C46A4D` | 主 CTA 悬停，保持白字 |

**状态色（4 语义 × 3 角色）：**

决策树与类名拼接规则见《Claude设计哲学》原则2"状态色决策树"（不在此重复）。28 色的 CSS 变量定义见 `src/styles/design-tokens.css`。

**约束：**
- 状态色不上实底（见《Claude设计哲学》原则4"单点聚光灯"）
- 异常文字统一用正文墨 `text-status-danger-text`（color: `var(--ink-body)` = `#1F1E1D`）
- 状态淡底用独立 hex，不用透明度（见《Claude设计哲学》原则1"封闭系统"）

**状态色分层**（当状态标签与数据指标共存时的优先级配方）：

| 层级 | 配方 | 典型场景 |
|---|---|---|
| **数据指标** | 饱和色字，无底或微淡底 | 红涨绿跌（核心决策依据） |
| **状态标签（异常级）** | 淡底 + 元数据墨字 + 饱和色圆点 | 异常/删稿/限流（需被看到但不抢主角） |
| **状态标签（正常）** | 无底 + 信号墨字 + 弱圆点 `#D6D3D1` | 正常状态（静默基线） |

**圆点的双重作用**：① 吸引注意（饱和色=异常，淡灰=正常）；② 视觉定位锚点（帮助眼睛对齐表格行，即使正常状态也保留淡圆点，不可删除）。

**计数徽章降级**：异常计数等辅助徽章用灰底灰字（`bg-[#F1F1F0] text-[#78716C]`），不与数据指标竞争。

### 2.3 边框与悬停

| Token | 色值 | 场景 |
|---|---|---|
| **Border** | `#E2E2DF` | 发丝线，表格行底、输入框边框 |
| **Hover** | `#EBEBE9` | 悬停态背景 |
| **Row Hover** | `#F7F7F6` | 表格行悬停 |
| **Row Selected** | `#E4E4E1` | 表格行选中 |

**纯白触点物理凸出律**：纯白落在暖白桌面上，必须配发丝边 `#E2E2DF` 与微投影，严禁裸落。

### 2.4 阴影四档

```css
--shadow-input:         0 1px 2px 0 rgba(28,25,23,0.04);
--shadow-card-ring:     0 0 0 1px rgba(28,25,23,0.08), 0 1px 2px 0 rgba(28,25,23,0.05);
--shadow-claude-float:  0 1px 2px rgba(28,25,23,0.04), 0 10px 28px -4px rgba(28,25,23,0.12), 0 3px 8px -2px rgba(28,25,23,0.06);
--shadow-claude-dialog: 0 1px 3px rgba(28,25,23,0.04), 0 18px 42px -6px rgba(28,25,23,0.16), 0 6px 18px -2px rgba(28,25,23,0.08);
```

| 用途 | Token |
|---|---|
| 交互触点（输入框、次按钮） | `shadow-input` |
| 托盘（主卡片、主表格） | `shadow-card-ring` |
| 浮层（下拉、气泡、浮出面板） | `shadow-claude-float` |
| 弹窗**与抽屉** | `shadow-claude-dialog` |

**禁用** Tailwind 原生阴影（`shadow-2xs/xs/sm/md/2xl`，由门禁强制，见《组件与场景契约》§7.1）。
